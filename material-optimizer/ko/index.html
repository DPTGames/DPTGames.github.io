도구의 기능

Material Optimizer & Texture Atlas Creator은 하나 이상의 모델에서 머티리얼 입력을 수집하고 지원되는 텍스처를 공유 아틀라스에 배치한 뒤 메시 UV를 다시 매핑합니다. 호환되는 원본 머티리얼은 공유 출력 머티리얼로 통합됩니다. 모델을 개별적으로 내보내거나 하나의 부모 프리팹 아래에 모으거나 선택한 호환 메시를 병합할 수 있습니다.

작업변경 내용실제 의미
텍스처 아틀라스 생성텍스처 배치와 UV0 좌표.여러 모델이 하나의 메시가 되지 않고도 같은 텍스처 에셋을 사용할 수 있습니다.
머티리얼 통합머티리얼 참조와 호환되는 서브메시 슬롯.모델을 분리된 상태로 유지하면서 머티리얼이나 슬롯 수를 줄일 수 있습니다.
선택적 메시 병합선택한 호환 렌더러와 지오메트리.렌더러 수를 줄일 수 있습니다. 병합된 부품은 표시 상태와 컬링을 공유합니다.

이 가이드는 메탈릭 워크플로를 사용하는 URP Lit 머티리얼을 대상으로 합니다. 최적화는 Unity Editor에서 실행되며 생성된 에셋에는 최적화 도구 전용 런타임 컴포넌트가 필요하지 않습니다. 내보낸 프리팹은 원본 스크립트, 애니메이션 클립, 아바타 및 콜라이더 에셋을 계속 참조할 수 있습니다.

설치, 실행 및 언어 선택

Material Optimizer와 함께 DPT_Core를 임포트하세요. 에디터 창은 DPT.Core.Editor의 공통 헤더, 문서 버튼, 섹션 스타일 및 버튼 색상을 사용합니다. DPT Package Exporter에서 Material_Optimizer와 DPT_Core를 모두 선택하고 System Marker Overrides에서 DPT_Marker_MaterialOptimizer.cs를 활성화하세요.

  1. URP 프로젝트에 패키지를 임포트하고 Unity의 임포트와 컴파일이 끝날 때까지 기다립니다. 프로젝트 컴파일 오류가 있다면 먼저 해결하세요.
  2. Tools > DPT Games > Material Optimizer을 엽니다. Tools 메뉴의 제품명은 언어 설정과 관계없이 영어로 표시됩니다.
  3. 창 상단에서 English, 日本語 또는 한국어를 선택합니다. 선택한 언어는 유지됩니다. 에셋 이름, 셰이더 프로퍼티 식별자 및 출력 파일명은 번역되지 않습니다.
  4. Edit Mode에서 작업합니다. Play Mode에 진입하거나 실행 중일 때는 아틀라스 컨트롤이 비활성화됩니다. 설정 열과 미리보기를 위한 공간을 확보하세요. 최소 창 크기는 1020 × 650입니다.

이 도구는 자체 Editor 어셈블리를 사용하며 DPT Core, Color Swapper 또는 DPT 셰이더가 필요하지 않습니다. 지원 Unity 버전은 패키지 제품 페이지를 확인하세요.

도움말 숨기기 (Hide Help Boxes)는 모델 내보내기 영역의 정보 메시지를 포함한 선택적 안내를 숨깁니다. 툴팁, 경고, 오류와 중요한 작업 상태는 계속 표시됩니다. 미리보기 생성 완료 메시지는 따로 표시하지 않습니다. 아틀라스 크기 요약에 마우스를 올려 공유 색상 픽셀로 통합된 삼각형 수를 확인하세요. 메모리 비교 표는 결과 데이터이므로 계속 표시됩니다.

Hierarchy에서 열기

모델 루트를 하나 이상 선택하고 오른쪽 클릭하여 DPT Games > Material Optimizer를 선택합니다. 선택 항목을 불러와 스캔합니다. 선택하지 않은 오브젝트를 오른쪽 클릭하면 그 오브젝트를 불러옵니다. 부모·자식 중복과 지원 메시가 없는 빈 입력은 제거합니다. 베이크, 내보내기 또는 씬 변경은 수행하지 않습니다. 지원 메시가 포함된 오브젝트에 대해 Edit Mode에서 사용할 수 있습니다.

첫 아틀라스 만들기

  1. 1. 원본 오브젝트 (1. Source objects)에 씬 오브젝트, 모델 에셋 또는 프리팹을 하나 이상 드롭합니다. Unity에서 선택한 뒤 선택 항목 추가 (Add Selection)을 눌러도 됩니다. 처음에는 확인하기 쉬운 작은 구성으로 시작하세요.
  2. 원본 스캔 (Scan Sources)를 누릅니다. 렌더러, 머티리얼, 슬롯 및 삼각형 수를 확인하고 경고를 읽은 뒤 진행하세요.
  3. 기본적으로 모든 디테일 유지 (Preserve All Details)가 켜져 있습니다. 단색 영역을 단일 픽셀 스와치로 통합하려면 모두 자동 통합 (Auto Fold All)을 사용하거나 개별 머티리얼에서 검증된 균일 색상 통합 (Fold Verified Colours)을 선택하세요. 대부분의 머티리얼은 보통 (Normal priority)로 두세요.
  4. URP Lit 머티리얼 템플릿 (Material Template)을 지정하거나 비워 두어 현재 파이프라인의 기본 Lit 셰이더를 사용합니다. 최대 크기에 자동 맞춤 (Auto Fit to Maximum Size)를 켜 둡니다. 최대 아틀라스 크기 (Maximum Atlas Size) 기본값은 4096입니다.
  5. 초록색 아틀라스 미리보기 생성 (Create Atlas Preview) 버튼을 누릅니다. 아틀라스 채널과 변경 전 / 후 모델 (Before / after model) 보기를 확인합니다. 중요한 표면의 디테일이 부족하면 디테일 우선순위 (Detail Priority)를 높여 미리보기를 다시 생성하세요.
  6. 아틀라스 에셋을 공유하는 독립 모델을 내보내려면 개별 프리팹 (Separate Prefabs)를 유지합니다. 그룹화나 메시 병합이 필요할 때 메시 출력 (Mesh Output)를 변경하세요.
  7. 출력 이름 (Output Name)과 현재 프로젝트의 Assets 안에 있는 출력 폴더 (Output Folder)를 지정한 뒤 파란색 저장 및 내보내기 (Save & Export) 버튼을 누릅니다. 최신 미리보기는 재사용합니다. 소스나 베이크 설정이 바뀌면 내보내기 전에 다시 생성합니다.
  8. 새 출력 폴더를 열고 Prefabs 하위 폴더의 프리팹을 사용합니다. 생성된 프리팹을 씬으로 드래그해 실제 조명과 애니메이션에서 확인한 뒤 씬을 저장하세요.

첫 연습에는 테이블, 단색 머그잔, 인쇄 무늬가 있는 책 및 유리병 등을 사용해 보세요. 먼저 개별 프리팹으로 내보냅니다. 다음에는 움직이는 소품과 유리를 분리한 채 테이블 구조물만 병합한 결과와 비교할 수 있습니다. 자신의 에셋으로 진행하는 연습 예시입니다.

동봉된 데모 텍스처: 최적화된 데모 아틀라스는 원본 4K 머티리얼 텍스처로 베이크했습니다. 패키지 용량을 줄이기 위해 입력용으로 1K-2K 축소 사본을 제공하며 AO는 현재 UV에 맞는 맵을 사용합니다. 씬에 표시된 메모리는 동봉된 에셋의 측정값입니다. 축소 사본으로 다시 베이크한 결과는 동봉된 아틀라스와 다를 수 있습니다.

재사용 가능한 설정 프로필

소스 목록 위의 설정 프로필을 펼치세요. 다른 이름으로 저장...은 이름이 있는 프로젝트 에셋을 만듭니다. 기존 설정 프로필을 선택하고 불러오기로 적용하거나 저장으로 업데이트합니다. 아틀라스 설정, 메시 출력 옵션, 출력 이름과 위치 및 일치하는 머티리얼 에셋의 개별 설정을 저장합니다. 불러와도 현재 소스 오브젝트, 렌더러별 병합 선택 및 부착 본은 유지됩니다. 소스 머티리얼은 바꾸지 않습니다. 씬에만 있는 머티리얼의 개별 설정은 저장하지 않으며 머티리얼 템플릿은 프로젝트 에셋이어야 합니다. 설정 초기화는 아틀라스, 머티리얼 및 메시 출력 설정을 기본값으로 복원하면서 소스 오브젝트, 출력 이름과 위치를 유지합니다. 불러온 설정은 독립적인 복사본이므로 다시 저장하기 전까지 저장된 프로필은 바뀌지 않습니다.

소스 선택과 스캔 결과

소스는 루트 GameObject입니다. 스캔에는 비활성 오브젝트와 모든 메시 LOD를 포함해 하위의 지원 렌더러가 들어갑니다. 부모와 자식을 모두 추가해도 자식을 별도 소스로 중복 계산하지 않습니다. 개별 프리팹 모드에서는 소스 루트마다 하나의 프리팹이 생성됩니다.

컨트롤 또는 수치의미
선택 항목 추가 (Add Selection)선택한 GameObject를 추가하고 스캔합니다.
원본 스캔 (Scan Sources)현재 소스를 새로 확인합니다. 일치하는 머티리얼 설정과 렌더러 병합 선택은 유지됩니다.
X / 비우기 (Clear)X는 소스 하나를 제거합니다. Clear는 소스 목록, 머티리얼 목록 및 병합 선택을 비웁니다.
렌더러 / 머티리얼 / 슬롯렌더러 수, 고유 머티리얼 수 및 전체 원본 머티리얼 슬롯 수입니다. 서로 다른 수치입니다.
삼각형스캔한 모든 LOD와 비활성 자식을 포함합니다. 게임 카메라에서 동시에 보이는 삼각형 수는 아닙니다.

스킨 모델은 참조하는 모든 본과 루트 본이 포함되도록 캐릭터의 전체 루트를 선택하세요. 여러 모델을 배치하거나 부착 부품의 위치를 조정하려면 씬 인스턴스가 편리합니다. 텍스처는 머티리얼 참조를 통해 읽으므로 원본 텍스처를 한 폴더에 모을 필요가 없습니다.

자동 설정 및 실행 취소

소스를 추가한 뒤 소스 컨트롤 아래의 자동 설정(Auto Configure)을 누릅니다. 텍스처 크기, 타일링, 필터링과 셰이더 호환성을 확인하며 픽셀 베이크나 내보내기는 수행하지 않습니다. 설정 세부 정보(Configuration Details)를 펼치면 선택 이유를 볼 수 있습니다. 권장값을 시작점으로 사용하고 미리보기와 의도한 카메라 거리에 맞춰 우선순위를 조정하세요.

아틀라스 입력에는 자동 크기 모드와 256~4096픽셀 사이의 추정 상한을 선택합니다. 자동 조정, 형태 기반 패킹, 자동 패딩과 원본 해상도 제한을 켜고 업스케일링은 끕니다. 8K 또는 고정 크기는 직접 선택할 수 있습니다. 텍스처가 없는 표준 머티리얼은 검증된 단일 픽셀 접기를 사용합니다. 밉맵이 없는 포인트 입력은 포인트 필터링, 밉맵 끄기와 비압축을 사용합니다. 상세 입력에는 부드러운 필터링, 밉맵과 고품질 압축을 사용합니다. 텍스처가 있는 머티리얼의 기존 패킹 선택은 유지합니다. 커스텀 셰이더, 텍스처 배열, 스페큘러 워크플로 또는 감지된 디테일·패럴랙스 효과에는 머티리얼을 보존하는 메시 전용 모드를 선택합니다.

소스 분석에서 병합 가능한 그룹을 찾은 경우 정적 또는 공유 리그 병합을 권장합니다. 추정값이므로 최종 UV 구성이나 내보내기 호환성에 따라 결과가 달라질 수 있습니다. 기존 메시 전용 모드는 유지하며 아틀라스를 사용할 수 있으면 아틀라스 및 메시 출력 선택도 유지합니다. 머티리얼 매핑, 우선순위, 렌더러 제외, 부착 본, LOD 개별 설정과 출력 위치는 유지합니다.

설정 실행 취소(Undo Configure)는 마지막 자동 설정 이전의 설정과 머티리얼 패킹 선택을 복원합니다. 현재 소스 선택과 창 세션에서 사용할 수 있습니다. 베이크에 영향을 주는 변경은 기존 미리보기를 갱신 대기 상태로 만들고 자동 업데이트 설정에 따라 다시 생성합니다. 최적화 모드를 바꾸면 미리보기를 해제합니다. 내보내기나 병합 설정만 바뀌면 기존 아틀라스와 수동 배치를 유지합니다. 실행 취소는 설정을 복원하며 다시 생성하여 잃은 수동 배치를 복원하지 않습니다.

마이크로 텍스처와 상세 영역

검증된 균일 색상 통합(Fold Verified Colours)은 각 삼각형이 매핑된 모든 채널에서 일정한 값을 샘플링하는지 확인합니다. UV가 변하는 영역은 필터링 여백도 확인합니다. UV가 모두 같은 팔레트 위치를 가리키는 면은 이중선형 필터링을 사용하고 주변 텍셀이 다른 색이어도 일정합니다. 해당 영역은 패딩이 있는 단일 픽셀 스와치가 됩니다. 서로 다른 모델과 머티리얼도 검증된 스와치가 일치하면 같은 픽셀을 사용할 수 있습니다.

베이스 컬러가 단색이어도 노멀, 메탈릭, 스무스니스, 오클루전, 불투명도 또는 이미션의 디테일을 지우지 않습니다. 매핑된 채널 중 하나라도 변하면 상세 영역으로 유지됩니다. 그라디언트와 그려진 음영도 유지됩니다. 판정이 모호하거나 검사 비용이 큰 영역은 보수적으로 상세 상태를 유지합니다. 아트 스타일 이름이 아닌 실제 텍스처 데이터를 검사합니다.

통합할 수 있는 경우에도 머티리얼을 상세 아틀라스 영역으로 유지하려면 디테일 유지 (Preserve Details)를 선택합니다. 모두 자동 통합 (Auto Fold All)은 스캔된 모든 머티리얼에 검증 기반 통합을 적용하고 모든 디테일 유지 (Preserve All Details)는 모두 상세 패킹으로 전환합니다. 단색 스와치와 상세 영역은 같은 아틀라스에 함께 들어갈 수 있습니다. 통합은 텍스처 샘플링을 변경하며 모델의 형태나 삼각형 수를 줄이지 않습니다.

같거나 비슷한 단색 공유

모두 자동 통합(Auto Fold All) 또는 개별 머티리얼의 검증된 균일 색상 통합을 켜세요. 패킹 버튼 아래의 색상 허용 오차(Colour Tolerance) 슬라이더 범위는 0~400이며 기본값 0은 정확히 일치하는 색만 공유합니다. Color Swapper와 같은 8비트 RGB 차이의 합을 사용합니다. (100, 110, 120)과 (102, 110, 120)의 차이는 2입니다.

값을 높이면 비슷한 색의 검증된 단색 영역이 가장 가까운 기존 대표 스와치를 공유할 수 있습니다. 색이 약간 변할 수 있습니다. 그라데이션이나 노이즈가 있는 상세 영역을 단색으로 취급하는 설정은 아닙니다. 불투명도, 노멀, 메탈릭, 부드러움, AO 및 발광은 여전히 정확히 일치해야 합니다. 색만 같다고 다른 표면 차이가 사라지지 않습니다. 프로필에 저장되며 자동 구성은 값을 유지합니다. 설정 초기화는 0으로 복원합니다.

UV 겹침: 자동은 AO도 일치하는 검증된 단색 스와치를 공유할 수 있습니다. 상세 AO 영역은 소스 메시 간에 분리합니다. 허용도 공유를 허용하며 방지는 렌더러별 스와치를 분리합니다. 불투명 및 투명 캔버스가 분리된 경우 서로 독립적입니다.

입력 채널과 URP 머티리얼 매핑

2. 패킹 및 입력 채널 (2. Packing & source channels)에서 머티리얼을 펼쳐 원본 프로퍼티를 확인합니다. URP Lit 메탈릭 규칙은 자동 감지됩니다. 프로퍼티 입력란에는 텍스처 파일명이 아닌 _BaseMap 같은 셰이더 식별자를 지정합니다. 커스텀 셰이더는 미리보기 생성 전에 매핑을 확인하세요.

타일링과 커스텀 셰이더

URP Lit에서는 베이스 맵 타일링 공유 (Share Base Map Tiling)을 켜 둡니다. 매핑된 채널 전체에서 베이스 텍스처 변환을 공유합니다. 프로퍼티별로 독립된 스케일과 오프셋을 사용하는 호환 커스텀 셰이더에서만 해제하세요. 지원되는 Repeat, Mirror, MirrorOnce 및 Clamp 샘플링과 음수 타일링은 상세 영역에 베이크됩니다.

활성 채널 모두가 같은 정확한 반복 주기를 지원하면 하나의 영역을 재사용할 수 있습니다. 그러나 삼각형 하나가 많은 반복을 가로지르면 여전히 큰 영역이 필요할 수 있습니다. 요청 크기는 원본 이미지 크기와 같지 않을 수 있습니다. 커스텀 출력 셰이더는 출력 텍스처 프로퍼티 매핑 (Output texture property mappings)를 확인하고 템플릿 선택 후 템플릿에서 감지 (Detect From Template)을 사용하세요. 이 가이드의 URP 워크플로에서는 Metallic Smoothness 패킹 형식을 사용합니다.

텍스처 속성 선택: 입력 채널과 출력 속성은 선택한 셰이더의 Texture2D 속성을 표시 이름과 식별자로 나열합니다. 없음 (텍스처 제외)으로 텍스처 입력을 제외할 수 있습니다. 저장된 속성이 없으면 기존 값을 유지하고 찾을 수 없음으로 표시하므로 매핑을 자동으로 변경하지 않습니다. 텍스처 배열과 큐브맵은 제외합니다. 각 속성은 기존 색상, 노멀, 금속성/마스크, AO, 발광 채널의 의미로 처리하며 임의의 절차적 셰이더 효과를 자동 베이크하지 않습니다.

아틀라스 해상도, 자동 조정 및 패딩

미리보기는 축소 영역 수를 포함한 간결한 아틀라스 크기 요약 한 줄을 유지합니다. 이 줄에 마우스를 올리면 원본 해상도 제한, 밀도 목표, 패딩, 접힌 삼각형 수, UV 중첩 보호 및 회전 판단을 확인할 수 있습니다. 다시 생성을 기다리는 동안에도 현재 표시된 미리보기를 설명합니다.

자동 가장자리 패딩은 자동 크기와 고정 크기 모두에서 기본으로 켜집니다. 각 캔버스의 실제 생성 크기에 따라 패딩을 정하며 밉맵 없는 작은 비압축 아틀라스는 1픽셀부터, 8K는 16픽셀까지 사용합니다. 압축 또는 밉맵 사용 시 최소 4픽셀입니다. 불투명 캔버스와 투명 캔버스는 서로 다른 패딩을 사용할 수 있습니다. 이 옵션을 끄면 가장자리 패딩을 수동으로 설정할 수 있습니다. 실제 값은 아틀라스 크기 툴팁과 내보내기 해상도 보고서에 표시됩니다. API 설정은 AtlasSettings.automaticPadding입니다.

고급 아틀라스 설정의 아틀라스 크기 설정은 기본적으로 자동입니다. 자동은 최대 아틀라스 크기 이내에서 요청한 디테일이 들어가는 가장 작은 캔버스를 선택합니다. 고정을 선택하면 고정 아틀라스 크기가 정확한 가로와 세로 크기가 됩니다. 예를 들어 요청한 디테일이 4096 x 4096에 들어가더라도 8192 x 8192를 사용할 수 있습니다. 고정은 정사각형 캔버스를 사용하며 직사각형 크기 선택과 NPOT 축소를 적용하지 않습니다. 자동으로 돌아가면 기존 설정이 다시 적용됩니다. 남는 공간으로 디테일 향상은 영역에 남는 공간을 배분하며 원본 해상도를 넘는 확대 허용하면 소스 해상도 또는 월드 공간 목표를 초과할 수 있습니다. 고정을 선택해도 이 옵션들은 자동으로 켜지지 않으며 입력에 없는 디테일을 복원하지 않습니다. 투명 아틀라스를 분리하면 각 캔버스에 고정 크기가 적용됩니다. 내보내기 해상도 보고서에도 크기 설정 모드가 기록됩니다.

Atlas Shape의 기본값은 Square(정사각형)입니다. Rectangular(직사각형)는 별도로 선택할 수 있습니다. 2의 거듭제곱이 아닌 크기는 별도의 설정으로 허용합니다.

Allow Non-Power-of-Two Dimensions는 기본적으로 꺼져 있습니다. 기본 출력은 2의 거듭제곱 정사각형입니다. Atlas Shape를 Rectangular로 바꾸면 1024 x 2048처럼 각 변이 2의 거듭제곱인 직사각형도 사용할 수 있습니다. 켜면 4픽셀 단위로 더 줄일 수 있습니다. 소스 머티리얼을 펼치면 할당된 텍스처 이름과 경로, 임포트된 크기 및 이미지 파일 크기를 확인할 수 있습니다. 해상도 상한은 현재 할당된 임포트 텍스처와 각 UV 영역의 범위에 따라 정해집니다. 할당되지 않은 4K 원본이나 이전 베이크의 원본은 읽지 않습니다.

형태 기반 패킹과 직사각형 아틀라스: 아일랜드의 빈 공간을 재사용하되 사용 텍셀과 여백은 겹치지 않게 배치합니다. 경계 사각형은 겹칠 수 있습니다. 베이크는 할당된 형태와 주변 여백에 대응하는 원본 텍스처 픽셀을 복사하며 아일랜드 끝 색상을 늘리지 않습니다. 형태 밖 틈은 다른 차트에 사용할 수 있고 수동 크기 맞춤 재베이크에서도 주변 원본 디테일을 유지합니다. 너비와 높이는 압축 블록에 맞춰 개별적으로 정합니다. 남는 공간에서 원본 해상도까지 디테일을 복원할 수 있으며 원본을 넘는 확대에는 명시적인 설정이 필요합니다. 미리보기에는 전체 텍스처 테두리와 여백을 포함한 사용률 및 빈 공간 비율이 표시됩니다.

가장자리 여백 (Edge Padding)기본값은 자동. 수동 범위는 1~16픽셀.모든 맵에서 각 영역 둘레에 여백을 추가합니다. 자동 패딩은 생성 크기를 따르며 밉맵 또는 압축 사용 시 최소 4픽셀입니다. 자동 가장자리 패딩을 끄면 직접 지정할 수 있습니다. 패딩도 아틀라스 공간을 차지합니다.

자동 조정으로 디테일이 줄면 미리보기에 알림이 표시되고 각 상세 머티리얼에 요청 크기와 출력 픽셀 크기가 나타납니다. 내보낸 Atlas_Resolution.txt에도 기록됩니다. 원본 텍스처나 임포트 설정의 크기를 변경하지 않습니다.

4096 텍스처가 4092 × 4088을 요청하는 이유: 영역 크기는 메시 UV가 사용하는 범위를 나타냅니다. 이미지 가장자리의 미사용 영역 때문에 원본 이미지보다 조금 작을 수 있습니다. 이 범위 바깥에 패딩이 추가되므로 약 4K인 영역도 엄격 모드에서는 4K 아틀라스에 들어가지 않을 수 있습니다.

요청 밀도를 자동 축소 없이 유지해야 할 때만 자동 조정을 끕니다. 이 경우 디테일 우선순위는 비활성화됩니다. 엄격 패킹에 실패하면 자동 조정을 켜거나 최대 크기를 늘리거나 원본 디테일 제한을 낮추세요. 자동 조정도 패딩이 있는 단일 픽셀 영역을 무제한으로 넣을 수는 없습니다. 최소 배치조차 들어가지 않으면 소스를 나누거나 패딩을 줄이거나 최대 크기를 늘려야 합니다.

텍셀 밀도 기준

텍셀 밀도(Texel Density)의 기본값은 소스 해상도(Source Resolution)이며 임포트된 텍스처 크기와 타일링을 사용합니다. 월드 공간(World Space)은 오브젝트 스케일을 포함하여 UV 방향에 따른 메시 크기로 계산해 크기가 비슷한 표면에 비슷한 밀도를 배분합니다. Unity 단위당 픽셀 수(Pixels Per Unity Unit)의 기본값은 512이며 슬라이더 범위는 64~2048입니다. 자동 맞춤으로 목표값이 줄어들 수 있습니다. 월드 공간은 상세 영역을 렌더러별로 배치하므로 반복 오브젝트도 공간을 더 사용할 수 있습니다.

패킹 시간을 제한하기 위해 캔버스당 영역이 256개를 초과하면 남는 공간을 이용한 확대를 건너뜁니다. 형태, 패딩 및 디테일 상한 때문에 빈 공간이 남을 수도 있습니다. 최대 크기를 높이거나 확대를 허용해도 완전히 채워지는 것은 아닙니다.

자동 UV 공유와 수동 겹치기

UV 겹침(UV Overlap)의 기본값은 자동(Auto)이며 AO 또는 HDRP 마스크를 사용하는 서로 다른 소스 메시의 상세 영역을 분리합니다. 검증된 단색 스와치는 매핑된 표면 값이 같으면 공유할 수 있으며 허용 오차는 기본 RGB에만 적용합니다. 허용(Allow)은 같은 소스 머티리얼의 상세 영역을 렌더러 간에 재사용할 수 있지만 텍스처를 공유하는 모든 머티리얼을 자동으로 겹치지는 않습니다. 방지(Prevent)는 렌더러와 분리된 UV 셸을 별도 영역으로 만들며 단색 스와치도 분리합니다. 연결된 소스 셸 안의 기존 겹침은 자동으로 수정할 수 없습니다. 형태 기반 패킹은 사용 픽셀과 패딩을 분리한 채 경계 사각형을 겹칠 수 있습니다. 수동 겹치기에는 별도의 공유 텍스처 검사를 사용합니다.

중요한 머티리얼에 디테일 할당하기

우선순위: 보통은 모든 소스 머티리얼을 보통으로 설정합니다. 우선순위는 상대적이므로 모든 머티리얼을 같은 우선순위로 설정하면 밀도 균형은 바뀌지 않습니다. 남는 공간으로 디테일 향상은 공통 밀도 배율로 영역을 함께 확대하며 자동 맞춤이 활성화되어 있으면 머티리얼 우선순위도 유지합니다. 업스케일링을 끄면 소스 해상도 또는 월드 공간 목표가 확대 한도가 됩니다. 아틀라스 크기는 유지되며 아일랜드 모양과 패딩 때문에 빈 공간이 남을 수 있습니다.

디테일 우선순위 (Detail Priority)는 자동 조정으로 상세 영역을 줄일 때 사용하는 상대적 우선순위입니다. 일반 머티리얼은 보통으로 두고 중요한 항목만 높이세요. 여러 머티리얼을 높음 또는 매우 높음으로 설정할 수 있습니다. 모든 머티리얼에 비율을 지정하거나 텍스처 채널마다 따로 조정할 필요가 없습니다.

우선순위상대 요청 면적사용 예
낮음 (Low priority)보통의 0.5배단순하거나 잘 보이지 않는 표면.
보통 (Normal priority)1배. 기본값.대부분의 머티리얼.
높음 (High priority)보통의 2배인쇄 라벨, 직물 무늬, 얼굴 또는 사슬 갑옷.
매우 높음 (Very high priority)보통의 4배매우 중요한 소수의 상세 머티리얼.

이 값은 상대 면적 배분이며 고정된 아틀라스 점유율이나 가로·세로 크기의 배수를 보장하지 않습니다. 원본 크기, UV 범위, 패딩 및 패킹 형태도 영향을 줍니다. 남는 공간을 활용하면 초기 디테일 목표보다 높게 원본 해상도까지 복원할 수 있습니다. 원본 샘플 수를 넘는 확대에는 원본 해상도를 넘는 확대 허용 설정이 필요합니다. 이미 모두 들어가는 경우 우선순위를 높여도 다른 머티리얼을 불필요하게 줄이지 않습니다. 통합된 단색 스와치는 단일 픽셀로 유지됩니다.

예: 목재, 가죽 및 단순한 금속은 보통으로 두고 사슬 갑옷과 얼굴을 모두 높음으로 설정한 뒤 미리보기를 다시 생성합니다. 필요하면 자동 조정이 상세 영역을 재분배합니다. 베이스 컬러, 노멀 및 다른 매핑 채널은 함께 유지됩니다. 높은 우선순위가 특정 해상도를 보장한다고 가정하지 말고 실제 출력 크기를 확인하세요.

필터링, 밉맵 및 텍스처 임포트

도구 업데이트 후 기존 창은 수정된 기본값을 적용하도록 미프맵을 한 번만 활성화합니다. 이후 수동 변경은 유지됩니다. 기존 프로필을 불러오면 저장된 미프맵 설정을 복원합니다.

포인트 필터링 (Point Filtering)은 기본적으로 꺼져 있습니다. 미프맵이 없으면 이중선형, 있으면 삼선형 필터링을 사용합니다. 선명한 팔레트나 픽셀 텍스처가 필요하면 포인트 필터링을 켜세요. 미프맵 생성 (Generate Mip Maps)은 일반적인 원본 머티리얼과 맞추고 원거리 하이라이트를 안정시키도록 기본적으로 켜져 있습니다. 기존 프로필의 저장 설정은 유지합니다. 미프맵을 끄면 미세한 금속이나 노멀 무늬가 원본보다 선명하거나 깜박일 수 있습니다. 작은 밉 레벨에서는 인접 아틀라스 영역이 섞이며 특히 작은 팔레트 스와치에서 눈에 띕니다. 상세 에셋은 밉맵으로 원거리 샘플링이 개선될 수 있으므로 패딩을 늘리고 실제 사용 거리에서 확인하세요.

내보낸 아틀라스는 Clamp 래핑, 선택한 Export Compression 설정 및 Read/Write 비활성화 설정을 사용합니다. 지원되는 원본 래핑 동작은 각 영역에 이미 베이크되어 있습니다. 압축은 작은 스와치와 데이터 채널을 손상시킬 수 있으므로 변경 후 결과를 확인하세요. 공유 아틀라스는 필터링과 임포트 정책도 공유합니다. 하나의 출력 세트에서 소스 모델마다 서로 다른 필터링을 동시에 사용할 수는 없습니다.

출력 압축(Export Compression)의 기본값은 고품질(High Quality)이며 균형(Balanced)과 비압축(Uncompressed)도 선택할 수 있습니다. 실제 GPU 형식은 플랫폼과 텍스처 종류에 따라 달라집니다. 외형 차이가 압축 때문인지 확인하려면 비압축을 사용하세요.

불투명, 컷아웃 및 투명 머티리얼

아틀라스를 공유한다고 모든 표면이 하나의 머티리얼을 사용할 수 있는 것은 아닙니다. 불투명, 알파 클리핑 및 블렌딩 투명 표면에는 호환되는 출력 상태가 필요합니다. 블렌딩, 컷오프, 컬링, 깊이 설정, 렌더 큐 또는 지원 조명 설정의 차이로 그룹이 추가될 수 있습니다. 도구는 예정 그룹 수를 표시하고 투명 소스가 있으면 알려줍니다.

투명도를 유지하려면 투명 표면을 불투명하게 만들기 (Make Transparent Surfaces Opaque)를 꺼 둡니다. 유리 같은 블렌딩 투명 표면을 의도적으로 불투명하게 만들 때만 켜세요. 창에 경고가 표시됩니다. 알파 클리핑 컷아웃은 유지됩니다. 원본 머티리얼은 변경되지 않으며 다른 상태 차이 때문에 여러 출력 머티리얼이 필요할 수도 있습니다.

예: 불투명 가구와 유리병은 불투명 머티리얼과 투명 머티리얼을 사용하면서 같은 아틀라스 텍스처를 공유할 수 있습니다. 프리팹도 개별적으로 내보낼 수 있습니다. 병합 시 투명 부분은 정렬 동작을 유지하도록 별도 렌더러로 남습니다.

투명 아틀라스 공유와 분리

투명 아틀라스(Transparent Atlas)의 기본값은 자동(Auto)입니다. 불투명과 블렌딩 투명 영역이 모두 있으면 분리한 텍스처의 예상 총 메모리가 공유할 때보다 10% 넘게 적거나 분리 패킹만 성공할 경우 별도 캔버스를 사용합니다. 공유(Shared)는 하나를 사용하며 분리(Separate)는 두 종류가 모두 있을 때 항상 나눕니다. 캔버스별 크기와 패딩은 다를 수 있습니다. 고정 크기는 각 캔버스에 선택한 정사각형 크기를 적용하므로 메모리가 늘 수도 있습니다. 출력 머티리얼은 각각의 렌더 상태를 유지합니다.

아틀라스와 모델 미리보기 확인

세부 영역을 줄일 때 출력 픽셀이 덮는 원본 텍셀 면적을 평균합니다. 색상, 불투명도, 노멀, 금속성, 매끄러움, AO, 발광과 수동 아일랜드 크기 조정에 적용됩니다. 노멀 방향은 평균 후 정규화하며 채널별 원본 크기와 타일링을 사용합니다. 원본 Filter Mode가 Point이면 최근접 샘플링을 유지하고 검증된 단색 스와치는 바꾸지 않습니다. 일반 출력은 미프맵이 있을 때 삼선형, 없을 때 이중선형 필터링을 사용합니다. Point Filtering은 출력 샘플링 설정입니다. 기존 아틀라스에 적용하려면 미리보기를 다시 생성하고 내보내세요.

자동 업데이트는 미리보기 생성 버튼 옆에 있습니다. 모델 카메라는 표시된 모델의 범위와 화면 비율에 맞춰집니다. 스크롤로 처음 거리의 5%까지 접근할 수 있고 클리핑 평면도 모델 크기에 맞게 조정됩니다. 뷰 초기화로 전체 보기를 복원합니다.

세로 구분선을 드래그하여 설정 패널 너비를 조절합니다. 두 번 클릭하면 기본 너비로 돌아가며 Escape는 너비 변경을 취소합니다. 아틀라스 영역을 드래그하지 않고 클릭하면 설정 패널에서 소스 머티리얼을 펼쳐 강조하고 해당 위치로 스크롤합니다. 선택한 머티리얼의 영역은 청록색 테두리로 표시합니다. 접힌 색상 픽셀을 여러 머티리얼이 공유하면 모든 소유 머티리얼을 강조합니다. 빈 캔버스를 클릭하면 선택을 해제합니다. 드래그 이동, 보조 키를 누른 드래그 및 두 번 클릭으로 전체 보기도 계속 사용할 수 있습니다. 선택은 차트 마스크로 맞물린 영역을 구분하고 현재 표시 중인 투명 캔버스를 따릅니다. 선택해도 UV나 출력 텍스처는 바뀌지 않습니다.

수동 아일랜드 배치 (고급)

아틀라스 미리보기에서 수동 아틀라스 배치 (고급)를 펼치고 편집을 켭니다. 왼쪽 드래그로 아일랜드 전체를 이동합니다. 전체 UV 표시를 꺼도 이동 중인 아일랜드의 실제 UV 모서리는 표시됩니다. 자유 / X / Y로 이동 축을 선택합니다. X는 Y를 고정한 가로 이동입니다. 드래그 중 X 또는 Y를 누르면 해당 축으로 제한하고 같은 키를 다시 누르면 해제합니다. Esc로 취소합니다. Shift를 누르면 가로 이동(Y 고정), Ctrl(macOS에서는 Command)을 누르면 세로 이동(X 고정)합니다. 놓으면 선택한 축 모드로 돌아가며 둘 다 누르면 위치를 유지합니다. 가운데/오른쪽 드래그로 화면 이동, 스크롤로 확대/축소, 두 번 클릭으로 텍스처 전체 보기를 사용할 수 있습니다. 스냅 이동 간격은 1, 4, 8, 16, 32픽셀입니다. 왼쪽 아래 기준의 X/Y 좌표 입력에도 축 제한이 적용됩니다. 고정으로 실수로 이동하는 것을 막을 수 있습니다.

간결한 수동 배치 툴바는 편집, 스냅, 자유/X/Y, 고정, X/Y 좌표, 이동, 실행 취소 및 초기화를 한 줄에 표시합니다. 실행 취소와 초기화는 툴팁이 있는 아이콘입니다. UV 겹침을 허용하면 같은 줄에 크기 일치가 나타납니다. 배치 상태는 아틀라스 하단에 표시합니다. 버튼은 선택적으로 사용할 수 있는 DPT_CoreGUI.ButtonStyles API를 사용하며 기존 코어 스타일은 유지됩니다.

다른 영역을 재배치하는 동안 아일랜드를 텍스처 상자 밖에 임시로 둘 수 있습니다. UV 윤곽선이 계속 표시되며 화면 이동 범위가 확장되어 바깥의 아일랜드에도 접근할 수 있습니다. 샘플을 유지하므로 다시 안으로 옮겨도 맵 데이터가 손실되지 않습니다. 모든 아일랜드와 패딩을 아틀라스 안으로 되돌릴 때까지 내보내기는 비활성화됩니다. 극단적인 좌표를 방지하기 위해 각 방향으로 아틀라스의 긴 변 길이의 8배까지만 이동할 수 있습니다.

UV 겹침: 허용에서는 같은 원본 텍스처 세트를 사용하는 아일랜드를 수동으로 겹칠 수 있습니다. 같은 텍스처를 공유하는 서로 다른 머티리얼도 포함됩니다. 원본 UV 영역, 크기와 방향이 달라도 됩니다. 활성 색상, 노멀, 메탈릭/마스크, 오클루전과 발광 채널의 원본 텍스처가 모두 같아야 합니다. 다른 맵이 다르면 베이스 맵만 같아서는 겹칠 수 없습니다. 텍스처가 없는 영역은 같은 원본 머티리얼 또는 모든 채널이 같은 단색 스와치를 공유할 수 있습니다. 다른 텍스처 세트는 거부됩니다. 겹친 영역은 모든 맵의 베이크된 픽셀을 공유하며 마지막으로 이동한 아일랜드가 해당 픽셀을 제공합니다. 다른 원본 영역이나 머티리얼 틴트를 겹치면 외형이 바뀔 수 있습니다. Alt 클릭으로 겹친 아일랜드를 순서대로 선택합니다. 샘플은 보관되어 겹침을 해제하면 복원됩니다. 자동과 방지는 패딩을 포함한 영역의 겹침을 거부합니다. 불투명과 투명 캔버스는 독립적입니다. 실행 취소는 크기와 표시 순서를 포함해 최대 20회 복원합니다. 배치 초기화는 원래 배치와 크기를 복원하고 고정과 기록을 지웁니다. 수동 배치는 현재 미리보기에만 적용되며 설정 프로필에는 저장되지 않습니다. 다시 생성, 스크립트 다시 로드 또는 창 닫기로 초기화됩니다. 배치를 유지하려면 현재 미리보기를 내보내세요.

겹칠 때 크기 맞추기는 기본으로 켜져 있습니다. 자유 이동 중 작은 아일랜드의 중심을 같은 텍스처를 사용하는 큰 영역 안에 놓으면 작은 쪽의 크기와 위치를 맞춥니다. 드래그 윤곽선으로 결과를 확인할 수 있으며 놓을 때 모든 맵과 밉맵을 원본 텍스처에서 새 크기로 다시 베이크합니다. 원본에 남아 있는 디테일을 복원할 수 있지만 원본 해상도를 넘으면 새 디테일은 생기지 않습니다. 끄면 현재 크기를 유지하며 부분 겹침이 가능합니다. X/Y 축을 잠그면 크기를 맞추지 않습니다. 겹침을 해제해도 새 크기를 유지하며 실행 취소로 이전 크기를 복원합니다. 드래그한 작은 아일랜드만 커집니다. 큰 아일랜드를 옮겨도 정지된 작은 영역의 크기는 바꾸지 않습니다.

아틀라스 표시 컨트롤 아래의 UV 와이어프레임, 영역 상자, 텍스처 테두리 색상 필드를 직접 사용합니다. 모델 미리보기에는 조명 컨트롤 옆에 두 화면이 공유하는 배경 선택기가 있습니다. 선택하거나 이동하는 UV 모서리에도 같은 색상이 적용되고 잘못된 이동은 빨간색으로 표시됩니다. 재빌드와 에디터 재시작 후에도 설정을 유지하며 씬 카메라, 원본 머티리얼과 출력 텍스처는 바꾸지 않습니다.

보기 또는 동작확인할 내용

수치와 알림아틀라스 크기, 패킹 영역, 머티리얼 슬롯, 출력 머티리얼 및 자동 해상도 감소를 확인합니다.

스킨 메시는 원본 스켈레톤과 블렌드 셰이프 가중치를 사용해 표시됩니다. 양쪽 미리보기에는 동일한 포즈가 사용됩니다. 비활성 렌더러와 비활성 오브젝트는 표시되지 않습니다. 원본 포즈나 표시 상태를 변경한 경우 미리보기를 다시 생성하세요. 미리보기는 원본 계층에서 아틀라스 적용 전후의 외형을 비교하며 최종 병합 지오메트리나 애니메이션 재생은 표시하지 않습니다. 내보낸 프리팹을 씬에서 확인해 변형, 부착물, 투명도, LOD 및 게임 동작을 검증하세요.

패킹 또는 아틀라스 설정을 바꾸면 미리보기가 갱신 대기 상태가 됩니다. 자동 업데이트가 켜져 있으면 설정이 안정된 후 다시 생성합니다. 소스나 계층 변경으로도 다시 생성해야 할 수 있습니다. 저장 및 내보내기 (Save & Export)는 필요할 때 다시 생성하고 그렇지 않으면 크기 맞춤을 포함한 현재 수동 배치를 유지하여 내보냅니다. 창 닫기, 스크립트 리로드 및 Play Mode 전환 시 임시 미리보기가 해제됩니다. 작업이 오래 걸리면 Unity 진행 대화상자에서 취소한 뒤 입력을 조정해 다시 시도하세요.

두 미리보기 모두 스크롤로 조금씩 확대하거나 축소할 수 있습니다. 아틀라스는 커서 위치를 중심으로 확대됩니다. 전체 보기 (Fit) 또는 아틀라스를 더블 클릭하여 확대 배율과 이동 위치를 초기화할 수 있습니다.

메모리 및 내보내기 통계

아틀라스와 메시 전용 모드 모두에서 미리보기 세부 정보 드롭다운을 항상 표시되는 메모리 비교(Memory Comparison) 표로 교체했습니다. 변경 전, 적용 후 미리보기, 추정 변화 열에서 활성 렌더러, 고유 머티리얼, 삼각형, 정점, 메시 VRAM, 텍스처 VRAM 및 강조된 합계를 비교합니다. 감소는 초록색, 증가는 빨간색이며 부호가 있는 수치와 백분율을 표시합니다. 행에 마우스를 올려 집계 범위를 확인하세요. 지오메트리는 모든 LOD와 활성 메시 인스턴스를 포함하며 UV 변경으로 정점이 늘 수 있습니다. 최종 병합은 내보낼 때 수행합니다.

메모리는 비활성 입력, 밉맵 및 텍스처 배열을 포함하여 선택 범위에서 참조되는 각 메시·텍스처 리소스를 한 번만 계산합니다. 메시 VRAM은 정점 배열을 복사하지 않고 저장된 정점 구성에서 정점 및 인덱스 버퍼를 추정합니다. CPU 읽기용 복사본, 블렌드 셰이프 저장 공간, 추가 스키닝 버퍼 및 엔진 오버헤드는 제외합니다. 원본 텍스처는 임포트된 형식을 사용하고 아틀라스 출력은 기존 플랫폼별 압축 추정값을 사용합니다. KB/MB는 십진 단위이며 디스크 크기나 Editor 프로세스 메모리가 아닌 리소스 추정값입니다. 프레임 시간을 예측하지 않습니다. 계산값은 캐시되며 미리보기 재생성, 메시·머티리얼 교체 또는 출력 압축·밉 설정 변경 시 갱신됩니다.

내보내기가 성공하면 내보내기 작업 옆의 최근 내보내기를 펼쳐 실제 렌더러, 머티리얼, 슬롯 및 지오메트리 수를 확인합니다. 미리보기 생성 시간과 내보내기 처리 시간은 따로 표시합니다. 선택한 루트 내 활성 지오메트리를 모든 LOD 레벨과 함께 계산하며 병합 후 비활성 상태로 남은 원본 렌더러는 제외합니다. 정점과 삼각형은 메시 인스턴스별로 계산하고 메시 에셋은 중복을 제외합니다. 드로 콜이나 프레임 시간 측정값이 아닙니다.

모든 출력 모드에서 Atlas_Statistics.txt를 저장합니다. 통계 보고서 열기로 최신 보고서를 확인하세요. Raw Atlases & Meshes 출력은 비활성 입력을 포함한 모든 원본 메시 인스턴스와 저장된 UV 변경 메시를 비교합니다. 렌더러나 머티리얼은 생성하지 않습니다. 최근 내보내기 통계는 다음 내보내기가 성공할 때까지 해당 시점의 기록으로 남으며 소스 선택이 바뀌면 숨겨집니다.

Atlas_Statistics.txt에는 지오메트리 수와 처리 시간이 기록됩니다. 아틀라스 출력의 Atlas_Resolution.txt에는 예상 텍스처 메모리와 현재 Editor 플랫폼에서 실제로 임포트된 아틀라스 형식, 밉 수 및 크기도 기록됩니다. 보고서의 소스 메모리는 매핑된 입력만 계산합니다. 비교 표는 머티리얼에서 참조하는 모든 텍스처를 포함하므로 소스 총값이 다를 수 있습니다.

내보내기 모드와 생성 파일

Unity Project 창의 폴더를 출력 폴더 필드에 직접 놓거나 옆의 찾아보기...로 기존 저장 위치를 선택하세요. 현재 폴더가 있으면 해당 위치에서 찾아보기를 시작합니다. 선택한 경로는 Assets 기준 상대 경로로 저장됩니다. 파일, 여러 폴더의 동시 드롭 또는 이 프로젝트의 Assets 디렉터리 밖에 있는 폴더는 선택할 수 없습니다. 새 Assets 경로를 직접 입력하면 내보내기 시 폴더를 생성합니다. 저장 위치를 바꿔도 아틀라스를 다시 생성하지 않습니다.

Atlas_Statistics.txt실제 지오메트리, 렌더러 및 머티리얼 수와 미리보기 생성·내보내기 처리 시간. 모든 출력 모드에 포함됩니다.
Atlas_Merge.txt병합 모드에서 생성. 병합 소스와 강체 부착물 수 및 분리 유지 이유를 기록합니다.

내보내기 후 Unity는 생성된 프리팹을 선택하고 첫 프리팹을 강조 표시합니다. 상태 메시지에 폴더가 표시됩니다. 생성된 에셋은 해당 폴더의 Prefabs 하위 폴더에서 확인하세요. 이동할 때는 Unity Project 창에서 생성된 에셋 세트를 함께 이동하세요. 원본 삭제나 출력 배포 전에는 스크립트, 아바타, 애니메이션 클립 및 콜라이더 메시 같은 남은 의존성을 확인하세요. 내보낸 후 씬 오브젝트 교체를 켜면 지원되는 씬 입력을 바꿉니다. 끄면 생성 프리팹을 직접 배치하세요.

씬 교체: 내보낸 후 씬 오브젝트 교체를 켜면 내보내기 성공 후 소스 인스턴스를 출력 프리팹으로 바꿉니다. 한 번의 Undo로 원본을 복구합니다. 개별 프리팹은 부모와 변환을 유지하고 그룹 출력은 새 루트 안에서 배치를 유지합니다. 같은 일반 씬의 인스턴스만 지원하며 프로젝트 에셋과 프리팹 편집 스테이지는 제외합니다. 제거된 씬 오브젝트 참조는 검토해야 합니다. Undo해도 출력 파일은 남고 씬은 자동 저장하지 않습니다.

아틀라스와 UV가 변경된 메시만 내보내기

Mesh Output: Raw Atlases & Meshes를 선택하고 아틀라스와 메시 내보내기를 누릅니다. Textures/, Meshes/, Atlas_Raw.txt, Atlas_Resolution.txt, Atlas_Statistics.txt를 저장합니다. 머티리얼이나 프리팹 생성, 메시 병합, 씬 교체는 수행하지 않습니다. 할당 보고서는 원본 렌더러와 출력 서브메시를 사용할 아틀라스, 호환 머티리얼 그룹과 기본 렌더 상태에 연결합니다. 보고서에 따라 직접 머티리얼을 만들고 맵과 메시를 할당하세요. 지원되는 틴트와 표면 값은 이미 베이크되므로 머티리얼 곱셈 값은 중립으로, 타일링은 1로 설정하세요. 스킨 메시에는 기존 스켈레톤, 본 순서와 블렌드 셰이프 가중치를 유지하세요. 기존 채널 구성을 사용하며 임의의 추가 맵이나 절차적 효과는 포함하지 않습니다.

Editor API: AtlasExporter.ExportRaw(build, parentFolder, outputName) 또는 AtlasExportMode.RawAtlasesAndMeshes를 설정하고 ExportAll을 호출합니다. 결과의 prefabs는 비어 있고 materialsFolder와 prefabsFolder는 빈 문자열입니다. 프리팹을 반환하는 Export는 에셋 생성 전에 이 모드를 거부합니다.

아틀라스 없이 메시 병합하기

설정 패널 상단에서 최적화 모드 > 메시 병합만을 선택하세요. 완전한 소스 오브젝트를 추가하고 병합할 정적 메시, 공유 리그 메시와 부착물을 선택한 다음 병합 미리보기 만들기를 클릭하세요. 예상 렌더러 수를 확인하고 병합 및 내보내기를 클릭하세요.

이 모드는 텍스처 배열, 키워드와 셰이더 속성을 포함한 원본 프로젝트 머티리얼과 셰이더를 유지합니다. 텍스처 샘플링, 아틀라스 베이크, UV 재매핑 또는 서로 다른 머티리얼 통합을 수행하지 않습니다. 버텍스 컬러와 모든 원본 UV 채널은 VCCore 등의 셰이더에서 계속 사용할 수 있습니다. UV0가 없는 메시도 지원합니다. 미리보기는 원본 외형과 유지된 머티리얼을 비교하며, 실제 메시 병합은 내보낼 때 수행됩니다.

내보내기는 프리팹, 메시 에셋, Atlas_Merge.txt 및 Atlas_Statistics.txt를 생성합니다. 아틀라스 텍스처나 해상도 보고서는 만들지 않습니다. 기존 프로젝트 머티리얼을 직접 참조합니다. 메모리에만 존재하는 머티리얼은 새 에셋으로 저장하며, 해당 텍스처는 미리 저장되어 있어야 합니다. 서로 다른 머티리얼은 별도의 슬롯을 유지하므로 렌더러 수가 줄어도 드로 콜이 줄어드는 것은 아닙니다. 원본 에셋과 임포트 설정은 유지됩니다.

이 모드에서는 UV1 좌표를 변경하지 않도록 베이크된 라이트맵을 사용하는 렌더러를 분리 유지합니다. 투명 표면, 독립적으로 애니메이션되는 부품과 호환되지 않는 렌더 설정에 대한 기존 병합 제한은 그대로 적용됩니다. 각 원본 오브젝트의 로컬 위치, 피벗 또는 크기에 의존하는 커스텀 셰이더는 병합 후 외형을 확인하세요. 텍스처 아틀라스로 전환하면 아틀라스 설정이 다시 표시됩니다. 설정 프로필은 선택한 모드를 저장합니다.

var settings = new AtlasSettings { mergeMeshesOnly = true };
var scan = AtlasScan.Create(sourceObjects, preserveMaterials: true);
using (var build = AtlasBuilder.Build(scan, settings))
{
    AtlasExporter.ExportAll(build, "Assets/Optimized", "Merged_Model");
}

고급 선택과 정적 메시 병합

최신 아틀라스 미리보기를 생성하면 메시 병합 섹션에서 소스 메시 렌더러 수와 예상 출력 수를 보여줍니다. 병합 스위치, 렌더러 선택 또는 부착 본을 바꾸면 예측을 업데이트합니다. 파트를 개별로 유지하는 이유를 펼치면 제외 항목, LOD, 호환되지 않는 렌더러 설정, 리그, 애니메이션 제한 및 투명 부분을 확인할 수 있습니다. 불투명과 투명이 섞인 메시에서는 병합 후에도 투명 부분의 렌더러가 남아 렌더러 수가 늘어날 수 있습니다. 이는 렌더러 수 예측이며 드로 콜 수는 렌더링 패스와 배칭에 따라 달라집니다. 최종 결과는 내보낼 때 기록합니다. 분석은 모델을 복제하거나 소스 오브젝트를 바꾸지 않고 데이터를 읽기만 합니다.

4. 메시 병합 (Mesh Merging)은 내보내기 설정 앞에 독립된 항목으로 표시됩니다. 메시 출력 (Mesh Output)에서 병합을 선택하고 바로 아래의 정적 메시와 같은 리그 병합 옵션을 설정합니다. 개별 부품과 부착할 본은 렌더러 선택 및 부착물 (Renderer Selection & Attachments)에서 선택합니다. 저장 위치는 5. 모델 내보내기에서 설정합니다.

  1. 선택한 메시 병합 (Merge Selected Meshes)를 선택하고 렌더러 선택 및 부착물 (Renderer Selection & Attachments)를 펼칩니다. 정적 병합에는 정적 메시 병합 (Merge Static Meshes)를 켭니다. 리그 메시 병합에는 별도 스위치가 있습니다.
  2. 포함할 렌더러 항목을 체크합니다. 모두 선택 (Select All) 또는 모두 분리 유지 (Keep All Separate)로 초기 선택을 바꿀 수 있습니다. 소스 번호와 계층 경로로 중복 이름을 구분합니다. 체크를 해제한 렌더러에도 아틀라스 머티리얼이 적용됩니다.
  3. 내보낸 뒤 Atlas_Merge.txt를 확인합니다. 병합 그룹에는 호환되는 선택 렌더러가 최소 두 개 필요합니다. 렌더러 설정이 다르면 여러 병합 렌더러가 생성될 수 있습니다.

고정 가구 부품, 건물 구조물, 기계 외장 및 항상 함께 움직이고 표시될 소품이 적합합니다. 호환성에는 레이어, 그림자, 프로브, 정렬, 모션 벡터 및 기타 지원 렌더러 설정이 포함됩니다. 정적 병합에는 호환되는 베이크 라이트맵 UV 변환이 적용됩니다.

문, 서랍, 탈착 장비 및 개별적으로 움직이거나 숨겨야 하는 부품은 독립 렌더러가 필요하면 분리하세요. 원본 Transform과 콜라이더는 유지되지만 병합 메시에 완전히 포함된 렌더러는 비활성화됩니다. 기존 원본 Transform을 움직여도 병합된 정적 메시의 해당 지오메트리는 개별적으로 움직이지 않습니다.

기존 LOD 레벨 안에서 메시 병합하기

Merge Selected Meshes 또는 메시 병합만에서는 호환되는 정적 메시와 공유 리그 스킨 메시를 기존 LODGroup 및 일치하는 레벨 구성 안에서 병합합니다. 예를 들어 호환되는 LOD0 부품 두 개는 하나의 LOD0 렌더러가 되고, LOD1 부품은 별도의 LOD1 렌더러가 됩니다. 독립된 LODGroup은 분리 유지됩니다. 기존 LOD 소속이 없는 선택된 소품은 병합 내보내기 시 호환 그룹에 자동 배정됩니다.

내보내기는 LOD 렌더러 목록을 생성된 메시로 갱신합니다. 레벨 수, 화면 상대 전환 임계값, 페이드 폭, 페이드 모드, 애니메이션 크로스페이드, 그룹 활성 상태, 로컬 기준점과 그룹 크기를 유지합니다. LOD 경계를 다시 계산하거나 단순화된 지오메트리를 생성하지 않습니다. 제외된 부품, 남은 투명 부분과 호환되지 않는 부품은 원래 레벨에 남습니다. 병합한 블렌드 셰이프 렌더러도 같은 LOD 소속을 유지합니다.

여러 레벨에서 재사용되는 렌더러는 전체 레벨 구성이 일치하는 렌더러와만 병합할 수 있습니다. 여러 LODGroup이 공유하는 렌더러는 분리 유지됩니다. 전체 그룹 루트와 참조하는 모든 렌더러를 선택하세요. 소스 루트 간 참조에는 Grouped Prefab 또는 Merge Selected Meshes가 필요합니다. 각 Separate Prefab에는 완전한 LOD 구성이 포함되어야 합니다.

렌더러 수 예측에도 내보내기와 동일한 LOD 제한이 적용됩니다. 수치는 한순간에 표시되는 레벨뿐 아니라 스캔한 모든 레벨을 포함합니다. Atlas_Merge.txt에는 갱신한 LODGroup 수가 기록되며, Editor API의 AtlasExportResult.mergedLODGroups에서도 확인할 수 있습니다. 모델 미리보기에는 가장 높은 유효 레벨이 표시됩니다. 전환과 크로스페이드는 내보낸 프리팹을 씬에서 확인하세요.

소품과 LOD: 같은 계층, 같은 소스 오브젝트, 가까운 호환 그룹 순으로 대상을 선택합니다. 그룹 대비 소품의 크기와 각 전환 임계값으로 화면 높이를 추정하며, 다음 레벨 진입 시 기본 기준은 화면 높이의 3%입니다. LOD0에는 항상 포함합니다. 작은 소금통은 LOD0에만, 의자는 LOD0–2에 남을 수 있습니다. 여러 레벨에서 하나의 렌더러를 참조하므로 지오메트리를 복제하지 않으며 그룹과 함께 컬링됩니다.

고급 LOD 제어에서 자동 배정과 기준을 바꾸고 소품별 대상 그룹 및 자동 / 모든 레벨 / LOD0만 / 마지막 레벨 지정 / 독립을 선택합니다. 기존 LOD 소속은 유지합니다. 제외된 부품과 독립 스크립트, 애니메이션 또는 물리 제어 부품은 자동 배정하지 않습니다. 수동 배정은 병합되지 않거나 제외된 소품도 LOD 표시 제어에 포함할 수 있습니다. 보고서에 배정을 기록하며 AtlasExportResult.assignedLooseLODRenderers로 개수를 확인합니다. 저폴리곤 LOD 메시를 생성하는 기능은 아닙니다.

Editor API: AtlasSettings.automaticLODForLooseObjects의 기본값은 true입니다. lodMinimumScreenSize는 비율로 저장하며 기본값은 0.03f입니다(UI는 % 표시). AtlasMergeSelection에는 lodMode(AtlasLooseLODMode), 선택적 lodGroup과 lodLastLevel이 있습니다. 자동 배정을 꺼도 수동 표시 모드는 동작합니다. 씬 교체에서는 원래의 중첩 자식 대신 완전한 프리팹 인스턴스 루트를 선택해야 합니다.

공유 리그와 강체 부착물

4. 메시 병합 (Mesh Merging)에서 같은 리그의 메시 및 부착물 병합 (Merge Shared-Rig Meshes & Attachments)를 켜면 실제로 같은 스켈레톤을 참조하는 호환 Skinned Mesh Renderer를 병합할 수 있습니다. 본 이름이 같다는 이유만으로 공유 리그가 되지는 않습니다. 본 이름이 같은 캐릭터 인스턴스 두 개도 서로 다른 스켈레톤으로 유지됩니다.

같은 리그에 스키닝된 메시 병합

  1. 캐릭터의 전체 루트와 해당 본을 이미 참조하는 별도의 스킨 소스를 포함합니다. 참조되는 모든 본과 루트 본이 선택한 소스 안에 있어야 합니다.
  2. 렌더러를 분리한 상태로 내부 본 참조를 공유하려면 그룹 프리팹 (Grouped Prefab)을, 호환 부품을 병합하려면 선택한 메시 병합 (Merge Selected Meshes)를 사용합니다. 개별 프리팹에서는 각 소스에 전체 리그가 포함되어야 합니다.
  3. 내보낸 뒤 씬에서 애니메이션을 확인합니다. 병합 가능한 스킨의 본 참조, 보정된 바인드 포즈 및 가변 본 가중치는 유지됩니다. 일반 본 애니메이션을 지원하며 병합 시 블렌드 셰이프 커브의 대상을 변경할 수 있습니다. 다른 렌더러 프로퍼티 애니메이션은 렌더러를 분리 유지합니다.

스키닝되지 않은 강체 부품 부착

  1. 강체 부품과 캐릭터의 전체 리그를 포함하고 내보내기 전에 원하는 위치에 부품을 배치합니다. 장비 외에도 도구, 패널, 기계 부품, 액세서리 등 강체 지오메트리에 사용할 수 있습니다.
  2. 강체 렌더러를 체크합니다. 부착할 본 (Attachment Bone)을 자동 (Automatic)으로 두면 기존 리그 본 부모를 감지합니다. 별도 소스라면 팝업에서 포함된 모델의 본이나 소켓을 선택합니다. 이 선택기는 프리팹과 모델 에셋에서도 작동합니다.
  3. 리그 병합 스위치를 켠 상태에서 병합 모드로 내보냅니다. 부품은 현재 배치를 유지하고 모든 정점이 선택한 본에 100% 가중치로 따라갑니다. 강체 추종이며 변형 스킨 가중치를 자동 생성하거나 손에 자동으로 맞추는 기능은 아닙니다.

전용 런타임 부착 스크립트는 필요하지 않습니다. 병합된 부착물은 스킨 출력의 표시 상태를 공유합니다. 게임에서 개별 숨김, 교체, 분리 또는 오프셋 애니메이션이 필요하면 별도로 유지하세요. 공통 캐릭터 루트의 Rigidbody는 호환될 수 있지만 독립적으로 움직이는 물리 부품은 분리됩니다. 움직이는 스킨 출력에는 라이트맵 부품을 병합하지 않습니다.

블렌드 셰이프가 있는 메시 병합

공유 리그 병합 아래의 블렌드 셰이프 메시 병합은 기본으로 켜집니다. 호환 스킨 메시의 모든 프레임, 프레임 가중치와 현재 가중치를 유지합니다. 고유 이름은 유지하며 중복 이름에는 원본 부품 이름을 붙여 분리합니다. 해당 Animator 클립을 Animations/에 복제하고 출력 Animator Override Controller에서 대상을 변경합니다. 기존 오버라이드와 Legacy Animation도 지원합니다. 원본 클립과 컨트롤러는 바꾸지 않으며 추가 런타임 컴포넌트도 필요 없습니다. 남은 투명 부분에는 기존 커브를 유지합니다.

선택 소스 안의 직렬화된 스크립트가 직접 참조하는 렌더러는 분리합니다. 표시 상태나 머티리얼 애니메이션과 호환되지 않는 설정도 분리합니다. 외부 스크립트, 인덱스 기반 제어, 동적 로드 클립, Playables와 출력 계층에 없는 애니메이션 시스템은 참조를 확인해야 합니다. 임의의 참조를 자동 변경하지 않습니다. 옵션을 끄면 이전처럼 렌더러를 분리합니다. 보고서에 병합한 셰이프 수와 변경한 클립 수를 기록합니다. API: AtlasSettings.mergeBlendShapes, AtlasExportResult.mergedBlendShapes, remappedAnimationClips.

효과적인 최적화 선택과 검증

대표적인 씬에서 최적화 전후를 측정하세요. Unity 프로파일링 도구로 머티리얼 슬롯, 렌더러 수, 드로 콜, 텍스처 메모리 및 프레임 시간을 비교합니다. 개별 모델이 머티리얼을 공유해도 모든 오브젝트가 자동으로 한 드로 콜이 되지는 않습니다. 투명도, 패스, 조명, 배칭 및 렌더러 설정도 영향을 줍니다.

큰 병합 메시는 일부만 화면에 보여도 전체가 표시 대상으로 남을 수 있습니다. 보통 함께 보이고 움직이는 그룹을 병합하세요. 큰 아틀라스는 관련 없는 텍스처도 함께 로드하게 만들 수 있습니다. 용도에 맞춰 아틀라스 크기, 채널 수 및 그룹을 선택하세요. 원본 고해상도 이미지를 계속 포함한다면 출력 아틀라스가 작아져도 원본 이미지의 패키지 크기는 줄지 않습니다.

  • 같은 씬 조명과 카메라 거리에서 출력 프리팹과 원본을 비교합니다.
  • 변형, 블렌드 셰이프, LOD 전환, 투명도, 콜라이더 및 개별 렌더러를 참조하는 스크립트를 테스트합니다.
  • 두 보고서를 확인하고 출력 의존성과 동작 검증을 마칠 때까지 원본 에셋을 보관합니다.

출력 머티리얼이 여러 개 생성됨투명도, 클리핑, 컬링, 블렌딩, 컷오프 및 다른 렌더 상태 차이를 확인합니다. 텍스처 공유가 같은 머티리얼 상태를 뜻하지는 않습니다.
유리가 불투명해짐투명 표면 불투명화 옵션을 끄고 다시 출력하세요. 커스텀 출력 셰이더의 표면 설정도 확인합니다.
본이 소스 밖에 있다는 메시지참조되는 모든 본과 루트 본을 포함하는 전체 캐릭터 루트를 선택합니다. 소스 간 공유라면 전체 리그도 선택 소스에 포함하세요.
공유 스킨 부품이 개별 프리팹에서 거부됨그룹 프리팹 또는 선택 메시 병합을 사용합니다. 개별 출력은 각 소스 안에 완전한 독립 리그가 필요합니다.
선택 메시가 병합되지 않음Atlas_Merge.txt를 읽고 두 병합 스위치, 선택, 그룹 크기, 리그 동일성 및 위의 제외 조건을 확인하세요.
부착물 위치나 따라가는 본이 잘못됨출력 전 배치와 선택한 본·소켓을 확인합니다. 현재 배치를 유지하며 자동 포즈 조정이나 스냅은 하지 않습니다.
미리보기에 애니메이션이나 병합 결과가 없음스킨 미리보기는 모델 미리보기를 처음 열었을 때의 포즈와 원본 계층을 사용합니다. 원본 포즈나 표시 상태를 변경한 경우 미리보기를 다시 생성하세요. 씬에서 생성 프리팹을 확인하세요.
내보낸 모델을 찾을 수 없음상태 메시지의 폴더를 확인하고 Prefabs 하위 폴더의 에셋을 씬에 드래그합니다. 지원되는 씬 입력은 내보낸 후 씬 오브젝트 교체를 켠 경우에만 교체됩니다.
출력 폴더가 거부됨현재 프로젝트의 Assets 안에 있는 경로를 선택하세요. Assets 밖이나 상위 디렉터리 이동을 포함하는 경로는 허용되지 않습니다.

Editor 스크립팅 참고

AtlasSettings.colourTolerance은 0~400의 정수이며 기본값은 0입니다. 검증된 단색 스와치의 표시용 8비트 RGB 차이 합계만 비교합니다. 알파와 다른 채널은 정확히 일치해야 합니다. 설정 복사본과 프로필에도 포함됩니다.

DPT.TextureAtlasCreator.DPT_AtlasSettingsProfile: settings, materials, preserveAllDetails, outputFolder, outputName.

settings.atlasSizeMode = AtlasSizeMode.Fixed; settings.maxAtlasSize = 8192;

고급 통합은 DPT.MaterialOptimizer.Editor의 공개 네임스페이스 DPT.TextureAtlasCreator를 사용합니다. 어셈블리 정의는 Editor 전용이고 자동 참조되며 포함된 DPT.Core.Editor 어셈블리에 의존합니다. 통합 코드는 Editor 어셈블리에 두고 자체 어셈블리 정의에 필요하면 참조를 추가하세요. API 식별자는 원래 이름을 유지합니다.

진입점 또는 데이터용도
AtlasScan.Create선택 소스 루트를 스캔하고 입력을 검증하며 렌더러·머티리얼 입력을 제공합니다.
AtlasSettings크기, 패딩, detailScale, autoFit, 머티리얼 매핑, 투명 변환 및 출력·병합 선택.
AtlasMaterialInput.priorityLow, Normal, High 또는 VeryHigh. 기본값은 Normal이며 자동 조정 시 적용됩니다.
AtlasBuilder.Build텍스처, 다시 매핑된 메시, 머티리얼 및 렌더러 머티리얼 그룹이 있는 AtlasBuild를 생성합니다. 사용 후 Dispose하세요.
AtlasExporter.ExportAll생성 프리팹, 폴더 경로, 병합 수 및 메모가 있는 AtlasExportResult를 반환합니다. Export는 첫 생성 프리팹을 반환합니다.
AtlasExportMode.MergeStaticMeshes창의 선택 메시 병합 모드에 해당하는 기존 직렬화 열거형 이름입니다. 활성화된 공유 리그 경로도 지원합니다.
AtlasMergeSelection원본 스캔 renderer, include 플래그 및 선택적 attachmentBone입니다. 렌더러별 선택은 settings.mergeSelections를 사용합니다.

생성 에셋이 프리팹 옆에 있다고 가정하지 말고 결과의 meshesFolder, texturesFolder, materialsFolder 및 prefabsFolder를 사용하세요.

DPT_TextureAtlasCreatorWindow.OpenWithSources(IEnumerable<GameObject>)은 지원되는 루트를 불러와 스캔한 창을 엽니다. 베이크나 내보내기는 수행하지 않습니다. 부모·자식 중복은 제거하며 사용 가능한 메시 입력이 없으면 예외를 반환합니다.

AtlasBuild.sourceStatistics, previewStatistics 및 buildMilliseconds는 미리보기 정보입니다. AtlasExportResult.statistics는 source, output, buildMilliseconds, exportMilliseconds, rawMeshes를 포함하는 AtlasResultStatistics입니다. AtlasGeometryStatistics는 renderers, uniqueMeshes, submeshes, materialSlots, materials, vertices, triangles를 제공합니다. 통계는 숫자만 보관하며 Unity 에셋을 소유하지 않습니다.
