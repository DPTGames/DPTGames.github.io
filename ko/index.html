도구의 기능

Material Optimizer & Texture Atlas Tool은 하나 이상의 모델에서 머티리얼 입력을 수집하고 지원되는 텍스처를 공유 아틀라스에 배치한 뒤 메시 UV를 다시 매핑합니다. 호환되는 원본 머티리얼은 공유 출력 머티리얼로 통합됩니다. 모델을 개별적으로 내보내거나 하나의 부모 프리팹 아래에 모으거나 선택한 호환 메시를 병합할 수 있습니다.

작업변경 내용실제 의미
텍스처 아틀라스 생성텍스처 배치와 UV0 좌표.여러 모델이 하나의 메시가 되지 않고도 같은 텍스처 에셋을 사용할 수 있습니다.
머티리얼 통합머티리얼 참조와 호환되는 서브메시 슬롯.모델을 분리된 상태로 유지하면서 머티리얼이나 슬롯 수를 줄일 수 있습니다.
선택적 메시 병합선택한 호환 렌더러와 지오메트리.렌더러 수를 줄일 수 있습니다. 병합된 부품은 표시 상태와 컬링을 공유합니다.

이 가이드는 메탈릭 워크플로를 사용하는 URP Lit 머티리얼을 대상으로 합니다. 최적화는 Unity Editor에서 실행되며 생성된 에셋에는 최적화 도구 전용 런타임 컴포넌트가 필요하지 않습니다. 내보낸 프리팹은 원본 스크립트, 애니메이션 클립, 아바타 및 콜라이더 에셋을 계속 참조할 수 있습니다.

설치, 실행 및 언어 선택

  1. URP 프로젝트에 패키지를 임포트하고 Unity의 임포트와 컴파일이 끝날 때까지 기다립니다. 프로젝트 컴파일 오류가 있다면 먼저 해결하세요.
  2. Tools > DPT Games > Material Optimizer & Texture Atlas Tool을 엽니다. Tools 메뉴의 제품명은 언어 설정과 관계없이 영어로 표시됩니다.
  3. 창 상단에서 English, 日本語 또는 한국어를 선택합니다. 선택한 언어는 유지됩니다. 에셋 이름, 셰이더 프로퍼티 식별자 및 출력 파일명은 번역되지 않습니다.
  4. Edit Mode에서 작업합니다. Play Mode에 진입하거나 실행 중일 때는 아틀라스 컨트롤이 비활성화됩니다. 설정 열과 미리보기를 위한 공간을 확보하세요. 최소 창 크기는 1020 × 650입니다.

이 도구는 자체 Editor 어셈블리를 사용하며 DPT Core, Color Swapper 또는 DPT 셰이더가 필요하지 않습니다. 지원 Unity 버전은 패키지 제품 페이지를 확인하세요. 포함된 Validation.md는 소스 컴파일 확인과 엔진 테스트를 구분합니다. 컴파일 성공만으로 전체 렌더링 호환성을 확인할 수는 없습니다.

첫 아틀라스 만들기

  1. 1. 원본 오브젝트 (1. Source objects)에 씬 오브젝트, 모델 에셋 또는 프리팹을 하나 이상 드롭합니다. Unity에서 선택한 뒤 선택 항목 추가 (Add Selection)을 눌러도 됩니다. 처음에는 확인하기 쉬운 작은 구성으로 시작하세요.
  2. 원본 스캔 (Scan Sources)를 누릅니다. 렌더러, 머티리얼, 슬롯 및 삼각형 수를 확인하고 경고를 읽은 뒤 진행하세요.
  3. 균일한 영역을 자동 감지하려면 검증된 균일 색상 통합 (Fold Verified Colours)를 사용합니다. 상세 영역으로 유지할 머티리얼에는 디테일 유지 (Preserve Details)를 선택합니다. 대부분의 머티리얼은 보통 (Normal priority)로 두세요.
  4. URP Lit 머티리얼 템플릿 (Material Template)을 지정하거나 비워 두어 현재 파이프라인의 기본 Lit 셰이더를 사용합니다. 최대 크기에 자동 맞춤 (Auto Fit to Maximum Size)를 켜 둡니다. 최대 아틀라스 크기 (Maximum Atlas Size) 기본값은 4096입니다.
  5. 초록색 아틀라스 미리보기 생성 (Create Atlas Preview) 버튼을 누릅니다. 아틀라스 채널과 변경 전 / 후 모델 (Before / after model) 보기를 확인합니다. 중요한 표면의 디테일이 부족하면 디테일 우선순위 (Detail Priority)를 높여 미리보기를 다시 생성하세요.
  6. 아틀라스 에셋을 공유하는 독립 모델을 내보내려면 개별 프리팹 (Separate Prefabs)를 유지합니다. 그룹화나 메시 병합이 필요할 때 내보내기 모드 (Export Mode)를 변경하세요.
  7. 출력 이름 (Output Name)과 현재 프로젝트의 Assets 안에 있는 출력 폴더 (Output Folder)를 지정한 뒤 파란색 저장 및 내보내기 (Save & Export) 버튼을 누릅니다. 내보내기 시 현재 소스를 다시 스캔하고 처리합니다.
  8. 새 출력 폴더를 열고 Prefabs 하위 폴더의 프리팹을 사용합니다. 생성된 프리팹을 씬으로 드래그해 실제 조명과 애니메이션에서 확인한 뒤 씬을 저장하세요.

첫 연습에는 테이블, 단색 머그잔, 인쇄 무늬가 있는 책 및 유리병 등을 사용해 보세요. 먼저 개별 프리팹으로 내보냅니다. 다음에는 움직이는 소품과 유리를 분리한 채 테이블 구조물만 병합한 결과와 비교할 수 있습니다. 자신의 에셋으로 진행하는 연습 예시입니다.

소스 선택과 스캔 결과

소스는 루트 GameObject입니다. 스캔에는 비활성 오브젝트와 모든 메시 LOD를 포함해 하위의 지원 렌더러가 들어갑니다. 부모와 자식을 모두 추가해도 자식을 별도 소스로 중복 계산하지 않습니다. 개별 프리팹 모드에서는 소스 루트마다 하나의 프리팹이 생성됩니다.

컨트롤 또는 수치의미
선택 항목 추가 (Add Selection)선택한 GameObject를 추가하고 스캔합니다.
원본 스캔 (Scan Sources)현재 소스를 새로 확인합니다. 일치하는 머티리얼 설정과 렌더러 병합 선택은 유지됩니다.
X / 비우기 (Clear)X는 소스 하나를 제거합니다. Clear는 소스 목록, 머티리얼 목록 및 병합 선택을 비웁니다.
렌더러 / 머티리얼 / 슬롯렌더러 수, 고유 머티리얼 수 및 전체 원본 머티리얼 슬롯 수입니다. 서로 다른 수치입니다.
삼각형스캔한 모든 LOD와 비활성 자식을 포함합니다. 게임 카메라에서 동시에 보이는 삼각형 수는 아닙니다.

스킨 모델은 참조하는 모든 본과 루트 본이 포함되도록 캐릭터의 전체 루트를 선택하세요. 여러 모델을 배치하거나 부착 부품의 위치를 조정하려면 씬 인스턴스가 편리합니다. 텍스처는 머티리얼 참조를 통해 읽으므로 원본 텍스처를 한 폴더에 모을 필요가 없습니다.

마이크로 텍스처와 상세 영역

검증된 균일 색상 통합 (Fold Verified Colours)는 필터링 여유 영역을 포함해 삼각형이 샘플링하는 영역이 모든 매핑된 입력 채널에서 균일한지 확인합니다. 적합한 영역은 패딩이 있는 단일 픽셀 스와치로 통합됩니다. 전체 매핑된 표면 값이 일치할 때만 스와치를 공유하므로 스타일라이즈드 모델에 작은 팔레트 아틀라스를 사용할 수 있습니다.

베이스 컬러가 단색이어도 노멀, 메탈릭, 스무스니스, 오클루전, 불투명도 또는 이미션의 디테일을 지우지 않습니다. 매핑된 채널 중 하나라도 변하면 상세 영역으로 유지됩니다. 그라디언트와 그려진 음영도 유지됩니다. 판정이 모호하거나 검사 비용이 큰 영역은 보수적으로 상세 상태를 유지합니다. 아트 스타일 이름이 아닌 실제 텍스처 데이터를 검사합니다.

통합할 수 있는 경우에도 머티리얼을 상세 아틀라스 영역으로 유지하려면 디테일 유지 (Preserve Details)를 선택합니다. 모두 자동 통합 (Auto Fold All)은 스캔된 모든 머티리얼에 검증 기반 통합을 적용하고 모든 디테일 유지 (Preserve All Details)는 모두 상세 패킹으로 전환합니다. 단색 스와치와 상세 영역은 같은 아틀라스에 함께 들어갈 수 있습니다. 통합은 텍스처 샘플링을 변경하며 모델의 형태나 삼각형 수를 줄이지 않습니다.

입력 채널과 URP 머티리얼 매핑

2. 패킹 및 입력 채널 (2. Packing & source channels)에서 머티리얼을 펼쳐 원본 프로퍼티를 확인합니다. URP Lit 메탈릭 규칙은 자동 감지됩니다. 프로퍼티 입력란에는 텍스처 파일명이 아닌 _BaseMap 같은 셰이더 식별자를 지정합니다. 커스텀 셰이더는 미리보기 생성 전에 매핑을 확인하세요.

채널일반적인 URP 프로퍼티출력 형식
베이스 컬러와 불투명도_BaseMapRGB는 색상, A는 불투명도입니다. sRGB 샘플링 PNG입니다.
탄젠트 공간 노멀_BumpMap노멀 맵으로 임포트되는 PNG입니다.
메탈릭과 스무스니스_MetallicGlossMap리니어 PNG입니다. R은 메탈릭, A는 스무스니스입니다.
앰비언트 오클루전_OcclusionMap리니어 PNG입니다. G에 오클루전을 저장합니다.
이미션_EmissionMap일반 색상 범위를 넘는 발광을 유지하는 리니어 HDR EXR입니다.

매핑된 모든 채널은 같은 영역 배치와 다시 매핑된 UV0를 사용합니다. 지원되는 원본 틴트와 일반적인 표면 배율은 맵에 베이크되며 출력 값은 중복 적용되지 않도록 중립값으로 설정됩니다. 선택 맵이 없으면 지원되는 머티리얼 값을 사용할 수 있습니다. 임의의 셰이더 코드를 자동 변환하는 기능은 아닙니다.

타일링과 커스텀 셰이더

URP Lit에서는 베이스 맵 타일링 공유 (Share Base Map Tiling)을 켜 둡니다. 매핑된 채널 전체에서 베이스 텍스처 변환을 공유합니다. 프로퍼티별로 독립된 스케일과 오프셋을 사용하는 호환 커스텀 셰이더에서만 해제하세요. 지원되는 Repeat, Mirror, MirrorOnce 및 Clamp 샘플링과 음수 타일링은 상세 영역에 베이크됩니다.

활성 채널 모두가 같은 정확한 반복 주기를 지원하면 하나의 영역을 재사용할 수 있습니다. 그러나 삼각형 하나가 많은 반복을 가로지르면 여전히 큰 영역이 필요할 수 있습니다. 요청 크기는 원본 이미지 크기와 같지 않을 수 있습니다. 커스텀 출력 셰이더는 출력 텍스처 프로퍼티 매핑 (Output texture property mappings)를 확인하고 템플릿 선택 후 템플릿에서 감지 (Detect From Template)을 사용하세요. 이 가이드의 URP 워크플로에서는 Metallic Smoothness 패킹 형식을 사용합니다.

아틀라스 해상도, 자동 조정 및 패딩

설정기본값 또는 범위사용 방법

원본 디테일 한도 (%) (Source Detail Limit (%))기본값 100%. 범위 5~100%.자동 조정 전 원본 요청 밀도의 상한입니다. 전체 아틀라스 점유율이 아닙니다.
가장자리 여백 (Edge Padding)기본값 4픽셀. 범위 1~16.모든 맵에서 각 영역 둘레에 여백을 추가합니다. 패딩도 아틀라스 공간을 차지합니다.

자동 조정으로 디테일이 줄면 미리보기에 알림이 표시되고 각 상세 머티리얼에 요청 크기와 출력 픽셀 크기가 나타납니다. 내보낸 Atlas_Resolution.txt에도 기록됩니다. 원본 텍스처나 임포트 설정의 크기를 변경하지 않습니다.

4096 텍스처가 4092 × 4088을 요청하는 이유: 영역 크기는 메시 UV가 사용하는 범위를 나타냅니다. 이미지 가장자리의 미사용 영역 때문에 원본 이미지보다 조금 작을 수 있습니다. 이 범위 바깥에 패딩이 추가되므로 약 4K인 영역도 엄격 모드에서는 4K 아틀라스에 들어가지 않을 수 있습니다.

요청 밀도를 자동 축소 없이 유지해야 할 때만 자동 조정을 끕니다. 이 경우 디테일 우선순위는 비활성화됩니다. 엄격 패킹에 실패하면 자동 조정을 켜거나 최대 크기를 늘리거나 원본 디테일 제한을 낮추세요. 자동 조정도 패딩이 있는 단일 픽셀 영역을 무제한으로 넣을 수는 없습니다. 최소 배치조차 들어가지 않으면 소스를 나누거나 패딩을 줄이거나 최대 크기를 늘려야 합니다.

중요한 머티리얼에 디테일 할당하기

디테일 우선순위 (Detail Priority)는 자동 조정으로 상세 영역을 줄일 때 사용하는 상대적 우선순위입니다. 일반 머티리얼은 보통으로 두고 중요한 항목만 높이세요. 여러 머티리얼을 높음 또는 매우 높음으로 설정할 수 있습니다. 모든 머티리얼에 비율을 지정하거나 텍스처 채널마다 따로 조정할 필요가 없습니다.

우선순위상대 요청 면적사용 예
낮음 (Low priority)보통의 0.5배단순하거나 잘 보이지 않는 표면.
보통 (Normal priority)1배. 기본값.대부분의 머티리얼.
높음 (High priority)보통의 2배인쇄 라벨, 직물 무늬, 얼굴 또는 사슬 갑옷.
매우 높음 (Very high priority)보통의 4배매우 중요한 소수의 상세 머티리얼.

이 값은 상대 면적 배분이며 고정된 아틀라스 점유율이나 가로·세로 크기의 배수를 보장하지 않습니다. 원본 크기, UV 범위, 패딩 및 패킹 형태도 영향을 줍니다. 요청된 원본 디테일을 넘어서 확대하지 않습니다. 이미 모두 들어가는 경우 우선순위를 높여도 다른 머티리얼을 불필요하게 줄이지 않습니다. 통합된 단색 스와치는 단일 픽셀로 유지됩니다.

예: 목재, 가죽 및 단순한 금속은 보통으로 두고 사슬 갑옷과 얼굴을 모두 높음으로 설정한 뒤 미리보기를 다시 생성합니다. 필요하면 자동 조정이 상세 영역을 재분배합니다. 베이스 컬러, 노멀 및 다른 매핑 채널은 함께 유지됩니다. 높은 우선순위가 특정 해상도를 보장한다고 가정하지 말고 실제 출력 크기를 확인하세요.

필터링, 밉맵 및 텍스처 임포트

포인트 필터링 (Point Filtering)은 기본적으로 꺼져 있어 바이리니어 필터링을 사용합니다. 선명한 팔레트나 픽셀 텍스처가 필요하면 포인트 필터링을 켜세요. 밉맵 생성 (Generate Mip Maps)도 기본적으로 꺼져 있습니다. 작은 밉 레벨에서는 인접 아틀라스 영역이 섞이며 특히 작은 팔레트 스와치에서 눈에 띕니다. 상세 에셋은 밉맵으로 원거리 샘플링이 개선될 수 있으므로 패딩을 늘리고 실제 사용 거리에서 확인하세요.

내보낸 아틀라스는 Clamp 래핑, 비압축 임포트 및 Read/Write 비활성화 설정을 사용합니다. 지원되는 원본 래핑 동작은 각 영역에 이미 베이크되어 있습니다. 압축은 작은 스와치와 데이터 채널을 손상시킬 수 있으므로 변경 후 결과를 확인하세요. 공유 아틀라스는 필터링과 임포트 정책도 공유합니다. 하나의 출력 세트에서 소스 모델마다 서로 다른 필터링을 동시에 사용할 수는 없습니다.

불투명, 컷아웃 및 투명 머티리얼

아틀라스를 공유한다고 모든 표면이 하나의 머티리얼을 사용할 수 있는 것은 아닙니다. 불투명, 알파 클리핑 및 블렌딩 투명 표면에는 호환되는 출력 상태가 필요합니다. 블렌딩, 컷오프, 컬링, 깊이 설정, 렌더 큐 또는 지원 조명 설정의 차이로 그룹이 추가될 수 있습니다. 도구는 예정 그룹 수를 표시하고 투명 소스가 있으면 알려줍니다.

투명도를 유지하려면 투명 표면을 불투명하게 만들기 (Make Transparent Surfaces Opaque)를 꺼 둡니다. 유리 같은 블렌딩 투명 표면을 의도적으로 불투명하게 만들 때만 켜세요. 창에 경고가 표시됩니다. 알파 클리핑 컷아웃은 유지됩니다. 원본 머티리얼은 변경되지 않으며 다른 상태 차이 때문에 여러 출력 머티리얼이 필요할 수도 있습니다.

예: 불투명 가구와 유리병은 불투명 머티리얼과 투명 머티리얼을 사용하면서 같은 아틀라스 텍스처를 공유할 수 있습니다. 프리팹도 개별적으로 내보낼 수 있습니다. 병합 시 투명 부분은 정렬 동작을 유지하도록 별도 렌더러로 남습니다.

패킹 또는 아틀라스 설정을 바꾸면 현재 미리보기가 초기화됩니다. 소스나 계층이 바뀌면 미리보기가 오래된 상태가 될 수 있으므로 비교 전에 다시 생성하세요. 저장 및 내보내기 (Save & Export)는 항상 현재 소스로 다시 처리하므로 이전 미리보기를 그대로 내보내지 않습니다. 창 닫기, 스크립트 리로드 및 Play Mode 전환 시 임시 미리보기가 해제됩니다. 작업이 오래 걸리면 Unity 진행 대화상자에서 취소한 뒤 입력을 조정해 다시 시도하세요.

고급 선택과 정적 메시 병합

  1. 선택한 메시 병합 (Merge Selected Meshes)를 선택하고 고급 옵션 (Advanced Options)를 펼칩니다. 정적 병합에는 정적 메시 병합 (Merge Static Meshes)를 켭니다. 리그 메시 병합에는 별도 스위치가 있습니다.
  2. 포함할 렌더러 항목을 체크합니다. 모두 선택 (Select All) 또는 모두 분리 유지 (Keep All Separate)로 초기 선택을 바꿀 수 있습니다. 소스 번호와 계층 경로로 중복 이름을 구분합니다. 체크를 해제한 렌더러에도 아틀라스 머티리얼이 적용됩니다.
  3. 내보낸 뒤 Atlas_Merge.txt를 확인합니다. 병합 그룹에는 호환되는 선택 렌더러가 최소 두 개 필요합니다. 렌더러 설정이 다르면 여러 병합 렌더러가 생성될 수 있습니다.

고정 가구 부품, 건물 구조물, 기계 외장 및 항상 함께 움직이고 표시될 소품이 적합합니다. 호환성에는 레이어, 그림자, 프로브, 정렬, 모션 벡터 및 기타 지원 렌더러 설정이 포함됩니다. 정적 병합에는 호환되는 베이크 라이트맵 UV 변환이 적용됩니다.

문, 서랍, 탈착 장비 및 개별적으로 움직이거나 숨겨야 하는 부품은 독립 렌더러가 필요하면 분리하세요. 원본 Transform과 콜라이더는 유지되지만 병합 메시에 완전히 포함된 렌더러는 비활성화됩니다. 기존 원본 Transform을 움직여도 병합된 정적 메시의 해당 지오메트리는 개별적으로 움직이지 않습니다.

공유 리그와 강체 부착물

고급 옵션 (Advanced Options)에서 같은 리그의 메시 및 부착물 병합 (Merge Shared-Rig Meshes & Attachments)를 켜면 실제로 같은 스켈레톤을 참조하는 호환 Skinned Mesh Renderer를 병합할 수 있습니다. 본 이름이 같다는 이유만으로 공유 리그가 되지는 않습니다. 본 이름이 같은 캐릭터 인스턴스 두 개도 서로 다른 스켈레톤으로 유지됩니다.

같은 리그에 스키닝된 메시 병합

  1. 캐릭터의 전체 루트와 해당 본을 이미 참조하는 별도의 스킨 소스를 포함합니다. 참조되는 모든 본과 루트 본이 선택한 소스 안에 있어야 합니다.
  2. 렌더러를 분리한 상태로 내부 본 참조를 공유하려면 그룹 프리팹 (Grouped Prefab)을, 호환 부품을 병합하려면 선택한 메시 병합 (Merge Selected Meshes)를 사용합니다. 개별 프리팹에서는 각 소스에 전체 리그가 포함되어야 합니다.
  3. 내보낸 뒤 씬에서 애니메이션을 확인합니다. 병합 가능한 스킨의 본 참조, 보정된 바인드 포즈 및 가변 본 가중치는 유지됩니다. 일반 본 애니메이션은 지원하지만 블렌드 셰이프 렌더러와 렌더러 프로퍼티 애니메이션은 분리 유지됩니다.

스키닝되지 않은 강체 부품 부착

  1. 강체 부품과 캐릭터의 전체 리그를 포함하고 내보내기 전에 원하는 위치에 부품을 배치합니다. 장비 외에도 도구, 패널, 기계 부품, 액세서리 등 강체 지오메트리에 사용할 수 있습니다.
  2. 강체 렌더러를 체크합니다. 부착할 본 (Attachment Bone)을 자동 (Automatic)으로 두면 기존 리그 본 부모를 감지합니다. 별도 소스라면 팝업에서 포함된 모델의 본이나 소켓을 선택합니다. 이 선택기는 프리팹과 모델 에셋에서도 작동합니다.
  3. 리그 병합 스위치를 켠 상태에서 병합 모드로 내보냅니다. 부품은 현재 배치를 유지하고 모든 정점이 선택한 본에 100% 가중치로 따라갑니다. 강체 추종이며 변형 스킨 가중치를 자동 생성하거나 손에 자동으로 맞추는 기능은 아닙니다.

전용 런타임 부착 스크립트는 필요하지 않습니다. 병합된 부착물은 스킨 출력의 표시 상태를 공유합니다. 게임에서 개별 숨김, 교체, 분리 또는 오프셋 애니메이션이 필요하면 별도로 유지하세요. 공통 캐릭터 루트의 Rigidbody는 호환될 수 있지만 독립적으로 움직이는 물리 부품은 분리됩니다. 움직이는 스킨 출력에는 라이트맵 부품을 병합하지 않습니다.

선택한 부품이 분리 유지되는 이유

조건이유 또는 결과
투명 표면독립적인 정렬을 유지합니다. 혼합 렌더러는 투명 부분만 분리 유지할 수 있습니다.
블렌드 셰이프 렌더러원본 렌더러와 애니메이션 바인딩을 유지합니다. 아틀라스 매핑에서도 블렌드 셰이프 프레임이 보존됩니다.
LOD 렌더러LODGroup 소속을 유지합니다. 스캔된 모든 LOD 메시에 아틀라스는 적용할 수 있습니다.
비활성, 비활성화 또는 강제 비표시 렌더러원래의 독립적인 표시 상태를 유지합니다.
반전되거나 특이한 Transform별도 메시가 필요합니다. 음수 또는 0 스케일을 확인하세요.
다른 리그 인스턴스본 이름이 같아도 실제 스켈레톤 참조가 다릅니다.
독립 물리·이동 또는 스크립트/애니메이션이 제어하는 정적 오브젝트독립 동작을 보존합니다.
표시 상태, 머티리얼, 렌더러 프로퍼티 또는 부착 오프셋 애니메이션바인딩에 원본 렌더러나 Transform이 필요합니다. 일반 본 애니메이션은 지원합니다.
렌더러 설정 불일치 또는 적합한 렌더러 하나뿐호환 그룹을 나누거나 단일 렌더러 그룹에는 병합 메시를 생성하지 않습니다.

포함 선택은 호환될 때 병합해 달라는 요청이며 호환되지 않는 동작을 버리라는 명령이 아닙니다. Atlas_Merge.txt에서 분리된 경로와 이유를 확인하세요. 일부 또는 모든 메시가 분리 상태여도 아틀라스 생성은 성공할 수 있습니다.

워크플로 예시

목표권장 설정사용 전 확인
재사용 소품 여러 개소품을 모두 추가하고 아틀라스를 만든 뒤 개별 프리팹으로 출력.호환 머티리얼과 텍스처는 공유하고 각 프리팹은 독립적으로 유지합니다.
텍스처가 지나치게 큰 단일 모델자동 조정을 사용하고 최대 아틀라스 크기를 낮춘 뒤 중요한 머티리얼 우선순위를 높임.실제 카메라 거리에서 작은 글자, 얼굴 디테일 및 노멀 맵을 비교합니다.
테이블 또는 고정 매장 진열대호환 구조 메시를 병합하고 움직이는 소품과 투명 유리는 분리.내보낸 뒤 컬링, 상호작용 및 콜라이더를 확인합니다.
모듈형 캐릭터 또는 기계전체 리그를 포함하고 공유 리그 병합과 필요한 강체 부착 본 지정.애니메이션, 소켓 및 독립 표시가 필요한 부품을 확인합니다.

효과적인 최적화 선택과 검증

대표적인 씬에서 최적화 전후를 측정하세요. Unity 프로파일링 도구로 머티리얼 슬롯, 렌더러 수, 드로 콜, 텍스처 메모리 및 프레임 시간을 비교합니다. 개별 모델이 머티리얼을 공유해도 모든 오브젝트가 자동으로 한 드로 콜이 되지는 않습니다. 투명도, 패스, 조명, 배칭 및 렌더러 설정도 영향을 줍니다.

큰 병합 메시는 일부만 화면에 보여도 전체가 표시 대상으로 남을 수 있습니다. 보통 함께 보이고 움직이는 그룹을 병합하세요. 큰 아틀라스는 관련 없는 텍스처도 함께 로드하게 만들 수 있습니다. 용도에 맞춰 아틀라스 크기, 채널 수 및 그룹을 선택하세요. 원본 고해상도 이미지를 계속 포함한다면 출력 아틀라스가 작아져도 원본 이미지의 패키지 크기는 줄지 않습니다.

  • 같은 씬 조명과 카메라 거리에서 출력 프리팹과 원본을 비교합니다.
  • 변형, 블렌드 셰이프, LOD 전환, 투명도, 콜라이더 및 개별 렌더러를 참조하는 스크립트를 테스트합니다.
  • 두 보고서를 확인하고 출력 의존성과 동작 검증을 마칠 때까지 원본 에셋을 보관합니다.

문제 해결

증상먼저 확인할 사항
창을 열 수 없거나 컨트롤이 비활성화됨Console 컴파일 오류를 해결하고 임포트·리로드가 끝날 때까지 기다린 뒤 Edit Mode로 돌아옵니다. Tools 메뉴에서 도구를 여세요.
사용 가능한 렌더러가 없음지원 메시 컴포넌트가 포함된 루트를 선택하세요. Particle, Line 등 다른 렌더러는 아틀라스 메시 입력이 아닙니다.
영역이 아틀라스 상한보다 큼자동 조정을 켜세요. 이미 켜져 있다면 과도한 UV 타일링, 패딩 및 최소 영역 수를 확인합니다. 필요하면 크기를 늘리거나 소스를 나누세요.
출력이 예상보다 흐림해상도 감소 알림과 머티리얼별 크기를 확인합니다. 중요한 항목의 우선순위를 높이거나 최대 크기를 늘리거나 함께 출력하는 모델을 줄이세요.
우선순위를 바꿔도 차이가 없음우선순위는 자동 조정이 켜져 있고 축소가 필요할 때만 적용됩니다. 원본 디테일 상한과 패킹 형태도 차이를 제한할 수 있습니다.
스타일라이즈드 머티리얼이 단일 픽셀이 되지 않음다른 매핑 채널이나 그려진 그라디언트에 디테일이 있을 수 있습니다. 패킹 모드와 원본 맵을 확인하세요. 불확실한 영역은 보수적으로 유지됩니다.
원거리에서 색이 번지거나 바뀜밉맵, 패딩, 압축 및 필터링을 확인합니다. 엄격한 팔레트에는 밉맵을 끄고 포인트 필터링을 고려하세요. 먼저 비압축 출력을 비교합니다.
노멀, 메탈릭 또는 이미션이 이상함채널별 미리보기, 프로퍼티 식별자, 패킹 형식, 베이스 타일링 및 원본 워크플로를 확인합니다. 같은 조명에서 비교하세요. 커스텀 효과는 자동 베이크되지 않습니다.
출력 머티리얼이 여러 개 생성됨투명도, 클리핑, 컬링, 블렌딩, 컷오프 및 다른 렌더 상태 차이를 확인합니다. 텍스처 공유가 같은 머티리얼 상태를 뜻하지는 않습니다.
유리가 불투명해짐투명 표면 불투명화 옵션을 끄고 다시 출력하세요. 커스텀 출력 셰이더의 표면 설정도 확인합니다.
본이 소스 밖에 있다는 메시지참조되는 모든 본과 루트 본을 포함하는 전체 캐릭터 루트를 선택합니다. 소스 간 공유라면 전체 리그도 선택 소스에 포함하세요.
공유 스킨 부품이 개별 프리팹에서 거부됨그룹 프리팹 또는 선택 메시 병합을 사용합니다. 개별 출력은 각 소스 안에 완전한 독립 리그가 필요합니다.
선택 메시가 병합되지 않음Atlas_Merge.txt를 읽고 두 병합 스위치, 선택, 그룹 크기, 리그 동일성 및 위의 제외 조건을 확인하세요.
부착물 위치나 따라가는 본이 잘못됨출력 전 배치와 선택한 본·소켓을 확인합니다. 현재 배치를 유지하며 자동 포즈 조정이나 스냅은 하지 않습니다.
미리보기에 애니메이션이나 병합 결과가 없음스킨 미리보기는 바인드 포즈와 원본 계층을 사용합니다. 씬에서 생성 프리팹을 확인하세요.
내보낸 모델을 찾을 수 없음상태 메시지의 폴더를 확인하고 Prefabs 하위 폴더의 에셋을 씬에 드래그합니다. 기존 씬 인스턴스가 자동 교체되지는 않습니다.
출력 폴더가 거부됨현재 프로젝트의 Assets 안에 있는 경로를 선택하세요. Assets 밖이나 상위 디렉터리 이동을 포함하는 경로는 허용되지 않습니다.

Editor 스크립팅 참고

고급 통합은 DPT.MaterialOptimizer.Editor의 공개 네임스페이스 DPT.TextureAtlasCreator를 사용합니다. 어셈블리 정의는 Editor 전용이고 자동 참조되며 명시적인 외부 어셈블리 참조가 없습니다. 통합 코드는 Editor 어셈블리에 두고 자체 어셈블리 정의에 필요하면 참조를 추가하세요. API 식별자는 원래 이름을 유지합니다.

AtlasBuilder.Build텍스처, 다시 매핑된 메시, 머티리얼 및 렌더러 머티리얼 그룹이 있는 AtlasBuild를 생성합니다. 사용 후 Dispose하세요.
AtlasExporter.ExportAll생성 프리팹, 폴더 경로, 병합 수 및 메모가 있는 AtlasExportResult를 반환합니다. Export는 첫 생성 프리팹을 반환합니다.
AtlasExportMode.MergeStaticMeshes창의 선택 메시 병합 모드에 해당하는 기존 직렬화 열거형 이름입니다. 활성화된 공유 리그 경로도 지원합니다.
AtlasMergeSelection원본 스캔 renderer, include 플래그 및 선택적 attachmentBone입니다. 렌더러별 선택은 settings.mergeSelections를 사용합니다.

생성 에셋이 프리팹 옆에 있다고 가정하지 말고 결과의 meshesFolder, texturesFolder, materialsFolder 및 prefabsFolder를 사용하세요. 자세한 API와 검증 내용은 패키지 README 및 Validation.md에 있습니다. 포함된 엔진 확인은 Tools > DPT Games > Validate Material Optimizer & Texture Atlas Tool에서 실행하며 패키지의 ValidationOutput 폴더에 보고서를 생성합니다.
