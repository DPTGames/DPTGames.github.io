Stylized Color Swapper & Material Optimizer

한국어 기술 가이드

Color Swapper는 Unity Editor 안에서 바로 사용할 수 있는 툴로, Unity를 벗어나거나 이미지 편집 프로그램을 열지 않고도 3D 모델의 색상과 외형을 변경할 수 있습니다. 모델을 선택하고 3D 프리뷰 창에서 새로운 색상을 페인팅한 뒤, 몇 번의 클릭만으로 바로 사용할 수 있는 버전으로 저장할 수 있으며 별도의 이미지 파일을 따로 관리할 필요가 없습니다.

효율적인 실행: Vertex Bake & Pack 모드는 컬러 텍스처를 완전히 제거해, 색상이 서로 다른 사실상 무제한의 프롭이 하나의 마스터 머티리얼을 공유할 수 있게 합니다. Zones로 변형을 제어하면 수천 개의 서로 다른 색상 인스턴스도 계속 함께 배칭할 수 있습니다. Texture Coloring 모드는 원본 텍스처 시트 대신 초경량 마이크로 팔레트를 사용해 VRAM 사용량을 최대 96%까지 줄일 수 있습니다.

빠른 시작

바로 시작하고 싶다면, 설치 후 첫 모델을 페인팅하기까지의 가장 빠른 과정은 다음과 같습니다.

  1. 툴 열기: Unity 메뉴 바에서 다음 경로로 이동합니다. Tools > DPT Games > Stylized Color Swapper.
  2. 대상 설정: 리컬러하려는 GameObject를 Scene Hierarchy 또는 Project 창에서 창 상단의 Target Object 필드로 드래그합니다.
  3. 페인팅 시작: 툴이 모델을 자동으로 스캔한 뒤 바로 3D 프리뷰로 이동합니다. Swatch를 선택하고 색상을 고른 다음 모델 위에서 클릭하거나 드래그해 페인팅합니다.

작동 방식, 단계별 안내

이 툴은 원본 파일을 실수로 변경하지 않습니다. 항상 복사본에서 작업하며, 저장 버튼을 누르기 전까지는 아무것도 저장되지 않습니다. 기본 흐름은 다음과 같습니다.

  1. 모델 선택: 리컬러하려는 오브젝트 또는 모델을 툴 창으로 드래그합니다.
  2. 스캔: 툴이 모델의 현재 색상을 분석하고 표면을 색상 그룹인 "Swatch" 목록으로 정리합니다. 하나씩 편집하거나 여러 개를 동시에 편집할 수 있습니다.
  3. 페인팅: 3D 프리뷰 창에서 모델을 직접 클릭하고 드래그해 새 색상을 칠하고, 부드러운 색상 전환을 만들고, 나무나 금속 같은 머티리얼 표현을 적용하고, 날카로운 엣지를 부드럽게 하거나 발광과 자연스러운 바람 움직임을 설정할 수 있습니다.
  4. 저장: 결과가 마음에 들면 변경 사항을 새로운 게임용 모델 버전으로 저장합니다.

모델 스캔 및 저장 방식 선택

페인팅하기 전에 툴이 모델의 현재 색상을 읽어야 합니다. 색상을 읽는 방식과 결과를 저장하는 방식에는 여러 선택지가 있습니다.

툴이 모델의 색상을 읽는 방식

옵션 기능 및 사용 시점
Texture Palette (Default) 모델에 이미 적용된 컬러 이미지를 분석하고 동일하거나 유사한 색상별로 표면을 그룹화합니다. Synty나 Polygon 스타일 팩과 같은 대부분의 스타일라이즈드 모델에 적합합니다.
Vertex Colors 이미지가 아니라 모델 표면에 직접 저장된 Vertex Color를 읽습니다. Blender나 ZBrush 등에서 Vertex Color로 제작된 모델 또는 이 툴로 이미 저장한 모델을 다시 열어 계속 편집할 때 사용합니다.
Material Colors 이미지나 페인팅된 색상 없이 단일한 플랫 컬러만 사용하는 모델용입니다. 이 모드는 해당 머티리얼의 단색 값을 읽습니다.

다음 두 옵션을 사용하면 스캔 방식을 더 세밀하게 조정할 수 있습니다. Combine Similar Colors (Alt+C)는 거의 동일한 색상을 하나의 그룹으로 합쳐, 비슷한 색상을 따로따로 편집해야 하는 일을 줄여줍니다. Split Disconnected Islands (Alt+I)는 같은 색상을 사용하더라도 물리적으로 분리된 파트, 예를 들어 양쪽 팔을 서로 독립적으로 편집 가능한 그룹으로 유지합니다. 저장할 때 최종 색상이 동일한 그룹은 효율성을 위해 자동으로 다시 병합됩니다.

추가 정확도 설정

다음 설정은 툴이 모델을 읽고 재구성하는 정확도를 제어합니다.

  • Auto-Uncompress Textures: 일부 이미지 파일은 용량을 줄이기 위해 압축되어 있어 직접 샘플링할 때 색상이 약간 흐리거나 블록 형태로 보일 수 있습니다. 이 옵션은 스캔 중 압축을 일시적으로 해제해 정확한 색상을 읽습니다. 압축된 이미지를 감지하면 한 번의 클릭으로 사용할 수 있는 Re-Scan (Lossless) 버튼을 표시해 최고 품질로 다시 스캔할 수 있습니다.
  • Adaptive Tessellation: 작은 텍스트, 로고 또는 데칼처럼 세밀한 디테일을 이미지 대신 모델 자체에 저장해야 하는 경우, 이 설정은 해당 디테일을 보존하는 데 필요한 부분에만 추가 지오메트리를 자동 생성합니다. Protect Smooth Surfaces 는 바퀴처럼 자연스럽게 곡면을 이루는 부분이 불필요하게 분할되지 않도록 보호하고, Max Subdivision 는 추가되는 세분화의 최대 수준을 제한하며, Color Threshold 는 색상 차이가 어느 정도일 때 추가 디테일을 생성할지 결정합니다. 각진 하드 서피스 모델에서 가장 잘 작동하며, 이미 디테일이 적고 대부분 단색인 모델에는 효과가 제한적입니다.
  • Auto-Unwrap (Lossless): 일부 모델은 2D 이미지가 3D 형태에 어떻게 감기는지 정의하는 깔끔한 UV 레이아웃이 없을 수 있습니다. 이 기능은 원본 파일을 변경하지 않고 필요할 때 깨끗한 UV 레이아웃을 자동 생성합니다. Hard Edge Cutoff 슬라이더는 UV를 펼치기 위해 필요한 Seam을 얼마나 적극적으로 추가할지 제어합니다. 값이 낮을수록 더 날카로운 모서리 쪽에 Seam이 배치됩니다.
  • Smooth Normals (Per Piece): 캠프파이어 돌이나 잘린 통나무처럼 각지고 저디테일인 표면의 조명 반사를 부드럽게 만듭니다. 추가 지오메트리는 생성하지 않고 라이팅 표현만 바꾸며, 어떤 저장 방식에서도 사용할 수 있습니다.

결과 저장 방식

옵션 결과
Texture Coloring 전통적인 방식으로 모델을 리컬러하고 원본과 같은 형태의 새로운 이미지 파일을 생성합니다. 구형 프로젝트나 가벼운 구성이 필요한 모바일 게임에 적합합니다.
Vertex Bake & Pack (Recommended) 색상과 머티리얼 설정(Metallic, Smoothness, AO)을 별도 이미지 대신 모델 자체에 직접 저장합니다. 컬러 이미지를 완전히 생략할 수 있으며 Smooth Gradient, 실시간 Wind Animation, Smooth Normals, Zones 같은 추가 기능을 사용할 수 있습니다.

모델 파트 선택 방법

툴은 세 가지 Selection Scope와 빠른 전환 단축키를 제공합니다. 툴바 버튼 또는 I키로 전환할 수 있습니다.

Face

작은 Triangle 하나씩 선택해 매우 정밀하게 편집합니다. 얇은 장식선이나 발광 룬처럼 작은 디테일에 적합합니다.

Island

이미지에서 하나의 연속된 영역을 공유하는 연결된 UV Island 전체를 선택합니다. 명확하게 구분된 영역을 한 번에 리컬러할 때 유용합니다.

Shell

갑옷 판, 검, 머리카락 덩어리처럼 물리적으로 분리된 전체 파트를 한 번에 선택합니다.

Face Extract (Q)

전체 모델을 먼저 분리할 필요 없이 커서 아래의 표면만 즉시 독립적으로 편집 가능한 파트로 분리합니다.

부드러운 색상 그라디언트 & 자연스러운 바람 흔들림

권장 옵션인 Vertex Bake & Pack 모드에서만 사용할 수 있습니다. Gradient Paint tool (G) 을 사용하면 모델 위에서 클릭하고 드래그해 한 가지 단일 값만 적용하는 대신 색상이나 설정 값을 부드럽게 전환할 수 있습니다.

부드러운 그라디언트

클릭해 시작점을 지정한 뒤 드래그하여 블렌드의 방향과 길이를 설정합니다. 모델 크기에 관계없이 정확하게 작동합니다.

  • Blend Mode: 그라디언트가 기존 값과 결합되는 방식을 선택합니다. Multiply (어둡게), Replace (완전히 대체), 또는 SoftLight (더 부드럽게 혼합).
  • Alpha: 그라디언트 전체의 강도를 조절합니다.
  • Sharpness: 전환이 얼마나 부드럽거나 급격한지 조절합니다.
  • Clear: 현재 선택 영역의 그라디언트를 즉시 제거합니다.

바람 움직임 페인팅

Wind 설정으로 전환한 뒤 식물이나 프롭의 밑부분에서 끝부분 방향으로 드래그하면 자연스럽고 점진적인 흔들림을 설정할 수 있습니다. 밑부분은 거의 움직이지 않고 끝부분이 가장 많이 흔들립니다.

  • Live Preview: 저장하기 전에 "Simulate Wind"를 켜면 프리뷰 창에서 흔들림을 실시간으로 확인할 수 있습니다.
  • 추가 비용 없음: 이 움직임 데이터는 모델에 직접 저장되며 게임 실행 시 별도의 추가 비용이 들지 않습니다.

Vertex Bake & Pack을 사용하는 이유

Vertex Bake & Pack은 색상과 머티리얼 설정을 Mesh에 직접 저장하므로 컬러 텍스처가 전혀 필요하지 않습니다. 따라서 외형이 서로 다른 수많은 프롭으로 구성된 씬도 하나의 마스터 머티리얼만으로 구성할 수 있으며, Zones를 이용해 색상 변형을 제어하면 서로 다른 색상의 수천 개 인스턴스도 계속 함께 배칭할 수 있습니다. 또한 Gradient Paint를 지원하는 유일한 모드이므로 단일 값만 적용하는 대신 모델 전체에 색상과 설정을 부드럽게 블렌딩할 수 있습니다.

홈과 틈새의 Ambient Occlusion(AO)에 대한 참고: Texture AO는 이미지를 모델에 직접 옮기기 어렵습니다. 일반적으로 이미지는 모델의 Vertex가 표현할 수 있는 것보다 훨씬 많은 디테일을 담고 있기 때문입니다. 따라서 이미지에서 색상을 스캔하고 Vertex Bake & Pack으로 저장할 경우 AO는 1.0 (추가 Occlusion 없음)에서 시작합니다. 부정확한 값을 추측해서 넣지 않기 위한 방식입니다. 이후 직접 페인팅하거나 아래의 Raycast AO Baker 를 사용해 실제 지오메트리를 기반으로 계산할 수 있습니다.
페인팅된 AO는 단순한 색상 효과가 아니라 스타일라이즈드 그림자에도 영향을 줍니다: 머티리얼에서 "Stylized Lighting" 옵션을 켜면 페인팅하거나 Bake한 AO가 실제 그림자 표현에 반영됩니다. 예를 들어 눈 주위나 갑옷 홈의 AO를 더 깊게 해 원하는 위치에 의도적으로 그림자를 배치하는 등 스타일라이즈드 쉐도우를 직접 제어할 수 있습니다.

3D 프리뷰 창

Unity의 일반 Scene View 대신 툴 전용 3D 프리뷰 창을 사용합니다. 실제 게임 씬에 모델을 먼저 배치하지 않아도 바로 페인팅할 수 있습니다.

Before / After

기본적으로 편집된 버전이 표시됩니다. O 키를 누르고 있는 동안 원본의 편집되지 않은 버전을 잠시 확인할 수 있으며, 키를 놓으면 편집 버전으로 돌아갑니다.

씬에서 비교

B 키를 누르면 프리뷰 복사본을 실제 게임 씬에 임시로 배치해 실제 라이팅 아래에서 나란히 비교할 수 있습니다. 툴을 닫으면 자동으로 제거됩니다.

자동 회전

T 키 또는 Space 키를 누르면 모델이 천천히 회전하므로 모든 각도에서 외형을 확인할 수 있습니다.

실제 라이팅 반영

프리뷰는 프로젝트의 실제 라이팅 설정을 실시간으로 반영하므로 Metallic과 Smoothness 표현을 정확하게 확인할 수 있습니다.

프리뷰 숨기기

V 키를 누르면 3D 프리뷰 창을 완전히 숨기고 Color Group 목록을 위한 공간을 확보할 수 있습니다.

카메라 맞추기

Sync Scene 및 Sync Game 토글 버튼을 사용하면 Scene 또는 Game View 카메라를 툴의 프리뷰 카메라와 맞출 수 있습니다.

Marquee Select

Shift 키를 누른 채 프리뷰 창에서 박스를 드래그하면 박스 안의 모든 항목을 한 번에 선택할 수 있습니다.

실시간 바람 프리뷰

Wind 설정을 보고 있을 때 Simulate Wind를 켜면 식물과 프롭의 흔들림을 프리뷰 창에서 실시간으로 확인할 수 있습니다.

툴바 & 단축키 레퍼런스

모델을 스캔하면 프리뷰 창 아래의 툴바에서 다음 기능을 사용할 수 있습니다. 저장 경로 같은 텍스트 입력 필드에 입력 중일 때는 대부분의 단축키가 비활성화됩니다.

툴 단축키 기능
Selection Scope I 다음 선택 범위를 순환합니다. Face (단일 Triangle), Island (연결된 UV 영역), Shell (완전히 분리된 파트).
Face Extract Q 모델의 나머지 부분은 그대로 두고 커서 아래의 표면만 별도 파트로 분리합니다.
Paint Mode P 클릭 및 드래그 페인팅을 활성화해 드래그한 위치에 선택한 색상 또는 설정을 적용합니다. Shift 키를 누른 상태에서는 Paint Mode가 꺼져 있어도 페인팅할 수 있습니다.
Gradient Paint G Vertex Bake & Pack 모드에서만 사용 가능합니다. 클릭하고 드래그해 색상이나 설정을 부드럽게 블렌딩합니다.
Eraser Mode E Paint Mode가 켜져 있을 때만 사용 가능합니다. 클릭한 표면을 원래 색상과 기본 설정으로 되돌립니다.

Texel Density & Smooth Normals

Color Editing 패널에 있는 이 설정들은 패턴의 크기를 일정하게 유지하고 모델 엣지가 얼마나 둥글거나 날카롭게 보일지 조절하는 데 사용됩니다.

Texel Density

Wood Grain이나 Fabric Weave 같은 패턴이 모델의 각 부분에서 늘어나거나 눌리지 않고 비슷한 크기로 보이도록 도와줍니다. Calculate & Assign Scale 및 Auto-Normalize Scale 버튼이 이 값을 자동으로 계산해 줍니다.

Smooth Normals & Angle Threshold

선택한 파트에서 Smooth Normals를 켜면 외형을 제어하는 0°-180° Angle Slider가 표시됩니다.

  • 0° - 원래의 각지고 Flat Facet 형태를 그대로 유지합니다.
  • 10°-60° - 작은 주름은 부드럽게 하면서 날카로운 모서리는 유지합니다.
  • 120°-180° - 큰 각도까지 부드러운 곡면처럼 보이도록 스무딩합니다.
어떤 크기에서도 정확하게 작동: 모델이 거대한 드래곤이든 작은 강아지든 아주 작은 캠프파이어든, Import 시 Scale과 관계없이 Smooth Normals와 Gradient가 정확하게 계산됩니다.

원클릭 머티리얼 표현 (Feature IDs)

Vertex Bake & Pack 모드로 저장할 때 직접 디테일을 손으로 그리지 않고도 페인팅된 파트에 한 번의 클릭으로 사실적인 표면 표현을 추가할 수 있습니다.

파트를 선택한 뒤 Feature ID Dropdown에서 다음 표면 표현 중 하나를 선택합니다.

  • Default (None) - 페인팅한 색상과 설정만 사용하며 추가 표면 디테일은 적용하지 않습니다.
  • Wood - 나무 계열 Color Tint와 Wood Grain 표면 패턴을 함께 추가해 색상과 표면 디테일을 모두 변경합니다.
  • Fur - Wood 과 동일하게 Color Tint를 추가하지만 Surface Normal 패턴은 적용하지 않습니다.
  • Bark, Steel, Copper, Cast Iron, Leather, Cloth, Stone, Rope, Foliage - 기본 색상을 변경하지 않고 각 재질에 맞는 스크래치, 직조, Grain 등의 표면 패턴을 추가합니다.

머티리얼 표현 세부 조정

Feature ID를 선택하면 추가 조절 항목이 표시됩니다.

  • Detail Scale: Wood Grain 같은 패턴의 크기를 키우거나 줄입니다.
  • Detail Rotation: 패턴의 방향을 회전합니다. Wood Grain이 옆 방향으로 흐르는 등 방향이 잘못됐을 때 유용합니다.
  • Blend Detail: 패턴이 모델 표면을 따라 부드럽게 이어지도록 해 반복되거나 타일처럼 보이는 현상을 줄입니다. 일반 Edge와 더 날카로운 Seam을 위해 별도의 Face 및 Seam Strength Slider를 제공합니다.
  • Apply Wind: 표면 디테일에 흔들림을 추가하며 Strength Slider로 강도를 조절합니다. 더 자연스럽고 방향성 있는 흔들림은 Gradient Paint의 Wind Channel을 사용할 수 있습니다.
최초 1회 설정이 필요할 수 있습니다: Material에서 _DETAIL Keyword가 아직 활성화되지 않은 경우 Feature ID를 선택하면 Enable Procedural Details 버튼이 포함된 경고가 표시되며 자동으로 활성화할 수 있습니다.

Zones (나중에 사용할 영역 태그)

Vertex Bake & Pack 모드에서는 각 파트에 0부터 7까지의 Zone ID를 지정할 수 있습니다. 툴 안에서 즉시 외형이 바뀌는 기능은 아니며, 나중에 게임 코드나 Shader에서 영역별로 다르게 처리할 수 있도록 태그하는 방식입니다. 예를 들어 특정 Zone에만 랜덤 컬러 변형을 적용할 수 있습니다.

  • Change Channel을 Zones로 전환하면 실제 페인트 색상 대신 각 파트가 Zone별 고유 색상으로 표시됩니다.
  • 파트를 선택한 뒤 Zone Slider(0-7)를 조절하거나 일반 색상처럼 프리뷰에서 직접 페인팅할 수 있습니다. 이 Channel이 활성화된 동안 Brush는 색상 대신 Zone 번호를 적용합니다.
  • Zone 7은 기본/Fallback Zone입니다. 게임 로직이나 Shader Effect에 직접 사용할 Zone은 0-6을 사용하세요.
모델 자체의 색상 대신 이미지를 사용하나요? 이 Zone Painting 기능은 Vertex Bake & Pack 모드에서만 사용할 수 있습니다. 이미지 기반 모델에서 Zones가 필요하다면 VCCore 를 Non-Vertex-Color 모드로 설정하세요. 해당 모드에는 Zone Data 전용 이미지 슬롯이 있습니다.

Color Palette 관리

나란히 표시되는 두 개의 Color Grid를 사용해 여러 모델에서 일관된 색상 선택을 유지할 수 있습니다.

  • Custom Palette (왼쪽): 직접 채울 수 있는 18개의 Color Slot입니다. 컴퓨터에 저장되어 프로젝트가 바뀌어도 유지됩니다. Slot을 클릭하면 해당 색상을 Brush에 불러옵니다.
  • Imported Palette (오른쪽): 현재 모델을 스캔할 때 발견된 색상으로 자동 채워집니다.
  • Copy 버튼: Imported Palette의 색상을 Custom Palette로 바로 복사해 다른 모델에서도 다시 사용할 수 있습니다.

또한 Export Palette (PNG) 및 Import Palette (PNG) 버튼을 사용해 Custom Palette를 작은 이미지 파일로 저장하거나 불러올 수 있습니다. 백업하거나 팀원과 동일한 색상 구성을 공유할 때 유용합니다.

여러 Material을 사용하는 모델 처리

모델이 여러 Material을 사용하는 경우, 자체 이미지를 가진 각 Material은 Settings Panel에 이름별 섹션으로 표시됩니다. 각 섹션에서 Base Color와 Metallic/Smoothness/AO 입력을 독립적으로 설정할 수 있으며, Material의 PBR Mode에 따라 하나의 Packed MRAO Map 또는 분리된 Metal, Smooth, AO Texture Slot을 사용할 수 있습니다. 비워 두면 툴이 자동 감지한 값을 그대로 사용합니다.

Raycast AO Baker

메인 페인팅 워크플로와는 별도의 툴로, 미리 제작된 이미지에 의존하지 않고 모델 주변에서 빛이 실제로 어떻게 차단되는지 시뮬레이션해 모서리와 틈새의 Ambient Occlusion(AO)을 계산합니다.

  • Rays Per Vertex: 각 지점에서 사용하는 Light Sample 수입니다. 값이 높을수록 결과가 깨끗하지만 계산 시간이 늘어납니다.
  • Max Distance: Ray가 차단되지 않은 것으로 판단되기 전까지 이동할 수 있는 최대 거리입니다.
  • Intensity: 결과 Shading의 전체 강도를 조절합니다.
  • Blur Passes: 결과의 거친 노이즈를 줄입니다.
  • Bake Target: AO를 모델에 직접 저장할지 별도 Texture로 Bake할지 선택합니다. 별도 Texture를 사용할 경우 Match Base Color 버튼으로 다른 이미지와 해상도를 자동으로 맞출 수 있습니다.

Compute & Bake Global Raycast AO를 클릭하여 실행합니다. Texture Coloring 모드에서 Optimize Palette Size가 켜져 있으면 이 툴은 숨겨집니다. AO Bake는 모델의 각 파트가 이미지 안에서 독립된 공간을 가져야 하지만, 해당 옵션은 용량 절감을 위해 그 공간을 제거하기 때문입니다. 잘못된 결과를 생성하는 대신 이 경우에는 툴 자체를 표시하지 않습니다.

작업 저장

편집이 완료되면 창 하단의 버튼을 사용해 저장합니다. 표시되는 버튼은 현재 작업 대상에 따라 달라집니다.

  • Apply to Scene Object: Scene에 이미 배치된 오브젝트를 편집할 때만 표시됩니다. 새 버전을 디스크에 저장하고 원본 백업을 유지한 뒤 Scene의 오브젝트를 새 버전으로 자동 교체해 계속 조정할 수 있습니다.
  • Create New Version: 원본 모델을 변경하지 않고 선택한 폴더에 독립된 새 복사본을 저장합니다.

별도의 설정으로 저장할 때 Material File을 어떻게 처리할지 지정할 수 있습니다.

  • Make a New Copy Each Time: 저장할 때마다 새로운 Material File을 생성합니다.
  • Share One Copy: 같은 Session에서 저장된 모든 결과가 하나의 Material File을 공유합니다.
  • Reuse the Existing Material: 새 파일을 만들지 않고 모든 저장 결과가 원래 Material을 사용하도록 합니다.
  • Edit the Original Directly: 새 파일을 만들지 않고 기존 Material File 자체를 변경합니다.
  • Leave It Alone: Material 할당을 전혀 변경하지 않습니다.

어떤 저장 버튼을 사용하든 내부적으로 다음 과정이 진행됩니다.

  1. 원본 모델의 복사본을 만듭니다.
  2. 페인팅한 색상을 해당 복사본에 적용합니다.
  3. Metallic, Smoothness, AO 설정을 모델에 효율적으로 저장합니다.
  4. 설정한 Smooth Normals를 적용합니다.
  5. 새 모델과, 해당 저장 방식을 선택한 경우 새 이미지도 선택한 폴더에 저장합니다.
  6. 올바른 Material이 이미 설정된 즉시 사용 가능한 버전을 생성하거나 업데이트합니다.
저장 전 메모리 사용량 확인: Footprint Audit 패널과 F 단축키를 사용하면 저장 전에 새 버전의 예상 메모리 사용량을 확인해 실제 저장 전에 절감 효과를 미리 볼 수 있습니다.

문제 해결 & 자주 묻는 질문

"Split Disconnected Islands"를 켰는데도 각 파트를 따로 페인팅할 수 없습니다.
"Group Similar"(Ctrl+G)가 꺼져 있는지 확인하세요. 두 기능이 모두 켜져 있으면 분리한 뒤에도 비슷한 색상의 파트가 다시 그룹화됩니다.
식물이나 천에 바람 흔들림을 어떻게 페인팅하나요?
Change Channel을 Wind로 전환하고 Gradient Paint(G)를 켠 뒤 식물이나 줄기의 밑부분을 클릭해 끝부분 방향으로 드래그합니다. 툴바에서 "Simulate Wind"를 켜면 프리뷰에서 실시간 흔들림을 확인할 수 있습니다.
Face, Island, Shell 선택의 차이는 무엇인가요?
Face 는 정밀한 편집을 위해 작은 Triangle 하나씩 선택합니다. Island 는 모델 이미지에서 하나의 연속 영역을 공유하는 전체 Patch를 선택합니다. Shell 는 머리카락 덩어리나 갑옷 판처럼 완전히 분리된 파트 전체를 한 번에 선택합니다. 다음 키로 모드를 순환합니다. I 키.
파트의 색상은 변경할 수 있지만 선택 Highlight가 올바르게 표시되지 않습니다.
대부분 Mirror된 모델 파트가 같은 이미지 공간을 공유할 때 발생합니다. 모델의 새 버전을 만든 뒤 해당 버전을 Target으로 사용해 보세요.
Smooth Normals를 켜도 Low-Poly 돌이나 통나무가 둥글게 보이지 않는 이유는 무엇인가요?
각지고 저디테일한 형태는 표면 사이의 각도가 보통 60°-90° 이상으로 큽니다. Smooth Normals Angle Slider를 120°-180°정도로 높이면 큰 각도도 스무딩할 수 있습니다. 0° 설정은 모든 표면을 완전히 Flat하게 유지합니다.
모델 전체가 아니라 일부 파트만 부드럽게 만들 수 있나요?
가능합니다. Smooth Normals는 각 파트(Swatch)별로 설정됩니다. 나무, 돌, 생물 몸체 같은 유기적인 파트는 둥글게 하고 금속 칼날이나 갑옷 같은 Hard-Surface 파트는 날카롭고 Flat하게 유지할 수 있습니다.
모델을 클릭해 페인팅했는데 아무 일도 일어나지 않습니다.
Eraser Mode가 실수로 켜져 있지 않은지 확인하세요. 또한 변경하려는 항목에 맞는 Channel을 보고 있는지 확인하세요. 예를 들어 Color Channel을 보고 있는 동안에는 Metallic을 페인팅할 수 없습니다.
파트에서 원클릭 Material 표현(Feature ID) 옵션을 찾을 수 없습니다.
해당 옵션은 Vertex Bake & Pack 모드에서만 표시됩니다. Texture Coloring 모드에서는 일반 이미지 기반 작업으로 간주해 옵션을 숨깁니다.
Undo를 눌렀는데 마지막 Brush Stroke 대신 Scene의 다른 작업이 취소됐습니다.
Undo는 이 툴 전용 기록이 아니라 프로젝트 전체의 Unity 기본 History를 사용합니다. 따라서 페인팅 직후 Scene에서 다른 작업을 했다면 해당 작업이 먼저 Undo됩니다. 계속 Undo하면 다음에 Paint Stroke가 취소됩니다.
저장한 모델이 밝은 분홍색으로 표시됩니다.
프로젝트에 툴이 필요한 Material, 예를 들어 VCCore)이 없다는 의미입니다. 패키지의 모든 항목이 제대로 Import되었는지, 프로젝트의 Rendering 설정이 툴 요구 사항과 일치하는지 확인하세요.
디테일이 많은 모델을 페인팅할 때 툴이 느리거나 버벅입니다.
정확한 선택을 위해 클릭 위치를 모든 표면과 비교하므로 매우 디테일한 모델에서는 시간이 더 걸릴 수 있습니다. Triangle이 50,000개 이상인 모델이라면 Combine Similar Colors Tolerance를 높여 개별 Swatch 수를 줄여 보세요.
