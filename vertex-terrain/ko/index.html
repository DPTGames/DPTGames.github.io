작은 화면에서는 넓은 표를 좌우로 스크롤하여 모든 열을 확인할 수 있습니다.

Vertex 3D Terrain을 사용하면 Unity 안에서 메시 기반 Terrain을 직접 생성하고 편집할 수 있습니다. 일반적인 Ground, 행성, 떠 있는 섬을 만든 뒤 지오메트리를 변형하고 표면을 페인트하며 경로와 Structure를 만들고 그라디언트를 적용하고 여러 Terrain Tile을 가로질러 작업할 수 있습니다.

지오메트리 도구는 실제 메시를 바꾸고 표면 도구는 외형을 바꿉니다. 호환되는 지오메트리 도구와 표면 도구는 같은 Stroke에서 함께 사용할 수 있으므로 Terrain을 변형하면서 동시에 페인트할 수 있습니다.

첫 번째 지형 만들기

  1. Tools → DPT Games → Vertex 3D Terrain을 엽니다.
  2. 지형 생성을 열고 만들 지형 유형을 평면 지형, 행성, 떠 있는 섬 중에서 선택합니다.
  3. 시작 바이옴을 선택합니다. 떠 있는 섬에서는 상단 바이옴과 하단 바이옴을 선택합니다. 지형의 크기, 형태, 해상도도 조정합니다. 사용할 수 있는 항목은 선택한 지형 유형에 따라 달라집니다. 예를 들어 떠 있는 섬에서는 폭, 길이, 하부 깊이, 고원 형태, 하부 형태, 표면 변화를 설정할 수 있습니다.
  4. 생성 위치로 지형을 생성할 위치를 선택합니다. 실시간 미리보기가 활성화되어 있다면 생성 전에 전체 크기와 형태를 확인합니다.
  5. 선택한 지형 유형에 맞는 생성 버튼을 클릭합니다. 예: 떠 있는 섬 생성, 소행성 생성, 표면 생성.
  6. 생성된 지형은 지오메트리 도구와 표면 도구로 바로 편집할 수 있습니다. 메시를 조각하거나 형태를 바꾸고, 바이옴을 페인트하고, 경로와 그라디언트를 만들고, 마스크로 Face를 선택할 수 있습니다. 호환되는 지오메트리 도구와 표면 도구는 같은 Stroke에서 함께 사용할 수도 있습니다.
  7. 작은 디테일을 추가하기 전에 전체 형태부터 크게 조정합니다. 더 세밀한 편집이 필요한 영역은 나중에 로컬 지오메트리 밀도를 늘릴 수 있습니다.
  8. 결과가 만족스러우면 Unity Scene과 유지할 Generated Asset과 함께 지형을 저장합니다.

첫 연습으로 좋은 방법: 작은 지형을 하나 생성하고 조각으로 실루엣 일부를 바꾼 뒤 페인트, 경로 또는 다른 표면 도구를 시험해 보십시오. 더 큰 Scene을 만들기 전에 생성과 편집의 기본 흐름을 빠르게 익힐 수 있습니다.

편집 대상, 라이브러리, 브러시 설정

무엇을 편집할지 선택하기

활성 Terrain은 현재 메시와 설정을 제공합니다. 여러 오브젝트로 이루어진 지형에서는 대상 List를 사용해 어떤 오브젝트를 페인트 또는 조각할 수 있는지 선택합니다. 활성과 페인트/조각 활성화는 역할이 다릅니다. 한 Tile을 선택했다고 해서 주변 Tile이 모두 자동으로 편집 가능해지는 것은 아닙니다.

필요한 Terrain Object를 추가하거나 등록하고 Scene 구성이 바뀌면 목록을 새로 고칩니다. 경계를 가로지르는 Stroke를 사용하기 전에 페인트/조각 스위치를 확인하십시오. 대상에는 Tool이 사용하는 메시 Component가 있어야 합니다. 런타임에 Physics Raycast로 지형을 감지하려면 Collider도 필요합니다.

설정의미변경할 때
지형 아틀라스바이옴 라이브러리에서 Compile한 Texture와 색상 Ramp를 사용해 페인트된 지표면을 렌더링합니다.Texture 기반의 Rock, Sand, 풀, Water-like 표면 및 머티리얼 디테일에 사용합니다. 전용 Terrain Shader는 SH_DPT_VCTerrain입니다.
직접 정점 색상Atlas 기반 바이옴 Texture 대신 메시 Vertex에 표면 Color를 저장합니다.더 단순한 색상 기반 스타일에 사용합니다. Vertex 수와 위치가 페인트 가능한 색상 디테일의 정도를 결정합니다.
바이옴 라이브러리재사용 가능한 Ground 프리셋 모음입니다. 두 Pipeline은 하나의 Library 안에 서로 다른 프리셋 List를 가집니다.관련 Terrain Piece는 하나의 Library를 공유하고, 표면이 독립적으로 변경되어야 한다면 별도 Copy를 사용합니다.
반경World Metre 단위의 브러시 범위입니다.넓은 지형 형태에는 큰 반경을, 마무리에는 작은 반경을 사용합니다. 지오메트리와 페인트가 같은 영역에 적용되어야 한다면 반경을 연결합니다.
지오메트리 속도 / 강도Stroke가 메시를 얼마나 빠르게 움직이는지 결정합니다.정밀한 변경에는 낮게 설정합니다. 너무 높으면 짧은 Stroke에서도 깊은 홈이나 높은 Spike가 생길 수 있습니다.
페인트 불투명도선택한 표면이 기존 표면을 얼마나 강하게 대체하거나 혼합하는지 결정합니다.낮은 값은 약한 Stroke를 반복해 조절할 수 있고 1은 선택 표면을 강하게 적용합니다.
블렌드 선명도페인트된 바이옴 사이 경계의 성격을 정합니다.낮추면 점진적인 전환, 높이면 더 뚜렷한 Patch가 됩니다. 메시 Vertex를 추가하지는 않습니다.
브러시 형태원, 사각형, 마름모, 노이즈 지터가 Stroke의 Footprint를 바꿉니다.원이 좋은 시작점입니다. 의도적인 직선형 Edge에는 더 각진 Shape를 사용하고 불규칙한 흔적에는 지터를 사용합니다.
펜 필압최소 Pressure Floor와 함께 강도, 반경 또는 둘 다에 영향을 줄 수 있습니다.Tablet Stroke를 점진적으로 만들려면 강도, 누를수록 브러시를 넓히려면 반경을 선택합니다.
미리보기 색상편집 가능한 지오메트리와 페인트 Color로 두 브러시 Footprint를 구분합니다. Alpha는 미리보기 투명도를 바꿉니다.Terrain에서 잘 보이는 색을 사용합니다. 이 색은 실제로 페인트되는 바이옴을 바꾸지 않습니다.
작업등 / 씬 HUD추가 작업용 Light와 현재 Tool을 보여 주는 간단한 표시입니다.형태를 확인하고 어떤 Tool이 활성화되어 있는지 놓치지 않도록 사용합니다. 최종 결과는 Scene의 실제 Lighting에서도 확인하십시오.

Pipeline을 바꾸면 Terrain Surface Data를 사용하는 방식이 달라집니다. 완성된 작업을 변환하기 전에 Copy를 저장하고 변환 뒤 외형을 비교하십시오. 지형 아틀라스의 Texture 디테일이 직접 정점 색상에서 동일하게 보일 것이라고 기대해서는 안 됩니다.

개별 프리셋, Texture Input, Library 작업은 바이옴 가이드를 참고하십시오. 머티리얼 전체에 영향을 주는 설정은 지형 머티리얼 설정을 참고하십시오. 바이옴 기반 풀, Flower, Mushroom, Pebble 및 사용자 지정 메시 배치는 3D 스캐터 가이드를 참고하십시오.

시작 형태 생성하기

지형 생성을 열고 평면 지형, 행성, 떠 있는 섬 중 하나를 선택합니다. 각 Generator는 지형 머티리얼이 적용된 메시를 만들고 편집 대상으로 등록합니다. 조각나 세부 페인트를 시작하기 전에 목적에 맞는 시작 형태와 바이옴을 설정하십시오.

배치, 프리뷰, 바이옴 선택

실시간 미리보기는 Scene View에 임시 저해상도 회색 메시를 표시합니다. 위치, 크기, 실루엣을 판단하는 데 사용합니다. 최종 Terrain은 선택한 전체 해상도를 사용하며 회색 미리보기는 완성된 바이옴 Texture의 미리보기가 아닙니다.

생성 위치배치
월드 원점(0, 0, 0)에서 시작합니다.
위치 오프셋월드 원점을 기준으로 입력한 절대 XYZ 위치를 사용합니다.
Scene View 중심Scene View Camera의 Orbit Pivot을 사용합니다.
지면 스냅 뷰View의 X/Z 위치를 사용하고 Y = 0으로 설정합니다. 임의의 Terrain 표면에 Raycast하여 붙는 기능은 아닙니다.

시작 바이옴은 평면 지형과 행성의 초기 표면을 선택합니다. Picker는 현재 표면 Pipeline과 Library를 따릅니다. 떠 있는 섬은 아래에 설명하는 상단 바이옴과 하단 바이옴을 별도로 사용합니다. 생성 뒤에는 모든 표면을 다시 페인트할 수 있습니다.

평면 지형

형태 프리셋에서 평면, 섬 산, 강 계곡 또는 분화구 분지를 선택합니다. 평면 지형은 Generator Category이며 Height 프리셋을 사용해 Hill과 Depression도 만들 수 있습니다.

Control용도
표면 이름생성되는 Terrain Object의 이름을 지정합니다.
Quick Size / Tile Size (Square)정사각형 Tile의 폭과 길이를 metre 단위로 정합니다. Quick Size는 25, 50, 100, 250, 500, 1000 m를 제공합니다.
격자 세분화X와 Z 방향의 Grid 밀도를 정합니다. 밀도 버튼은 32, 64, 128, 256을 시작값으로 제공합니다.
고밀도 경계내부 해상도는 유지하면서 영구 Tile Edge의 밀도를 두 배로 만듭니다. Tile 전체 밀도를 두 배로 하지 않고 Seam Support를 추가합니다.
메시 Complexity예상 Vertex/Triangle 수와 Quad 간격을 표시합니다. 크고 조밀한 Terrain을 만들기 전에 확인하십시오.

준비가 되면 표면 생성을 클릭합니다. 처음부터 모든 Tile을 최대 해상도로 만들기보다 필요한 큰 특징을 표현할 정도의 지오메트리를 선택하고 세부 영역은 나중에 추가하십시오.

행성: 연속형 또는 Tile형

소행성 이름, 시작 바이옴, 반경, 메시 구조를 설정합니다. 단일 메시는 하나의 연속 Object를 만들고 다중 타일은 큐브의 여섯 Face에 Tile 배열을 만듭니다.

Structure형태 및 밀도 설정용도
단일 메시형태 프리셋: 구, 큐브 또는 둥근 큐브. 둥근 큐브는 둥근 정도를 0(큐브)부터 1(구)까지 설정합니다. 큐브 Shape는 면 격자 밀도를 사용합니다.연속된 닫힌 Base를 만듭니다. 상자 형태의 World를 뒤집어 Room으로 만드는 용도도 포함합니다.
단일 메시 구구 토폴로지: 큐브 구, 정이십면체 구 또는 UV Sphere. 큐브 구는 면 격자 밀도, 정이십면체 구는 재귀적 세분화 수준, UV Sphere는 해상도를 사용합니다.원하는 형태와 편집 방식에 맞는 Triangle 분포를 선택합니다. 서로 다른 토폴로지 Type의 밀도 값은 동일한 의미가 아닙니다.
다중 타일형태 프리셋: 소행성 또는 큐브. Tiles Per Face (N×N), 자동 Tile Size, 타일 격자 세분화, 고밀도 경계.서로 분리해 편집할 수 있는 Terrain Tile입니다. 총 Tile 수는 6 × N²이며 N=2면 24개, N=4면 96개입니다.

다중 타일에서 각 Face가 맞닿도록 Tile Size는 (2 × 반경) / Tiles Per Face로 계산됩니다. 고밀도 경계는 Projection 전에 각 Tile Edge의 밀도를 두 배로 하며 Face 사이 Seam과 큐브 Corner도 포함합니다. 소행성 생성을 클릭한 뒤 Join을 확인하고 월드 위쪽 방향이 맞지 않는 곳에서는 표면-oriented 브러시를 사용하십시오.

Interior를 만들려면 단일 메시 큐브 또는 둥근 큐브를 생성하고 마스크 Mode에서 모든 Face를 선택한 뒤 면 뒤집기를 사용합니다. 이는 별도의 Generator Type이 아니라 편집 작업입니다.

떠 있는 섬

떠 있는 섬은 위쪽 Plateau와 조형된 Underside를 가진 닫힌 메시입니다. 이름, 배치, 두 바이옴을 설정한 뒤 위와 아래의 실루엣을 모두 확인하십시오.

가장자리 블렌드 폭Rim 양쪽에서 두 바이옴이 섞이는 거리를 metre 단위로 정합니다. 공유 Rim은 동일한 비율로 섞입니다. 양쪽에 같은 바이옴을 선택하면 이 Control은 비활성화됩니다.
폭 (X), 길이 (Z), 밑면 깊이 (Y)섬의 수평 크기와 아래 방향 깊이를 정합니다.

동적 토폴로지와 노멀

동적 토폴로지는 작업에 더 작은 Triangle이 필요할 때 지오메트리를 추가합니다. Max Edge Length는 Edge가 너무 길다고 판단하는 기준입니다. 값이 낮을수록 더 세밀한 지오메트리가 만들어지고 보통 Processing과 Memory 비용이 늘어납니다. 동굴/터널 작업에 사용되며 지원되는 조각 또는 페인트 Workflow에서도 활성화할 수 있습니다.

큰 Triangle 때문에 원하는 형태를 만들 수 없을 때 사용하십시오. 모든 거친 메시를 균일한 고밀도 Grid로 바꾸는 기능은 아닙니다. 큰 변경 뒤에는 Wireframe을 확인하고 Scene 크기에 맞는 Threshold를 사용하십시오.

전역 Smooth / Sharp 셰이딩 Button은 씬 HUD 옆에 있습니다. 선명 노멀은 개별 Polygon을 강조하고 스무딩 노멀은 Terrain 메시 Face 사이의 Lighting을 부드럽게 연결합니다. Vertex를 실제로 움직이는 스무딩 브러시 및 Scatter Variant의 스무딩 각도와는 별개의 설정입니다.

Face 선택, 편집 범위 제한, 형태 만들기

  1. 마스크를 활성화하고 선택 방식을 고릅니다. 브러시는 영역을 칠해 선택하고 단일 면은 개별 Face를 정밀하게 선택하며 연결 영역 선택은 연결된 영역을 선택합니다.
  2. 원하는 형태의 Footprint가 될 Face를 선택합니다. Shift를 누르면 선택에서 Face를 제거할 수 있습니다.
  3. 늘리기, 축소, 반전으로 선택을 다듬습니다. 경사 선택은 Degree Range를 사용하고 바이옴 면 선택은 선택한 표면 ID를 사용합니다.
  4. 이동 또는 회전의 Scene 뷰 기즈모로 선택한 Face를 조정하거나 작업 또는 형태 프리셋을 선택합니다. 적용 전에 영향을 받는 영역을 확인하십시오.
  5. 위에서뿐 아니라 옆에서도 결과를 확인합니다. 필요하면 실행 취소한 뒤 Footprint나 설정을 조정합니다.

선택과 페인트 경계

브러시 드래그는 원 또는 사각형 Footprint로 Patch를 선택하고 단일 면은 개별 Triangle을 선택하며 연결 영역 선택은 연결 영역을 선택합니다. Shift는 Face를 제거합니다. 늘리기와 축소는 선택을 한 Face Ring씩 늘리거나 줄이고 반전은 반대 영역을 선택하며 지우기는 현재 선택을 지웁니다. Counter에는 여러 Tile에 걸친 선택 Face 수가 표시됩니다.

절차적 선택을 사용하려면 경사 Angles를 설정한 뒤 경사 선택을 클릭하거나 바이옴 ID을 입력하고 바이옴 면 선택을 사용합니다. 모두 선택은 Face Inversion 같은 전체 메시 작업에 유용합니다.

가장자리 페인트는 페인트 작업과 자동으로 페인트되는 Generated Shape에 적용됩니다. 선명은 선명한 Face Boundary를 유지하고 블렌드는 인접 Face 사이 표면 전환을 부드럽게 합니다. 이 설정은 페인트 Edge를 제어하고 저장된 편집 마스크는 어디를 편집할 수 있는지 제어합니다.

마스크로 선택한 면 이동 및 회전하기

  1. 마스크 도구로 조정할 면을 선택합니다.
  2. 표면 편집에서 선택을 이동 또는 회전으로 전환합니다.
  3. Scene 뷰에서 기즈모를 드래그합니다. 이동은 월드 축을 따라 이동하고 회전은 선택 영역의 중심을 기준으로 회전합니다.
  4. 면 선택을 변경하거나 다듬으려면 선택으로 돌아갑니다.

공유 경계 정점이 선택 영역과 함께 움직이므로 인접한 면도 그에 맞춰 변형됩니다. 활성 지형 타일 사이에서도 용접된 정점의 복사본이 함께 움직여 주변 지오메트리와의 연결을 유지합니다. 크게 이동하거나 회전한 뒤에는 옆에서도 형태를 확인하십시오.

드래그 중 Escape를 누르면 해당 드래그를 취소합니다. 완료한 편집은 실행 취소와 다시 실행을 지원합니다. 저장된 편집 마스크가 있으면 잠긴 경계는 계속 보호됩니다.

X, Y, Z축을 따라 정렬하기

수평 맞추기 옆에서 월드 축을 선택한 뒤 선택한 면에 적용합니다. Y는 높이를 맞춰 수평 플랫폼을 만듭니다. 수평축인 X 또는 Z를 선택하면 벽이나 측면을 정렬할 수 있습니다. 각 옵션은 선택한 정점을 해당 축의 평균 좌표로 옮기며 인접한 면도 공유 정점을 따라 움직입니다. 타일 경계에서도 연결이 유지됩니다.

경사진 영역이나 행성 표면처럼 선택 영역의 평균 표면 방향에 맞춘 평면이 필요하면 평탄화를 사용합니다.

저장한 영역으로 편집 제한하기

  1. 마스크 Tool로 편집할 Face를 선택합니다.
  2. 마스크 설정을 클릭해 해당 선택을 편집 영역으로 저장합니다.
  3. 편집 마스크를 활성화하면 그 영역 안에서만 페인트와 조각이 가능합니다. 바깥 Face는 보호됩니다. 공유 Boundary Vertex는 고정되므로 인접 Face와 Weld된 Tile Seam이 서로 벌어지지 않습니다.
  4. 편집 마스크를 끄면 제한을 일시 중지하고 다시 켜면 같은 제한을 재개합니다. 기본 Shortcut은 Ctrl/Cmd + Shift + L이며 단축키 안내에서 바꿀 수 있습니다.

저장된 편집 마스크는 현재 Face Selection과 별개입니다. 현재 선택을 늘리기, 지우기 또는 교체해도 저장 영역은 바뀌지 않습니다. 새 Boundary를 원하면 마스크 설정을 다시 사용하십시오. 공유 Boundary를 고정해야 하므로 매우 좁은 Selection은 실제로 움직일 수 있는 내부 Vertex가 적을 수 있습니다.

Extrusion이나 Hole Filling 전에 활성 편집 마스크를 지우십시오. 마스크가 일시 중지된 상태에서 작업이 Face를 재구성하면 Tool이 저장된 마스크를 지우고 알림을 표시할 수 있습니다. 토폴로지 변경 뒤 새 영역을 선택하고 마스크 설정을 다시 사용하십시오.

반전은 어떤 Face가 선택되는지를 바꾸고 면 뒤집기는 메시 자체를 바꿉니다. 노멀 Recalculation 및 지원되는 Subdivision, Cleanup, LOD Workflow는 선택한 Face Orientation을 유지합니다. 닫힌 표면의 일부만 반전하면 인접 Face가 서로 반대 방향을 향할 수 있으므로 Local Selection을 반전한 뒤 Join을 확인하십시오.

Step 만들기

계단 조각 Operation을 선택합니다. Step Height는 각 Step의 수직 높이이며 Step Depth는 경로 방향의 수평 Tread 길이를 독립적으로 제어합니다. Step Bevel은 Edge 둥근 정도를 정합니다. 낮은 값은 더 날카롭고 높은 값은 더 닳거나 둥근 Edge를 만듭니다.

Character 크기에 맞춰 Height와 Depth를 정한 뒤 옆에서 Stair를 확인하십시오. Bevel은 필요한 평평함 Tread를 없애지 않으면서 Edge만 부드럽게 해야 합니다. 원하는 간격을 표현할 충분한 지오메트리를 추가하십시오. 매우 거친 Terrain에서 긴 Stair Run을 만들면 더 세밀한 토폴로지가 필요할 수 있습니다.

중앙과 Bank 페인트하기

경로 그라디언트는 Route를 따라 바이옴을 바꿉니다. Stop Position 0은 시작, 1은 끝입니다. Dirt, Gravel, Rock 같은 구간을 위해 Stop을 추가합니다. Bank Control은 Side 쪽에 별도 바이옴을 배치하며 Bank Width는 metre가 아니라 Half-width의 비율입니다. 예를 들어 0.35는 각 Side Half-width의 바깥 35%를 사용합니다.

미리보기는 인접 표면이 어디에서 Influence를 공유하는지 보여 줍니다. 페인트 전에 Bank와 전환을 확인하십시오. River 바이옴을 페인트하면 강처럼 보이는 Strip은 만들 수 있지만 실제 Channel 지오메트리가 필요하면 Bed를 별도로 Carve해야 합니다.

터널 만들기

터널로 전환하고 Terrain을 통과하도록 Route를 배치합니다. Cross-section은 원, 사각형 또는 평평한 바닥 아치를 선택합니다. 터널에 Walking 표면이 필요하면 평평함 Bottom이 유용합니다.

Minimum cover depth는 터널 위에 필요한 Solid Terrain 두께입니다. Route Centre가 지하에 있어도 전체 Width나 Height가 외부로 뚫고 나오면 유효하지 않을 수 있습니다. 빨간색 또는 Invalid 미리보기 영역을 확인하고 Route를 더 깊게 옮기거나 크기를 줄이거나 목적에 맞게 Cover Requirement를 조정하십시오.

터널 생성은 지오메트리를 바꾸고 터널 페인트는 Wall 표면을 바꿉니다. 생성 뒤 Entrance, Exit 및 Tile Boundary를 확인하십시오.

다리 만들기

다리로 전환합니다. 연결할 Landmass에 양 끝을 놓고 Gap 위에 Intermediate Node를 사용합니다. 평평한 상판은 단순한 Deck, 깊은 거더는 더 깊은 Structural Profile, 아치형 밑면은 평평함 Walking Top 아래에 아치를 추가합니다.

특히 각 Landmass와 만나는 부분을 중심으로 다리를 위와 아래에서 확인하십시오. Curved World에서는 World-up 배치가 행성의 모든 면에 적합하다고 가정하지 말고 전체 Span이 Terrain을 충분히 통과하는지 확인합니다.

필요할 때 정확한 Endpoint 선택하기

터널과 다리는 기본적으로 Endpoint를 자동 배치합니다. 특정 Opening이나 Join이 필요하면 Pick 시작 또는 Pick 끝으로 Endpoint Face나 연결 Face Patch를 선택합니다. 양 끝은 독립적이므로 시작만, 끝만 또는 둘 다 고정할 수 있습니다.

원하는 Opening과 Boundary가 일치하는 관련 Terrain Object의 연결 Patch를 선택합니다. 사각형 또는 Rectangular Patch는 의도적인 사각형 끝에 유용합니다. Endpoint Selection을 지우기하면 해당 끝은 자동 배치로 돌아갑니다. 고정 Endpoint 근처 Face를 삭제하거나 재구성했다면 토폴로지가 바뀌었는지 확인하고 필요하면 다시 선택하십시오.

Terrain Tile을 가로질러 작업하기

Tile은 큰 Terrain을 여러 개의 개별 메시 Object로 나눕니다. Tool의 Neighbour 및 Seam 처리를 통해 지원되는 편집은 공유 Boundary를 가로질러 동작할 수 있지만 해당 Object는 여전히 등록되어 있고 작업에 활성화되어 있어야 합니다.

  1. 생성된 Tile 배열을 사용하거나 의도한 Border가 정확히 맞닿는지 확인합니다.
  2. 대상 List에 Tile을 등록하고 페인트/조각 스위치를 확인합니다.
  3. 하나의 Seam을 가로지르는 작은 Stroke를 시험합니다. 지오메트리와 표면 전환을 모두 확인합니다.
  4. 경로, 터널 또는 Generated Feature가 여러 Tile을 가로지르면 적용 뒤 영향을 받은 모든 Join을 확인합니다.
  5. 활성 Tile만이 아니라 영향을 받은 모든 Tile 메시를 저장합니다.

머티리얼의 이음새 블렌드 설정은 Texture Projection을 블렌드합니다. 메시 Border를 Weld하거나 Hole을 복구하지는 않습니다. Seam이 이상하다면 먼저 실제 지오메트리 Gap인지, Lighting 노멀 불일치인지, Texture 전환인지 구분하십시오. 각 문제는 다른 조정이 필요합니다. 임의로 겹친 메시가 자동으로 연결된 Terrain을 형성한다고 가정해서는 안 됩니다.

Terrain 저장 및 최적화

편집을 관리하기 쉬운 상태로 유지하기

세밀한 토폴로지를 사용하기 전에 큰 형태를 먼저 만드십시오. 디테일에는 더 작은 브러시를 사용하고 추가 Triangle이 꼭 필요하지 않다면 넓은 영역에 매우 작은 Max Edge Length를 사용하지 마십시오. 지오메트리 밀도는 편집 비용에 영향을 주고 Texture 해상도는 표면 Memory와 품질에 영향을 줍니다. 하나를 낮춘다고 다른 문제가 자동으로 해결되지는 않습니다.

호환되는 지오메트리 도구와 표면 도구는 Combined Stroke 중 브러시 Data를 공유합니다. Vertex 이동은 재사용 가능한 페인트 Buffer를 유지하고 토폴로지 변경, Seam Data 변경, 실행 취소/다시 실행은 영향을 받은 Cache를 갱신합니다. 이 과정은 자동으로 이루어지며 추가 설정이 필요하지 않습니다. 반복 준비 비용을 줄이지만 조각, 토폴로지, Scatter Rebuild 비용은 여전히 Terrain과 브러시에 따라 달라집니다.

직접 정점 색상에서 Ambient Occlusion Bake하기

레이캐스트 AO 베이커는 직접 정점 색상 Workflow에서 Crevice와 Contact Area에 셰이딩을 추가합니다. Lightmap이 아니며 Scene Lighting을 대체하지 않습니다. 주요 형태가 끝난 뒤 Bake하십시오. 이후 지오메트리를 편집하면 저장된 셰이딩이 오래된 상태가 될 수 있습니다.

Ray Quality를 높이면 Bake 시간 대신 Sampling Quality가 올라갑니다. Maximum 그림자 거리는 주변 지오메트리가 얼마나 멀리까지 셰이딩에 영향을 줄 수 있는지 정하고 Contrast는 결과의 강도를 정합니다. 먼저 Test Bake를 하고 가려진 모든 영역이 검게 뭉개지지 않도록 조정하십시오.

Partition 및 LOD 생성

Chunking은 Terrain을 1×1, 2×2, 4×4, 8×8 같은 Grid로 나눕니다. 작은 Chunk는 Unity가 필요한 부분만 표시하는 데 도움이 될 수 있지만 Object와 Rendering Group 수를 늘립니다. 항상 가장 큰 Grid를 선택하기보다 Scene에 맞는 Layout을 사용하십시오.

LOD1과 LOD2는 단순화된 메시입니다. 대상 Ratio는 유지할 지오메트리 비율을 나타냅니다. 낮은 Ratio는 Triangle을 줄이지만 작은 Shape를 잃을 가능성이 커집니다. Unity 전환 Threshold는 metre 단위 거리가 아니라 상대적인 Screen Height를 사용합니다. 마지막 Culling Threshold는 Group이 더 이상 Draw되지 않는 시점을 정합니다.

생성된 Collider는 LOD2를 사용합니다. Stair, Edge, Opening이 의도한 대로 Collision하는지 확인하십시오. Triangle 기반 표면 Query를 사용한다면 표면 Data는 Collider의 실제 메시와 Triangle Order에 대응해야 합니다. 다른 메시에서 Bake된 Data는 잘못된 표면을 반환할 수 있습니다.

생성 결과에 적합한 경우 원본 메시 숨기기를 사용하고 원본과 생성본을 동시에 표시하고 있지 않은지 확인하십시오. Chunking과 LOD Generation은 마무리 Workflow로 다루십시오. 원본 Terrain의 모든 편집을 자동으로 빠르게 만들지는 않습니다.

키보드 및 마우스 참고

아래 Keyboard Binding은 기본값입니다. Scene View에서 작업할 때 Shortcut을 사용합니다. 같은 Key라도 마스크, 경로, 그라디언트, 더스팅 Mode에서 다른 동작을 할 수 있으므로 Context가 중요합니다. 편집 가능한 Input Field에 입력 중이면 텍스트 입력이 우선됩니다. macOS에서는 Ctrl/Cmd Binding에 Cmd를 사용합니다.

  • [ / ]와 Shift + Mouse Wheel은 브러시 반경을 조정합니다. Ctrl/Cmd + Shift + PageUp / PageDown은 미세하게 조정합니다.
  • Ctrl/Cmd + Shift + Up / Down은 지오메트리 Rate, Ctrl/Cmd + Shift + Left / Right은 표면 Opacity를 조정합니다. Minus/Equal Binding은 현재 Tool Context에 따라 동작합니다.
  • Ctrl + Drag는 지원되는 조각/부풀리기 Stroke 방향을 반대로 바꿉니다. Shift는 지원되는 브러시 Stroke를 일시적으로 스무딩 또는 블렌드하고 마스크 선택 중에는 Face를 제외합니다.
  • Alt + Shift + 1…9, 0은 현재 보이는 Palette Group에서 바이옴을 선택합니다. Tab / Shift + Tab은 바이옴 Page를 바꿉니다.
  • Escape는 현재 특수 상호작용을 종료하거나 Tool을 비활성화합니다. 경로 Mode를 나가도 Node는 유지됩니다. Route 자체를 삭제하려면 노드 지우기를 사용하십시오.

단축키 안내에서 Shortcut 변경하기

  1. Terrain Window에서 단축키 안내를 엽니다. Action이나 Key로 검색하거나 도구, 브러시 조정, 마스크 mode, 경로 mode 같은 Group을 펼칩니다.
  2. Action의 Key Button을 클릭한 뒤 새 Key Combination을 누릅니다. Modifier Key만 누르면 Main Key 입력을 기다립니다. Escape는 기록을 취소합니다.
  3. ×로 Binding을 지우고 초기화로 한 Action을 복원하며 기본값 복원으로 전체 목록을 기본값으로 되돌립니다.

변경 내용은 현재 Unity Editor User에 자동 저장되며 Project 사이에서 공유됩니다. Tooltip과 씬 HUD에는 현재 설정된 Key가 표시됩니다. 겹치는 Context에서 다른 Action과 Key가 충돌하면 Sheet가 해당 Action 이름을 표시하고 할당을 거부합니다. 먼저 다른 Binding을 변경하거나 지우십시오. 마스크, 경로, 그라디언트는 Context가 겹치지 않으면 같은 Key를 재사용할 수 있지만 일반 Action은 Mode 전체에 적용됩니다.

Mouse Gesture와 Unity 실행 취소/다시 실행은 고정입니다. Shift + Mouse Wheel은 반경 조정, Shift + Drag는 일시적 스무딩/블렌드 또는 선택 Face 제외, Ctrl + Drag는 Lower/Deflate, 페인트에서 Ctrl + Click은 바이옴 Sample, Shift + Click은 경로 Node를 X/Z에 제한합니다. 실행 취소는 Ctrl/Cmd + Z, 다시 실행은 Ctrl/Cmd + Shift + Z 또는 Ctrl/Cmd + Y를 사용합니다. Shortcut 기록 중이 아닐 때는 편집 가능한 Input Field의 텍스트 입력이 계속 우선됩니다.
