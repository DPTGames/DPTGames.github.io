작은 화면에서는 넓은 표를 좌우로 스크롤하여 모든 열을 확인할 수 있습니다.

Vertex 3D Terrain을 사용하면 Unity 안에서 Mesh 기반 Terrain을 직접 생성하고 편집할 수 있습니다. 일반적인 Ground, Planet, Floating Island를 만든 뒤 Geometry를 변형하고 Surface를 Paint하며 Path와 Structure를 만들고 Gradient를 적용하고 여러 Terrain Tile을 가로질러 작업할 수 있습니다.

Geometry Tool은 실제 Mesh를 바꾸고 Surface Tool은 외형을 바꿉니다. 호환되는 Geometry Tool과 Surface Tool은 같은 Stroke에서 함께 사용할 수 있으므로 Terrain을 변형하면서 동시에 Paint할 수 있습니다.

첫 번째 지형 만들기

  1. Tools → DPT Games → Vertex 3D Terrain을 엽니다.
  2. Create Terrain을 열고 만들 지형 유형을 Flat Terrain, Planet, Floating Island 중에서 선택합니다.
  3. Starting Biome을 선택합니다. Floating Island에서는 Top Biome과 Bottom Biome을 선택합니다. 지형의 크기, 형태, 해상도도 조정합니다. 사용할 수 있는 항목은 선택한 지형 유형에 따라 달라집니다. 예를 들어 Floating Island에서는 폭, 길이, 하부 깊이, Plateau Shape, 하부 형태, Surface Variation을 설정할 수 있습니다.
  4. Spawn Position으로 지형을 생성할 위치를 선택합니다. Live Preview가 활성화되어 있다면 생성 전에 전체 크기와 형태를 확인합니다.
  5. 선택한 지형 유형에 맞는 생성 버튼을 클릭합니다. 예: Generate Floating Island, Generate Planetoid, Generate Surface.
  6. 생성된 지형은 Geometry Tool과 Surface Tool로 바로 편집할 수 있습니다. 메시를 Sculpt하거나 형태를 바꾸고, 바이옴을 Paint하고, Path와 Gradient를 만들고, Mask로 Face를 선택할 수 있습니다. 호환되는 Geometry Tool과 Surface Tool은 같은 Stroke에서 함께 사용할 수도 있습니다.
  7. 작은 디테일을 추가하기 전에 전체 형태부터 크게 조정합니다. 더 세밀한 편집이 필요한 영역은 나중에 로컬 Geometry Density를 늘릴 수 있습니다.
  8. 결과가 만족스러우면 Unity Scene과 유지할 Generated Asset과 함께 지형을 저장합니다.

첫 연습으로 좋은 방법: 작은 지형을 하나 생성하고 Sculpt로 실루엣 일부를 바꾼 뒤 Paint, Path 또는 다른 Surface Tool을 시험해 보십시오. 더 큰 Scene을 만들기 전에 생성과 편집의 기본 흐름을 빠르게 익힐 수 있습니다.

편집 대상, 라이브러리, 브러시 설정

무엇을 편집할지 선택하기

Active Terrain은 현재 Mesh와 설정을 제공합니다. 여러 오브젝트로 이루어진 지형에서는 Target List를 사용해 어떤 오브젝트를 Paint 또는 Sculpt할 수 있는지 선택합니다. Active와 Paint/Sculpt 활성화는 역할이 다릅니다. 한 Tile을 선택했다고 해서 주변 Tile이 모두 자동으로 편집 가능해지는 것은 아닙니다.

필요한 Terrain Object를 추가하거나 등록하고 Scene 구성이 바뀌면 목록을 새로 고칩니다. 경계를 가로지르는 Stroke를 사용하기 전에 Paint/Sculpt 스위치를 확인하십시오. Target에는 Tool이 사용하는 Mesh Component가 있어야 합니다. 런타임에 Physics Raycast로 지형을 감지하려면 Collider도 필요합니다.

시작 형태 생성하기

Create Terrain을 열고 Flat Terrain, Planet, Floating Island 중 하나를 선택합니다. 각 Generator는 Terrain Material이 적용된 Mesh를 만들고 편집 Target으로 등록합니다. Sculpt나 세부 Paint를 시작하기 전에 목적에 맞는 시작 형태와 바이옴을 설정하십시오.

배치, 프리뷰, 바이옴 선택

Live Preview는 Scene View에 임시 저해상도 회색 Mesh를 표시합니다. 위치, 크기, 실루엣을 판단하는 데 사용합니다. 최종 Terrain은 선택한 전체 해상도를 사용하며 회색 Preview는 완성된 Biome Texture의 Preview가 아닙니다.

Spawn Position배치
World Origin(0, 0, 0)에서 시작합니다.
Position OffsetWorld Origin을 기준으로 입력한 절대 XYZ 위치를 사용합니다.
Scene View CenterScene View Camera의 Orbit Pivot을 사용합니다.
Ground Snapped ViewView의 X/Z 위치를 사용하고 Y = 0으로 설정합니다. 임의의 Terrain Surface에 Raycast하여 붙는 기능은 아닙니다.

Starting Biome은 Flat Terrain과 Planet의 초기 Surface를 선택합니다. Picker는 현재 Surface Pipeline과 Library를 따릅니다. Floating Island는 아래에 설명하는 Top Biome과 Bottom Biome을 별도로 사용합니다. 생성 뒤에는 모든 Surface를 다시 Paint할 수 있습니다.

Flat Terrain

Shape Preset에서 Flat Plane, Island Mountain, River Valley 또는 Crater Basin을 선택합니다. Flat Terrain은 Generator Category이며 Height Preset을 사용해 Hill과 Depression도 만들 수 있습니다.

Control용도
Surface Name생성되는 Terrain Object의 이름을 지정합니다.
Quick Size / Tile Size (Square)정사각형 Tile의 폭과 길이를 metre 단위로 정합니다. Quick Size는 25, 50, 100, 250, 500, 1000 m를 제공합니다.
Grid SubdivisionsX와 Z 방향의 Grid Density를 정합니다. Density 버튼은 32, 64, 128, 256을 시작값으로 제공합니다.
High Density Borders내부 해상도는 유지하면서 영구 Tile Edge의 Density를 두 배로 만듭니다. Tile 전체 Density를 두 배로 하지 않고 Seam Support를 추가합니다.
Mesh Complexity예상 Vertex/Triangle 수와 Quad 간격을 표시합니다. 크고 조밀한 Terrain을 만들기 전에 확인하십시오.

준비가 되면 Generate Surface를 클릭합니다. 처음부터 모든 Tile을 최대 해상도로 만들기보다 필요한 큰 특징을 표현할 정도의 Geometry를 선택하고 세부 영역은 나중에 추가하십시오.

Planet: 연속형 또는 Tile형

Planetoid Name, Starting Biome, Radius, Mesh Structure를 설정합니다. Single Mesh는 하나의 연속 Object를 만들고 Multi Tile은 Cube의 여섯 Face에 Tile 배열을 만듭니다.

Structure형태 및 Density 설정용도
Single MeshShape Preset: Sphere, Cube 또는 Rounded Cube. Rounded Cube는 Roundness를 0(Cube)부터 1(Sphere)까지 설정합니다. Cube Shape는 Face Grid Density를 사용합니다.연속된 닫힌 Base를 만듭니다. Box 형태의 World를 뒤집어 Room으로 만드는 용도도 포함합니다.
Single Mesh SphereSphere Topology: Cube Sphere, Icosphere 또는 UV Sphere. Cube Sphere는 Face Grid Density, Icosphere는 재귀적 Subdivision Level, UV Sphere는 Resolution을 사용합니다.원하는 형태와 편집 방식에 맞는 Triangle 분포를 선택합니다. 서로 다른 Topology Type의 Density 값은 동일한 의미가 아닙니다.
Multi TileShape Preset: Planetoid 또는 Cube. Tiles Per Face (N×N), 자동 Tile Size, Tile Grid Subdivisions, High Density Borders.서로 분리해 편집할 수 있는 Terrain Tile입니다. 총 Tile 수는 6 × N²이며 N=2면 24개, N=4면 96개입니다.

Multi Tile에서 각 Face가 맞닿도록 Tile Size는 (2 × Radius) / Tiles Per Face로 계산됩니다. High Density Borders는 Projection 전에 각 Tile Edge의 Density를 두 배로 하며 Face 사이 Seam과 Cube Corner도 포함합니다. Generate Planetoid를 클릭한 뒤 Join을 확인하고 World Up 방향이 맞지 않는 곳에서는 Surface-oriented Brush를 사용하십시오.

Interior를 만들려면 Single Mesh Cube 또는 Rounded Cube를 생성하고 Mask Mode에서 모든 Face를 선택한 뒤 Invert Faces를 사용합니다. 이는 별도의 Generator Type이 아니라 편집 작업입니다.

Floating Island

Floating Island는 위쪽 Plateau와 조형된 Underside를 가진 닫힌 Mesh입니다. 이름, 배치, 두 Biome을 설정한 뒤 위와 아래의 실루엣을 모두 확인하십시오.

Bottom Keel ShapePointed Spire, Rounded Bowl, Stepped Crag 또는 Flat Taper Profile을 선택합니다.

Generate Floating Island를 클릭합니다. Edge Radius는 Geometry를 바꾸고 Edge Blend Width는 Biome Transition을 바꿉니다. 두 값을 따로 조정한 뒤 Paint나 Scatter 배치 전에 Underside도 확인하십시오.

Surface Variation

Surface Variation을 활성화하면 생성 Terrain, Planetoid, Floating Island Top에 결정론적인 Height Variation을 추가할 수 있습니다. Island Underside의 Rock Jaggedness와는 별개입니다.

Control의미
Strength최대 Height Displacement를 metre 단위로 정합니다. 선택한 Base Shape를 유지하려면 낮은 값부터 시작하십시오.
Feature SizeWorld Space에서 가장 큰 Noise Feature의 대략적인 크기입니다. 값이 클수록 넓은 Hill이 만들어집니다.
DetailFractal Noise Layer 수로 1부터 6까지입니다. Layer가 많을수록 더 세밀한 Variation이 추가되며 이를 표현할 충분한 Geometry가 필요합니다.
World Seed / RandomizeSeed를 편집하거나 Randomize를 누르기 전까지 Pattern을 동일하게 유지합니다. 설정을 재현해야 한다면 Seed를 보관하십시오.

Live Preview로 설정을 비교한 뒤 최종 판단은 Full-resolution Generated Result에서 하십시오. 거친 Grid에 강한 Variation을 적용해도 미세한 Detail을 만들 수 없으며 Noise 추가와 Surface Texture Painting은 별개의 작업입니다.

Geometry Tool과 Surface Tool

Tool에는 Geometry와 Surface를 위한 별도의 선택 항목이 있습니다. 일부 Brush Tool은 함께 사용할 수 있으므로 한 Stroke에서 형태를 바꾸면서 Paint할 수 있습니다. Path, Mask, Gradient는 각각의 전용 편집 Workflow를 사용합니다. Drag하기 전에 Active Button과 Scene HUD를 확인하십시오.

On/Off Control은 Button입니다. 활성화된 Geometry Control은 녹색으로 강조되고 다른 영역의 활성 Control은 파란색으로 강조되며 비활성 상태는 회색입니다. Path Control도 다른 Geometry Tool과 같은 녹색 강조를 사용합니다. 공간이 허용되면 관련 Action은 Compact Row에 함께 표시됩니다.

Dynamic Topology와 Normal

Dynamic Topology는 작업에 더 작은 Triangle이 필요할 때 Geometry를 추가합니다. Max Edge Length는 Edge가 너무 길다고 판단하는 기준입니다. 값이 낮을수록 더 세밀한 Geometry가 만들어지고 보통 Processing과 Memory 비용이 늘어납니다. Cave/Tunnel 작업에 사용되며 지원되는 Sculpt 또는 Paint Workflow에서도 활성화할 수 있습니다.

큰 Triangle 때문에 원하는 형태를 만들 수 없을 때 사용하십시오. 모든 거친 Mesh를 균일한 고밀도 Grid로 바꾸는 기능은 아닙니다. 큰 변경 뒤에는 Wireframe을 확인하고 Scene Scale에 맞는 Threshold를 사용하십시오.

전역 Smooth / Sharp Shading Button은 Scene HUD 옆에 있습니다. Sharp Normal은 개별 Polygon을 강조하고 Smooth Normal은 Terrain Mesh Face 사이의 Lighting을 부드럽게 연결합니다. Vertex를 실제로 움직이는 Smooth Brush 및 Scatter Variant의 Smoothing Angle과는 별개의 설정입니다.

Face 선택, 편집 범위 제한, 형태 만들기

  1. Mask를 활성화하고 선택 방식을 고릅니다. Brush는 영역을 칠해 선택하고 Single Face는 개별 Face를 정밀하게 선택하며 Flood Island는 연결된 영역을 선택합니다.
  2. 원하는 형태의 Footprint가 될 Face를 선택합니다. Shift를 누르면 선택에서 Face를 제거할 수 있습니다.
  3. Grow, Shrink, Invert로 선택을 다듬습니다. Select Slope는 Degree Range를 사용하고 Select Biome Faces는 선택한 Surface ID를 사용합니다.
  4. 작업 또는 Shape Preset을 선택합니다. 적용 전에 영향을 받는 영역을 확인하십시오.
  5. 위에서뿐 아니라 옆에서도 결과를 확인합니다. 필요하면 Undo한 뒤 Footprint나 설정을 조정합니다.

선택과 Paint 경계

Brush Drag는 Circle 또는 Square Footprint로 Patch를 선택하고 Single Face는 개별 Triangle을 선택하며 Flood Island는 연결 영역을 선택합니다. Shift는 Face를 제거합니다. Grow와 Shrink는 선택을 한 Face Ring씩 늘리거나 줄이고 Invert는 반대 영역을 선택하며 Clear는 현재 선택을 지웁니다. Counter에는 여러 Tile에 걸친 선택 Face 수가 표시됩니다.

절차적 선택을 사용하려면 Slope Angles를 설정한 뒤 Select Slope를 클릭하거나 Biome ID를 입력하고 Select Biome Faces를 사용합니다. Select All은 Face Inversion 같은 전체 Mesh 작업에 유용합니다.

Paint Edges는 Paint 작업과 자동으로 Paint되는 Generated Shape에 적용됩니다. Sharp는 선명한 Face Boundary를 유지하고 Blended는 인접 Face 사이 Surface Transition을 부드럽게 합니다. 이 설정은 Paint Edge를 제어하고 저장된 Editing Mask는 어디를 편집할 수 있는지 제어합니다.

Step 만들기

Steps Sculpt Operation을 선택합니다. Step Height는 각 Step의 수직 높이이며 Step Depth는 Path 방향의 수평 Tread 길이를 독립적으로 제어합니다. Step Bevel은 Edge Roundness를 정합니다. 낮은 값은 더 날카롭고 높은 값은 더 닳거나 둥근 Edge를 만듭니다.

Character 크기에 맞춰 Height와 Depth를 정한 뒤 옆에서 Stair를 확인하십시오. Bevel은 필요한 Flat Tread를 없애지 않으면서 Edge만 부드럽게 해야 합니다. 원하는 간격을 표현할 충분한 Geometry를 추가하십시오. 매우 거친 Terrain에서 긴 Stair Run을 만들면 더 세밀한 Topology가 필요할 수 있습니다.

중앙과 Bank Paint하기

Path Gradient는 Route를 따라 Biome을 바꿉니다. Stop Position 0은 시작, 1은 끝입니다. Dirt, Gravel, Rock 같은 구간을 위해 Stop을 추가합니다. Bank Control은 Side 쪽에 별도 Biome을 배치하며 Bank Width는 metre가 아니라 Half-width의 비율입니다. 예를 들어 0.35는 각 Side Half-width의 바깥 35%를 사용합니다.

Preview는 인접 Surface가 어디에서 Influence를 공유하는지 보여 줍니다. Paint 전에 Bank와 Transition을 확인하십시오. River Biome을 Paint하면 강처럼 보이는 Strip은 만들 수 있지만 실제 Channel Geometry가 필요하면 Bed를 별도로 Carve해야 합니다.

Tunnel 만들기

Tunnel로 전환하고 Terrain을 통과하도록 Route를 배치합니다. Cross-section은 Circle, Square 또는 Flat Bottom Arch를 선택합니다. Tunnel에 Walking Surface가 필요하면 Flat Bottom이 유용합니다.

Minimum cover depth는 Tunnel 위에 필요한 Solid Terrain 두께입니다. Route Centre가 지하에 있어도 전체 Width나 Height가 외부로 뚫고 나오면 유효하지 않을 수 있습니다. 빨간색 또는 Invalid Preview 영역을 확인하고 Route를 더 깊게 옮기거나 크기를 줄이거나 목적에 맞게 Cover Requirement를 조정하십시오.

Create Tunnel은 Geometry를 바꾸고 Paint Tunnel은 Wall Surface를 바꿉니다. 생성 뒤 Entrance, Exit 및 Tile Boundary를 확인하십시오.

Bridge 만들기

Bridge로 전환합니다. 연결할 Landmass에 양 끝을 놓고 Gap 위에 Intermediate Node를 사용합니다. Flat Deck은 단순한 Deck, Deep Girder는 더 깊은 Structural Profile, Arched Underside는 Flat Walking Top 아래에 Arch를 추가합니다.

특히 각 Landmass와 만나는 부분을 중심으로 Bridge를 위와 아래에서 확인하십시오. Curved World에서는 World-up 배치가 Planet의 모든 면에 적합하다고 가정하지 말고 전체 Span이 Terrain을 충분히 통과하는지 확인합니다.

필요할 때 정확한 Endpoint 선택하기

Tunnel과 Bridge는 기본적으로 Endpoint를 자동 배치합니다. 특정 Opening이나 Join이 필요하면 Pick Start 또는 Pick End로 Endpoint Face나 연결 Face Patch를 선택합니다. 양 끝은 독립적이므로 Start만, End만 또는 둘 다 고정할 수 있습니다.

원하는 Opening과 Boundary가 일치하는 관련 Terrain Object의 연결 Patch를 선택합니다. Square 또는 Rectangular Patch는 의도적인 Square End에 유용합니다. Endpoint Selection을 Clear하면 해당 끝은 자동 배치로 돌아갑니다. 고정 Endpoint 근처 Face를 삭제하거나 재구성했다면 Topology가 바뀌었는지 확인하고 필요하면 다시 선택하십시오.

Terrain Tile을 가로질러 작업하기

Tile은 큰 Terrain을 여러 개의 개별 Mesh Object로 나눕니다. Tool의 Neighbour 및 Seam 처리를 통해 지원되는 편집은 공유 Boundary를 가로질러 동작할 수 있지만 해당 Object는 여전히 등록되어 있고 작업에 활성화되어 있어야 합니다.

  1. 생성된 Tile 배열을 사용하거나 의도한 Border가 정확히 맞닿는지 확인합니다.
  2. Target List에 Tile을 등록하고 Paint/Sculpt 스위치를 확인합니다.
  3. 하나의 Seam을 가로지르는 작은 Stroke를 시험합니다. Geometry와 Surface Transition을 모두 확인합니다.
  4. Path, Tunnel 또는 Generated Feature가 여러 Tile을 가로지르면 적용 뒤 영향을 받은 모든 Join을 확인합니다.
  5. Active Tile만이 아니라 영향을 받은 모든 Tile Mesh를 저장합니다.

Material의 Seam Blend 설정은 Texture Projection을 Blend합니다. Mesh Border를 Weld하거나 Hole을 복구하지는 않습니다. Seam이 이상하다면 먼저 실제 Geometry Gap인지, Lighting Normal 불일치인지, Texture Transition인지 구분하십시오. 각 문제는 다른 조정이 필요합니다. 임의로 겹친 Mesh가 자동으로 연결된 Terrain을 형성한다고 가정해서는 안 됩니다.

Terrain 저장 및 최적화

편집을 관리하기 쉬운 상태로 유지하기

세밀한 Topology를 사용하기 전에 큰 형태를 먼저 만드십시오. Detail에는 더 작은 Brush를 사용하고 추가 Triangle이 꼭 필요하지 않다면 넓은 영역에 매우 작은 Max Edge Length를 사용하지 마십시오. Geometry Density는 편집 비용에 영향을 주고 Texture Resolution은 Surface Memory와 품질에 영향을 줍니다. 하나를 낮춘다고 다른 문제가 자동으로 해결되지는 않습니다.

호환되는 Geometry Tool과 Surface Tool은 Combined Stroke 중 Brush Data를 공유합니다. Vertex 이동은 재사용 가능한 Paint Buffer를 유지하고 Topology 변경, Seam Data 변경, Undo/Redo는 영향을 받은 Cache를 갱신합니다. 이 과정은 자동으로 이루어지며 추가 설정이 필요하지 않습니다. 반복 준비 비용을 줄이지만 Sculpt, Topology, Scatter Rebuild 비용은 여전히 Terrain과 Brush에 따라 달라집니다.

Direct Vertex Color에서 Ambient Occlusion Bake하기

Raycast AO Baker는 Direct Vertex Color Workflow에서 Crevice와 Contact Area에 Shading을 추가합니다. Lightmap이 아니며 Scene Lighting을 대체하지 않습니다. 주요 형태가 끝난 뒤 Bake하십시오. 이후 Geometry를 편집하면 저장된 Shading이 오래된 상태가 될 수 있습니다.

Ray Quality를 높이면 Bake 시간 대신 Sampling Quality가 올라갑니다. Maximum Shadow Distance는 주변 Geometry가 얼마나 멀리까지 Shading에 영향을 줄 수 있는지 정하고 Contrast는 결과의 강도를 정합니다. 먼저 Test Bake를 하고 가려진 모든 영역이 검게 뭉개지지 않도록 조정하십시오.

Partition 및 LOD 생성

Chunking은 Terrain을 1×1, 2×2, 4×4, 8×8 같은 Grid로 나눕니다. 작은 Chunk는 Unity가 필요한 부분만 표시하는 데 도움이 될 수 있지만 Object와 Rendering Group 수를 늘립니다. 항상 가장 큰 Grid를 선택하기보다 Scene에 맞는 Layout을 사용하십시오.

LOD1과 LOD2는 단순화된 Mesh입니다. Target Ratio는 유지할 Geometry 비율을 나타냅니다. 낮은 Ratio는 Triangle을 줄이지만 작은 Shape를 잃을 가능성이 커집니다. Unity Transition Threshold는 metre 단위 거리가 아니라 상대적인 Screen Height를 사용합니다. 마지막 Culling Threshold는 Group이 더 이상 Draw되지 않는 시점을 정합니다.

생성된 Collider는 LOD2를 사용합니다. Stair, Edge, Opening이 의도한 대로 Collision하는지 확인하십시오. Triangle 기반 Surface Query를 사용한다면 Surface Data는 Collider의 실제 Mesh와 Triangle Order에 대응해야 합니다. 다른 Mesh에서 Bake된 Data는 잘못된 Surface를 반환할 수 있습니다.

생성 결과에 적합한 경우 Hide Original Mesh를 사용하고 원본과 생성본을 동시에 표시하고 있지 않은지 확인하십시오. Chunking과 LOD Generation은 마무리 Workflow로 다루십시오. 원본 Terrain의 모든 편집을 자동으로 빠르게 만들지는 않습니다.

키보드 및 마우스 참고

아래 Keyboard Binding은 기본값입니다. Scene View에서 작업할 때 Shortcut을 사용합니다. 같은 Key라도 Mask, Path, Gradient, Dusting Mode에서 다른 동작을 할 수 있으므로 Context가 중요합니다. 편집 가능한 Input Field에 입력 중이면 텍스트 입력이 우선됩니다. macOS에서는 Ctrl/Cmd Binding에 Cmd를 사용합니다.

  • [ / ]와 Shift + Mouse Wheel은 Brush Radius를 조정합니다. Ctrl/Cmd + Shift + PageUp / PageDown은 미세하게 조정합니다.
  • Ctrl/Cmd + Shift + Up / Down은 Geometry Rate, Ctrl/Cmd + Shift + Left / Right은 Surface Opacity를 조정합니다. Minus/Equal Binding은 현재 Tool Context에 따라 동작합니다.
  • Ctrl + Drag는 지원되는 Sculpt/Inflate Stroke 방향을 반대로 바꿉니다. Shift는 지원되는 Brush Stroke를 일시적으로 Smooth 또는 Blend하고 Mask 선택 중에는 Face를 제외합니다.
  • Alt + Shift + 1…9, 0은 현재 보이는 Palette Group에서 Biome을 선택합니다. Tab / Shift + Tab은 Biome Page를 바꿉니다.
  • Escape는 현재 특수 상호작용을 종료하거나 Tool을 비활성화합니다. Path Mode를 나가도 Node는 유지됩니다. Route 자체를 삭제하려면 Clear Nodes를 사용하십시오.

Hotkey Sheet에서 Shortcut 변경하기

  1. Terrain Window에서 Hotkey Sheet를 엽니다. Action이나 Key로 검색하거나 Tools, Brush adjustments, Mask mode, Path mode 같은 Group을 펼칩니다.
  2. Action의 Key Button을 클릭한 뒤 새 Key Combination을 누릅니다. Modifier Key만 누르면 Main Key 입력을 기다립니다. Escape는 기록을 취소합니다.
  3. ×로 Binding을 지우고 Reset으로 한 Action을 복원하며 Restore Defaults로 전체 목록을 기본값으로 되돌립니다.

변경 내용은 현재 Unity Editor User에 자동 저장되며 Project 사이에서 공유됩니다. Tooltip과 Scene HUD에는 현재 설정된 Key가 표시됩니다. 겹치는 Context에서 다른 Action과 Key가 충돌하면 Sheet가 해당 Action 이름을 표시하고 할당을 거부합니다. 먼저 다른 Binding을 변경하거나 지우십시오. Mask, Path, Gradient는 Context가 겹치지 않으면 같은 Key를 재사용할 수 있지만 General Action은 Mode 전체에 적용됩니다.

Mouse Gesture와 Unity Undo/Redo는 고정입니다. Shift + Mouse Wheel은 Radius 조정, Shift + Drag는 일시적 Smooth/Blend 또는 선택 Face 제외, Ctrl + Drag는 Lower/Deflate, Paint에서 Ctrl + Click은 Biome Sample, Shift + Click은 Path Node를 X/Z에 제한합니다. Undo는 Ctrl/Cmd + Z, Redo는 Ctrl/Cmd + Shift + Z 또는 Ctrl/Cmd + Y를 사용합니다. Shortcut 기록 중이 아닐 때는 편집 가능한 Input Field의 텍스트 입력이 계속 우선됩니다.

Paint 경계가 각져 보입니다Paint 정보는 Mesh Geometry에 연결됩니다. Vertex Density를 확인한 뒤 Local Subdivision 또는 지원되는 Dynamic Topology를 고려하십시오. Blend Sharpness는 Transition을 바꾸지만 Triangle 수는 바꾸지 않습니다.
Hill이 너무 들쭉날쭉합니다Displacement Rate를 낮추고 더 넓은 Brush를 사용하며 Topology를 확인합니다. Geometry를 부드럽게 Smooth하십시오. Normal만 바꾸면 Lighting만 달라집니다.
Tunnel이 Surface를 뚫고 나옵니다전체 Route의 Width/Height와 Minimum Cover Depth를 확인합니다. 필요한 곳에서 더 깊게 이동하거나 Cross-section을 줄이십시오.
Gradient가 전체에 하나의 Surface만 Paint합니다Height 또는 Slope Range가 Terrain을 포함하는지, Cone이 Terrain과 겹치는지, Ramp Stop이 의도한 Biome ID를 사용하는지 확인합니다.
Tile 사이에 Seam이 보입니다먼저 실제 Geometry Gap을 찾고 Registration, 활성 Neighbour, Normal, Material Setting을 확인합니다. Projection Seam Blend는 Geometry Gap을 닫을 수 없습니다.
다른 Terrain의 외형도 바뀝니다둘이 같은 Library, Material 또는 Texture Asset을 사용하는지 확인합니다. 서로 다른 설정이 필요하면 독립 Copy를 만드십시오.
Character가 Feature를 통과하거나 위에 떠 있습니다Collider가 편집된 Mesh를 반영하는지 확인합니다. Chunk Collider를 생성했다면 LOD2 Simplification도 확인하십시오.
Gameplay에서 잘못된 Biome을 반환합니다변경 뒤 Surface Data를 다시 Bake하고 Hit Collider의 Triangle Order와 맞춥니다. Triangle 기반 Lookup에는 유효한 Mesh Triangle이 필요하며 Mesh가 아닌 Collider Hit가 자동으로 Biome 0을 반환하지는 않습니다. Query 제한은 Raycast Tester 가이드를 참고하십시오.
편집이 느려집니다Triangle 수, Brush Reach, Dynamic Topology 설정을 확인합니다. Copy에서 불필요한 Density를 줄이고 다시 측정하며 Texture Resolution은 별도로 확인하십시오.
