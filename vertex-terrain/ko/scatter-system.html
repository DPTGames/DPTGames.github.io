재사용 가능한 설정으로 여러 Terrain Atlas 바이옴에 잔디, 꽃, 버섯, 자갈, 커스텀 메시 및 파티클 효과를 배치합니다.

작은 화면에서는 넓은 표를 좌우로 스크롤하여 모든 열을 확인할 수 있습니다.

3D Scatter 시스템은 Terrain Atlas Biome Data에서 Instanced Mesh와 파티클 방출 지점을 직접 배치합니다. Scatter Object는 Mesh Variant, Particle Effect 또는 두 가지 모두를 위한 재사용 가능한 배치 규칙을 저장합니다. 바이옴마다 동일한 Grass 설정을 새로 만들 필요 없이 한 Object에 여러 Target Biomes를 추가하고 필요할 때 각 Target의 Density Multiplier를 다르게 설정할 수 있습니다.

Scatter는 잔디, 꽃, 버섯, 돌, 작은 Prop처럼 반복적으로 배치되는 Surface Detail에 적합합니다. Terrain Mesh 자체를 편집하지 않으며 각 Instance마다 Collider를 만들거나 Scatter된 오브젝트를 개별 GameObject로 변환하지 않습니다.

Scatter Library 이해하기

Scatter Authoring은 각 Biome Inspector 안에 개별 저장되는 것이 아니라 Terrain Atlas Biome Library 전체에 적용됩니다. Vertex 3D Terrain 창의 3D Scatter 섹션을 열어 Library를 만들고 편집합니다.

항목역할중요한 결과
Scatter Object재사용 가능한 배치 규칙, Mesh Variant, Particle Effect 및 Mesh Wind/Player Interaction 설정을 저장합니다.Grass를 한 번 설정한 뒤 전체 설정을 복제하지 않고 여러 바이옴을 대상으로 사용할 수 있습니다.
Target Biome선택한 Terrain Atlas 바이옴이 기여하는 위치에서 해당 Scatter Object가 생성될 수 있게 합니다.각 Target마다 0에서 2까지 별도의 Density Multiplier를 지정할 수 있습니다.
Scatter OutputMeshes, Particles 또는 Both를 선택합니다.동일한 Biome과 Placement Rule로 표시되는 Mesh 및 Particle 방출 지점을 만들 수 있습니다.
Mesh Variant내장 Preset 또는 Custom Mesh와 상대적인 선택 확률을 지정합니다.여러 Variant가 같은 배치 규칙을 공유할 수 있습니다.
Scatter SettingsSeed, Batching, Distance, LOD Transition, Far Density 및 Safety Budget을 제어합니다.각 Object마다 반복되는 설정이 아니라 Scatter Library 전체에서 공유됩니다.
Active Terrain RendererProfile을 선택된 Terrain Root에 연결하고 GPU Instanced Draw를 제출합니다.수천 개의 Instance가 Scene의 개별 GameObject로 표현되지 않습니다.

첫 Scatter Object 만들기

  1. Terrain Atlas 파이프라인을 사용하고 Terrain에 바이옴 데이터가 페인트되어 있는지 확인합니다.
  2. Vertex 3D Terrain 창에서 3D Scatter를 엽니다. Profile이 없다면 Scatter Library를 만듭니다.
  3. + Add Scatter Object를 선택하고 Meadow Grass처럼 알아보기 쉬운 이름을 지정합니다.
  4. Target Biomes에서 현재 Library의 바이옴을 하나 이상 선택합니다.
  5. 처음에는 각 Target의 Density Multiplier를 1로 설정합니다.
  6. 전체 Density(제곱미터당 Clump 수), Spacing, Coverage 범위, Slope, Scale 및 Surface Alignment를 설정합니다.
  7. 이 Grass 설정에서는 Scatter Output을 Meshes로 둡니다. 내장 Grass Preset이나 Custom Mesh로 Mesh Variant를 추가합니다. 파티클은 아래 Particle 설정을 참고하십시오.
  8. Material을 지정하거나 확인하고 필요하다면 GPU Instancing을 활성화합니다. 큰 설정 변경 후 Preview가 자동 갱신되지 않았다면 Rebuild Scatter를 사용합니다.

예: Meadow Grass Object 하나를 만든 뒤 Lush Grass는 ×1.0, Dry Meadow는 ×0.65, Forest Soil은 ×0.25로 Target에 추가합니다. 같은 Grass Mesh, Colour Ramp, Roughness 및 Wind 설정을 세 Surface 모두에서 재사용할 수 있습니다.

하나의 설정으로 여러 바이옴 대상 지정하기

하나의 Scatter Object는 원하는 수의 Terrain Atlas 바이옴을 대상으로 할 수 있습니다. Biome Picker에는 현재 바이옴 이름과 숫자 ID가 표시됩니다. + Add Target Biome으로 목록을 확장합니다.

Control의미예
Biome이 Scatter Object가 나타날 수 있는 Terrain Atlas 바이옴입니다.Grassland, Forest Soil 또는 현재 Library의 다른 항목.
Density Multiplier: 0–2이 Target Biome에서만 Scatter Object의 Base Density를 곱합니다.1은 기본 밀도, 0.5는 절반, 0은 해당 Target 비활성화, 2는 두 배까지 허용합니다.

페인트된 Blend 영역에서는 Scatter Object가 대상으로 삼은 여러 바이옴의 합산 기여도를 평가합니다. 따라서 재사용 가능한 Object 하나가 Grass/Forest 경계를 가로질러 이어질 수 있으며 별도의 중복 정의가 필요하지 않습니다.

승인된 각 Instance는 해당 위치에서 기여한 Target을 기준으로 소유 바이옴을 유지합니다. 따라서 하나의 재사용 가능한 Grass Object가 여러 바이옴을 대상으로 하더라도 Live Biome Modifier가 그중 하나에만 영향을 줄 경우 해당 바이옴 소유 Instance만 다르게 반응할 수 있습니다.

배치 설정

Scatter Output 위치: Vertex 3D Terrain 창에서 3D Scatter를 펼친 다음 Scatter Object의 이름이나 화살표를 클릭해 설정을 엽니다. Scatter Output은 Target Biomes 바로 아래, Placement 위에 있습니다. Meshes, Particles, Both 중 선택합니다.

Placement의 Player Interaction은 Static Scatter 옆에 있습니다. 활성화하면 버튼 아래에 Bend Distance가 표시됩니다.

Control의미권장 접근
Player Interaction / Bend Distance호환 Scatter Mesh가 가까운 Scatter Interactor로부터 멀어지도록 휩니다. Bend Distance는 월드 미터 단위의 끝부분 최대 이동 거리를 제한합니다.잔디나 유연한 식물에서 켜십시오. Player Collision & Interaction 가이드를 참고하십시오. Particles 전용 출력에는 이 Mesh 설정이 없습니다.
Scatter OutputMeshes는 설정한 Variant를 그립니다. Particles는 Mesh Variant 없이 방출 지점을 생성하며 Both는 두 출력을 결합합니다.기존 Scatter Object의 기본값은 Meshes입니다. Both는 Mesh Variant의 배치 지점을 사용합니다.
Density: 0–100 clumps/m²Target Biome Multiplier와 Live Runtime Density가 적용되기 전의 기본 예상 Instance 밀도입니다.낮은 값부터 시작해 Instance Count와 먼 거리 Coverage를 확인하면서 올립니다.
Coverage Min / Max: 0–1모든 Target Biome의 합산 Coverage가 선택한 범위 안에 있는 위치에서만 배치를 허용합니다.희미한 Blend를 제외하려면 Min을 올립니다. 완전히 채워진 바이옴 내부를 제외하려면 Max를 1보다 낮춥니다. Max 1은 일반적인 내부 배치를 유지합니다.
Spacing이 Scatter Object의 Clump 중심 사이에 필요한 최소 World-space 거리입니다. Terrain Tile 경계를 넘어도 적용됩니다. 0이면 제한하지 않습니다.Clumping과 겹침을 줄이려면 늘립니다. 최종 Instance 수가 Density 기대치보다 줄어들 수 있습니다. 중심 간 거리이므로 큰 Mesh 외곽은 여전히 겹칠 수 있습니다.
Max Slope: 0–90°선택한 각도보다 가파른 Surface를 제외합니다.Grass는 보통 Rock이나 Cliff Debris보다 낮은 한계가 적합합니다.
Scale Min / Max승인된 Instance에 적용되는 Random Uniform Scale 범위입니다.자연스러운 차이를 주되 눈에 띄는 크기 점프가 없도록 제한된 범위부터 사용합니다.
Alignment: 0–1선택한 Up Mode와 Terrain Normal 사이를 Blend합니다.0은 선택한 Up Direction에 대해 Object를 세우고 1은 Surface Normal을 완전히 따릅니다.
Offset샘플된 Surface Normal을 따라 Instance를 이동합니다.Mesh가 떠 보이거나 파묻힐 때 작은 양수 또는 음수로 조정합니다.
Enable Wind이 Scatter Object가 DPT Scatter Wind를 사용하도록 합니다. 지정된 Shader가 DPT Scatter Wind 기능을 지원하는 경우에만 사용할 수 있습니다.호환되는 Grass, Flower 및 유연한 Mesh에 활성화합니다. 단단한 Prop에는 끕니다. VCCORE Material은 자체 Authoring된 Wind Data를 사용하므로 이 옵션이 필요하지 않습니다.

해안선에만 Reeds 배치하기

  1. Reeds Scatter Object를 만들고 Water만 Target으로 지정합니다.
  2. 0.15–0.65 같은 Coverage 범위를 사용하면 Water가 Mud와 섞이는 곳에는 Reeds를 허용하면서 Coverage 1인 순수 Water는 제외할 수 있습니다.
  3. 페인트된 Transition Width와 Coverage 범위를 조정해 Band 위치를 정한 뒤 Density와 Spacing으로 원하는 개수와 간격을 설정합니다.

Coverage는 모든 Target Biome을 합산합니다. Water와 Mud를 모두 Target으로 지정하면 Transition 전체에서 두 값의 합이 1이 될 수 있으므로 같은 범위 설정이 해당 영역을 제외할 수 있습니다. 필요한 Edge를 설명하는 부분 Coverage를 가진 바이옴만 Target으로 지정하십시오. Coverage는 배치 가능한 Surface를 필터링하고 바이옴별 Density Multiplier는 그곳에 나타나는 Clump 수를 변경합니다.

내장 프리셋과 커스텀 메시

각 Scatter Object는 여러 Mesh Variant를 가질 수 있습니다. Relative Chance는 상대적인 선택 Weight이며 합계가 100이 되어야 하는 백분율이 아닙니다. Placement Seed를 바꾸지 않고 내장 Mesh 형태에 변화를 주려면 서로 다른 Shape Seed 값을 사용합니다. Preset 설명은 Tooltip에서 확인할 수 있습니다.

Shading과 Surface Property

Crystals를 포함한 모든 내장 Preset에는 Smoothing Angle: 0–180°가 있습니다. 0에서는 Face가 Flat하게 유지되고 180에서는 맞닿은 모든 Face가 Normal을 Blend할 수 있습니다. 중간 값은 완만한 Join을 부드럽게 하면서 날카로운 Edge는 유지합니다. 이는 Lighting을 변경하며 Mesh Silhouette이나 Terrain 전체의 Smooth / Sharp 설정은 변경하지 않습니다.

Vertex Colour Ramp는 생성된 각 Element마다 Bottom에서 Top까지 Local하게 평가됩니다. Smoothness는 거친 0에서 광택 있는 1까지이며 새 Variant의 기본값은 0.2입니다. Metallic은 0에서 1까지 금속 반응을 제어합니다.

생성 Mesh는 Metallic을 UV3.R에 저장합니다. UV3.G에는 Raw Smoothness가 아니라 Smoothness에서 파생된 DPT Packed Scale/Roughness 값이 들어갑니다. Custom Shader에서 올바르게 사용하려면 이 DPT Mesh Data를 Decode해야 합니다.

Emissive Scatter

내장 Variant에서 Emissive를 활성화한 뒤 Ramp의 HDR Colour로 밝기를, Ramp Alpha로 Glow Coverage를 설정합니다. DPT는 Emissive Biome과 같은 방식으로 Coverage를 Vertex Alpha에 저장합니다. HDR Colour만으로 Emission이 활성화되지는 않습니다. Material의 Emission Control도 적용되며 눈에 보이는 Bloom은 Scene Post-processing에 따라 달라집니다. Emission 자체는 Light Source를 생성하지 않습니다.

Custom Mesh

Custom Mesh를 선택하고 3D Mesh, 선택적 Submesh Index, Material 및 선택적 Distant Mesh를 지정합니다. Distant Mesh가 없으면 Near Mesh를 재사용합니다. Custom Mesh는 Authoring된 Normal, Vertex Colour 및 UV3 Surface Data를 유지하며 내장 Shading, Metallic, Smoothness, Emissive Control이 이를 다시 쓰지 않습니다. 지원되는 DPT Scatter Wind를 활성화하면 Wind/Biome Data를 가진 Runtime Copy가 준비되며 원본 Asset은 그대로 유지됩니다.

Material 선택은 중요합니다. Scatter는 GPU Instancing을 사용합니다. Mesh Data와 호환되는 Material을 사용하고 요청될 경우 GPU Instancing을 활성화하십시오. Variant Material을 비워 두면 적절한 경우 Source Terrain Material이 사용됩니다.

Scatter 배치 위치에서 파티클 방출하기

설정 위치: Vertex 3D Terrain 창에서 3D Scatter를 열고 Scatter Object를 펼친 다음 Scatter Output을 Particles 또는 Both로 설정합니다. 이어서 Particle Effect를 펼칩니다. 첫 항목은 Particle Preset과 Emission Trigger입니다. Custom을 선택하면 Particle Prefab 필드가 나타납니다.

Preview Particles, Follow Live Biome, Follow Flow Speed는 각각의 파티클 Inspector에 있는 토글 버튼입니다. 파란색은 활성화 상태이며 다시 클릭하면 꺼집니다.

꽃가루, 떠다니는 포자, 불씨 또는 반복되는 다른 파티클 효과에는 Scatter Object를 사용합니다. Mesh Scatter와 동일한 Target Biomes, Density, Coverage, Spacing, 경사 및 배치 설정이 적용됩니다.

파티클이 언제, 어디에서 방출되나요?

Particle Effect 안에서 Emission Trigger를 선택합니다. Continuous는 카메라 범위 안의 적합한 배치 지점에서 Rate / Emitter에 따라 자동 방출합니다. Player Movement는 움직이는 Scatter Interactor가 배치 지점에 충분히 가까워졌을 때만 방출하며 반경, 강도 및 높이 허용 범위를 고려합니다. 움직이지 않거나 Minimum Movement Speed보다 느리면 새로운 방출이 멈춥니다. 출력하려면 Particles 또는 Both와 Particle Preset을 지정해야 합니다. Preview Particles 버튼은 편집 중 효과를 보여 주며 Wind만으로는 Player Movement 방출이 시작되지 않습니다.

  • Both: 같은 Scatter Object의 Mesh 배치 지점이 파티클 방출 지점으로도 사용됩니다. Emitter Fraction으로 방출 가능한 위치의 비율을 고르고 Emission Offset으로 각 지점에 대한 효과의 상대 위치를 설정합니다. 해당 Object의 모든 Mesh Variant가 파티클 설정을 공유합니다.
  • Particles: Mesh Variant 없이 Biome과 배치 규칙을 사용해 별도의 방출 위치를 생성합니다.
  • 다른 Scatter Object: Object마다 출력과 파티클 설정이 독립적입니다. 같은 Profile에 Pollen Scatter Object를 따로 만들면 자체 방출 지점이 생성되며, 다른 Object의 Grass나 Flower에 자동으로 연결되지 않습니다. 기존 Grass 위치에서 방출하려면 해당 Grass Object에 Both를 선택하십시오.

예: 주변에 Grass 배치 지점이 100개 있을 때 Emitter Fraction 0.1은 약 10개를 선택합니다. Rate / Emitter 1이면 Live Biome 배율과 Emitter/Particle 제한을 적용하기 전 초당 약 10회의 방출 이벤트가 발생합니다. 물방울과 안개를 모두 포함한 Prefab은 이벤트당 파티클을 여러 개 생성할 수 있습니다.

  1. Scatter Object를 만들고 Target Biomes를 선택합니다.
  2. Scatter Object 설정을 열고 Target Biomes 아래, Placement 위에 있는 Scatter Output을 찾습니다. Mesh 없는 효과는 Particles, Mesh Variant도 유지하려면 Both를 선택합니다.
  3. Particle Effect를 펼친 뒤 Particle Preset에서 Pollen, Grass Flecks, Water Splash 등을 선택합니다. 자체 효과를 사용하려면 Custom을 선택하고 표시되는 Particle Prefab에 할당합니다.
  4. Emitter Fraction과 Rate / Emitter를 낮게 설정하고 Offset과 Rotation을 조정합니다.
  5. Preview Particles를 켜서 Scene View에서 확인합니다. 편집 Preview는 기본적으로 꺼져 있으며 Runtime 방출에는 필요하지 않습니다.
  6. 거리와 Emitter/Particle 수 제한을 설정하고 Game Camera에서 확인합니다.

파티클 프리셋 선택하기

Particle Preset 드롭다운은 Scatter, Player Surface Effects 및 Waterfall Emitter에서 공통으로 사용됩니다. Preset은 외형을 고르고 Emission Trigger 또는 Component가 방출 시점을 결정합니다. Preset이 Biome을 자동으로 선택하지는 않습니다. 아홉 가지 내장 선택지는 모두 Procedural 방식입니다. 움직임, 색상 및 수명은 코드로 구성되며 URP Shader는 가져온 Sprite 없이 수학적으로 파티클 모양을 그립니다. 직접 만든 ParticleSystem Prefab에는 Custom을 사용할 수 있습니다.

플레이어가 Scatter를 건드릴 때 파티클 방출하기

  1. Grass Scatter Object를 열고 Scatter Output을 Both로 설정합니다.
  2. Static Scatter 옆의 Player Interaction 버튼을 켜고 Bend Distance를 0보다 크게 설정합니다. 호환 Material을 사용하십시오.
  3. Particle Effect를 펼치고 Particle Preset에서 Grass Flecks 또는 Pollen, Emission Trigger에서 Player Movement를 선택합니다.
  4. Emitter Fraction 0.2, Rate / Emitter 15, Minimum Movement Speed 0.1부터 시작합니다. 식물 높이에 맞게 Emission Offset을 조정하고 Particle Limit을 제한합니다.
  5. 플레이어 발 근처에 DPT_ScatterInteractor를 추가하고 Play Mode에서 풀밭을 달려 봅니다. 멈추면 새 방출이 중단되고 기존 파티클은 수명까지 남습니다.

이 판정은 Shader가 변형한 Vertex를 읽는 대신 Scatter 뿌리 주변에서 움직이는 Interactor의 접촉 범위를 사용합니다. 이동 샘플 사이를 Sweep하여 빠른 통과도 감지하고 높이 범위를 고려하며 Maximum Movement Step을 넘는 Teleport는 무시합니다. Particles 전용 출력에서도 Mesh Bend를 켜지 않고 동일한 Trigger를 사용할 수 있습니다. Live Biome Strength와 Density는 계속 방출 빈도를 조절하며 Static Scatter는 이러한 Modifier에서 독립적입니다.

Scatter Mesh 없이 발밑에 물보라나 먼지를 생성하려면 Player Surface Effects와 베이크된 Biome Data를 사용하십시오.

Live Biome 반응과 자연스러운 사라짐

Live Biome의 Strength와 Scatter Density는 대상 Biome ID가 소유한 배치 지점의 새 방출 빈도에 곱해집니다. 둘 중 하나를 낮추면 새 파티클이 줄어들고 0이면 새로운 방출이 멈추지만 기존 파티클은 자연스럽게 수명을 마칩니다. Static Scatter의 파티클 방출은 이러한 Live Modifier의 영향을 받지 않습니다.

점진적인 사라짐은 파티클 자체의 Lifetime으로 구현됩니다. Mesh용 Live Crossfade는 파티클 투명도를 제어하지 않습니다. 색상은 선택한 Procedural Preset 또는 Custom Prefab에 의해 결정됩니다. Live Scatter Colour Multiplier는 Mesh Tint로, 파티클 효과의 색을 바꾸지 않습니다.

초원 꽃가루: Grass Group에 Both와 Pollen을 선택하고 Emitter Fraction 0.1, Rate / Emitter 1, Particle Distance 25, Particle Limit 300부터 시작합니다. 겨울을 향해 Grass Biome의 Live Density를 0으로 Animate하면 새 파티클은 줄어들고 기존 꽃가루는 떠다니다가 사라집니다.

Procedural Preset, Custom Prefab 및 예산

활성 Scatter Group 하나당 공유 Generated Effect 하나 또는 Custom Prefab 인스턴스 하나가 사용됩니다. Grass Clump마다 Particle GameObject가 생기지 않습니다. Emitter는 World-space Simulation을 사용하고 방출을 수동 제어하므로 Prefab의 자동 Rate와 Burst는 비활성화됩니다. 일반적인 각 자식 System은 방출 이벤트마다 한 번씩 방출할 수 있어 물방울과 안개처럼 결합된 효과를 구성할 수 있습니다. Particle Limit은 자식 System 사이에 분배됩니다.

내장 Preset은 실제 활성 효과가 필요할 때만 ParticleSystem과 Material을 생성합니다. 효과를 교체하거나 비활성화하면 생성한 Object와 Material을 해제합니다. 여전히 Unity ParticleSystem을 사용하므로 Procedural 생성만으로 Frame Rate 향상이 보장되지는 않습니다. Custom Prefab에는 사용 중인 Render Pipeline에 적합한 Material을 사용하십시오.

방출 지점은 Placement Transform과 Terrain 이동을 따릅니다. 이미 생성된 파티클은 World Space에 남습니다. Shader Wind와 Player Bending은 방출 위치를 이동시키지 않으므로 식물의 기본 위치에 맞게 Emission Offset을 조정하십시오. Preset 또는 Custom Prefab 변경, Meshes로 전환 또는 Renderer 비활성화 시 생성된 효과는 즉시 해제됩니다.

폭포 물보라와 안개

DPT_WaterfallSplashEmitter는 폭포 아래에 직접 배치하는 충돌 지점용 띠 형태의 효과입니다. 각 충돌 지점에 Scatter Profile이나 GameObject를 별도로 만들지 않고 띠 전체에 공유 파티클 효과를 방출합니다.

Component를 활성화하면 Play Mode에서 카메라 범위 내에 있는 동안 Emission Rate에 따라 계속 방출합니다. 물이나 플레이어와의 충돌을 기다리지 않습니다. 편집 중 확인하려면 Preview Particles를 켜십시오. 선택적으로 Live Biome과 Flow에 연결해 새로운 방출을 줄이거나 멈출 수 있습니다.

  1. 폭포 아래에 GameObject를 만들고 Add Component에서 DPT_WaterfallSplashEmitter를 추가합니다.
  2. 기본 Procedural Waterfall Splash를 사용하거나 다른 Particle Preset을 고릅니다. 직접 만든 효과는 Custom을 선택한 뒤 표시되는 Particle Prefab에 할당합니다.
  3. Splash Width와 Splash Depth를 조절해 충돌 영역을 덮습니다. 선택한 Object의 Gizmo에 해당 띠가 표시됩니다.
  4. 위쪽으로 분사하려면 Spray Direction (0, 1, 0)을 유지하고 Emission Rate와 Particle Limit을 조정합니다.
  5. Preview Particles를 켜서 편집 중 확인합니다.
  6. 원한다면 아래 설명대로 Water Biome과 Flow Speed에 연결합니다.

플레이어에 반응하는 잔디

호환되는 Grass 또는 Plant Scatter Object에서 Player Interaction을 켜고 플레이어에 DPT_ScatterInteractor를 추가합니다. 가까운 Mesh의 끝부분이 플레이어로부터 멀어지는 방향으로 휘고 뿌리는 고정됩니다. Wind와 독립적으로 작동합니다.

Wind 설정

DPT Scatter Wind에는 두 단계의 제어가 있습니다. Material은 Shader에서 Wind 기능 자체가 활성화되는지를 결정하고 Scatter Object의 Enable Wind는 해당 Scatter Object가 DPT Scatter Wind Path를 사용할지를 결정합니다. Scatter Object Control은 지정된 Shader가 _DPT_SCATTER_WIND Boolean Keyword를 선언한 경우에만 사용할 수 있으며 이를 통해 Vertex 3D Terrain이 해당 Shader의 기능 지원 여부를 인식합니다.

Vertex Terrain Material 사용하기

  1. Material의 Wind 섹션을 열고 Enable Wind를 켭니다.
  2. 적당한 Wind Strength 값을 설정합니다.
  3. Height To Tip을 Scatter Mesh의 Object-space 높이에 가깝게 설정하여 Base는 고정되고 Tip은 전체 움직임을 받을 수 있게 합니다.
  4. Compass Heading과 Vertical Pitch를 선택합니다.
  5. 3D Scatter 섹션으로 돌아가 DPT Scatter Wind를 사용해야 하는 각 Scatter Object에서 Enable Wind를 켭니다.
  6. 강하게 움직이는 Tip이 Camera 또는 Frustum 경계 근처에서 사라진다면 Scatter Settings의 Wind Bounds를 늘립니다.

Pebbles 같은 단단한 Scatter는 같은 Material을 공유하면서도 Scatter Object의 Enable Wind를 끈 상태로 둘 수 있습니다.

VCCORE Material

VCCORE는 자체 Authoring된 Wind System을 사용하므로 Scatter Object의 Enable Wind Control이 의도적으로 비활성화됩니다. 정상 동작입니다. Stylized Color Swapper & Material Optimizer로 모델에 Wind를 페인트했거나 DPT Pack에서 이미 Wind Data가 Authoring된 모델을 사용하는 경우 Scatter 전용 Wind 설정은 필요하지 않습니다. 움직임을 활성화하거나 조정할 때는 VCCORE Material 자체의 Wind Control을 사용하십시오.

Terrain Surface에서 사용하는 동일한 네 개의 Live Biome Modifier Slot으로 Target Biome ID에 속한 Scatter도 제어할 수 있습니다. 이를 통해 Seasonal System이 지면과 식생을 함께 변경할 수 있습니다.

Material 설정은 Terrain Material 설정, 예제 Controller는 데모 & 런타임 가이드를 참고하십시오.

Live 변경 중 Scatter 페이드하기

  1. 3D Scatter → Scatter Settings → Distance & LOD를 엽니다.
  2. Live Crossfade를 활성화하고 Fade Range를 기본값인 0.15부터 사용합니다.
  3. Scatter Fade를 지원하는 제공 DPT Terrain Shader를 사용한 다음 Live Modifier의 Strength 또는 Scatter Density를 애니메이션합니다.
  4. 전환을 보며 Fade Range를 조정합니다. 값이 클수록 각 Instance의 페이드가 Density Animation의 더 넓은 구간에 걸쳐 일어납니다. 실제 전환 시간과 Easing은 Controller에서 설정합니다.

Live Crossfade는 Dithered Visibility를 사용합니다. Live Population이 변하면 각 Mesh와 Shadow의 표시 영역이 점진적으로 사라지거나 복원됩니다. CPU 및 GPU Scatter Rendering 모두에서 작동하며 기존 Instance 위치는 유지합니다. Live Density가 0이면 해당 Scatter와 Shadow는 완전히 숨겨집니다. Animation을 반대로 진행하면 원래 위치에서 다시 페이드인됩니다.

Live 변경에 반응할 Scatter를 선택하십시오. Live Density, Colour 및 Surface Override를 포함한 Live Biome Animation을 무시해야 하는 Scatter Object에는 Static Scatter를 활성화합니다. Static Object는 Live Crossfade를 사용하지 않습니다. 그러나 Paint와 Sculpt 작업에 따른 Placement Update는 계속 적용됩니다.

DPT Scatter Fade를 지원하지 않는 Material은 기존 Visibility 동작을 유지합니다. Scatter Object의 Authoring용 Density 변경이나 Placement Rebuild는 Live Density Animation과 별개입니다. Transition은 거리 기반 LOD 전환을 제어하고 Live Crossfade는 Live Biome 변경을 제어합니다.

계절별 스냅샷과 접을 수 있는 프로파일

Dynamic Biome Demo Controller를 사용하면 Material의 모습을 Environment Profiles로 캡처할 수 있습니다. Material을 수정한 다음 + Capture Current Settings as NEW Profile을 선택합니다. 각 Profile은 저장된 독립적인 Snapshot이며, 이후 Material을 변경하더라도 다시 캡처하지 않으면 저장된 Profile은 수정되지 않습니다.

Profile의 화살표나 이름을 클릭하면 접거나 펼칠 수 있습니다. 접힌 상태에서도 Header에는 이름과 Sequence Position이 표시되고 첫 번째 Profile에는 START가 표시됩니다. 새로 캡처한 Profile은 자동으로 펼쳐집니다. Profile을 펼치면 Name, Transition Seconds, Easing 및 Channels to Animate를 수정하거나 Capture, Apply, 순서 변경 및 삭제 기능을 사용할 수 있습니다. Animate To Profile은 현재 모습에서 선택된 Channel을 블렌딩하고 완료된 상태를 유지합니다.

스냅샷 변경 항목적용 시점

시작 시 Dusting이 없는 경우의 Dusting Biome ID시작 상태의 Dusting Strength가 0이거나 Dusting이 비활성화되어 있거나 Modifier Slot이 비활성인 경우, 목적지 Dusting ID는 Transition 시작 시 적용됩니다. 이후 그 ID를 사용해 Dusting Strength가 애니메이션됩니다.
시작 시 Dusting이 보이는 경우의 Dusting Biome ID시작 Slot이 활성 상태이고 Dusting이 켜져 있으며 Strength가 0보다 크면 기존 Dusting ID는 Transition이 끝날 때까지 유지됩니다.

이 규칙은 Sequence Playback, Edit Mode Preview/Scrubbing 및 Animate To Profile 모두에 적용됩니다. 각 Live Biome Modifier Slot은 최대 3개의 Target Biome ID를 지원합니다. 이는 원하는 개수의 Biome을 지정할 수 있는 Scatter Object의 Target Biomes 목록과는 별개입니다.

봄 → 겨울 → 봄 → 폭염: 봄은 Water의 Dusting Strength를 0으로 캡처하고 겨울은 Ice Dusting으로 캡처합니다. 다시 봄으로 돌아가는 Profile은 Strength를 0으로, 폭염은 Sand Dusting으로 캡처합니다. 폭염 Transition에서는 시작부터 Sand가 선택되므로 Ice가 먼저 늘어났다가 끝에서 Sand로 전환되는 문제가 없습니다. 건기에 사용할 Snapshot에서 Target Biome을 추가했다면 그 Biome도 Transition 시작부터 Live Modifier의 대상이 됩니다.

Scene View에서 Dusting을 페인트할 때 빨간색 Dusting Preview는 Brush Handle보다 먼저 그려지므로 Highlight 위에서도 선택한 Brush Handle의 색상을 확인할 수 있습니다.

런타임 Scatter와 베이크된 Terrain Data

Scatter Placement는 Main Thread에서 동기적으로 생성된 뒤 Rendering용으로 Cache됩니다. Readable Terrain Mesh는 Placement Geometry를 직접 제공합니다. Non-readable Terrain Mesh는 Scatter Geometry가 Bake된 대응 DPT_TerrainSurfaceData Asset을 대신 사용할 수 있으므로 이 Runtime Path를 위해 Terrain Read/Write를 계속 켜 둘 필요가 없습니다.

  1. Bake하기 전에 Scatter Profile을 지정합니다.
  2. Terrain을 Editor에서 Authoring할 수 있는 동안 Bake Surface Data를 사용합니다. Scatter Profile이 지정된 경우 Gameplay Surface 정보뿐 아니라 Placement Vertex, Normal, Triangle 및 Biome Channel도 포함됩니다.
  3. 각 Source Terrain의 DPT_TerrainSurfaceTarget에 Baked Asset을 지정한 상태로 유지하고 Build에 포함합니다.
  4. Terrain Geometry, Painting, Biome ID 또는 Topology를 변경한 뒤에는 다시 Bake합니다. Gameplay 전용 또는 오래된 Bake는 Scatter Placement에 충분하지 않습니다.
  5. Terrain Read/Write를 비활성화한 상태로 Build Scene을 테스트합니다. Renderer가 Scatter Geometry Bake를 요구한다면 최신 Data를 제공하거나 해당 Source Mesh를 Readable 상태로 유지하십시오.

Bake된 Placement Array 자체는 Memory를 사용합니다. Terrain Read/Write를 끈다고 Scatter Data 자체가 사라지는 것은 아닙니다. 큰 Population을 생성하거나 Rebuild하는 작업은 여전히 Main Thread 시간을 사용할 수 있습니다. 이 Terrain Data 옵션은 DPT Wind Copy를 준비할 때 Readable Mesh Channel이 필요한 경우를 포함해 Authoring된 Custom Mesh의 요구 사항을 없애지 않습니다.

성능과 실용적인 제한

  • Scatter는 Instance마다 GameObject를 만드는 대신 GPU Instanced Draw를 사용합니다.
  • Placement는 Terrain Mesh에서 생성되고 Cache됩니다. 일반적인 Camera 이동과 Live Density 변경은 Terrain Scatter Distribution을 다시 만들지 않습니다.
  • Camera Distance와 Frustum Culling은 Scatter Batch/Cell 단위로 작동합니다. 따라서 Cell Size는 Grouping Overhead와 Culling Precision 모두에 영향을 줍니다.
  • Far Density는 더 저렴한 Distant Mesh를 사용하는 것과 함께 먼 거리 Population 자체도 줄일 수 있습니다.
  • 큰 Terrain에서 매우 높은 Density를 사용하면 Candidate 또는 Instance Safety Cap에 도달할 수 있습니다. 이 Limit를 최대화 목표가 아니라 Setup을 Profile하라는 Warning으로 취급하십시오.
  • Custom Mesh는 Instancing에 적합해야 하며 수천 개가 표시될 경우 불필요한 Vertex/Submesh/Material Complexity를 피해야 합니다.

파티클에는 Mesh LOD와 별개로 Emitter Fraction, Rate / Emitter, Particle Distance, Emitter Limit 및 Particle Limit을 조정하십시오. 크고 투명한 파티클이나 겹치는 Mist는 수가 많지 않아도 비쌀 수 있습니다. Particle Simulation과 Vertex Bending은 베이크된 Gameplay Surface Query를 변경하지 않습니다.

Runtime Discovery는 Opt-in이므로 안정적인 Terrain Hierarchy에서는 Play 중 매초 Full Search를 할 필요가 없습니다. 내장 Variant Signature는 Profile이 바뀔 때까지 Cache됩니다. Configured Mesh Cache는 Active Renderer가 여전히 사용하는 Mesh를 유지하고 Rebuild 후 더 이상 필요하지 않은 Entry를 해제합니다. 마지막 Renderer를 비활성화하면 공유 Scatter Cache가 Clear됩니다. Profile 변경은 여전히 Regeneration을 요구할 수 있습니다.

Blend Edge가 너무 비어 있습니다Coverage Min과 Max 양쪽 및 Target Density Multiplier를 확인합니다. Coverage는 모든 Target Biome을 합산합니다. Shoreline Band에서는 Water와 Mud를 함께 Target으로 지정하지 말고 Water만 지정합니다.
Clump가 너무 많이 겹칩니다Spacing을 늘리고 Scale Min/Max를 확인합니다. Spacing은 이 Scatter Object 안의 중심을 분리할 뿐 전체 Mesh 외곽이나 다른 Scatter Object 사이를 분리하지 않으며 최종 Count를 줄일 수 있습니다.
호수 중앙에도 Scatter가 나타납니다Water만 Target으로 지정하고 Coverage Max를 1보다 낮춥니다. Reeds가 자라야 하는 위치에 점진적인 Water/Mud Transition을 페인트합니다.
특정 바이옴에 Grass가 너무 많습니다Scatter Object 전체를 복제하는 대신 해당 Target의 Density Multiplier를 낮춥니다.
Custom Mesh가 Render되지 않습니다Mesh/Material을 지정하고 Submesh Index를 확인한 뒤 GPU Instancing을 활성화합니다. Material이 Custom Mesh의 Authoring Data와 호환되는지도 확인하십시오.
LOD 경계에서 Scatter가 튑니다Transition을 늘리고 적절한 Distant Mesh 또는 내장 Distant Preset이 존재하는지 확인합니다. Near/Far Silhouette과 Scale도 비교하십시오.
계절 변화 중 Scatter가 갑자기 사라집니다Distance & LOD에서 Live Crossfade를 활성화하고 Fade Range를 조정합니다. DPT Scatter Fade를 지원하는 Material을 사용하고 반응해야 하는 Object에는 Static Scatter가 꺼져 있는지 확인하십시오. Authoring Placement를 다시 만들기보다 Live Strength 또는 Scatter Density를 애니메이션하십시오.
폭염으로 전환할 때 Sand 대신 Ice가 먼저 증가합니다중간에 있는 봄 Profile은 Water의 Dusting Strength를 0으로 캡처하고 폭염 Profile은 Dusting Biome ID를 Sand로 설정해 캡처합니다. 시작 Strength가 0이면 새 ID가 Transition 시작 시 적용됩니다. 이미 보이는 0보다 큰 Strength의 Dusting은 Transition 끝까지 기존 ID를 유지합니다.
새로 지정한 건기 Biome이 반응하지 않습니다업데이트된 Target List를 목적지 Profile에 다시 캡처하고 해당 Modifier Slot이 Channels to Animate에 포함되어 있는지 확인하십시오. 목적지 Target List는 Transition 시작 시 적용되지만 Material만 수정해도 기존 Snapshot이 자동 업데이트되지는 않습니다.
Profile 설정 버튼이 보이지 않습니다Environment Profile의 화살표 또는 이름을 클릭해 펼칩니다. 접힌 Profile은 이름과 Sequence Position만 보여 주며 편집 및 작업 버튼은 Foldout 안에 있습니다.
Visual Studio에서 Scatter Instancing 선언을 오류로 표시하지만 Unity에서는 컴파일됩니다업데이트된 DPT Scatter Instancing Include를 사용하십시오. Unity 전용 Instancing Macro를 Guard하고 독립 실행형 HLSL Editor를 위한 Fallback 선언이 포함되어 있습니다. 실제 Shader Compile Error는 Unity Console에서 별도로 확인하십시오.
먼 거리 Scatter가 너무 조밀합니다Far Density 또는 Draw Distance를 낮춥니다. 바이옴별 Target Density Multiplier를 오직 거리 제어 용도로 사용하지 마십시오.
Enable Wind가 비활성화되어 있습니다지정된 Shader가 _DPT_SCATTER_WIND Boolean Keyword를 선언하지 않아 Scatter Object가 DPT Scatter Wind를 사용할 수 없습니다. Shader Graph에 DPT Scatter Wind 설정을 추가하거나 Shader 자체 Wind System을 사용합니다.
VCCORE Material에서 Enable Wind가 비활성화되어 있습니다의도된 동작입니다. VCCORE는 자체 Authoring된 Wind Data 및 Material Wind Control을 사용하므로 DPT Scatter Wind 설정이 필요하지 않습니다.
DPT 호환 Custom Shader인데도 움직이지 않습니다Material의 DPT Scatter Wind Keyword, Scatter Object의 Enable Wind, Blackboard Reference 이름의 정확한 일치, 복사한 Wind Block의 Vertex Position 연결, Wind Strength / Height To Tip 값을 확인합니다.
Wind가 오브젝트 전체를 이상하게 움직입니다Enable Wind, Height To Tip, Mesh Object-space Height 및 Wind Strength를 확인합니다. 일반 Terrain, 회전 Terrain 또는 Planetoid에 적절한 Up Mode를 사용하십시오.
Wind로 움직이는 Tip이 사라집니다Wind Bounds를 늘려 예상되는 최대 변위를 Draw Bounds에 포함합니다.
Neutral Live Slot이 Scatter를 Tint합니다Slot 1을 포함한 네 Slot 모두에서 HDR Intensity 0의 White가 Neutral입니다. 겹치는 Slot Target, 다른 Colour Multiplier 및 Shader의 Scatter Input을 확인합니다. Dusting과 Scatter Response는 별도 Path입니다.
HDR Ramp Colour가 빛나지 않습니다내장 Variant에서 Emissive를 활성화하고 Ramp Alpha와 Material Emission Control을 확인합니다. Custom Mesh는 자체 Authoring된 Emission Data가 필요합니다.
Non-readable Terrain을 사용하는 Build에서 Scatter가 사라집니다Scatter Profile이 있는 상태에서 Surface Data를 지정하고 다시 Bake합니다. Runtime Data 설정을 참고하십시오. Gameplay 전용 Data에는 Placement Geometry가 포함되지 않습니다.
Snow가 Terrain은 바꾸지만 Grass는 바꾸지 않습니다Scatter Object가 Live Slot과 같은 Biome ID를 Target으로 하는지, Scatter Density/Colour Multiplier가 Neutral 상태가 아닌지, Live-biome Master Switch가 켜져 있는지, Scatter Renderer가 같은 호환 Material을 사용하는지 확인합니다.
Scatter Density를 바꿔도 바로 효과가 없습니다Profile의 Authoring Density만이 아니라 Live Material Scatter Response를 변경하고 있는지 확인합니다. Profile Density 변경은 Placement를 바꾸므로 Rebuild가 필요할 수 있고 Live Scatter Density는 제출되는 Population을 변경합니다.
