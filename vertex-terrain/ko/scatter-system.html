화면이 작으면 넓은 표를 좌우로 스크롤하여 모든 열을 확인하세요.

3D Scatter 시스템은 Terrain Atlas 바이옴 데이터를 바탕으로 인스턴싱 메시와 파티클 방출 지점을 직접 배치합니다. 하나의 scatter object 에는 메시 변형, 파티클 레이어 및 선택적 오디오를 포함하는 재사용 가능한 배치 규칙이 저장됩니다. 바이옴마다 동일한 잔디 설정을 다시 만드는 대신 한 오브젝트에 여러 Target Biomes 를 추가하고 필요하다면 대상마다 밀도 배율을 지정할 수 있습니다.

Scatter는 잔디, 꽃, 버섯, 돌 및 작은 소품처럼 반복되는 표면 디테일에 적합합니다. 지형 메시를 편집하거나 인스턴스마다 콜라이더를 만들거나 흩뿌린 오브젝트를 개별 GameObject로 변환하지는 않습니다.

Scatter 라이브러리 이해하기

Scatter 설정은 각 바이옴 Inspector에 따로 저장되지 않고 Terrain Atlas 바이옴 라이브러리 전체에서 공유됩니다. Vertex 3D Terrain 창의 3D Scatter 섹션을 열어 라이브러리를 만들고 편집하세요.

구성 요소역할중요 사항
Scatter Object재사용 가능한 배치 규칙, 메시 변형, 다중 파티클 효과, 선택적 오디오 및 바람/플레이어 상호작용 설정을 저장합니다.한 번 설정하여 여러 바이옴에 적용할 수 있습니다.
Target Biome선택한 Terrain Atlas 바이옴이 기여하는 위치에 Scatter Object를 배치할 수 있게 합니다.대상별로 0~2 범위의 Density Multiplier를 설정할 수 있습니다.
Scatter OutputMeshes, Particles, Meshes + Particles 또는 Audio Only를 선택합니다.오디오는 별도로 구성하며 어떤 출력에도 추가할 수 있습니다. Audio Only는 메시나 파티클 없이 소리 배치 지점을 생성합니다.
Mesh Variant내장 프리셋 또는 사용자 지정 메시와 상대적인 선택 확률을 지정합니다.여러 변형이 같은 배치 규칙을 공유할 수 있습니다.
Scatter Settings시드, 배칭, 거리, LOD 전환, 원거리 밀도 및 안전 한도를 제어합니다.오브젝트마다 반복하지 않고 Scatter 라이브러리 전체에서 공유합니다.
Active Terrain Renderer프로필을 선택한 지형 루트에 연결하고 GPU 인스턴싱 드로우를 제출합니다.각 인스턴스를 수천 개의 씬 GameObject로 표현하지 않습니다.

첫 Scatter Object 만들기

  1. 먼저 Terrain Atlas 파이프라인을 사용하고 지형에 바이옴 데이터가 칠해져 있는지 확인합니다.
  2. Vertex 3D Terrain 창에서 3D Scatter 을 엽니다. 프로필이 없다면 Scatter Library를 만드세요.
  3. + Add Scatter Object 를 선택한 뒤 Meadow Grass처럼 알기 쉬운 이름을 지정합니다.
  4. Target Biomes아래에서 현재 라이브러리의 바이옴을 하나 이상 선택합니다.
  5. 각 대상의 Density Multiplier를 우선 1로 설정합니다.
  6. 전체 Density (제곱미터당 덤불 수), Spacing, Coverage 범위, 경사, 스케일 및 표면 정렬을 설정합니다.
  7. 이 잔디 설정에서는 Scatter Output 을 Meshes 로 유지합니다. 내장 Grass 프리셋이나 Custom Mesh를 사용하는 Mesh Variant를 추가합니다. 파티클은 아래의 파티클 설정 을 참고하세요.
  8. 머티리얼을 지정하거나 확인하고 요청 시 GPU Instancing을 켭니다. 큰 변경 후 미리보기가 갱신되지 않았다면 Rebuild Scatter 을 실행하세요.

예시: Meadow Grass 오브젝트 하나를 만들고 Lush Grass에는 ×1.0, Dry Meadow에는 ×0.65, Forest Soil에는 ×0.25를 지정합니다. 같은 잔디 메시, 컬러 램프, 거칠기 및 바람 설정이 세 표면에 재사용됩니다.

편집 미리보기 및 지형 도구 업데이트

Play 모드 밖에서 Scatter를 표시하려면 Preview 제목 옆의 3D Scatter 를 사용합니다. 새 렌더러에서는 기본적으로 꺼져 있으며 런타임 렌더링에는 영향을 주지 않습니다. 활성화하면 연결된 Update After Stroke 버튼이 나타나며 기본적으로 켜져 있습니다. 지형 도구를 사용하는 동안 기존 배치를 유지하고 작업이 끝난 후 영향을 받는 소스를 갱신합니다. 이 옵션을 끄면 작업 중에도 갱신할 수 있습니다.

Continuous 파티클은 효과의 Preview Particles 옵션도 켜야 합니다. Scene 뷰에서 Effects와 Particle Systems를 활성화하세요. 이러한 보기 설정 때문에 미리보기가 숨겨지면 도구가 수정 방법을 제공합니다. Player Movement 효과와 오디오는 Play 모드에서 테스트합니다. Animate Preview 는 바람과 애니메이션 머티리얼을 지속적으로 새로고침하는 별도의 Scatter 설정입니다.

하나의 설정으로 여러 바이옴 지정하기

Scatter Object는 원하는 수만큼 Terrain Atlas 바이옴을 대상으로 할 수 있습니다. 바이옴 선택기에는 현재 이름과 숫자 ID가 표시됩니다. + Add Target Biome 로 목록을 늘릴 수 있습니다.

설정의미예시
Biome이 Scatter Object가 나타날 수 있는 Terrain Atlas 바이옴입니다.Grassland, Forest Soil 또는 현재 라이브러리의 다른 항목입니다.
Density Multiplier: 0–2이 대상 바이옴에만 Scatter Object의 기본 밀도를 곱합니다.1은 기본 밀도, 0.5는 절반, 0은 대상 비활성화, 2는 두 배입니다.

페인팅된 혼합 영역에서는 대상 바이옴들의 합산 기여도를 평가합니다. 따라서 Grass와 Forest 경계에 걸친 경우에도 별도 정의를 복제하지 않고 하나의 오브젝트를 연속 배치할 수 있습니다.

승인된 인스턴스에는 그 위치에서 기여한 대상에 따라 소유 바이옴이 지정됩니다. 따라서 실시간 바이옴 모디파이어가 일부 대상 바이옴에만 적용되어도 같은 잔디 오브젝트의 인스턴스가 서로 다르게 반응할 수 있습니다.

배치 설정

Scatter Output 위치: Vertex 3D Terrain 창에서 3D Scatter를 펼치고 이름이나 화살표를 클릭해 Scatter Object를 엽니다. Scatter Output 드롭다운은 Target Biomes 바로 아래이자 Placement위에 있습니다. 여기에서 Meshes, Particles 또는 Meshes + Particles 를 선택합니다.

Placement 설정에서 Player Interaction 은 Static Scatter옆에 있습니다. 활성화하면 버튼 아래에 Bend Distance 가 나타납니다.

설정의미권장 설정
Scatter OutputMeshes는 설정된 메시 변형을 그립니다. Particles는 메시 변형 없이 방출 지점을 생성하며 Meshes + Particles는 둘을 결합합니다.기존 Scatter Object의 기본 출력은 Meshes입니다. Meshes + Particles는 메시 변형을 사용해 배치를 결정합니다.
Player Interaction / Bend DistanceScatter Interaction이 켜진 근처 Player Surface Effects 컴포넌트로부터 호환 메시의 끝부분이 멀어지도록 휘어집니다. Bend Distance는 끝부분의 최대 이동량을 월드 미터 단위로 제한합니다.잔디나 유연한 식물에 사용하세요. 자세한 내용은 플레이어 충돌 및 상호작용 가이드를 참조하세요. 파티클 전용 출력에는 이 메시 설정이 표시되지 않습니다.
Density: 0~100개/m²Target Biome 배율 및 실시간 런타임 밀도 적용 전의 기준 예상 인스턴스 밀도입니다.낮은 값에서 시작해 인스턴스 수와 원거리 배치 범위를 확인하며 늘리세요.
Coverage Min / Max: 0–1모든 Target Biomes의 합산 Coverage가 지정된 범위 안에 있을 때만 배치합니다.Min을 높이면 약한 혼합 영역을 제외합니다. Max를 1 미만으로 낮추면 순수 바이옴 내부를 제외합니다. Max가 1이면 일반적인 내부 배치를 유지합니다.
Spacing지형 타일 경계를 포함해 이 Scatter Object의 덤불 중심 사이에 적용되는 최소 월드 거리입니다. 0이면 간격 제한이 없습니다.뭉침과 겹침을 줄이려면 값을 늘리세요. 최종 인스턴스 수가 Density보다 적어질 수 있습니다. 중심 사이 거리이므로 큰 메시는 여전히 겹칠 수 있습니다.
Max Slope: 0–90°설정한 경사보다 가파른 표면을 제외합니다.잔디는 바위나 절벽 잔해보다 낮은 한도가 적합한 경우가 많습니다.
Scale Min / Max승인된 인스턴스에 적용할 균일한 무작위 스케일 범위입니다.크기 차이가 지나치게 눈에 띄지 않도록 적당한 범위를 사용하세요.
Alignment: 0–1선택한 Up Mode와 지형 법선 사이의 방향을 보간합니다.0은 선택한 위쪽 방향을 기준으로 수직을 유지하고 1은 표면 법선을 완전히 따릅니다.
Offset샘플링된 표면 법선 방향으로 인스턴스를 이동합니다.메시가 떠 보이거나 묻히면 작은 양수 또는 음수 값으로 조정하세요.
Enable Wind이 Scatter Object에 DPT Scatter Wind를 적용합니다. 지정된 셰이더가 해당 기능을 지원할 때만 사용할 수 있습니다.호환되는 잔디, 꽃 등 유연한 메시에서 켭니다. 단단한 소품에는 끕니다. VCCORE 머티리얼은 자체 바람 데이터를 사용하므로 필요하지 않습니다.

해안선을 따라서만 갈대 배치하기

  1. Reeds Scatter Object를 만들고 대상을 Water만으로 설정합니다.
  2. Coverage 범위를 예를 들어 0.15–0.65 으로 설정하면 Water와 Mud가 섞이는 곳에는 갈대가 배치되지만 Coverage가 1인 순수 Water는 제외됩니다.
  3. 칠해진 전이 영역의 폭과 범위를 조절해 위치를 정하고 Density와 Spacing으로 개수와 간격을 설정합니다.

Coverage는 모든 대상 바이옴의 기여도를 합산합니다. Water와 Mud를 모두 대상으로 하면 경계에서도 합계가 1이 되어 같은 범위에서 제외될 수 있습니다. 필요한 경계를 부분 Coverage로 나타내는 바이옴만 지정하세요. Coverage는 배치 가능한 표면을 결정하고 바이옴별 Density Multiplier 로 개수를 조정합니다.

내장 프리셋 및 사용자 지정 메시

Mesh Source 는 Built-in Preset 선택기 또는 Custom Mesh 필드와 같은 행에 있습니다. 추가 메시 변형은 빨간 Remove Mesh Variant 버튼으로 제거합니다.

Scatter Object는 여러 Mesh Variant를 포함할 수 있습니다. Relative Chance 는 합계가 100일 필요가 없는 상대 선택 가중치입니다. 배치 시드를 바꾸지 않고 내장 메시를 변형하려면 서로 다른 Shape Seed 값을 사용합니다. 프리셋 설명은 툴팁으로 제공됩니다.

셰이딩 및 표면 속성

Crystals를 포함한 모든 내장 프리셋은 Smoothing Angle: 0–180°을 제공합니다. 0에서는 면이 평평하게 유지되고 180에서는 맞닿은 면의 법선을 모두 혼합할 수 있습니다. 중간값은 완만한 연결부만 부드럽게 처리하고 날카로운 모서리는 유지합니다. 조명 결과만 바꾸며 메시 실루엣이나 지형 전체의 Smooth / Sharp 설정은 바꾸지 않습니다.

Vertex Colour Ramp 는 각 생성 요소의 로컬 아래쪽에서 위쪽으로 평가됩니다. Smoothness 는 0에서 거칠고 1에서 매끄러운 표면을 나타내며 새 변형의 기본값은 0.2 입니다. Metallic 는 0~1 범위의 금속 반응을 제어합니다.

생성된 메시는 Metallic을 UV3.R에 저장합니다. UV3.G에는 Smoothness 원값이 아니라 Smoothness에서 계산한 DPT의 패킹된 스케일/거칠기 값이 저장됩니다. 사용자 지정 셰이더는 이 데이터를 적절하게 디코딩해야 합니다.

발광 Scatter

내장 변형에서 Emissive 를 켠 다음 컬러 램프의 HDR 색상으로 밝기를, 램프 알파로 발광 영역을 지정합니다. DPT는 발광 바이옴과 마찬가지로 이 영역을 버텍스 알파에 패킹합니다. HDR 색상만으로는 발광이 활성화되지 않습니다. 머티리얼의 Emission 설정도 적용되며 Bloom 효과는 씬의 포스트 프로세싱에 따라 달라집니다. Emission은 실제 광원을 만들지 않습니다.

사용자 지정 메시

Custom Mesh를 선택한 뒤 3D Mesh, 선택적 서브메시 인덱스, Material 및 선택적 Distant Mesh를 지정합니다. Distant Mesh가 없으면 근거리 메시를 재사용합니다. 사용자 지정 메시는 원래 법선, 버텍스 색상 및 UV3 표면 데이터를 유지하며 내장 셰이딩, Metallic, Smoothness, Emissive 설정은 이를 수정하지 않습니다. 지원되는 DPT Scatter Wind를 켜면 원본 에셋을 바꾸지 않고 바람/바이옴 데이터가 포함된 런타임 사본을 만듭니다.

머티리얼 선택이 중요합니다. Scatter는 GPU 인스턴싱을 사용합니다. 메시 데이터에 맞는 머티리얼을 사용하고 요청 시 GPU Instancing을 켜세요. 변형의 머티리얼을 비워 두면 적절한 경우 원본 지형 머티리얼을 사용합니다.

Scatter 배치 지점에서 파티클 방출하기

Scatter Output에서 Particles 또는 Meshes + Particles 를 선택한 후 Particle Effect 1을 펼칩니다. 내장 프리셋은 가져온 스프라이트 없이 파티클 시스템, 머티리얼 및 수학적인 모양을 생성합니다. 자체 ParticleSystem 프리팹을 사용하려면 Custom을 선택하세요. 발자국은 Scatter 프리셋 목록이 아닌 Player Surface Effects에서 설정합니다.

트리거 및 방출 지점

Continuous 는 보는 카메라 주변의 유효한 배치 지점에서 방출합니다. Player Movement 는 Enable Scatter Interaction이 켜진 이동 중인 Player Surface Effects 컴포넌트가 배치 지점 가까이 지나갈 때 방출합니다. 상호작용 반경, 높이 및 강도를 사용하며 Scatter Teleport Distance보다 긴 순간 이동은 무시합니다. 메시 휘어짐은 선택 사항입니다.

Meshes + Particles는 이 Scatter Object의 메시 배치 지점을 사용합니다. Particles는 메시 변형 없이 자체 배치 지점을 생성합니다. 별도 Scatter Object는 별도 지점을 갖기 때문에 다른 오브젝트의 잔디에 자동으로 연결되지 않습니다. Emitter Fraction은 각 효과에 사용할 배치 지점의 일정 비율을 선택합니다.

Emitter Fraction과 Rate를 낮게 시작하고 Emission Offset/Rotation을 조절한 다음 카메라 범위와 예산을 설정하세요. Continuous 편집 미리보기에는 메인 Preview, Preview Particles 및 Scene 뷰의 Effects/Particle Systems가 필요합니다. Preview는 기본적으로 꺼져 있지만 Play 모드 방출에는 필요하지 않습니다.

같은 배치 지점에 독립된 레이어를 추가하려면 + Add Particle Effect 를 사용합니다. 각 레이어는 프리셋, 색상, 노이즈, 트리거, 비율, 속도 및 한도를 따로 설정할 수 있습니다. 추가 레이어는 빨간색 Remove Effect 버튼으로 제거합니다. 파티클 레이어는 상위 Shared Particle Limit를 공유합니다.

플레이어 이동에 반응시키기

  1. 기존 잔디 오브젝트에서는 Meshes + Particles를, 메시가 없는 효과에서는 Particles를 사용합니다.
  2. Grass Flecks 또는 Pollen을 선택하고 Emission Trigger를 Player Movement로 설정합니다. 우선 Emitter Fraction 0.2, Rate / Emitter 15, Minimum Movement Speed 0.1로 시작한 뒤 필요에 따라 한도를 낮추세요.
  3. 플레이어에 Player Surface Effects 를 추가하고 Enable Scatter Interaction을 켭니다. Interaction Origin/Offset을 뿌리 근처에 놓고 반경, 높이 및 강도를 조절합니다.
  4. Play 모드에서 배치 지점을 통과하세요. 멈추면 신규 방출도 멈춥니다. 메시도 휘어지게 하려면 별도로 Player Interaction과 0보다 큰 Bend Distance를 켜세요.

Scatter 뿌리가 아닌 플레이어 발밑에 효과를 표시하려면 바이옴 표면 효과를 사용하세요. 여러 바이옴을 대상으로 하는 플레이어 항목 하나에서 파티클, 발자국 및 발소리를 함께 설정할 수 있습니다.

실시간 반응 및 파티클 수명

실시간 바이옴 Strength와 Scatter Density는 신규 파티클 방출량에 곱해집니다. 값이 0이면 새 방출이 멈추고 이미 살아 있는 파티클은 수명을 마칩니다. Static Scatter는 이러한 변경과 무관하게 방출합니다. 메시 Live Shrinking은 파티클 투명도를 제어하지 않습니다.

각 활성 레이어는 배치 지점마다 GameObject를 만드는 대신 풀링된 생성 효과 또는 Custom 프리팹 인스턴스를 사용합니다. 시뮬레이션은 월드 공간에서 이뤄집니다. 프리팹의 자동 방출 속도/버스트는 비활성화되고 Scatter 방출기가 이벤트마다 하위 시스템을 제어하고 레이어 한도를 분배합니다.

방출 기준점은 배치 트랜스폼을 따릅니다. 바람이나 셰이더 휘어짐으로 변형된 메시 끝으로 이동하지는 않습니다. 프리셋/출력을 변경하거나 렌더러를 끄면 사용하지 않는 효과가 해제됩니다. 절차적 생성만으로 프레임 속도가 보장되는 것은 아니며 큰 반투명 파티클이 겹치면 비용이 높을 수 있습니다.

Scatter 배치 지점에서 공간 오디오 재생하기

Scatter Object에서 Scatter Audio 를 펼칩니다. Meshes, Particles 및 Meshes + Particles에 함께 사용할 수 있습니다. 같은 바이옴 및 배치 규칙을 따르는 보이지 않는 소리 지점을 만들려면 Audio Only 를 선택하세요. 메시 에셋이나 파티클 프리팹은 필요하지 않습니다.

  1. Target Biomes를 선택하고 Density, Coverage, Slope 및 Spacing을 설정합니다.
  2. Enable Audio 를 켜고 하나 이상의 Audio Clips을 지정합니다. 새 음성마다 유효한 클립 하나가 무작위로 선택됩니다.
  3. 공간 루프에는 Audio Trigger → Continuous 를, 플레이어 상호작용이 배치 지점에 닿을 때 재생하는 일회성 소리에는 Player Movement 를 선택합니다.
  4. 볼륨, 피치, 거리, Audio Emitter Fraction 및 소스 한도를 설정합니다. 이동 오디오에는 Minimum Movement Speed와 Sound Cooldown을 조절하세요.
  5. 활성 Audio Listener가 있는 상태에서 Play 모드로 테스트합니다. 오디오는 편집 모드 미리보기를 지원하지 않습니다.

메시, 파티클 및 오디오 효과가 배치를 공유해야 한다면 하나의 Scatter Object를 사용하세요. 트리거와 예산은 독립적입니다. 실제 발소리는 플레이어의 Footstep Audio를, 발밑 자국은 Footprints를 사용하세요. 충돌 속도나 착지 오디오를 위한 별도 설정은 없습니다.

초원: 잔디 메시를 유지하고 Grass Flecks와 Pollen 레이어를 추가한 다음 Scatter Audio에 Player Movement 잔디 스치는 소리 클립을 추가합니다. 물가 환경음: 물 바이옴에 Audio Only를 지정하고 낮은 Audio Emitter Fraction과 Source Limit를 사용해 Continuous를 선택합니다.

폭포 물보라 및 안개

폭포 아래쪽에 수동으로 배치하는 충돌 지점 띠에는 DPT_WaterfallSplashEmitter 를 사용합니다. Scatter 프로필이나 충돌 지점마다 GameObject가 없어도 띠 전체에서 공유 파티클 효과를 방출합니다.

활성화된 컴포넌트는 Play 모드에서 카메라 범위 안에 있을 때 Emission Rate 에 따라 계속 방출합니다. 물이나 플레이어와의 충돌을 기다리지 않습니다. 편집 시 Preview Particles 를 켜세요. 선택적인 실시간 바이옴/Flow 연결로 새 방출을 줄이거나 중단할 수 있습니다.

  1. 폭포 아래에 GameObject를 만들고 Add Component에서 DPT_WaterfallSplashEmitter 를 추가합니다.
  2. 기본 절차적 Waterfall Splash 를 사용하거나 다른 Particle Preset을 선택합니다. 또는 Custom 을 선택해 Particle Prefab을 표시하고 자체 효과를 지정합니다.
  3. Splash Width와 Splash Depth로 물이 닿는 범위를 덮습니다. 선택한 오브젝트의 기즈모에 띠가 표시됩니다.
  4. 위로 분사하려면 Spray Direction을 (0, 1, 0)으로 두고 Emission Rate와 Particle Limit를 조절합니다.
  5. 편집 중에 보려면 Preview Particles를 켭니다.
  6. 필요에 따라 아래 설명처럼 물 바이옴 및 Flow 속도에 연결합니다.

바람 설정

DPT Scatter Wind는 머티리얼과 Scatter Object에서 제어하며 Scatter Settings에서 카메라 거리에 따른 페이드도 설정할 수 있습니다. 머티리얼 은 셰이더에서 바람 기능이 활성화되는지 결정하며 Scatter Object의 Enable Wind 는 해당 오브젝트가 DPT Scatter Wind 경로를 사용하는지 결정합니다. 이 설정은 지정된 셰이더에 _DPT_SCATTER_WIND Boolean Keyword가 선언되어 있을 때만 표시되므로 Vertex 3D Terrain이 기능 지원 여부를 판단할 수 있습니다.

Vertex Terrain 머티리얼 사용하기

  1. 머티리얼의 Wind 섹션을 열고 Enable Wind를 켭니다.
  2. 적당한 Wind Strength를 설정합니다.
  3. Height To Tip 을 Scatter 메시의 오브젝트 공간 높이에 가깝게 지정하여 뿌리는 고정하고 끝부분은 충분히 움직이게 합니다.
  4. Compass Heading 와 Vertical Pitch를 선택합니다.
  5. 3D Scatter 섹션으로 돌아와 DPT Scatter Wind를 사용할 각 Scatter Object의 Enable Wind 를 켭니다.
  6. 크게 움직이는 끝부분이 카메라나 절두체 경계에서 사라지면 Scatter Settings의 Wind Bounds 를 늘립니다.

자갈 같은 단단한 Scatter는 같은 머티리얼을 공유하면서 Scatter Object의 Enable Wind를 끌 수 있습니다.

먼 거리의 바람 페이드 및 종료

  1. 3D Scatter → Scatter Settings → Distance & LOD를 엽니다.
  2. 움직임이 약해지기 시작할 카메라 거리를 Wind Fade Start에 설정합니다.
  3. Wind Cutoff를 시작 거리보다 크게 설정합니다. 두 거리 사이에서 바람이 부드럽게 약해지고 종료 거리에 도달하면 멈춥니다.
  4. 거리에 관계없이 바람을 유지하려면 Wind Cutoff를 0으로 되돌립니다. 종료 거리가 0이면 Wind Fade Start는 적용되지 않습니다.

예: Wind Fade Start를 20, Wind Cutoff를 40으로 설정하면 20미터 이내에서는 바람을 그대로 유지하고 20~40미터 사이에서 약해지며 40미터 이상에서는 멈춥니다.

거리는 현재 뷰의 카메라에서 각 Scatter 인스턴스의 원점까지 월드 미터 단위로 측정합니다. 각 덩어리 전체가 같은 비율로 페이드됩니다. 지원되는 DPT 셰이더에서는 근거리 및 원거리 메시와 해당 그림자에 적용되며 CPU와 GPU Scatter 렌더링 모두에서 동작합니다.

이 설정은 바람 애니메이션을 제어하며 그려지는 오브젝트 수를 줄이지는 않습니다. 렌더링 비용은 Draw Distance, Far Density 및 그림자 설정으로도 조절하십시오. 가까운 곳에서 가장 크게 움직일 때를 고려해 Wind Bounds에 충분한 여유를 두십시오.

거리 페이드에는 현재 제공되는 Vertex Terrain 셰이더를 사용하십시오. 커스텀 셰이더에는 호환되는 DPT 바람 거리 페이드 처리가 필요하며 바람 키워드만 활성화해도 이 기능이 추가되지는 않습니다. VCCORE와 다른 자체 바람 시스템은 해당 머티리얼의 설정을 사용합니다.

모션 블러나 TAA를 사용할 때 거리 페이드 변화는 이전 프레임의 모션 벡터에 포함되지 않으므로 카메라가 페이드 구간을 통과하면 재투영 정확도가 낮아질 수 있습니다.

VCCORE 머티리얼

VCCORE는 자체 제작된 바람 시스템을 사용하므로 Scatter Object의 Enable Wind 설정은 VCCORE 머티리얼에서 의도적으로 사용할 수 없습니다. 정상입니다. 모델에 Stylized Color Swapper & Material Optimizer로 바람을 칠했거나 이미 바람 데이터가 포함된 DPT 팩의 모델이라면 별도 Scatter 바람 설정이 필요하지 않습니다. VCCORE 머티리얼의 바람 설정으로 움직임을 활성화하거나 조절하세요.

지형 표면에 사용하는 네 Live Biome Modifier 슬롯은 대상 바이옴 ID에 속한 Scatter도 제어할 수 있습니다. 따라서 계절 시스템으로 지면과 식생을 함께 변경할 수 있습니다.

머티리얼 설정은 지형 머티리얼 설정 을, 예제 컨트롤러는 데모 및 런타임 가이드 를 참고하세요.

실시간 변경 중 Scatter 축소하기

  1. 3D Scatter → Scatter Settings → Distance & LOD을 엽니다.
  2. Live Shrinking 을 켜고 Fade Range 를 기본값 0.15로 시작합니다.
  3. Scatter 축소를 지원하는 제공된 DPT 지형 머티리얼을 사용하고 실시간 바이옴의 Strength 또는 Scatter Density를 애니메이션합니다.
  4. 더 부드러운 축소/재성장 전환을 원하면 Fade Range를 늘립니다. 이 값은 초가 아닌 실시간 밀도 범위의 일부이며 지속 시간과 이징은 컨트롤러에서 결정합니다.

Live Shrinking은 실시간 개체 수가 줄어들면 메시 버텍스를 인스턴스 뿌리 쪽으로 축소하고 밀도가 돌아오면 다시 키웁니다. 배치 위치를 유지하며 보이는 지오메트리와 해당 그림자에 모두 적용됩니다. 알파 클리핑 크로스페이드 대신 버텍스 축소를 사용합니다.

지원하는 CPU 및 GPU Scatter 경로에서 동작합니다. Static Scatter는 실시간 바이옴 변경을 무시합니다. 사용자 지정 머티리얼에는 DPT Scatter 축소 지원이 필요하며 지원하지 않으면 기존 가시성 동작을 유지합니다. 제작 시 배치 Density와 재생성은 실시간 밀도 애니메이션과 구분됩니다.

Transition 은 확률적 근거리/원거리 LOD 구간을 제어합니다. Live Shrinking 은 실시간 바이옴 개체 수 변경을 제어합니다. 파티클 페이드는 파티클 수명을 사용하고 수학적 발자국은 별도의 Footprint Lifetime/Fade를 사용합니다.

계절 스냅샷 및 접을 수 있는 프로필

Dynamic Biome Demo Controller 를 사용해 머티리얼 외형을 Environment Profiles로 저장합니다. 머티리얼을 편집한 다음 + Capture Current Settings as NEW Profile을 선택합니다. 각 프로필은 저장된 스냅샷이며 이후 머티리얼 편집은 다시 캡처해야 저장됩니다.

프로필의 화살표나 이름을 눌러 접거나 펼칠 수 있습니다. 제목에는 이름과 시퀀스 위치가 표시되고 첫 프로필에는 START가 표시됩니다. 새로 캡처한 프로필은 자동으로 펼쳐집니다. 펼치면 Name, Transition Seconds, 이징 및 Channels to Animate를 편집하거나 캡처, 적용, 순서 변경, 제거 버튼을 사용할 수 있습니다. Animate To Profile 는 현재 외형에서 선택한 채널을 혼합하고 결과를 유지합니다.

스냅샷 변경 사항적용 시점
라이브 모디파이어 Target Biomes전환 시작 시 추가, 교체 또는 제거된 ID를 포함하여 도착 프로필의 대상 목록이 적용됩니다. Strength, 밀도, 색상 등의 숫자 값은 계속 애니메이션됩니다. 선택되지 않은 모디파이어 슬롯은 현재 설정을 유지합니다.
시작 Dusting이 없는 경우의 Dusting Biome ID시작 Dusting Strength가 0이거나 Dusting이 꺼져 있거나 모디파이어 슬롯이 비활성이라면 시작할 때 도착 프로필의 Dusting ID를 적용합니다. 이후 Dusting Strength가 해당 ID를 사용해 애니메이션됩니다.
시작 Dusting이 보이는 경우의 Dusting Biome ID시작 슬롯이 활성이고 Dusting이 켜져 있으며 강도가 0보다 크면 기존 Dusting ID가 전환 종료 시점까지 유지됩니다.

이 규칙은 시퀀스 재생, Edit Mode Preview/스크러빙 및 Animate To Profile에 적용됩니다. 각 Live Biome Modifier 슬롯은 최대 세 대상 바이옴 ID를 지원합니다. 이는 바이옴 수에 제한이 없는 Scatter Object의 Target Biomes 목록과 다릅니다.

봄 → 겨울 → 봄 → 폭염: 물 Dusting Strength가 0인 봄, Ice Dusting이 있는 겨울, 강도가 다시 0이 된 봄, Sand Dusting이 있는 폭염을 차례로 캡처합니다. 폭염 전환은 시작 즉시 Sand를 선택하므로 얼음이 먼저 늘었다가 끝에 모래로 바뀌는 대신 강도에 따라 모래가 증가합니다. 건기에 추가 바이옴도 대상으로 지정했다면 전환 시작 시 그 바이옴이 라이브 모디파이어에 포함됩니다.

Scene 뷰에서 Dusting을 칠할 때 빨간 Dusting 미리보기는 브러시 핸들보다 먼저 그려지므로 선택된 브러시 핸들 색상이 강조 표시 위에서도 보입니다.

런타임 Scatter 및 베이크된 지형 데이터

Scatter 배치는 메인 스레드에서 동기적으로 생성한 후 렌더링을 위해 캐시합니다. 읽을 수 있는 지형 메시는 배치 지오메트리를 직접 제공합니다. 읽을 수 없는 지형 메시는 Scatter 지오메트리를 베이크한 일치하는 DPT_TerrainSurfaceData 에셋을 대신 사용할 수 있으므로 이 런타임 경로에서는 지형 Read/Write를 계속 켜 둘 필요가 없습니다.

  1. 베이크 전에 Scatter 프로필을 지정합니다.
  2. 편집기에서 지형을 수정할 수 있을 때 Bake Surface Data를 실행합니다. Scatter 프로필이 지정되어 있다면 게임플레이 표면 정보 외에도 배치 버텍스, 법선, 삼각형 및 바이옴 채널이 포함됩니다.
  3. 베이크된 에셋을 각 지형 소스의 DPT_TerrainSurfaceTarget 에 할당하고 빌드에 포함합니다.
  4. 지형 형상, 페인팅, 바이옴 ID 또는 토폴로지가 바뀌면 다시 베이크합니다. 게임플레이 전용 데이터나 오래된 베이크는 Scatter 배치에 충분하지 않습니다.
  5. 지형 Read/Write를 끈 상태로 빌드된 씬을 테스트합니다. 렌더러가 Scatter 지오메트리 베이크를 요구하면 최신 데이터를 제공하거나 해당 소스 메시의 읽기를 허용하세요.

베이크된 배치 배열은 메모리를 사용합니다. 지형 Read/Write를 꺼도 Scatter 데이터 자체는 없어지지 않습니다. 많은 인스턴스의 생성이나 재생성에는 여전히 메인 스레드 시간이 필요합니다. 이 지형 데이터 옵션은 DPT 바람 사본을 준비할 때 읽을 수 있는 메시 채널 등 사용자 지정 메시의 요구 사항을 없애지 않습니다.

성능 및 실제 사용 한계

오디오는 배치마다 음성을 만드는 대신 재사용되는 수 제한 공간 오디오 소스를 사용합니다. Audio Emitter Fraction, Audio Distance, 그룹 Source Limit 및 Shared Audio Source Limit를 조절하세요. 플레이어 표면 파티클, 발자국 및 발소리는 지형 감지와 바이옴 매칭을 공유합니다. 발자국은 시야/거리 컬링, 캐시된 인스턴싱 데이터 및 GPU 페이딩도 사용합니다. 실제 게임 카메라와 해상도에서 프로파일링하세요.

  • Scatter는 인스턴스마다 GameObject를 만드는 대신 GPU 인스턴싱으로 렌더링합니다.
  • 배치는 지형 메시에서 생성한 후 캐시됩니다. 일반적인 카메라 이동과 실시간 밀도 변경은 지형 Scatter 분포를 다시 생성하지 않습니다.
  • 카메라 거리 및 절두체 컬링은 Scatter 배치/셀 단위로 작동하므로 Cell Size는 그룹화 오버헤드와 컬링 정밀도에 모두 영향을 줍니다.
  • Far Density는 더 가벼운 원거리 메시를 사용하는 동시에 먼 곳의 인스턴스 수를 줄일 수 있습니다.
  • 넓은 지형에서 Density가 매우 높으면 후보 또는 인스턴스 안전 한도에 도달할 수 있습니다. 한도를 최대로 채우려 하지 말고 프로파일링이 필요한 경고로 간주하세요.
  • 수천 번 나타나는 사용자 지정 메시는 인스턴싱에 적합해야 하며 불필요한 버텍스, 서브메시 및 머티리얼 복잡도를 피해야 합니다.

파티클의 Emitter Fraction, Rate / Emitter, Particle Distance, Emitter Limit 및 Particle Limit는 메시 LOD와 별도로 조절합니다. 큰 투명 파티클이나 겹치는 안개는 개수가 적어도 비쌀 수 있습니다. 파티클 시뮬레이션과 버텍스 휘어짐은 베이크된 게임플레이 표면 질의를 바꾸지 않습니다.

Runtime Discovery는 선택 기능이므로 안정적인 지형 계층은 Play 중 매초 전체 탐색이 필요하지 않습니다. 내장 변형 서명은 프로필 변경 때까지 캐시됩니다. 메시 캐시는 활성 렌더러가 사용하는 메시를 유지하며 재생성 이후 오래된 항목을 해제합니다. 마지막 렌더러를 끄면 공유 Scatter 캐시가 비워집니다. 프로필 변경으로 다시 생성해야 할 수도 있습니다.

증상확인 순서
파티클이 나타나지 않음Scatter Output이 Particles 또는 Meshes + Particles인지 확인하고 Particle Preset을 선택합니다. Custom이라면 Particle Prefab을 지정하세요. Scene 뷰 편집 시 Scatter Preview와 Preview Particles를 모두 켜세요.
실시간 밀도가 0인데도 파티클이 계속 떠다님기존 파티클은 효과의 수명이 다할 때까지 남습니다. 내장 수명은 절차적 프리셋에서 정하며 다른 복구 시간을 원한다면 Custom 프리팹을 선택해 Start Lifetime을 줄이세요. 실시간 배율은 신규 방출을 제어합니다.

Scatter가 나타나지 않음Terrain Atlas 모드, Scatter Library, Target Biomes, 기본 Density, 대상 Density Multiplier, Coverage Min/Max 범위, Max Slope, 머티리얼 및 Preview를 확인하고 Rebuild Scatter를 실행하세요.
잘못된 바이옴에 Scatter가 나타남현재 Target Biome 이름/ID와 설정 후 바이옴 순서가 변경되었는지 확인하고 중복되거나 원치 않는 대상을 제거합니다.

사용자 지정 메시가 렌더링되지 않음메시/머티리얼을 지정하고 서브메시 인덱스를 확인한 뒤 GPU Instancing을 켭니다. 머티리얼이 사용자 지정 메시의 원본 데이터에 호환되는지 확인하세요.
LOD 경계에서 Scatter가 갑자기 바뀜Transition을 높이고 적절한 Distant Mesh 또는 내장 원거리 프리셋이 있는지 확인합니다. 근거리/원거리 실루엣과 스케일도 비교하세요.
계절 변경 시 Scatter가 갑자기 사라짐Distance & LOD 아래의 Live Shrinking 을 켜고 Fade Range를 조절합니다. DPT Scatter 축소를 지원하는 머티리얼을 사용하고 반응해야 하는 오브젝트에서는 Static Scatter가 꺼져 있는지 확인합니다. 제작한 배치를 다시 생성하는 대신 실시간 Strength 또는 Scatter Density를 애니메이션하세요.
폭염에서 모래로 바뀌기 전에 얼음이 자람중간 봄 프로필의 물 Dusting Strength를 0으로 캡처한 뒤 폭염 프로필에서 Sand를 Dusting Biome ID로 캡처합니다. 강도가 0인 Dusting은 시작할 때 새 ID를 적용하고, 눈에 보이는 0 초과 Dusting은 끝날 때까지 이전 ID를 유지합니다.
건기에 새로 추가한 바이옴이 반응하지 않음업데이트된 대상 목록을 도착 프로필에 캡처하고 해당 모디파이어 슬롯이 Channels to Animate에 포함됐는지 확인합니다. 도착 대상 목록은 전환 시작 시 적용되며 기존 스냅샷은 머티리얼 편집 후 자동으로 갱신되지 않습니다.
프로필 설정이 보이지 않음Environment Profile의 화살표나 이름을 눌러 펼칩니다. 접힌 프로필에는 이름과 시퀀스 위치만 표시되며 편집 및 동작 버튼은 펼친 안쪽에 있습니다.
Visual Studio에서 Scatter 인스턴싱 선언 오류가 나지만 Unity에서는 컴파일됨업데이트된 DPT Scatter 인스턴싱 include를 사용하세요. Unity 전용 인스턴싱 매크로를 보호하고 독립 HLSL 편집기를 위한 대체 선언을 제공합니다. 실제 셰이더 컴파일 오류는 Unity Console에서 별도로 확인하세요.
원거리 Scatter 밀도가 너무 높음Far Density 또는 Draw Distance를 낮춥니다. 바이옴별 Target Density Multiplier를 거리 제어 목적으로만 사용하지 마세요.
Enable Wind가 비활성화되어 있음지정된 셰이더가 _DPT_SCATTER_WIND Boolean Keyword를 선언하지 않아 Scatter Object에서 DPT Scatter Wind를 사용할 수 없습니다. Shader Graph에 DPT Scatter Wind 설정을 추가하거나 셰이더 자체 바람 시스템을 사용하세요.
VCCORE 머티리얼에서 Enable Wind가 비활성화되어 있음의도된 동작입니다. VCCORE는 자체 바람 데이터와 머티리얼 설정을 사용하므로 DPT Scatter Wind 구성이 필요하지 않습니다.
DPT 호환 사용자 지정 셰이더인데도 움직이지 않음머티리얼의 DPT Scatter Wind 키워드와 Scatter Object의 Enable Wind가 켜져 있는지 확인합니다. Blackboard Reference 이름이 정확하고 복사한 바람 블록이 Vertex Position에 연결되어 있으며 Wind Strength / Height To Tip가 적절한지도 확인하세요.
바람 때문에 오브젝트 전체가 이상하게 움직임Enable Wind, Height To Tip, 메시 오브젝트 공간 높이 및 Wind Strength를 확인합니다. 일반 지형, 회전 지형 또는 소행성에 맞는 Up Mode를 사용하세요.
카메라에서 멀어지면 바람이 멈춤Scatter Settings → Distance & LOD의 Wind Fade Start와 Wind Cutoff를 확인하십시오. 거리에 관계없이 바람을 유지하려면 Wind Cutoff를 0으로 설정합니다. 양수 종료 거리는 의도적으로 먼 거리의 애니메이션을 멈춥니다.
바람 거리 설정이 커스텀 머티리얼에 적용되지 않음셰이더가 DPT 바람 거리 페이드를 지원하는지 확인하십시오. 자체 제작된 바람과 VCCORE 바람은 해당 머티리얼의 설정을 사용하며 바람 키워드만으로는 거리 페이드가 추가되지 않습니다.
바람에 흔들리는 끝부분이 사라짐Wind Bounds를 높여 드로우 경계에 예상되는 최대 이동량이 포함되게 하세요.
중립 라이브 슬롯이 Scatter에 색상을 입힘HDR 강도 0의 흰색은 Slot 1을 포함한 네 슬롯 모두에서 중립입니다. 겹친 슬롯 대상, 다른 색상 배율 및 셰이더 Scatter 입력을 확인하세요. Dusting과 Scatter 반응은 별개 경로입니다.
HDR 램프 색상이 빛나지 않음내장 변형에서 Emissive를 켜고 램프 알파와 머티리얼 Emission 설정을 확인합니다. 사용자 지정 메시는 별도로 작성된 발광 데이터가 필요합니다.
읽기 불가능한 지형의 빌드에서 Scatter가 사라짐Scatter 프로필을 지정한 상태에서 Surface Data를 연결하고 다시 베이크합니다. 자세한 내용은 런타임 데이터 설정을 참고하세요. 게임플레이 전용 데이터에는 배치 지오메트리가 포함되지 않습니다.
눈으로 지형은 바뀌지만 잔디는 그대로임Scatter Object가 라이브 슬롯과 같은 바이옴 ID를 대상으로 하는지, Scatter Density/Colour Multiplier가 중립이 아닌지, 실시간 바이옴 마스터 스위치가 켜져 있는지, Scatter Renderer가 같은 호환 머티리얼을 사용하는지 확인하세요.
Scatter Density를 바꿔도 바로 적용되지 않음프로필 작성 밀도만이 아니라 머티리얼의 라이브 Scatter Response를 변경하고 있는지 확인합니다. 프로필 Density는 배치를 변경하므로 재생성이 필요할 수 있지만 라이브 Scatter Density는 실제 제출하는 인스턴스 수를 변경합니다.
Scatter 오디오가 들리지 않음Scatter Audio를 켜고 유효한 클립을 지정한 뒤 Volume, Emitter Fraction, 소스 한도 및 Audio Distance를 확인하세요. Play 모드에서 활성 Audio Listener로 테스트합니다. Player Movement에는 플레이어의 Enable Scatter Interaction도 필요합니다.
파티클 미리보기가 Game 뷰에만 표시됨메인 Preview와 Continuous 효과의 Preview Particles를 켭니다. Scene 뷰에서 Effects 및 Particle Systems를 활성화하고 필요하면 도구의 보기 옵션 수정 기능을 사용하세요.
파티클이나 발자국이 분홍색이 됨Console의 셰이더 오류를 확인하고 최신 공유 DPT_ProceduralParticle 셰이더를 설치하세요. 그림자 함수 시그니처는 설치된 URP 헤더를 따릅니다. URP/Core 패키지 버전을 맞추세요.
Scatter 프리셋에서 발자국을 찾는 중Player Surface Effects → 표면 효과 항목 → Footprints를 사용하세요. 발자국/오디오만 필요하면 파티클을 None으로 선택하고 바이옴 대상을 여러 개 지정하거나 Add All을 사용합니다.
