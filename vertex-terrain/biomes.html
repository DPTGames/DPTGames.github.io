DPT Vertex 3D Terrain - Biomes

Biome Setup & Reference Guide
A practical guide to creating, importing, editing, duplicating and merging terrain biomes. It explains the controls you need to use without exposing the internal generation or rendering techniques behind the system.
Scope of this guide: This documentation focuses on the user workflow: what each setting does, what textures to supply, and how to create useful biome variations. Internal generation, packing and shader implementation details are intentionally not documented.
Quick Navigation Reference: 1. Quick Start 2. Creating Biomes 3. Texture Inputs 4. Color Ramp 5. Surface Settings 6. Variants & Duplication 7. Merge Biomes 8. Direct Vertex Biomes 9. Optimization 10. Troubleshooting Support

1. Quick Start

A biome is a reusable terrain surface preset. A biome can define its color range, surface detail, normal appearance, metallic/smoothness response, emissive areas, tiling and other visual properties. Once created, it can be painted across terrain, floating islands and planetoids.

1. Create a biome. Use + Folder Biome for the fastest setup, or + New Biome if you want to assign the maps yourself.
2. Supply the source textures. At minimum, an Albedo/Base Color texture is recommended. Add Height, Normal and PBR maps when available.
3. Generate the surface. The tool creates the processed terrain detail and a matching Color Ramp automatically when a valid Source RGB texture is supplied.
4. Adjust the look. Tune Scale, AO Strength, Parallax, Normal, Smoothness, Metallic, Anti-Tiling and the Color Ramp until the biome matches your scene.
5. Create variations cheaply. Duplicate an existing biome and change its Color Ramp or surface settings instead of importing another copy of the same textures.
Recommended workflow: Build one accurate “master” biome from the original texture set first. Once it looks correct, duplicate it to make seasonal, dry, wet, darker, brighter or fantasy-colored variations.

2. Creating & Managing Biomes

Biome Palette

Biomes appear as cards in the Terrain Biomes Palette. The card shows the biome name, ID, a ramp preview and a small summary of important settings. Clicking a card selects it for painting and opens it in the Biome Inspector.

ControlDescription
+ New BiomeCreates a new biome that can be configured manually.
+ Folder BiomeCreates a biome and automatically scans a selected texture folder for suitable maps. A folder can also be dragged directly onto this control.
Auto FolderPopulates or refreshes the currently selected biome from a texture folder.
DuplicateCreates an independent copy of the biome settings while keeping the same source texture references. This is ideal for visual variants.
DeleteRemoves the selected biome from the library. Remaining biome IDs are kept in a valid order automatically.
Drag to ReorderBiome cards can be reordered in the palette. This is useful for keeping related surfaces together.
Groups / 1-0 HotkeysThe quick palette is arranged in groups of ten biomes. Number keys 1-9 and 0 select the corresponding biome in the active group.

Auto Folder Naming

The folder importer recognizes common texture naming conventions. Clear filenames make automatic setup more reliable.

Texture TypeCommon Names
Albedo / Base ColorAlbedo, BaseColor, Diffuse, Color
NormalNormal, Norm, NRM
HeightHeight, Displacement, Detail, Bump
MetallicMetallic, Metalness, Metal
Smoothness / RoughnessSmoothness, Gloss, Roughness, Rough
Ambient OcclusionAO, Occlusion, AmbientOcclusion
EmissiveEmissive, Emission, Glow
Packed PBRCommon packed-map names such as MRAO, MaskMap or Packed are recognized where possible.
Note: Auto Folder also configures the imported textures for the role it detects. If a texture is not detected correctly, simply assign it manually in the Biome Inspector.

3. Texture Inputs & Generation

Primary Inputs

PropertyDescription
Source RGBThe full-color Albedo/Base Color source. This is the main source used when automatically generating the biome's Color Ramp and processed detail.
Generated TexThe processed grayscale detail used by the terrain surface. It is normally created automatically and should usually be left to the tool.
Invert HeightReverses the height interpretation. Use this if raised areas appear recessed, or recessed areas appear raised.
Source HeightThe original imported height or displacement texture. It is kept as a source reference and does not replace the generated texture.
NormalOptional normal map for fine surface bump detail.
EmissiveOptional mask for glowing regions such as lava cracks, crystals, runes or magical surfaces.
Tip: A biome can still be useful without every map. Supply the maps you have; the system is designed to work with partial texture sets as well as complete PBR sets.

PBR Mode

Choose the input style that matches the texture package you are importing.

PropertyDescription
Separate TexturesUse individual Metallic, Smoothness/Roughness and AO textures.
Packed TextureUse a single packed PBR texture containing several surface channels.
MappingSelect the packed layout that matches the source texture. Available layouts include standard Unity MRAO/MRAR, Unreal ORM and Custom.
Packed PBRThe packed PBR texture used when Packed Texture mode is selected.
MetallicOptional metallic map used in Separate Textures mode.
Smooth/RoughOptional smoothness or roughness texture used in Separate Textures mode.
RoughnessEnable this when the Smooth/Rough texture contains roughness rather than smoothness.
AOOptional ambient occlusion source used when preparing the biome. It helps the generated result but does not need to remain as an additional standalone runtime texture.
Packed map looks wrong? The most common cause is selecting the wrong channel mapping. Check the texture package documentation and choose the matching layout before adjusting Metallic or Smoothness strength.

4. Color Ramp, Auto Generate & Color Variants

Color Ramp

The Color Ramp controls how the generated surface detail is colored. The left side represents darker/recessed detail and the right side represents brighter/raised detail. You can edit the keys manually at any time.

ControlDescription
Color RampEdit the biome's colors directly. Use this for precise art direction or to correct a small part of an automatically generated ramp.
Auto GenerateRegenerates the Color Ramp and processed detail from the current Source RGB and any other useful source maps assigned to the biome.
FixedUses stepped color bands instead of smooth interpolation. Leave it disabled for a smoothly blended ramp.
Auto Generate replaces manual ramp edits. If you have hand-edited the ramp and want to keep those edits, use the Ramp Transform controls for global color changes instead of regenerating.

Ramp Transform

Ramp Transform changes every color key together while preserving the existing relationships between the colors. It is particularly useful after duplicating a biome to create variants such as dry grass, autumn grass, scorched soil, cold stone or fantasy-colored surfaces.

ControlDescription
HueRange -1 to +1. Shifts all ramp colors around the color wheel. 0 leaves the hue unchanged.
SaturationRange -1 to +1. Negative values reduce color intensity, 0 leaves it unchanged, and positive values make colors more saturated.
BrightnessRange -1 to +1. Darkens or brightens all ramp colors together while keeping their relative arrangement.
ResetRestores the ramp to the state it was in before the current transform was started. This also preserves any manual ramp editing that had already been done before using the transform sliders.
Example - Dry Grass: Duplicate the finished grass biome, rename the copy to “Dry Grass”, move Hue toward yellow/brown, lower Saturation slightly, then adjust Brightness if required. The underlying texture set can remain the same.

5. Surface Appearance Settings

These controls change how the selected biome appears in the scene. Most changes can be previewed immediately.

PropertyRangeDescription
Scale0.1 - 10Controls how frequently the surface detail repeats across the terrain. Increase it for smaller, more frequent detail; decrease it for larger-looking texture features.
AO Strength0 - 1Controls the strength of the biome's ambient shadowing. Lower values flatten crevice shading; higher values make recessed detail read more strongly.
Parallax0 - 2Controls perceived surface depth. 0 is flat, 1 is the normal/default amount, and values above 1 exaggerate the depth.
Normal0 - 2Shown when a Normal map is assigned. 0 removes normal-map relief, 1 uses the normal amount, and higher values strengthen it.
Smoothness0 - 1 or 0 - 2Controls glossiness. When a smoothness source texture exists, values above 1 can boost the texture response.
Metallic0 - 1 or 0 - 2Controls metallic response. When a metallic source texture exists, values above 1 can boost the mapped response.
Emissive0 - 1Controls glow intensity for the biome's emissive regions.
PulseOn / OffEnables rhythmic emissive pulsing for the biome.
Priority0 - 100Used when determining which surface type should take precedence for gameplay-facing surface data such as footsteps, VFX, decals or physics. Higher values have greater priority.
Anti-Tiling0 - 1Breaks up obvious repetition. Start low and increase only as much as needed.
Seam Blend0 - 1Controls blending across difficult projection changes such as cliffs, cave entrances and sharp terrain angles. 0 is a hard transition; 1 applies full blending.
Adjustment order: Get Scale right first, then tune Normal and Parallax, then adjust AO / Smoothness / Metallic. Use Anti-Tiling and Seam Blend after the basic surface already looks correct.

6. Duplicating Biomes & Making Variants

Duplicate is intended for creating new looks from an existing biome without needlessly importing another full texture set.

  1. Finish the original biome first.
  2. Click Duplicate.
  3. Rename the copy so its purpose is clear.
  4. Use Ramp Transform, Smoothness, Metallic, AO, Parallax, Scale or other appearance settings to create the new look.
  5. Only assign different source textures when the new biome genuinely needs different texture detail.
Performance: Compatible duplicated biomes automatically reuse the same underlying texture data where possible. Their small per-biome appearance settings remain independent, allowing many visual variants without requiring a full duplicate of every source texture.
Examples: Lush Grass → Dry Grass / Autumn Grass / Dark Grass; Stone → Warm Stone / Frosted Stone / Volcanic Stone; Sand → Wet Sand / Pale Sand / Red Desert Sand.

7. Merging Two Biomes

Select exactly two terrain biomes to display the Merge Biomes controls. A merge creates a new biome; the two source biomes are left unchanged.

PropertyDescription
Mix RatioControls the balance between the two source biomes. The range keeps at least 10% of each source so the minority material is not completely lost.
Blend SoftnessControls how wide the transition is where one material meets the other. 0 gives sharper boundaries; 1 gives broader blending.
Patch SizeControls the overall scale of the generated material regions. Higher values create larger patches; lower values create smaller, busier areas.
IrregularityControls the shape of the patches. Lower values are smoother and rounder; higher values create more warped, varied boundaries.
Merge into New BiomeCreates the merged biome using the current settings. Repeating a merge creates a separate biome so different combinations can be compared safely.
Natural-looking mixes: If the result feels too noisy, increase Patch Size and/or reduce Irregularity. If the border between materials is too hard, raise Blend Softness. If one material dominates too much, move Mix Ratio back toward the center.
Merged biomes are different from simple duplicates. A merge creates genuinely new combined surface data, so it should be treated as its own authored biome rather than as a cheap color-only variation.

8. Direct Vertex Biomes

Direct Vertex Color mode is the lightweight alternative to texture-based Terrain Atlas biomes. Instead of using a source texture set, each biome is primarily driven by a direct color and its surface settings.

PropertyDescription
Direct RGBThe base color painted directly into the terrain's vertex data.
Auto Seam BlendAllows the tool to soften biome boundaries automatically where appropriate.
SmoothnessControls whether the surface reads as matte or glossy.
MetallicControls the metallic response of the biome.
AO StrengthControls ambient shadowing strength.
ParallaxControls the amount of surface depth used by the active terrain material setup.
Emissive / PulseControls glow strength and optional pulsing.
ScaleControls the biome's detail scale where applicable.
When to use Direct Vertex Color: Choose it when you want a very lightweight stylized color workflow and do not need a unique texture set for each terrain surface.

9. Library Quality & Optimization

Texture Array Export Settings

The Biome Library also contains export settings for the compiled terrain textures. These are advanced project-wide settings rather than per-biome art controls.

PropertyDescription
Compile ResolutionAuto chooses an appropriate shared resolution from the supplied biome textures. Manual options are available from 256 up to 8192 when a project needs an explicit target.
Compression ModeChoose high-quality compressed output to reduce memory use, or uncompressed RGBA32 when maximum source fidelity is more important than memory.
Generate MipmapsNormally recommended for terrain viewed at different distances. Mipmaps reduce distant texture shimmer and improve texture sampling at range.
Keep variants cheap: If two biomes use the same texture set, duplicate the biome and change its ramp/settings rather than making another copy of those texture files. The system can reuse compatible texture data automatically.
Resolution: Higher is not always better. Choose enough resolution for the closest expected camera distance. Very high-resolution source maps increase memory and compilation time even when the visible improvement is small.
Anti-Tiling: Use only as much as required to hide repetition. It is an artistic correction, not a substitute for choosing a sensible texture scale.

10. Troubleshooting Notes

"Auto Folder did not detect one of my maps."
Check that the filename contains a recognizable description such as Albedo/BaseColor, Normal, Height, Metallic, Roughness/Smoothness, AO or Emissive. If the source uses an unusual naming convention, assign that texture manually in the Biome Inspector.
"Auto Generate says I need a Source RGB texture."
Assign the biome's Albedo/Base Color texture to Source RGB, then run Auto Generate again.
"Raised areas look sunken, or cracks look raised."
Toggle Invert Height. If a Source RGB texture is assigned, the biome will regenerate using the corrected height direction.
"The automatically generated colors are close, but I want to art-direct them."
Edit individual Color Ramp keys for precise changes. For a broad color shift across the whole ramp, use Hue, Saturation and Brightness in Ramp Transform instead.
"I used Ramp Transform and want my manually edited ramp back."
Click Reset. It restores the ramp to the state captured before the current transform, including manual edits that existed before the sliders were moved.
"My packed PBR texture gives strange metallic or smoothness results."
Check PBR Mode is set to Packed Texture and confirm the Mapping matches the source package. If using separate maps instead, switch to Separate Textures and assign them individually.
"My roughness texture looks backwards."
In Separate Textures mode, enable the Roughness checkbox when the supplied map stores roughness rather than smoothness.
"The normal detail is too weak or too strong."
Adjust the Normal slider. 1 is the standard strength, 0 removes the normal-map effect, and values above 1 strengthen it.
"The surface looks too flat."
First check that a useful Source Height / Generated Tex exists. Then increase Parallax gradually. Also confirm Scale is sensible before exaggerating the depth.
"The texture repeats too obviously."
Adjust Scale first so the material is physically believable, then increase Anti-Tiling until the repeating pattern is less noticeable.
"I can see a transition line on cliffs or around cave entrances."
Increase Seam Blend. If the seam remains, check that the relevant Normal and source textures are assigned correctly and that the terrain has been updated after the change.
"My merged biome looks too spotty or noisy."
Increase Patch Size, lower Irregularity, or increase Blend Softness. These three controls have the largest effect on the overall shape and readability of the merge.
"I duplicated a biome just to make a different color. Will that duplicate all the heavy textures?"
Not when the duplicate continues to use the same compatible source texture set. Duplicated variants can reuse the underlying texture data while keeping their own ramp and appearance settings.
"I changed a source texture and the duplicate no longer behaves like the original."
That is expected. A duplicate only remains a lightweight variation while it continues to share the same source texture set. Assigning different detail, normal or PBR sources makes it a genuinely different surface.
