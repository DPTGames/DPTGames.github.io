DPT_VertexTerrainUI

Component Reference Guide
A Unity EditorWindow tool designed for real-time vertex-based terrain painting, organic sculpting, procedural gradient blending, spline path generation, multi-tile seamless terrains, and performance optimization.

1. Target & Brush Settings

Configuration Parameters

Controls target pipeline workflows, active terrain meshes, and primary brush characteristics in the Inspector.

Property Description
Pipeline Mode Switches the target between Terrain Atlas (texture-array based biomes rendered through the shared VCCore shader) and Direct Vertex Color (lightweight, texture-free biome blending baked straight into vertex data). Switching pipeline modes on an existing mesh automatically re-assigns the VCCore material and converts the mesh's vertex data to match the new mode.
Target Terrain Object The active root GameObject containing the MeshFilter and MeshRenderer targeted for painting or sculpting in the SceneView. When working with a multi-tile terrain, tools will automatically discover and include neighboring tiles near the brush without needing to reassign this per tile.
Radius The world-meter radius of the 3D interactive brush (adjustable via hotkeys [ and ] or Shift + ScrollWheel).
Brush Flow / Opacity Defines the rate of color and weight application per stroke, ranging from smooth gradual feathering (0.01) to instantaneous replacement (1.0).
Blend Sharpness Controls transition contrast between biomes, from soft gradual gradients (0.0) to crisp stylized borders (1.0).
Dynamic Topology When enabled, automatically subdivides triangle edges that stretch beyond a configurable maximum length while sculpting or drawing spline paths, so raised terrain keeps clean, evenly-sized geometry instead of a handful of giant stretched triangles. Subdivision is throttled internally (both by cursor movement and by time) so continuous strokes stay responsive rather than re-triangulating on every tick.
Pen / Tablet Input Graphics tablets and stylus pointers are supported alongside the mouse for brush placement, useful for freehand painting and sculpting passes that benefit from a more natural pointing device.
Tip: Use hotkeys B, H, G, S, and P to instantly toggle between Paint, Sculpt, Gradient, Smooth, and Path modes without using the UI buttons.

Ground / Biome Library

Each terrain (or family of terrains) references a Biome Library asset — the palette of ground presets available to the Paint brush and gradient tools. Terrain Atlas and Direct Vertex Color pipelines each keep their own independent list of presets within the same library, since they carry different data (Terrain Atlas presets reference source textures; Direct Vertex Color presets store a flat base color instead).

Action What it does
Add Appends a new, blank ground preset to the active pipeline's list and opens it in the preset editor.
Duplicate Clones the selected preset (including its ramp, textures, and PBR settings) as a starting point for a variant biome.
Delete Removes a preset from the library and re-indexes the remaining presets. In Terrain Atlas mode this also triggers a recompile of the Micro Atlas and Detail Texture Array so the material stays in sync.
Reorder / Swap Drag presets to reorder the palette, or swap two entries directly. Reordering updates preset IDs and any painted vertex/face data automatically remaps to the new indices.

Per-preset authoring options include a color ramp (used for both albedo tinting and height-based blending), emissive color and intensity, ambient occlusion / parallax depth strength, normal strength, tiling scale, and anti-tiling patch rotation to break up obvious texture repetition at large tiling scales. PBR input can come from a single packed texture (with selectable channel layouts covering common Unity, and Unreal-style ORM packing conventions) or from separate metallic/smoothness maps.

Note: The Micro Atlas and Detail Texture Array are regenerated automatically whenever the library changes in Terrain Atlas mode — you don't need to manually trigger a rebake after adding or editing a biome.

2. Core Architecture & Tool Modes

  • Primary Tool Modes: Manages 8 distinct operational modes including Paint, Sculpt, Cave Digger, Gradient, Smooth, Clean-Up Brush, Path Splines, and Eyedropper sampling.
  • Dynamic Topology & Tessellation: Automatically subdivides and tessellates stretched polygon edges on-the-fly when edge lengths exceed the configured threshold during sculpting or path creation.
  • Raycast AO Baker: Fires hemisphere raycasts per vertex to bake contact ambient occlusion directly into vertex data (UV2.x) for realistic crevice and shadow definition.
  • Chunk Partitioning & LODs: Slices large terrain meshes into N x N spatial grid partitions, automatically generating decimated LOD levels and native Unity LODGroup components.

Tool Modes In Depth

Mode What it's for
Paint Paints biome IDs and blend weights across triangle corners, blending multiple ground presets together at their borders according to Blend Sharpness.
Sculpt Raise / lower geometry along the vertex normal. Includes a Grab action for freeform vertex dragging (useful for pulling out ridges or overhangs by hand) alongside standard raise/lower.
Cave Digger (Carve) Digs tunnels, caves, and overhangs into the mesh. On multi-tile terrains, a carve that reaches a tile boundary can automatically detect and punch through into the neighboring tile so the tunnel continues seamlessly across the seam.
Gradient Automatically blends biomes based on slope angle or height range, useful for laying down large-scale rules like "snow above X height" or "rock on slopes steeper than Y" in a single pass.
Smooth Relaxes vertex positions toward their neighbors to soften sculpted detail. Smoothing passes run multi-threaded across the affected vertex groups for responsiveness on larger brushes.
Clean-Up Brush Simplifies over-dense or messy geometry (for example, areas that accumulated a lot of dynamic-topology subdivision) back down to a cleaner triangle budget.
Path Splines Lay down a spline in the SceneView (add, move, and delete nodes interactively) to paint a biome strip along a path or carve a trench/road profile following the curve.
Eyedropper Samples the biome under the cursor and sets it as the active paint biome — a quick way to match an existing area without hunting through the palette.

Material Pipelines: Terrain Atlas vs. Direct Vertex Color

Both pipelines render through the same shared VCCore master shader/material system used across all DPT packages, so switching a terrain between pipelines doesn't require assigning a different shader by hand — the tool configures the correct keywords and texture bindings automatically.

Pipeline Behavior
Terrain Atlas Compiles your biome library into a Detail Texture Array (per-biome normal, height, and packed PBR data) plus a small Micro Atlas lookup texture carrying per-biome color ramps and material parameters. Best suited to large, natural, photoreal-leaning terrains that need real texture detail up close.
Direct Vertex Color Bakes each biome's flat base color directly into the mesh's vertex colors — no texture arrays or atlases involved. Zero texture memory overhead and fully SRP Batcher / GPU Resident Drawer friendly, at the cost of per-texel surface texturing. A good fit for stylized, low-poly, or highly instanced environments.

Undo & Safety

All painting, sculpting, and carving operations are fully integrated with Unity's native Undo system. Each continuous stroke (from mouse/pen down to release) is grouped as a single Undo step rather than one step per tick, so undoing a stroke reverts the whole brush pass in one action instead of requiring dozens of undos.

3. Multi-Tile Terrains

Large worlds are typically built from several terrain tiles placed edge-to-edge rather than one enormous mesh. The tool keeps adjacent tiles' shared borders in sync automatically as you paint, sculpt, and carve near a seam:

  • Seam-aware sculpting and painting: Height changes, biome blends, and vertex colors applied near a tile boundary are mirrored onto the matching vertices of the neighboring tile, so the seam stays visually continuous instead of showing a hard edge.
  • Cross-tile carving: A carve stroke that reaches a boundary can tunnel through into the next tile automatically, continuing caves and overhangs across multiple tiles.
  • New tile placement checks: When creating a neighboring tile, the tool compares the new tile's footprint against the actual current mesh bounds of nearby tiles (not just their nominal grid size) and warns before creating it if they'd overlap — a safety net for tiles whose edges have already drifted from prior sculpting.
Best practice: Seam synchronization needs both tiles on either side of a boundary to have been touched at least once (so the seam is registered) before it can be reliably protected. If you carve or aggressively drag geometry right at the very edge of a brand-new tile pair before painting or sculpting a normal pass over that boundary first, the boundary may not be respected as strictly as it is once it's an established, registered seam. When starting a new tile next to an existing one, do an ordinary paint or sculpt pass across the shared edge first, then use Cave Digger near it with confidence.

4. Performance Tips

  • Dynamic Topology has a real cost: subdividing geometry is inherently more expensive than a plain sculpt tick. For broad, sweeping height changes, consider sculpting with Dynamic Topology off and only re-enabling it for a finishing pass where you want extra triangle density for detail.
  • Large single strokes vs. many small ones: a few large, deliberate strokes generally sync tile seams and rebuild vertex data less often than many tiny flicks of the brush — both get the same result, but fewer stroke boundaries means fewer full-mesh Undo snapshots.
  • Chunk Partitioning for big terrains: once a terrain's layout is finalized, partition it into an N x N grid of chunks with generated LODs rather than leaving it as one very large mesh — this keeps both editor responsiveness and runtime rendering cost down.
  • Smoothing large areas: the Smooth brush's relaxation pass is multi-threaded per affected vertex group, so larger brush radii scale reasonably well, but very large radii on very dense meshes will still take longer than a small, focused pass.

5. Troubleshooting Notes

"Target GameObject does not have the VCCore Shader assigned."
Ensure the GameObject's MeshRenderer references the correct `SH_DPT_VCCore` material. Click the "Assign VCCore Material" or "Enable on Material" button directly inside the Target section of the UI to automatically fix material configurations.
"Selected GameObject does not have a MeshFilter attached."
The target object must contain a valid MeshFilter and mesh asset to record vertex color and height data. Select an appropriate terrain tile or generate a new surface via the Terrain Generator panel.
A seam between two tiles looks cracked or misaligned after carving a tunnel near the edge.
This is almost always a not-yet-registered seam (see the Multi-Tile Terrains section above). Undo back to before the carve, run a normal Paint or Sculpt stroke across that shared edge so the boundary gets registered, then redo the carve.
Sculpting feels sluggish, or there's a brief pause right at the start of a stroke.
A short pause at the very start of a stroke is expected — it's Unity's Undo system taking its one snapshot for that stroke, and it's proportional to mesh size. If sculpting stays slow throughout the stroke rather than just at the start, try disabling Dynamic Topology temporarily; subdivision is the most expensive part of a sculpt tick, especially with a small brush radius moving quickly (e.g. with a pen tablet) across a lot of stretched geometry.
