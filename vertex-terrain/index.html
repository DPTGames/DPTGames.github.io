DPT_VertexTerrainUI

Component Reference Guide
A Unity EditorWindow tool designed for real-time vertex-based terrain painting, organic sculpting, procedural gradient blending, spline path generation, and performance optimization.
Quick Navigation Reference: 1. Target & Brush Settings 2. Core Architecture & Tools 3. Troubleshooting Notes 4. Support

1. Target & Brush Settings

Configuration Parameters

Controls target pipeline workflows, active terrain meshes, and primary brush characteristics in the Inspector.

Property Description
Pipeline Mode Switches between Terrain Atlas (Texture-based arrays using VCCore shaders) and Direct Vertex Color modes.
Target Terrain Object The active root GameObject containing the MeshFilter and MeshRenderer targeted for painting or sculpting in the SceneView.
Radius The world-meter radius of the 3D interactive brush (adjustable via hotkeys [ and ] or Shift + ScrollWheel).
Brush Flow / Opacity Defines the rate of color and weight application per stroke, ranging from smooth gradual feathering (0.01) to instantaneous replacement (1.0).
Blend Sharpness Controls transition contrast between biomes, from soft gradual gradients (0.0) to crisp stylized borders (1.0).
Tip: Use hotkeys B, H, G, S, and P to instantly toggle between Paint, Sculpt, Gradient, Smooth, and Path modes without using the UI buttons.

2. Core Architecture & Tool Modes

  • Primary Tool Modes: Manages 8 distinct operational modes including Paint, Sculpt, Cave Digger, Gradient, Smooth, Clean-Up Brush, Path Splines, and Eyedropper sampling.
  • Dynamic Topology & Tessellation: Automatically subdivides and tessellates stretched polygon edges on-the-fly when edge lengths exceed the configured threshold during sculpting or path creation.
  • Raycast AO Baker: Fires hemisphere raycasts per vertex to bake contact ambient occlusion directly into vertex data (UV2.x) for realistic crevice and shadow definition.
  • Chunk Partitioning & LODs: Slices large terrain meshes into N x N spatial grid partitions, automatically generating decimated LOD levels and native Unity LODGroup components.

3. Troubleshooting Notes

"Target GameObject does not have the VCCore Shader assigned."
Ensure the GameObject's MeshRenderer references the correct `SH_DPT_VCCore` material. Click the "Assign VCCore Material" or "Enable on Material" button directly inside the Target section of the UI to automatically fix material configurations.
"Selected GameObject does not have a MeshFilter attached."
The target object must contain a valid MeshFilter and mesh asset to record vertex color and height data. Select an appropriate terrain tile or generate a new surface via the Terrain Generator panel.
