小さい画面では、幅の広い表を横にスクロールするとすべての列を読めます。

Vertex 3D Terrain は、Unity 内でメッシュを編集するツールです。丘を盛り上げる、開口部を作る、道を作る、同じオブジェクトに異なる地表を塗る、といった作業ができます。地形がメッシュなので、張り出した岩、浮島、惑星のような形も作れます。

作業は大きく二つに分かれます。形状ツールはメッシュの形を変えます。サーフェスツールは色や質感を変えます。岩のバイオームを塗っただけで崖になるわけではありません。法線や視差の強さを上げると細部が立体的に見えますが、キャラクターが立てる場所は変わりません。

最初の地形を作る

  1. Tools → DPT Games → Vertex 3D Terrain を開きます。ウィンドウ上部で English または 日本語を選べます。
  2. バイオームライブラリ（Biome Library）を選びます。これは地表に塗る素材のパレットです。最初は既存のライブラリを使って操作を覚えると進めやすくなります。
  3. パイプラインモード（Pipeline Mode）を選びます。テクスチャ付きの地面なら Terrain Atlas、頂点の色を中心とした見た目なら Direct Vertex Color を選びます。
  4. 地形生成の設定を開き、小さな平面や単純な島から始めます。練習では分割数を控えめにして、編集しやすいサイズにします。
  5. 生成したメッシュを編集対象にします。Scene ビューで地形を表示し、表面にブラシのプレビューが出ることを確認します。
  6. スカルプト（Sculpt）を選び、半径を広め、変位の速度を低めにしてドラッグし、丘を作ります。Ctrl を押しながら操作すると地形を下げられます。Smooth で形をなめらかに整えます。
  7. バイオームを選び、ペイント（Paint）で地表を塗ります。不透明度を下げると少しずつ混ぜられ、1 にすると選んだ地表を強く適用します。
  8. 境界に別のバイオームを塗り、ブレンドのシャープさを変えてみます。なだらかな境界と、はっきりした境界の違いを確認します。
  9. ツールの保存・プレハブ機能で地形を保存し、Unity のシーンも保存します。保存したものを開き直し、形と地表が保たれていることを確認してから、より大きな地形に進みます。

最初の練習におすすめの組み合わせ：草の丘を作り、片側に露出した岩を塗り、その上に土の道を通します。洞窟、複数タイル、実行時の効果を使わずに、形状・地表・パスの基本を試せます。

編集対象、ライブラリ、ブラシ設定

何を編集するかを選ぶ

現在の編集対象から、メッシュと設定が読み込まれます。複数のオブジェクトで構成する地形では、対象リストでペイントやスカルプトを許可するオブジェクトを選びます。Active と Paint/Sculpt の許可は別の役割を持ちます。一つのタイルを選んでも、周囲のすべてのタイルが編集可能になるとは限りません。

必要な地形を追加・登録し、シーンの構成を変えたら対象リストを更新します。境界をまたぐストロークの前に Paint/Sculpt のスイッチを確認してください。対象にはツールが使うメッシュのコンポーネントが必要です。ゲーム中に物理レイキャストで地形を検出する場合は、コライダーも必要になります。

設定意味変更する場面
Terrain Atlasライブラリから生成したテクスチャとカラーランプで、塗られた地表を描画します。岩、砂、草、水のような地表など、テクスチャの細部を使いたい場合に選びます。専用シェーダーは SH_DPT_VCTerrain です。
Direct Vertex Colorアトラスによるテクスチャ表現の代わりに、メッシュの頂点へ地表の色を保存します。色を中心としたシンプルな表現に使います。頂点の数と配置によって、塗れる色の細かさが変わります。
Biome Library再利用できる地表プリセットの集まりです。二つのパイプラインは、同じライブラリ内に別々のプリセット一覧を持ちます。関連する地形では同じライブラリを共有し、地表を独立して調整したい地形では別のコピーを使います。
半径（Radius）ワールド空間でのブラシの到達範囲です。単位はメートルです。大きな地形には広い半径、仕上げには小さい半径を使います。形状とペイントで同じ範囲を使うなら、半径を連動させます。
形状の速度・強さストロークでメッシュがどれだけ速く動くかを決めます。慎重な作業では低くします。高すぎると、短いストロークでも深い溝や高い突起ができます。
ペイントの不透明度選んだ地表が、既存の地表を置き換えたり混ざったりする強さです。低い値では弱いストロークを重ねて調整でき、1 では選んだ地表を強く適用します。
ブレンドのシャープさ塗ったバイオーム同士の境界の見え方を決めます。低い値ではなだらかに、高い値では境界が明確になります。メッシュの頂点数は増えません。
ブラシ形状Circle、Square、Diamond、Noise Jitter でストロークの形を変えます。最初は円形が扱いやすいです。直線的な輪郭には四角など、規則性を崩したいときはジッターを使います。
筆圧Strength、Radius、Both から、筆圧で変える項目を選べます。最低限の筆圧も設定できます。強さを徐々に変えるなら Strength、強く押すほどブラシを広げるなら Radius を選びます。
プレビューの色形状とペイントのブラシ範囲を区別する色です。アルファ値でプレビューの透明度を変えます。地形上で見やすい色を選びます。この色は、実際に塗られるバイオームの色には影響しません。
Worklight / Scene HUD作業用の追加照明と、現在のツールを示す簡易表示です。形を見やすくしたり、使用中のツールを確認したりするときに使います。最終結果はシーン本来の照明でも確認します。

パイプラインを変えると、地形のサーフェスデータの使い方が変わります。完成済みの地形を変換する前にコピーを保存し、変換後の見た目を比較してください。Terrain Atlas のテクスチャ細部が、Direct Vertex Color でも同じように見えるとは限りません。

個別のプリセット、テクスチャ入力、ライブラリの操作はバイオームガイドで説明しています。マテリアル全体に効く設定は地形マテリアル設定を参照してください。

土台となる形を生成する

ジェネレーターが作るのは、完成した風景ではなく、作業の出発点となるメッシュです。目的に近い形を選び、その輪郭をスカルプトし、地表を塗って仕上げます。

土台の形適した用途確認する点
平面地形・高さプリセット平らな地面や、Island Mountain、River Valley、Crater Basin などを使う風景。全体の大きさ、分割数、プリセットの高さ。分割数が多いほど細かく編集できますが、メッシュの負荷も増えます。
Planet / Planetoid複数の方向から編集できる、閉じた地形。Single Mesh と Multi Tile の違い、単一メッシュの Cube Sphere、Icosphere、UV Sphere。ワールド上方向が適さない場所では、表面の向きに沿って編集します。
Cube複数の面に地形を作るための箱型の土台。各面の分割数とタイル設定。スカルプト中は角と面の境界も確認します。
浮島下面を持つ台地。独立した陸地の制作に向いています。上面の輪郭、高さプリセット、下面の形状。円形、角を丸めた四角形、細長い形では輪郭が変わります。尖った下面、丸いボウル状、段状、先細りの下面も使い分けます。

解像度・分割数：必要な特徴を表現できる程度の頂点から始めます。広い範囲で密度を上げると、メッシュ全体のサイズが急に増えることがあります。高密度の境界オプションは、生成した境界付近に頂点を追加するためのものです。編集範囲全体に適切な密度を用意する代わりにはなりません。

配置：World Origin はシーンの原点、Position Offset は指定した位置です。Scene View Center は作業中のビューの中心に配置します。Ground Snapped View はビューの水平位置を使い、Y = 0 に置きます。任意の地形表面へ自動的に吸着させる機能としては扱わないでください。

浮島では、細部を追加する前に上面と下面の輪郭を確認します。縁を丸めるには、滑らかな曲線を表現できるだけの既存の頂点列が必要です。

形状ツールとサーフェスツール

形状と地表には別々のツール選択があります。一部のブラシは組み合わせて、一度のストロークで形を変えながら塗ることができます。Path、Mask、Gradient は専用の操作手順を使います。ドラッグする前に、有効なボタンと Scene HUD を確認してください。

形状ツール：メッシュを変える

ツール動作使用例
SculptUp、Surface Normal、View Direction の方向に頂点を上げ下げします。Ctrl で方向を反転します。普通の丘には Up、惑星や壁には Surface Normal、特定の視点からの作業には View Direction を使います。
Inflate表面の局所的な向きに沿って外側へ押し出します。反転したストロークでは内側へ引き込みます。岩の膨らみを厚くしたり、くぼみの形を調整したりします。
Smooth頂点の配置をなめらかにします。スカルプト後の鋭い凹凸を整えます。繰り返し使うと、残したい細部まで弱くなることがあります。
Grabブラシ範囲の形状をドラッグで移動します。地形全体を作り直さずに、稜線を横へ引いたり輪郭を直したりします。
Cave動的トポロジーを使い、空洞、洞窟、張り出しを作るための形状編集を行います。自然な開口部を作れます。経路と断面を指定したい場合は、トンネルパスを使います。
Clean-Upブラシ範囲内の不要な、または不均一な形状を整理します。トポロジー編集で密度が高くなった場所を整えます。実行後は輪郭と塗った地表の境界を確認します。
Path編集できるノードで曲線を作り、道、溝、階段、トンネル、橋を生成します。幅を決めて経路を作ります。パスの説明を参照してください。
Mask面を選び、選択範囲に操作を適用します。台地、柱、平らな壁などに使います。面マスクの説明を参照してください。

サーフェスツール：見た目を変える

ツール動作使用例
Paint選択したバイオーム、または複数のバイオームの重み付きの組み合わせを塗ります。道に土を塗ったり、草と岩を指定した割合で混ぜたりします。
Fill現在のバイオームでつながっている領域に、地表をまとめて適用します。すべての面を手で塗らずに、連続した領域を置き換えます。
Smear既存の地表の重みを、ストロークの方向に引き伸ばします。新しい地表を選ばずに、塗った領域を筋状に伸ばします。
Blend / Biome Blend既存のバイオームの境界をやわらげます。塗った境界をぼかします。地表の重みをならす機能で、地形そのものは平滑化しません。
Gradient高さ、傾斜、空間内の方向に応じてバイオームを配置します。山頂に雪、急斜面に岩を塗ります。グラデーションを参照してください。
Eyedropperカーソルの下にある地表を取得します。すでに塗られたバイオームで、続きを塗りたいときに使います。
Dustingダスティング効果用のマスクを、塗る、ならす、消す、埋める操作です。雪やほこりを重ねてよい場所を指定します。見た目はマテリアルのダスティング設定で決めます。

複数バイオームのブラシでは、塗る地表を選び、それぞれの相対的な重みを指定します。Equalize Weights は均等な重みにします。Noise を使うと分布の規則性を崩せます。複雑な組み合わせを全体に適用する前に、小さな範囲で試してください。

動的トポロジーと法線

動的トポロジー（Dynamic Topology）は、小さな三角形が必要な場所に形状を追加します。最大辺長（Max Edge Length）は、どの長さの辺を分割するかの基準です。低い値にすると細かい形状になり、通常は処理やメモリの負担も増えます。洞窟・トンネルの処理で使われ、対応するスカルプトやペイントでも有効にできます。

大きな三角形が原因で目的の形を作れないときに使います。粗いメッシュ全体が、必ず均一な高密度グリッドになるわけではありません。大きな変更後はワイヤーフレームを確認し、シーンの大きさに合う基準値を使ってください。

フラット法線とスムーズ法線は、面の間の照明の見え方を変えます。フラット法線は各ポリゴンを強調し、スムーズ法線は面の間の明暗をなめらかにつなぎます。頂点を実際に動かす Smooth ブラシとは別の設定です。

面を選んで形を作る

  1. Mask を有効にして選択方法を決めます。Brush は範囲を塗って選択、Single Face は一面ずつ選択、Flood Island はつながった領域を選択します。
  2. 作りたい形の土台になる面を選びます。Shift を押すと選択から面を取り除けます。
  3. Grow、Shrink、Invert で範囲を整えます。Select Slope は角度の範囲、Select Biome Faces は指定した地表 ID で選択します。
  4. 操作または形状プリセットを選びます。実行前に対象範囲を確認します。
  5. 上からだけでなく横からも結果を確認します。必要なら元に戻し、範囲や設定を調整します。
操作意味使い方の目安
Flat Plateau / 押し出し選択範囲を変位させます。高さが正なら上げ、負なら下げます。Taper は側面の広がり方です。Taper が 1 ならまっすぐ、1 未満なら内側へ、1 より大きければ外側へ広がります。直立した台地にはワールド上方向、斜面には表面の向きに合わせる設定が適しています。
PillarClassical、Cylindrical、Square Pedestal の柱を作ります。Height は高さ、段・リングと Taper は輪郭を変えます。Bevel で縁をやわらげられます。
Arch土台や入口の構成、頂点の高さ、アーチの厚み、曲線の分割数からアーチを作ります。Semi-Circular は半円、Gothic Pointed は頂点が尖った形、Segmental は浅い弧です。分割数を増やすとなめらかになり、形状の量も増えます。
Boulder選択範囲から Faceted Crag、Smooth Dome、Jagged Spire の岩を作ります。高さで大きさ、ノイズで不規則さを決めます。最初はノイズを控え、基本の形を確認します。
Bevel対応する生成形状の縁を面取りします。Width は面取り部分の幅です。分割数 1 は平らな面取り、多い分割数では丸みを付けやすくなります。
Level選択範囲を、ワールド Y 座標の平均高さにそろえます。水平な台に使います。壁や惑星の表面に合わせたい場合は Flatten を使います。
Flatten選択範囲の平均的な表面方向に合わせて平らにします。斜めの表面に、水平ではない平面を作ります。
Scale Mask選択範囲の中心を基準に X、Y、Z の倍率で拡縮します。1 はその軸を変更しません。正の倍率で、小さな調整から始めます。
Subdivide Mask選択範囲に三角形を追加します。細かい編集の前に、粗すぎる範囲を分割します。
Fill Holeマスクが接している、処理可能な開いた境界を埋めます。穴の境界に選択が触れている必要があります。保護された地形タイルの縁は、普通の穴とは別に扱われます。
Delete Faces保護された境界の処理を考慮しつつ、選択面を削除します。開口部に使います。元に戻せる状態を保ち、周囲の形状も確認します。
Paint Mask選択面へ地表を適用します。生成した台地や構造物に、手塗りせずに専用のバイオームを与えます。

高さ・傾斜・方向で地表を配置する

グラデーションは、ルールに沿って地表を分布させる機能です。始点と終点のバイオームを選ぶか、ランプに複数の停止点を追加します。グラデーション内の位置が混ざり方を決め、Strength が適用の強さ、Sharpness が境界の鋭さを決めます。

モード用途設定の進め方
Cone Volume一つの山など、局所的な地形。土台、頂点、半径、高さ範囲を指定します。Fit Mountain は対象地形に合う円錐を推定し、Snap to Peak は最高の頂点に移動します。傾きと向きで、斜めの地形にも合わせられます。
Directional Line指定した方向に沿う移り変わり。線や矢印のハンドルを範囲に置きます。始点と終点によって、どちらの地表が強くなる場所かを決めます。
Whole Altitude低地の草、高地の雪など、全体の高さルール。実際の地形を含む高さ範囲を指定します。範囲が地形より完全に上や下にあると、一種類だけで塗られることがあります。
Whole Slope平地の土、崖の岩など、傾斜のルール。角度範囲を選び、適用前に水平な場所と急斜面の両方を確認します。

山の地表を作る例：まず高さで草から雪への大まかなグラデーションを適用します。次に傾斜で岩を追加し、最後に個別の場所を手で塗ります。前の分布を少し残すなら、後の処理の Strength を下げます。

円錐の傾斜・崖フィルターで適用範囲を制限できます。Live Preview で配置を確認してから確定し、まったく別の地形では円錐をリセットします。バイオーム自身のカラーランプは別の設定です。その素材の細部に色を付けるもので、ワールド高度による雪の境界を作るものではありません。

道、川床、階段、トンネル、橋

地表のパスから始める

  1. Path を有効にし、Surface を選びます。
  2. Scene ビューで二つ以上のノードを追加します。ハンドルを動かして経路を決め、曲線を細かく調整したい場所にノードを追加します。
  3. Width、ブレンド、スカルプトの操作を選びます。最初は短い経路で試します。
  4. Single Biome、または経路に沿うグラデーションを選びます。地表だけを帯状に塗るなら Paint Path を使います。
  5. 形状だけなら Create Path、形状と地表の両方なら Create & Paint を使います。
設定調整するもの使用例
幅（Width）路肩を含む通路全体の幅です。外側のブレンド範囲は、中心の通路の外に移行部分を追加します。用途に必要な道幅を確保し、ブレンドで周囲の地形につなぎます。
ノードの幅倍率そのノードでのパス幅に掛ける倍率です。1 は通常の幅です。広場や分岐の場所でノードの幅を大きくします。
高さオフセット配置した位置に対して、目標のパス高さをずらします。小さな正の値で道を持ち上げ、負の値で浅い溝を作ります。
強さ（Strength）指定したパス断面へ形状を近づける強さです。低い値で軽く調整し、確認してから必要に応じて繰り返します。
Max Height Gapパスの元になる周辺の地表を探せる高さ差を制限します。使いたい地形が遠すぎて取得されない場合に上げます。階段の一段の高さを決める設定ではありません。
Grade and Level高さを整えた道のような通路を作ります。起伏のある場所に、通れる経路を作ります。
Raise Embankment通路を盛り上げます。周囲より高い道や土手を作ります。
Carve Trench / 川床地形に水路状のくぼみを掘ります。排水溝や、川の地表の下にある実際の川床を作ります。
Smooth Corridor経路の形状をなめらかにします。盛り上げや掘削の新しい断面を選ばずに、荒れた道を整えます。
断面（Cross-section）Flat、Crowned、Curved Trench で、経路を横切る方向の形を変えます。Crown Height は中央を上げ、Trench Depth は中央を下げます。どちらも形状の距離を指定します。
縁の平滑化周囲の地形との接続部分をやわらげます。道の中心、階段の踏み面、川床を保ちながら、外側をなじませます。
Closed Loop経路の終わりを始まりにつなぎます。環状の道に使います。最初のノードでのつながりを確認します。

階段を作る

スカルプト操作で Steps を選びます。Step Height は一段の垂直方向の高さです。Step Depth はパス方向の踏み面の長さで、高さとは独立して設定できます。Step Bevel は縁の丸みです。低い値では鋭い縁、高い値では摩耗したような丸い縁になります。

キャラクターの大きさに合わせて高さと奥行きを決め、横から確認します。面取りで縁をやわらげても、必要な平らな踏み面が失われないようにします。段の間隔を表現できる密度の形状を用意してください。粗い地形に長い階段を作る場合は、トポロジーを細かくする必要があります。

中央と側面を塗る

パスのグラデーションは、経路に沿ってバイオームを変えます。停止点の位置 0 は始点、1 は終点です。土、砂利、岩などの区間に停止点を追加できます。Bank の設定では両側に別のバイオームを配置します。Bank Width はメートルではなく、半幅に対する割合です。例えば 0.35 は、左右それぞれの半幅のうち外側 35% を使います。

プレビューで隣り合う地表の影響が重なる場所を確認できます。塗る前に側面と境界を見てください。川のバイオームを塗ると川のような帯になりますが、実際の水路が必要なら川床の形状を別に作ります。

トンネルを作る

Tunnel に切り替え、地形内を通る経路を配置します。断面は Circle、Square、Flat Bottom Arch から選べます。歩ける床が欲しい場合には、底が平らな断面が便利です。

最小被覆深さ（Minimum Cover Depth）は、トンネルの上に必要な地形の厚みです。中心が地中にあっても、幅や高さの端が外へ出ると無効になることがあります。赤い表示や無効な場所を確認し、経路を深くする、断面を小さくする、目的の開口に合わせて被覆条件を調整する、といった方法で直します。

Create Tunnel は形状を変え、Paint Tunnel は壁の地表を変えます。生成後は入口、出口、タイルの境界を確認してください。

橋を作る

Bridge に切り替えます。両端をつなぎたい陸地に置き、中間ノードを空間に配置します。Flat Deck はシンプルな橋床、Deep Girder は深い構造、Arched Underside は平らな歩行面の下にアーチを作ります。

上からも下からも確認し、特に各陸地との接続を見てください。曲面の世界では、橋全体が地形に埋まらないことを確認します。ワールド上方向を基準とする配置が、惑星のどの側でも適しているとは限りません。

必要な場合だけ端点を細かく指定する

トンネルと橋の端点は、標準では自動配置です。入口や接続を正確に決めたい場合は Pick Start または Pick End で、一面またはつながった面の集まりを選びます。両端は独立しているので、始点だけ、終点だけ、または両方を固定できます。

対象の地形オブジェクト上で、作りたい開口部に合う輪郭の、つながった面を選びます。四角い入口には正方形や長方形の範囲が便利です。端点の選択を解除すると、その端は自動配置に戻ります。固定した端点の周辺で面を削除・再生成したら、選択を確認し、トポロジーが変わった場合は選び直してください。

複数の地形タイルを編集する

タイルは、大きな地形を別々のメッシュオブジェクトに分けたものです。隣接タイルと継ぎ目の処理により、対応する編集を共有境界にまたがって行えます。ただし、各オブジェクトを登録し、その操作を許可しておく必要があります。

  1. 生成されたタイル配置を使うか、つなぐ境界が接していることを確認します。
  2. 対象リストにタイルを登録し、Paint/Sculpt のスイッチを確認します。
  3. 一つの継ぎ目をまたぐ、小さなストロークを試します。形状と地表の境界の両方を確認します。
  4. 複数タイルをまたぐパス、トンネル、生成形状では、処理後にすべての接続部分を確認します。
  5. 現在の対象だけでなく、変更したすべてのタイルのメッシュを保存します。

マテリアルの Seam Blend はテクスチャの投影をなじませる設定です。メッシュの境界を溶接したり、穴をふさいだりはしません。継ぎ目が気になる場合は、形状の隙間、法線による明暗の差、テクスチャの境界のどれかを先に見分けます。それぞれ対処が異なります。任意に重ねたメッシュが、自動で一続きの地形になるとは考えないでください。

地形を保存・最適化する

編集しやすい状態を保つ

細かいトポロジーを使う前に、大まかな形を作ります。細部には小さいブラシを使い、追加の三角形が必要でなければ、広い範囲に非常に小さな Max Edge Length を使わないようにします。形状の密度は編集の負荷、テクスチャ解像度は見た目とメモリに影響します。片方を下げても、もう片方の問題が自動的に解決するわけではありません。

Direct Vertex Color で AO をベイクする

レイキャスト AO ベイカーは、Direct Vertex Color の地形で、くぼみや接触部の陰影を追加します。ライトマップやシーン照明の代わりではありません。主要な形状が完成してからベイクしてください。後で形を変えると、保存した陰影が合わなくなることがあります。

レイの品質を上げるとサンプリング品質が上がる一方、時間もかかります。最大遮蔽距離は、どの距離の形状まで陰影に影響するかを決めます。コントラストは陰影の強調度です。まず試しにベイクし、遮られた場所がすべて真っ黒にならないように調整します。

チャンク分割と LOD

チャンク分割では、地形を 1×1、2×2、4×4、8×8 などのグリッドに分けます。小さいチャンクは Unity が必要な部分を表示しやすくする一方、オブジェクトと描画グループを増やします。最大の分割数を常に使うのではなく、シーンに合う配置を選びます。

LOD1 と LOD2 は簡略化したメッシュです。目標比率は、どれだけの形状を残すかを示します。小さい比率は三角形を減らしますが、小さな形を失いやすくなります。Unity の切り替えしきい値は、メートル単位の距離ではなく、画面上で占める相対的な高さです。最後のカリングしきい値で、描画をやめる大きさを決めます。

生成したコライダーには LOD2 が使われます。階段、縁、開口部で想定どおりに衝突するかを確認します。三角形ベースの地表問い合わせでは、サーフェスデータがコライダーの実際のメッシュと三角形の順序に一致する必要があります。別のメッシュ向けのベイクでは、違う地表が返ることがあります。

生成結果を使う場合は、必要に応じて Hide Original Mesh を有効にし、元と生成後の両方を重ねて表示していないか確認します。チャンクと LOD は仕上げの工程として扱ってください。元の地形のすべての編集が、自動的に軽くなるわけではありません。

保存・プレハブ出力メッシュと地表データを保ち、シーンで再利用できるようにします。開き直して、マテリアル参照、見た目、衝突を確認します。

マテリアルの変更は、それを共有するすべてのオブジェクトに影響します。GameObject を複製するだけでは、アセットが独立するとは限りません。地形ごとに異なる全体設定が必要なら、別のマテリアルを保存するか、独立コピーの機能を使います。

キーボード・マウス操作

ショートカットは Scene ビューで作業中に使います。同じキーでも、Mask、Path、Gradient、Dusting のモードによって動作が変わります。入力欄への文字入力が優先されます。macOS では、Ctrl/Cmd の操作に Cmd を使います。

  • [ / ] と Shift + マウスホイール で半径を変えます。Ctrl/Cmd + Shift + PageUp / PageDown は細かい半径調整です。
  • Ctrl/Cmd + Shift + Up / Down で形状の速度、Ctrl/Cmd + Shift + Left / Right で地表の不透明度を調整します。マイナス・イコールの操作は現在のツールに応じて働きます。
  • Ctrl + ドラッグ で対応する Sculpt/Inflate の方向を反転します。Shift は対応ブラシを一時的に平滑化・ブレンドへ切り替え、マスク選択中は範囲から除外します。
  • Alt + Shift + 1…9, 0 で表示中のパレットグループ内のバイオームを選びます。Tab / Shift + Tab でグループを切り替えます。
  • Escape は現在の特別な操作を終了するか、ツールを解除します。パスモードを離れてもノードは残ります。経路を消す場合は Clear Nodes を使います。

症状最初に確認すること
ブラシが何も変えない対象、Paint/Sculpt の許可、現在のツール、半径、強さを確認します。Scene ビューにフォーカスがあり、入力欄がキーを受け取っていないかも確認します。
塗った境界が角張るペイント情報はメッシュ形状に結び付いています。頂点密度を確認し、局所的な分割や対応する動的トポロジーを検討します。ブレンドのシャープさでは三角形の数は変わりません。
丘がとがりすぎる変位の速度を下げ、半径を広げ、トポロジーを確認します。形状を少しずつ平滑化してください。法線だけを変えても照明しか変わりません。
トンネルが地表を突き抜ける経路全体の幅、高さ、最小被覆深さを確認します。必要な場所で深くするか、断面を小さくします。
グラデーションで全面が同じ地表になる高さ・傾斜範囲が地形を含むか、円錐が重なるか、停止点の ID が正しいかを確認します。
タイルの間に継ぎ目が出るまず物理的な隙間を探し、登録、隣接タイルの許可、法線、マテリアルを確認します。投影用の Seam Blend では形状の隙間を閉じられません。
別の地形の見た目も変わるライブラリ、マテリアル、テクスチャを共有していないか確認します。独立した設定が必要なら別のコピーを作ります。
キャラクターが形状を通り抜ける、浮くコライダーが編集後のメッシュに合っているか確認します。チャンクを生成した場合は LOD2 の簡略化も確認します。
ゲーム中に違うバイオームが返る変更後にサーフェスデータを再ベイクし、当たったコライダーの三角形順序に合わせます。制約はレイキャストテスターのガイドを参照してください。
編集が重くなる三角形数、ブラシ範囲、動的トポロジーを確認します。コピーで不要な密度を減らして比較し、テクスチャ解像度は別に確認します。
