小さい画面では、幅の広い表を横にスクロールするとすべての列を読めます。

Vertex 3D Terrain では、Unity 内でメッシュベースの地形を直接生成・編集できます。一般的な地面、惑星、浮島を作成し、その後で形状を変形し、サーフェスをペイントし、パスや構造物を作成し、グラデーションを適用し、複数の地形タイルをまたいで編集できます。

形状ツールは実際のメッシュを変更し、サーフェスツールは見た目を変更します。対応している形状ツールとサーフェスツールは同じストロークで同時に使用できるため、地形を変形しながらペイントすることもできます。

最初の地形を作る

  1. Tools → DPT Games → Vertex 3D Terrain を開きます。
  2. Create Terrain を開き、作成する地形を Flat Terrain、Planet、Floating Island から選びます。
  3. Starting Biome を選びます。Floating Island では Top Biome と Bottom Biome を選びます。地形のサイズ、形状、解像度も調整します。使用できる項目は地形タイプによって異なり、たとえば Floating Island では幅、長さ、下面の深さ、台地の形、下面の形、Surface Variation を設定できます。
  4. Spawn Position で生成位置を選びます。Live Preview が有効なら、生成前に全体の大きさと輪郭を確認します。
  5. 選択した地形タイプに応じて、Generate Floating Island、Generate Planetoid、Generate Surface などの生成ボタンをクリックします。
  6. 生成後は形状ツールとサーフェスツールで編集できます。メッシュをスカルプト・変形し、バイオームを塗り、パスやグラデーションを作成し、マスクで面を選択できます。対応する形状ツールとサーフェスツールは、同じストロークで組み合わせることもできます。
  7. 細かなディテールを加える前に、まず全体の大きな形を整えます。細かい編集が必要な場所では、後から局所的に形状密度を増やせます。
  8. 満足できる結果になったら、Unity シーンと保持したい生成アセットと一緒に地形を保存します。

最初の練習：小さな地形を生成し、Sculpt で輪郭の一部を変形してから、Paint、Path、または別のサーフェスツールを試します。大きなシーンに取りかかる前に、生成と編集の基本的な流れを短時間で確認できます。

編集対象、ライブラリ、ブラシ設定

何を編集するかを選ぶ

現在の編集対象から、メッシュと設定が読み込まれます。複数のオブジェクトで構成する地形では、対象リストでペイントやスカルプトを許可するオブジェクトを選びます。Active と Paint/Sculpt の許可は別の役割を持ちます。一つのタイルを選んでも、周囲のすべてのタイルが編集可能になるとは限りません。

必要な地形を追加・登録し、シーンの構成を変えたら対象リストを更新します。境界をまたぐストロークの前に Paint/Sculpt のスイッチを確認してください。対象にはツールが使うメッシュのコンポーネントが必要です。ゲーム中に物理レイキャストで地形を検出する場合は、コライダーも必要になります。

設定意味変更する場面
Terrain Atlasライブラリから生成したテクスチャとカラーランプで、塗られた地表を描画します。岩、砂、草、水のような地表など、テクスチャの細部を使いたい場合に選びます。専用シェーダーは SH_DPT_VCTerrain です。
Direct Vertex Colorアトラスによるテクスチャ表現の代わりに、メッシュの頂点へ地表の色を保存します。色を中心としたシンプルな表現に使います。頂点の数と配置によって、塗れる色の細かさが変わります。
Biome Library再利用できる地表プリセットの集まりです。二つのパイプラインは、同じライブラリ内に別々のプリセット一覧を持ちます。関連する地形では同じライブラリを共有し、地表を独立して調整したい地形では別のコピーを使います。
半径（Radius）ワールド空間でのブラシの到達範囲です。単位はメートルです。大きな地形には広い半径、仕上げには小さい半径を使います。形状とペイントで同じ範囲を使うなら、半径を連動させます。
形状の速度・強さストロークでメッシュがどれだけ速く動くかを決めます。慎重な作業では低くします。高すぎると、短いストロークでも深い溝や高い突起ができます。
ペイントの不透明度選んだ地表が、既存の地表を置き換えたり混ざったりする強さです。低い値では弱いストロークを重ねて調整でき、1 では選んだ地表を強く適用します。
ブレンドのシャープさ塗ったバイオーム同士の境界の見え方を決めます。低い値ではなだらかに、高い値では境界が明確になります。メッシュの頂点数は増えません。
ブラシ形状Circle、Square、Diamond、Noise Jitter でストロークの形を変えます。最初は円形が扱いやすいです。直線的な輪郭には四角など、規則性を崩したいときはジッターを使います。
筆圧Strength、Radius、Both から、筆圧で変える項目を選べます。最低限の筆圧も設定できます。強さを徐々に変えるなら Strength、強く押すほどブラシを広げるなら Radius を選びます。
プレビューの色形状とペイントのブラシ範囲を区別する色です。アルファ値でプレビューの透明度を変えます。地形上で見やすい色を選びます。この色は、実際に塗られるバイオームの色には影響しません。
Worklight / Scene HUD作業用の追加照明と、現在のツールを示す簡易表示です。形を見やすくしたり、使用中のツールを確認したりするときに使います。最終結果はシーン本来の照明でも確認します。

パイプラインを変えると、地形のサーフェスデータの使い方が変わります。完成済みの地形を変換する前にコピーを保存し、変換後の見た目を比較してください。Terrain Atlas のテクスチャ細部が、Direct Vertex Color でも同じように見えるとは限りません。

個別のプリセット、テクスチャ入力、ライブラリの操作はバイオームガイドで説明しています。マテリアル全体に効く設定は地形マテリアル設定を参照してください。Terrain Atlas のバイオームデータを使って Grass、Flower、Mushroom、Pebble、Custom Mesh を配置する方法は3D Scatter ガイドを参照してください。

土台となる形を生成する

Create Terrain を開き、Flat Terrain、Planet、Floating Island のいずれかを選びます。各ジェネレーターは地形マテリアル付きのメッシュを作成し、編集対象として登録します。スカルプトや細かなペイントを始める前に、目的に合う土台の形とバイオームを設定してください。

配置、プレビュー、バイオーム選択

Live Preview は、Scene ビューに一時的な低解像度の灰色メッシュを表示します。位置、大きさ、輪郭の確認に使います。実際に生成される地形は選択したフル解像度を使用し、この灰色表示は完成したバイオームテクスチャのプレビューではありません。

Spawn Position配置
World Origin(0, 0, 0) から開始します。
Position Offsetワールド原点を基準に、指定した絶対 XYZ 座標を使います。
Scene View CenterScene ビューカメラの回転中心を使います。
Ground Snapped Viewビューの X/Z 座標を使い、Y = 0 に配置します。任意の地形表面へレイキャストして吸着する機能ではありません。

Starting Biome は、Flat Terrain と Planet の初期地表を選びます。選択肢は現在のサーフェスパイプラインとライブラリに従います。Floating Island では、下で説明する Top Biome と Bottom Biome を別々に選びます。生成後は、すべての地表を自由に塗り直せます。

Flat Terrain

Shape Preset から Flat Plane、Island Mountain、River Valley、Crater Basin を選びます。Flat Terrain はジェネレーターのカテゴリ名であり、高さプリセットによって丘やくぼみも作れます。

Control用途
Surface Name生成する地形オブジェクトの名前を指定します。
Quick Size / Tile Size (Square)正方形タイルの幅と長さをメートル単位で指定します。Quick Size には 25、50、100、250、500、1000 m のプリセットがあります。
Grid SubdivisionsX/Z 方向のグリッド密度を設定します。Density ボタンでは 32、64、128、256 を開始値として選べます。
High Density Borders内部は選択した解像度のまま、恒久的なタイル境界の密度を 2 倍にします。タイル全体を 2 倍の密度にせず、継ぎ目を支える頂点を増やせます。
Mesh Complexity頂点数・三角形数の概算と 1 クアッドあたりの間隔を表示します。大きく高密度な地形を作る前に確認してください。

準備ができたら Generate Surface をクリックします。最初から全タイルを最大解像度にせず、必要な大きな特徴を表現できる程度の形状を用意し、細部は後から局所的に追加します。

Planet：連続メッシュまたはタイル

Planetoid Name、Starting Biome、Radius、Mesh Structure を設定します。Single Mesh は一つの連続オブジェクトを作成し、Multi Tile は立方体の 6 面にタイルを配置します。

Structure形状と密度の設定用途
Single MeshShape Preset：Sphere、Cube、Rounded Cube。Rounded Cube では Roundness を 0（立方体）から 1（球）まで設定できます。Cube 系の形状では Face Grid Density を使います。連続した閉じた土台を作ります。箱型の世界を反転して室内にする用途にも使えます。
Single Mesh SphereSphere Topology：Cube Sphere、Icosphere、UV Sphere。Cube Sphere は Face Grid Density、Icosphere は再帰的な Subdivision Level、UV Sphere は Resolution を使います。目的の形や編集に合う三角形の分布を選びます。異なるトポロジー方式の密度値は同じ意味ではありません。
Multi TileShape Preset：Planetoid または Cube。Tiles Per Face (N×N)、自動計算の Tile Size、Tile Grid Subdivisions、High Density Borders。別々に編集できる地形タイルを作ります。総タイル数は 6 × N² で、2 なら 24 タイル、4 なら 96 タイルです。

Multi Tile では、各面が合うよう Tile Size は (2 × Radius) / Tiles Per Face で計算されます。High Density Borders は、投影前に各タイル境界の密度を 2 倍にし、面をまたぐ継ぎ目や立方体の角も対象にします。Generate Planetoid をクリックしたら接続部を確認し、World Up が不適切な場所では表面方向に沿うブラシを使います。

室内を作る場合は、Single Mesh の Cube または Rounded Cube を生成し、Mask モードで全ての面を選択して Invert Faces を使います。これは別のジェネレーターではなく編集操作です。

Floating Island

浮島は、上面の台地と造形された下面を持つ閉じたメッシュです。名前、配置、二つのバイオームを設定し、上面と下面の輪郭を両方確認してください。

Control変更内容
Top Biome / Bottom Biome上面の台地と下面に別々の地表を指定します。たとえば上を草、下を岩にできます。
Edge Blend Width縁の両側で二つのバイオームを混ぜる距離をメートル単位で指定します。共有する縁では均等に混ざります。両側に同じバイオームを選ぶと、この項目は無効になります。
Width (X), Length (Z), Underside Depth (Y)島の水平寸法と下面方向の深さを設定します。
Plateau ShapeCircular、Rounded Square、Oval Long の輪郭を選びます。
Bottom Keel ShapePointed Spire、Rounded Bowl、Stepped Crag、Flat Taper の下面形状を選びます。
Top Surface Preset上面に地形の高さプリセットを適用します。水平な台地から始める場合は Flat Plane を選びます。
Rock Jaggedness下面にプロシージャルな岩ノイズと凹凸を追加します。
Round Plateau Edge / Edge Radius既存の頂点列を曲げて縁を丸めます。新しいループを追加するのではないため、曲線を表現できるだけのグリッド解像度が必要です。
Grid Subdivisions浮島メッシュの密度を設定します。輪郭や予定している編集で必要な場合だけ増やしてください。

Generate Floating Island をクリックします。Edge Radius は形状を変更し、Edge Blend Width はバイオームの遷移を変更します。別々に調整し、ペイントや Scatter 配置の前に下面も確認してください。

Surface Variation

Surface Variation を有効にすると、生成する地形、Planetoid、Floating Island の上面に決定論的な高さ変化を加えられます。浮島下面の Rock Jaggedness とは別の機能です。

Control意味
Strength最大の高さ変位をメートル単位で指定します。選んだ基本形状を保つには低い値から始めます。
Feature Sizeワールド空間での最大ノイズ特徴のおおよその大きさです。大きい値では、より広い丘状の変化になります。
Detailフラクタルノイズのレイヤー数で、1～6 を指定します。レイヤーを増やすと細かい変化が増えるため、それを表現できる形状密度も必要です。
World Seed / RandomizeSeed を変更するか Randomize を選ぶまで、同じパターンを再現できます。同じ設定を再現したい場合は Seed を保持してください。

Live Preview で設定を比較し、最後はフル解像度の生成結果で判断します。粗いグリッドに強い Variation を加えても細かな形状は作れません。また、ノイズを加えることとサーフェステクスチャを塗ることは別の処理です。

形状ツールとサーフェスツール

形状と地表には別々のツール選択があります。一部のブラシは組み合わせて、一度のストロークで形を変えながら塗ることができます。Path、Mask、Gradient は専用の操作手順を使います。ドラッグする前に、有効なボタンと Scene HUD を確認してください。

形状ツール：メッシュを変える

ツール動作使用例
SculptUp、Surface Normal、View Direction の方向に頂点を上げ下げします。Ctrl で方向を反転します。普通の丘には Up、惑星や壁には Surface Normal、特定の視点からの作業には View Direction を使います。
Inflate表面の局所的な向きに沿って外側へ押し出します。反転したストロークでは内側へ引き込みます。岩の膨らみを厚くしたり、くぼみの形を調整したりします。
Smooth頂点の配置をなめらかにします。スカルプト後の鋭い凹凸を整えます。繰り返し使うと、残したい細部まで弱くなることがあります。
Grabブラシ範囲の形状をドラッグで移動します。地形全体を作り直さずに、稜線を横へ引いたり輪郭を直したりします。
Cave動的トポロジーを使い、空洞、洞窟、張り出しを作るための形状編集を行います。自然な開口部を作れます。経路と断面を指定したい場合は、トンネルパスを使います。
Clean-Upブラシ範囲内の不要な、または不均一な形状を整理します。トポロジー編集で密度が高くなった場所を整えます。実行後は輪郭と塗った地表の境界を確認します。
Path編集できるノードで曲線を作り、道、溝、階段、トンネル、橋を生成します。幅を決めて経路を作ります。パスの説明を参照してください。
Mask面を選び、選択範囲に操作を適用します。台地、柱、平らな壁などに使います。面マスクの説明を参照してください。

サーフェスツール：見た目を変える

ツール動作使用例
Paint選択したバイオーム、または複数のバイオームの重み付きの組み合わせを塗ります。道に土を塗ったり、草と岩を指定した割合で混ぜたりします。
Fill現在のバイオームでつながっている領域に、地表をまとめて適用します。すべての面を手で塗らずに、連続した領域を置き換えます。
Smear既存の地表の重みを、ストロークの方向に引き伸ばします。新しい地表を選ばずに、塗った領域を筋状に伸ばします。
Blend / Biome Blend既存のバイオームの境界をやわらげます。塗った境界をぼかします。地表の重みをならす機能で、地形そのものは平滑化しません。
Gradient高さ、傾斜、空間内の方向に応じてバイオームを配置します。山頂に雪、急斜面に岩を塗ります。グラデーションを参照してください。
Eyedropperカーソルの下にある地表を取得します。すでに塗られたバイオームで、続きを塗りたいときに使います。
Dustingダスティング効果用のマスクを、塗る、ならす、消す、埋める操作です。雪やほこりを重ねてよい場所を指定します。見た目はマテリアルのダスティング設定で決めます。

複数バイオームのブラシでは、塗る地表を選び、それぞれの相対的な重みを指定します。Equalize Weights は均等な重みにします。Noise を使うと分布の規則性を崩せます。複雑な組み合わせを全体に適用する前に、小さな範囲で試してください。

動的トポロジーと法線

動的トポロジー（Dynamic Topology）は、小さな三角形が必要な場所に形状を追加します。最大辺長（Max Edge Length）は、どの長さの辺を分割するかの基準です。低い値にすると細かい形状になり、通常は処理やメモリの負担も増えます。洞窟・トンネルの処理で使われ、対応するスカルプトやペイントでも有効にできます。

大きな三角形が原因で目的の形を作れないときに使います。粗いメッシュ全体が、必ず均一な高密度グリッドになるわけではありません。大きな変更後はワイヤーフレームを確認し、シーンの大きさに合う基準値を使ってください。

全体の Smooth / Sharp シェーディングボタンは Scene HUD の隣にあります。Sharp 法線は各ポリゴンを強調し、Smooth 法線は地形メッシュの面の間で照明をなめらかにつなぎます。頂点を実際に動かす Smooth ブラシや、Scatter Variant の Smoothing Angle とは別の設定です。

面を選択し、編集範囲を制限して形を作る

  1. Mask を有効にし、選択方法を決めます。Brush は範囲を塗って選択、Single Face は一面ずつ正確に選択、Flood Island はつながった領域を選択します。
  2. 作りたい形の土台になる面を選びます。Shift を押しながら操作すると選択から面を取り除けます。
  3. Grow、Shrink、Invert で範囲を整えます。Select Slope は角度範囲、Select Biome Faces は指定したサーフェス ID を使います。
  4. 操作または形状プリセットを選び、実行前に対象範囲を確認します。
  5. 上からだけでなく横からも結果を確認します。必要なら Undo し、選択範囲や設定を調整します。

選択とペイント境界

Brush Drag は Circle または Square の範囲で面を選び、Single Face は個別の三角形を選択し、Flood Island は連結した領域を選択します。Shift で面を除外できます。Grow と Shrink は選択を 1 面リングずつ広げたり縮めたりし、Invert は補集合を選び、Clear は現在の選択を消します。カウンターには複数タイルを含む選択面数が表示されます。

条件で選択する場合は Slope Angles を設定して Select Slope を使うか、バイオーム ID を入力して Select Biome Faces を使います。Select All は面の反転など、メッシュ全体に対する操作に便利です。

Paint Edges は Paint 操作と、自動ペイントされる生成形状に適用されます。Sharp は面境界を明確に保ち、Blended は隣接面へ地表の遷移をやわらげます。この設定はペイント境界を制御し、保存した Editing Mask は編集できる場所を制御します。

形状、サーフェス、トポロジーの操作

操作意味使い方の目安
Flat Plateau / extrusion選択範囲を変位させます。正の高さは上げ、負の高さは下げます。Taper は側面が広がる・狭まる形を変えます。Taper 1 はまっすぐ、1 未満は内側へ、1 より大きい値は外側へ広がります。直立した台地には World Up、斜面には表面方向への整列が適しています。
PillarClassical、Cylindrical、Square Pedestal の柱を作ります。Height は高さ、段やリングと Taper は輪郭を変えます。Bevel で縁をやわらげられます。
Arch選択した土台から Arch Apex Height、Vault Thickness、Curve Segments、Arch Profile を使ってアーチを作ります。Semi-Circular は丸い形、Gothic Pointed は尖った頂点、Segmental は浅い弧です。Align to Surface はタイルをまたぐ場合も選択範囲の平均法線に沿います。ワールド上方向へ伸ばす場合は無効にします。Dynamic Topology では Curve Segments を増やせます。
Boulder選択範囲から Faceted Crag、Smooth Dome、Jagged Spire の岩を作ります。Height は大きさ、Noise は規則性を崩します。最初はノイズを控え、基本形を確認します。
Bevel対応する生成形状の縁をやわらげます。Bevel Extrude Edge は押し出した上側の縁を丸め、地形側の基部は変えません。短い押し出しや狭いマスクでは Width が制限されます。1 Segment は面取り、多い Segment はより丸い形になります。Pillar の Bevel は輪郭変化と四角い縦角をやわらげ、Arch の Bevel は足元まで続きます。
Invert Faces選択した三角形の頂点順序と表面方向を反転します。Select All を使えば、閉じた立方体型 Planet を内向きの部屋にできます。これは選択範囲を反転する操作ではありません。
Level選択範囲を平均的なワールド Y 高さへそろえます。水平な台に使います。壁や Planet の表面方向に合わせたい場合は Flatten を使います。
Flatten選択範囲の平均表面方向に合わせて平らにします。斜面上に、強制的に水平へせず平面を作れます。
Scale Mask選択範囲の中心を基準に X、Y、Z の倍率で拡縮します。1 はその軸を変更しません。正の倍率で小さな調整から始めます。
Subdivide Mask選択範囲に三角形を追加します。細かな編集を行うには粗すぎる場所で先に使います。
Fill Hole選択が接している処理可能な穴を埋め、新しい面を選択状態にします。Seam Ledger または保持された Flat Tile の境界頂点から欠けた縁を定義できる場合、破損したタイル境界を修復できます。正常な外周は開いたままです。実行前に有効な Editing Mask を解除してください。
Delete Faces選択した三角形を削除して開いた境界を残します。Undo に対応します。まだ隣接タイルがない境界も含め、恒久的なタイル境界の面は保護されます。Tunnel Mouth のノードは削除できます。作成された開口部と Collider を確認してください。
Paint選択した面へ指定した地表を適用します。フリーハンドで塗らずに、生成した台地や構造物へ専用のバイオームを設定できます。

保存した範囲だけを編集する

  1. Mask ツールで、編集したい面を選択します。
  2. Set Mask をクリックし、その選択を編集範囲として保存します。
  3. Editing Mask を有効にすると、その範囲内だけをペイント・スカルプトできます。範囲外の面は保護されます。共有する境界頂点は固定されるため、隣接面や溶接済みタイル継ぎ目が引き離されません。
  4. Editing Mask をオフにすると制限を一時停止し、再度オンにすると同じ範囲を再開できます。既定のショートカットは Ctrl/Cmd + Shift + L で、Hotkey Sheet から変更できます。
  5. Clear Editing Mask で保存した範囲を削除します。現在の面選択はそのまま残ります。

保存した Editing Mask と現在の面選択は別のデータです。面選択を Grow、Clear、または置き換えても保存した範囲は変わりません。新しい境界に変更したい場合は Set Mask をもう一度使います。共有境界を固定する必要があるため、狭い選択では実際に動かせる内部頂点が少なくなることがあります。

Extrusion や Fill Hole の前には、有効な Editing Mask を解除してください。マスクを一時停止している間に操作が面を再構築すると、ツールが保存済みマスクを消去し、通知を表示する場合があります。トポロジー変更後に新しい範囲を選び、Set Mask を再度使ってください。

閉じた形を室内へ変える

Invert Faces は、選択した三角形とその表面方向を反転します。立方体型 Planet から部屋を作る場合は、Mask モードで Select All を使い、その後 Invert Faces を実行します。内側から見た結果を確認し、キャラクターが使う側から Collider も確認してください。Undo に対応します。

Invert は選択される面を反転し、Invert Faces はメッシュそのものを反転します。法線再計算や、対応する Subdivision、Cleanup、LOD のワークフローでは選択した面方向が維持されます。閉じた表面の一部だけを反転すると、隣り合う面が逆方向を向く場合があるため、局所的な反転後は接続部を確認してください。

高さ・傾斜・方向で地表を配置する

グラデーションは、ルールに沿って地表を分布させる機能です。始点と終点のバイオームを選ぶか、ランプに複数の停止点を追加します。グラデーション内の位置が混ざり方を決め、Strength が適用の強さ、Sharpness が境界の鋭さを決めます。

モード用途設定の進め方
Cone Volume一つの山など、局所的な地形。土台、頂点、半径、高さ範囲を指定します。Fit Mountain は対象地形に合う円錐を推定し、Snap to Peak は最高の頂点に移動します。傾きと向きで、斜めの地形にも合わせられます。
Directional Line指定した方向に沿う移り変わり。線や矢印のハンドルを範囲に置きます。始点と終点によって、どちらの地表が強くなる場所かを決めます。
Whole Altitude低地の草、高地の雪など、全体の高さルール。実際の地形を含む高さ範囲を指定します。範囲が地形より完全に上や下にあると、一種類だけで塗られることがあります。
Whole Slope平地の土、崖の岩など、傾斜のルール。角度範囲を選び、適用前に水平な場所と急斜面の両方を確認します。

山の地表を作る例：まず高さで草から雪への大まかなグラデーションを適用します。次に傾斜で岩を追加し、最後に個別の場所を手で塗ります。前の分布を少し残すなら、後の処理の Strength を下げます。

円錐の傾斜・崖フィルターで適用範囲を制限できます。Live Preview で配置を確認してから確定し、まったく別の地形では円錐をリセットします。バイオーム自身のカラーランプは別の設定です。その素材の細部に色を付けるもので、ワールド高度による雪の境界を作るものではありません。

道、川床、階段、トンネル、橋

地表のパスから始める

  1. Path を有効にし、Surface を選びます。
  2. Scene ビューで二つ以上のノードを追加します。ハンドルを動かして経路を決め、曲線を細かく調整したい場所にノードを追加します。
  3. Width、ブレンド、スカルプトの操作を選びます。最初は短い経路で試します。
  4. Single Biome、または経路に沿うグラデーションを選びます。地表だけを帯状に塗るなら Paint Path を使います。
  5. 形状だけなら Create Path、形状と地表の両方なら Create & Paint を使います。
設定調整するもの使用例
幅（Width）路肩を含む通路全体の幅です。外側のブレンド範囲は、中心の通路の外に移行部分を追加します。用途に必要な道幅を確保し、ブレンドで周囲の地形につなぎます。
ノードの幅倍率そのノードでのパス幅に掛ける倍率です。1 は通常の幅です。広場や分岐の場所でノードの幅を大きくします。
高さオフセット配置した位置に対して、目標のパス高さをずらします。小さな正の値で道を持ち上げ、負の値で浅い溝を作ります。
強さ（Strength）指定したパス断面へ形状を近づける強さです。低い値で軽く調整し、確認してから必要に応じて繰り返します。
Max Height Gapパスの元になる周辺の地表を探せる高さ差を制限します。使いたい地形が遠すぎて取得されない場合に上げます。階段の一段の高さを決める設定ではありません。
Grade and Level高さを整えた道のような通路を作ります。起伏のある場所に、通れる経路を作ります。
Raise Embankment通路を盛り上げます。周囲より高い道や土手を作ります。
Carve Trench / 川床地形に水路状のくぼみを掘ります。排水溝や、川の地表の下にある実際の川床を作ります。
Smooth Corridor経路の形状をなめらかにします。盛り上げや掘削の新しい断面を選ばずに、荒れた道を整えます。
断面（Cross-section）Flat、Crowned、Curved Trench で、経路を横切る方向の形を変えます。Crown Height は中央を上げ、Trench Depth は中央を下げます。どちらも形状の距離を指定します。
縁の平滑化周囲の地形との接続部分をやわらげます。道の中心、階段の踏み面、川床を保ちながら、外側をなじませます。
Closed Loop経路の終わりを始まりにつなぎます。環状の道に使います。最初のノードでのつながりを確認します。

階段を作る

スカルプト操作で Steps を選びます。Step Height は一段の垂直方向の高さです。Step Depth はパス方向の踏み面の長さで、高さとは独立して設定できます。Step Bevel は縁の丸みです。低い値では鋭い縁、高い値では摩耗したような丸い縁になります。

キャラクターの大きさに合わせて高さと奥行きを決め、横から確認します。面取りで縁をやわらげても、必要な平らな踏み面が失われないようにします。段の間隔を表現できる密度の形状を用意してください。粗い地形に長い階段を作る場合は、トポロジーを細かくする必要があります。

中央と側面を塗る

パスのグラデーションは、経路に沿ってバイオームを変えます。停止点の位置 0 は始点、1 は終点です。土、砂利、岩などの区間に停止点を追加できます。Bank の設定では両側に別のバイオームを配置します。Bank Width はメートルではなく、半幅に対する割合です。例えば 0.35 は、左右それぞれの半幅のうち外側 35% を使います。

プレビューで隣り合う地表の影響が重なる場所を確認できます。塗る前に側面と境界を見てください。川のバイオームを塗ると川のような帯になりますが、実際の水路が必要なら川床の形状を別に作ります。

トンネルを作る

Tunnel に切り替え、地形内を通る経路を配置します。断面は Circle、Square、Flat Bottom Arch から選べます。歩ける床が欲しい場合には、底が平らな断面が便利です。

最小被覆深さ（Minimum Cover Depth）は、トンネルの上に必要な地形の厚みです。中心が地中にあっても、幅や高さの端が外へ出ると無効になることがあります。赤い表示や無効な場所を確認し、経路を深くする、断面を小さくする、目的の開口に合わせて被覆条件を調整する、といった方法で直します。

Create Tunnel は形状を変え、Paint Tunnel は壁の地表を変えます。生成後は入口、出口、タイルの境界を確認してください。

橋を作る

Bridge に切り替えます。両端をつなぎたい陸地に置き、中間ノードを空間に配置します。Flat Deck はシンプルな橋床、Deep Girder は深い構造、Arched Underside は平らな歩行面の下にアーチを作ります。

上からも下からも確認し、特に各陸地との接続を見てください。曲面の世界では、橋全体が地形に埋まらないことを確認します。ワールド上方向を基準とする配置が、惑星のどの側でも適しているとは限りません。

必要な場合だけ端点を細かく指定する

トンネルと橋の端点は、標準では自動配置です。入口や接続を正確に決めたい場合は Pick Start または Pick End で、一面またはつながった面の集まりを選びます。両端は独立しているので、始点だけ、終点だけ、または両方を固定できます。

対象の地形オブジェクト上で、作りたい開口部に合う輪郭の、つながった面を選びます。四角い入口には正方形や長方形の範囲が便利です。端点の選択を解除すると、その端は自動配置に戻ります。固定した端点の周辺で面を削除・再生成したら、選択を確認し、トポロジーが変わった場合は選び直してください。

複数の地形タイルを編集する

タイルは、大きな地形を別々のメッシュオブジェクトに分けたものです。隣接タイルと継ぎ目の処理により、対応する編集を共有境界にまたがって行えます。ただし、各オブジェクトを登録し、その操作を許可しておく必要があります。

  1. 生成されたタイル配置を使うか、つなぐ境界が接していることを確認します。
  2. 対象リストにタイルを登録し、Paint/Sculpt のスイッチを確認します。
  3. 一つの継ぎ目をまたぐ、小さなストロークを試します。形状と地表の境界の両方を確認します。
  4. 複数タイルをまたぐパス、トンネル、生成形状では、処理後にすべての接続部分を確認します。
  5. 現在の対象だけでなく、変更したすべてのタイルのメッシュを保存します。

マテリアルの Seam Blend はテクスチャの投影をなじませる設定です。メッシュの境界を溶接したり、穴をふさいだりはしません。継ぎ目が気になる場合は、形状の隙間、法線による明暗の差、テクスチャの境界のどれかを先に見分けます。それぞれ対処が異なります。任意に重ねたメッシュが、自動で一続きの地形になるとは考えないでください。

地形を保存・最適化する

編集しやすい状態を保つ

細かいトポロジーを使う前に、大まかな形を作ります。細部には小さいブラシを使い、追加の三角形が必要でなければ、広い範囲に非常に小さな Max Edge Length を使わないようにします。形状の密度は編集の負荷、テクスチャ解像度は見た目とメモリに影響します。片方を下げても、もう片方の問題が自動的に解決するわけではありません。

対応する形状ツールとサーフェスツールは、同時ストローク中にブラシデータを共有します。頂点の移動では再利用可能なペイントバッファが維持され、トポロジー変更、Seam Data の変更、Undo/Redo では影響するキャッシュが更新されます。これは自動で行われ、追加設定は必要ありません。繰り返しの準備処理は減りますが、Sculpt、Topology、Scatter の再構築コストは地形とブラシの内容に応じて変わります。

Direct Vertex Color で AO をベイクする

レイキャスト AO ベイカーは、Direct Vertex Color の地形で、くぼみや接触部の陰影を追加します。ライトマップやシーン照明の代わりではありません。主要な形状が完成してからベイクしてください。後で形を変えると、保存した陰影が合わなくなることがあります。

レイの品質を上げるとサンプリング品質が上がる一方、時間もかかります。最大遮蔽距離は、どの距離の形状まで陰影に影響するかを決めます。コントラストは陰影の強調度です。まず試しにベイクし、遮られた場所がすべて真っ黒にならないように調整します。

チャンク分割と LOD

チャンク分割では、地形を 1×1、2×2、4×4、8×8 などのグリッドに分けます。小さいチャンクは Unity が必要な部分を表示しやすくする一方、オブジェクトと描画グループを増やします。最大の分割数を常に使うのではなく、シーンに合う配置を選びます。

LOD1 と LOD2 は簡略化したメッシュです。目標比率は、どれだけの形状を残すかを示します。小さい比率は三角形を減らしますが、小さな形を失いやすくなります。Unity の切り替えしきい値は、メートル単位の距離ではなく、画面上で占める相対的な高さです。最後のカリングしきい値で、描画をやめる大きさを決めます。

生成したコライダーには LOD2 が使われます。階段、縁、開口部で想定どおりに衝突するかを確認します。三角形ベースの地表問い合わせでは、サーフェスデータがコライダーの実際のメッシュと三角形の順序に一致する必要があります。別のメッシュ向けのベイクでは、違う地表が返ることがあります。

生成結果を使う場合は、必要に応じて Hide Original Mesh を有効にし、元と生成後の両方を重ねて表示していないか確認します。チャンクと LOD は仕上げの工程として扱ってください。元の地形のすべての編集が、自動的に軽くなるわけではありません。

必要なアセットを保存する

操作目的実行後の確認
保存・プレハブ出力メッシュと地表データを保ち、シーンで再利用できるようにします。開き直して、マテリアル参照、見た目、衝突を確認します。
Compile Terrain Texturesライブラリのアトラスとテクスチャ配列を作成・更新します。編集したバイオームを確認します。解像度、圧縮、ミップマップを対象機器に合わせます。
Make Standalone Copy共有ライブラリから分離するため、独立したマテリアル・テクスチャ構成を作ります。共有ライブラリを後で編集しても、独立させた結果が意図せず変わらないことを確認します。
Bake Surface Dataゲームプレイの問い合わせ用に三角形とバイオームの対応を保存します。Scatter Profile が割り当てられている場合は、Read/Write が無効な地形メッシュでもランタイム Scatter を配置できるよう、配置用ジオメトリも含めます。形状、ペイント、Biome ID、Topology の変更後は再 Bake します。ゲームプレイデータは Collider Mesh に、Scatter Data は描画される Terrain Mesh に一致させます。Runtime Scatter Data も参照してください。

マテリアルの変更は、それを共有するすべてのオブジェクトに影響します。GameObject を複製するだけでは、アセットが独立するとは限りません。地形ごとに異なる全体設定が必要なら、別のマテリアルを保存するか、独立コピーの機能を使います。

キーボード・マウス操作

以下のキーボード割り当ては既定値です。Scene ビューで作業中に使います。同じキーでも Mask、Path、Gradient、Dusting のモードによって動作が変わるため、現在のコンテキストが重要です。入力欄への文字入力が優先されます。macOS では Ctrl/Cmd の操作に Cmd を使います。

  • [ / ] と Shift + マウスホイール でブラシ半径を変えます。Ctrl/Cmd + Shift + PageUp / PageDown は細かい半径調整です。
  • Ctrl/Cmd + Shift + Up / Down で形状の速度、Ctrl/Cmd + Shift + Left / Right でサーフェスの不透明度を調整します。マイナス／イコールの割り当ては現在のツールコンテキストに応じて働きます。
  • Ctrl + ドラッグ で対応する Sculpt/Inflate の方向を反転します。Shift は対応ブラシを一時的に Smooth/Blend へ切り替え、Mask 選択中は面を除外します。
  • Alt + Shift + 1…9, 0 で表示中のパレットグループ内のバイオームを選びます。Tab / Shift + Tab でバイオームページを切り替えます。
  • Escape は現在の特別な操作を終了するかツールを解除します。Path モードを離れてもノードは残ります。経路そのものを消す場合は Clear Nodes を使います。

Hotkey Sheet でショートカットを変更する

  1. Terrain ウィンドウの Hotkey Sheet を開きます。操作名やキーで検索するか、Tools、Brush adjustments、Mask mode、Path mode などのグループを展開します。
  2. 操作のキーボタンをクリックしてから、新しいキーの組み合わせを押します。Modifier Key だけを押した場合は、メインキーの入力を待ちます。Escape で記録をキャンセルできます。
  3. × で割り当てを消去し、Reset で一つの操作を既定値へ戻し、Restore Defaults で一覧全体を初期状態へ戻します。

変更内容は現在の Unity Editor ユーザー用に自動保存され、プロジェクト間で共有されます。Tooltip と Scene HUD には現在設定されているキーが表示されます。重なるコンテキストで別の操作と競合するキーを指定すると、Hotkey Sheet は競合する操作名を表示して割り当てを拒否します。先にもう一方の割り当てを変更または消去してください。Mask、Path、Gradient はコンテキストが重ならない場合に同じキーを再利用できますが、General の操作は各モードで有効です。

マウス操作と Unity の Undo/Redo は固定です。Shift + Mouse Wheel は半径調整、Shift + Drag は一時的な Smooth/Blend または選択面の除外、Ctrl + Drag は Lower/Deflate、Paint 中の Ctrl + Click はバイオームのサンプル、Shift + Click は Path Node を X/Z に制限します。Undo は Ctrl/Cmd + Z、Redo は Ctrl/Cmd + Shift + Z または Ctrl/Cmd + Y です。ショートカット記録中以外では、入力欄への文字入力が引き続き優先されます。

このガイドで使う用語

用語意味
メッシュ・頂点・面地形の形・その形を作る点・点をつないだ三角形です。
トポロジー点と三角形のつながり方です。分割、削除、トンネル生成などで変わります。
バイオーム草、雪、岩など、再利用できる地表プリセットです。植物、敵、天候が自動配置されるわけではありません。
バイオーム ID現在のライブラリ内での番号です。自分のライブラリで確認してください。例に出る ID は共通の固定値ではありません。
重み（Weight）地表を混ぜるとき、その地表がどれだけ寄与するかです。色や物理的な高さとは別です。
マテリアル・シェーダー保存した見た目の設定・その設定を使って描画するコードです。
アトラス・テクスチャ配列地形マテリアルで使うためにまとめられた、ライブラリの地表テクスチャです。
法線マップ・視差細部の照明表現・奥行きの錯覚です。どちらも地形の衝突形状を動かしません。
ベイクあらかじめ計算し、結果を保存することです。元の情報が変わったら再ベイクします。
LOD画面上で小さく見えるときに使う、簡略化したメッシュです。
3D ScatterTerrain Atlas のバイオームデータを基に、Grass、Flower、Mushroom、Pebble、Custom Mesh などを GPU Instancing で地表へ配置するシステムです。詳しくは3D Scatter ガイドを参照してください。

思ったとおりの結果にならないとき

症状最初に確認すること
ブラシが何も変えないActive Target、その Paint/Sculpt スイッチ、現在のツール、Radius、Strength を確認します。Scene ビューにフォーカスがあり、入力欄がキー入力を受け取っていないことも確認してください。
マスク境界付近をブラシで編集できないEditing Mask と保存した範囲を確認します。共有する境界頂点は、隣接面と溶接済み継ぎ目を保護するため固定されます。制限を一時停止するにはマスクをオフにするか、より広い範囲を選択して Set Mask を再度使います。
Extrusion または Fill Hole が使用できないこれらの操作前に有効な Editing Mask を解除してください。保存した Editing Mask を消すことと、現在の面選択を Clear することは別です。
ショートカットがこのガイドと違って見える表に記載しているのは既定値です。Hotkey Sheet を開いて現在の割り当てを確認し、操作名を検索して必要なら Reset してください。
ペイントの境界が角張るペイント情報はメッシュ形状に結び付いています。頂点密度を確認し、局所的な Subdivision または対応する Dynamic Topology を検討します。Blend Sharpness は遷移を変えますが、三角形数は増やしません。
丘がとがりすぎる変位の速度を下げ、広いブラシを使い、トポロジーを確認します。形状を少しずつ Smooth してください。法線だけを変えても照明の見え方しか変わりません。
トンネルが地表を突き抜ける経路全体の幅、高さ、Minimum Cover Depth を確認します。必要な場所で経路を深くするか、断面を小さくしてください。
グラデーションで全面が一つの地表になる高さ・傾斜範囲が地形を含むか、Cone が地形と重なるか、Ramp Stop が意図した Biome ID を使っているか確認します。
タイルの間に継ぎ目が出る最初に物理的な隙間を確認し、その後で登録状態、隣接タイルの有効化、法線、Material 設定を確認します。Projection Seam Blend では形状の隙間を閉じられません。
別の地形の見た目も変わる両方が同じ Library、Material、Texture Asset を共有していないか確認します。設定を分けたい場合は独立したコピーを作ります。
キャラクターが形状を通り抜ける、または上に浮くCollider と編集後メッシュが一致しているか確認します。Chunk Collider を生成した場合は LOD2 の簡略化も確認してください。
ゲーム中に違うバイオームが返る変更後に Surface Data を再 Bake し、当たった Collider の三角形順序に一致させます。三角形ベースの検索には有効な Mesh Triangle が必要で、Mesh 以外の Collider に当たっても自動的に Biome 0 を返すわけではありません。制約はRaycast Tester のガイドを参照してください。
編集が重くなる三角形数、ブラシ範囲、Dynamic Topology 設定を確認します。コピーで不要な密度を減らして再測定し、Texture Resolution は別に確認してください。
