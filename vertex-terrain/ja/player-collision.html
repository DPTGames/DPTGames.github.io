プレイヤーとの衝突とスキャッターのインタラクション

プレイヤーや NPC が通過すると草が倒れ、草片や花粉が舞うように設定します。さらに、足元の地形に応じて水しぶき、砂ぼこり、雪のエフェクトを追加できます。

Scatter Interactor は、対応するスキャッターシェーダーに位置と影響範囲を渡します。近くの草の先端は Interactor から離れる方向に動き、その変位は半径の端に向かって滑らかに減衰します。根元は固定されたままで、プレイヤーが離れると草は元の形に戻ります。

まず 3D スキャッターガイド に従って草を設定し、次にこのページでプレイヤーへの反応を追加します。風、動的バイオームアニメーション、パーティクル放出はそれぞれ独立した設定です。

インタラクションの仕組み

実現したいこと必要な設定ベイク済みの地表データが必要か
プレイヤーが通ると草が曲がる草の Scatter Object で Scatter Interactor + Player Interaction を使用します。不要です。スキャッターがすでに描画されていれば動作します。
プレイヤーが植物を揺らすと草片や花粉が現れる同じ Scatter Object に Both output + Particle Preset + Player Movement trigger を設定します。ゲームプレイ用の追加の地表ベイクは不要です。
移動中のプレイヤーの足元に水しぶき、岩の粉じん、雪が現れるDPT_PlayerSurfaceEffects を使用し、エフェクトごとにバイオームとプリセットを明示的に指定します。必要です。Bake Surface Data を実行し、対応する地形 MeshCollider を使用します。

外観はプリセットで、放出するタイミングはトリガーまたはコンポーネントで指定します。同じ プリセット一覧 を 3 種類のパーティクル用インスペクターで利用できます。組み込みエフェクトは、マテリアルや数式で定義されたパーティクル形状も含めてコードから生成されるため、プレハブやスプライトを指定する必要はありません。独自に作成したパーティクルプレハブを使う場合は Custom を選んでください。

草の曲がりは見た目だけの反応です。 配置データと GPU インスタンシングを維持しながら、描画されるスキャッターの頂点を変形します。草のコライダーを生成したり、Rigidbody に力を加えたり、地形の衝突メッシュを変更したりしません。地形や障害物との物理衝突については 物理的な衝突とゲームプレイ を参照してください。

要素役割設定する場所
Scatter Interactor移動する影響中心、半径、高さの許容範囲、押しの強さを定義します。プレイヤー、NPC、または足元付近の子 Transform に DPT_ScatterInteractor を追加します。
Player Interaction個々の Scatter Object に曲がりの反応を許可します。3D Scatter セクションで、草や柔らかい植物の各グループに対して有効にします。
Bend Distanceその Scatter Object の先端変位をワールド単位のメートルで制限します。グループに小さな正の値を設定し、硬いプロップでは無効にします。
対応するスキャッターマテリアルインスタンスの描画時に頂点インタラクションを実行します。付属の SH_DPT_VCTerrain マテリアル設定から始めてください。

プレイヤーに草を反応させる

Scatter Output はどこにありますか？ Vertex 3D Terrain window で 3D Scatter を展開し、草の Scatter Object の名前または矢印をクリックして設定を開きます。Scatter Output のドロップダウンは、Target Biomes のすぐ下、Placement 見出しの上にあります。

草のメッシュのみなら Meshes、草のメッシュとパーティクルエフェクトの両方なら Both を選びます。

  1. Vertex 3D Terrain ウィンドウで 3D Scatter を展開します。草の Scatter Object を作成するか開き、意図した Terrain Atlas バイオームにすでに表示されていることを確認します。
  2. オブジェクトの設定上部で、Target Biomes の下かつ Placement の上にある Scatter Output を見つけ、Meshes または Both を選択します。
  3. Placement 内で、Static Scatter の横にある Player Interaction を有効にします。するとボタンの下に Bend Distance が現れます。まずは 0.3～0.5 メートル程度に設定します。
  4. 付属の SH_DPT_VCTerrain シェーダーなど、対応するマテリアルを使用します。
  5. プレイヤー、または足元付近の子オブジェクトで Add Component を選び、DPT_ScatterInteractor / Scatter Interactor を検索して追加します。
  6. Interactor の中心を草の根元付近に置きます。プレイヤーの Transform が高い位置にある場合は Centre Offset を使います。
  7. 最初は Radius 1、Height Tolerance 0.75、Strength 1 を使用します。コンポーネントを選択してギズモを確認します。
  8. Play モードでプレイヤーを草の中で動かします。影響範囲は Radius、先端の移動量は Bend Distance で調整します。
  9. 周囲の風による動きも必要であれば、風を別途有効にします。

歩くキャラクターの場合： 足元の高さにある子オブジェクトへ Interactor を配置します。Radius 0.8、Height Tolerance 0.5、Strength 1、草の Bend Distance 0.35 を使用します。反応の開始位置がキャラクターに近すぎる場合は半径を増やし、短い草が倒れすぎる場合は Bend Distance を下げます。

このコンポーネントは編集時にも動作します。Scene Preview を有効にすると、Play モードに入る前に Interactor の Transform を動かして草の反応を確認できます。

Scatter Interactor の設定

設定項目意味調整方法
Centre OffsetTransform のローカル軸に沿ったオフセットです。Transform の回転とスケールは、実際の中心位置に影響します。中心を胸ではなく足元付近に配置します。足元の子オブジェクトならオフセットを 0 にできます。
Radius各スキャッターインスタンスの表面平面で測った、ワールド単位のメートルでの影響半径です。初期値は 1 です。キャラクター周囲の反応範囲を広げるには大きくします。
Height Toleranceインスタンスのローカル上方向に沿って測定する、草の根元から上下方向に許容する距離です。初期値は 0.75 です。別の階のプレイヤーが下の草に影響しない程度に小さくします。
Strength: 0–1このキャラクターが周囲の草を押す強さです。初期値は 1 です。反応を弱くするには下げます。0 にすると、このキャラクターの影響はなくなります。
Maximum Movement Stepスキャッターパーティクルの発生を判定する際、1 サンプルで許容する中心の最大移動距離です。初期値は 5 メートルです。それ以上の移動はテレポートとして扱われ、移動経路に沿ったパーティクルを放出しません。ただし、移動先での草の曲がりは無効になりません。

Radius は反応する範囲を決めるもので、最大変位量ではありません。草の先端が動く距離はスキャッターグループの Bend Distance で決まります。距離と高さによる影響は、いずれも境界に向かって滑らかに減衰します。

選択中コンポーネントのギズモには中心、半径方向の範囲、高さの帯が表示されます。斜面や曲面地形では各インスタンスの表面平面を使って反応を計算するため、ギズモは設定用の目安であり、すべてのインスタンスの計算範囲をそのまま描画したものではありません。

曲がるスキャッターを選ぶ

スキャッターの設定効果実用的な使い方
Player Interactionマテリアルが機能をサポートしている場合に、グループの曲がりを有効にします。草、花、その他の柔らかいメッシュで有効にし、岩、クリスタル、硬いプロップでは無効にします。
Bend Distanceワールド単位のメートルで表した先端の最大変位量です。複数の Interactor が重なっても、この上限を共有します。初期値は 0.5 です。短い植物には小さい値を使います。0 にすると視覚的な曲がりは発生しません。
Enable Wind独立した風の機能を制御します。風が無効でもプレイヤーへの反応は動作します。両方を有効にすると、環境風と近くのプレイヤーによる反応を併用できます。
Static Scatter動的なバイオーム密度、色、地表の変化を無視します。プレイヤーへの反応は無効になりません。Player Interaction が有効であれば、Static Scatter の草も曲がります。
Scatter Output展開した Scatter Object で、Target Biomes の下、Placement の上にあるドロップダウンです。グループが可視メッシュを出力するかどうかを決めます。Meshes と Both は曲がります。Particles のみのグループには曲げるメッシュ頂点がありません。

Both の場合、この Scatter Object のメッシュ配置のうち、指定した割合がパーティクルの発生元になります。常時放出には Continuous、Interactor が通過したときの放出には Player Movement を選びます。Scatter Object ごとに独立した放出位置を持ちます。詳しくは パーティクルの発生条件と発生位置 を参照してください。

パーティクルの放出位置は配置 Transform に固定され、シェーダーで草の先端が曲がっても追従しません。植物が静止しているときの形状に合わせるには、パーティクルの Emission Offset を使って位置を調整します。

草を揺らしたときのパーティクル

パーティクル設定の場所： Vertex 3D Terrain ウィンドウ → 3D Scatter → 草の Scatter Object を開く → Scatter Output を Both にする → Particle Effect を展開します。Particle Effect の先頭に Particle Preset と Emission Trigger のドロップダウンがあります。

Preview Particles はボタンです。青色なら有効です。これは編集中のプレビューを制御し、実行時の放出は選択したトリガーに従います。

プレイヤーが草原を走り抜けたときに草片や花粉を舞わせるには、既存の草の Scatter Object で Both を選び、Player Interaction を有効にして Bend Distance を 0 より大きく設定します。Particle Effect 内で、Particle Preset ドロップダウンから Grass Flecks または Pollen を選び、Emission Trigger に Player Movement を指定します。

同じ Scatter Interactor が移動する接触範囲を提供します。Emitter Fraction はパーティクルを放出できる草の配置割合、Rate / Emitter は影響を受けている間の放出頻度を指定します。Minimum Movement Speed は静止時の放出や細かな位置の揺れによる誤放出を防ぎます。Emission Offset は静止時の配置からの相対位置です。風はこのモードのトリガーにはなりません。

パーティクルのみのグループも、移動する Interactor の範囲内で反応できます。判定には、描画された各頂点の変位ではなく根元までの距離と高さを使用します。スキャッター反応の設定 と 利用可能なプリセット を参照してください。

水しぶき、砂ぼこり、地表エフェクト

DPT_PlayerSurfaceEffects は、プレイヤーが指定した地形バイオームの上を移動するとパーティクルを放出します。スキャッターの配置とは独立して動作するため、水しぶきや岩の粉じんに草やメッシュのスキャッターグループは必要ありません。

  1. 地形を作成した後、地形ウィンドウで Bake Surface Data を実行します。ベイク処理によって DPT_TerrainSurfaceTarget とそのデータアセットが追加または更新されます。地形には、ベイクされた三角形構成と一致する MeshCollider を設定してください。ジオメトリやバイオームのペイントを変更した場合は再構築して再ベイクします。
  2. プレイヤーで Add Component を使い、DPT_PlayerSurfaceEffects を検索します。Foot Offset を調整してサンプル位置を足元に合わせます。このコンポーネントには Scatter Interactor は不要です。
  3. Surface Layers に地形のレイヤーを設定し、プレイヤーのレイヤーは除外します。まず Probe Lift を 0.2、Surface Reach を 0.4 メートルに設定します。
  4. 必要に応じて、Biome Names From にベイク済みデータアセットを指定すると、インスペクターで名前付きのバイオームを選択できます。実行時の判定には、実際にヒットした地形のデータを使用します。
  5. Add Surface Effect をクリックします。バイオームを明示的に選び、対応する Particle Preset を指定します。例えば水には Water Splash、岩には Rock Dust、乾いた地面には Sand Dust、雪には Snow Puffs を使用できます。独自プレハブには Custom を選びます。
  6. 各エフェクトの Emissions Per Metre、Minimum Movement Speed、Surface Offset、Scale を設定します。まずは 1 メートルあたり 8 回の放出、Minimum Movement Speed 0.1 から始めます。
  7. Play モードで動作を確認し、ゲームカメラに合わせて Particle Distance と Particle Limit を調整します。
設定項目意味初期設定の目安
Foot Offsetプレイヤーの下の地表をサンプリングするためのローカル位置です。足裏付近に配置します。プレイヤーのルートが地面の高さにある場合は 0 にできます。
Surface Layers地表を検索する物理レイヤーです。地形の MeshCollider を含め、プレイヤーは除外します。Trigger コライダーは無視されます。
Probe Lift / Surface Reachレイは足元のポイントの上から開始し、プレイヤーのローカル上方向に沿ってその下まで届きます。0.2 / 0.4 メートル。プレイヤーが地表から離れすぎていると何も放出されません。
Maximum Movement Step通常移動として認める、1 フレームあたりの足元ポイントの最大移動距離です。5 メートル。テレポート時には移動経路に沿ったエフェクトを生成しません。
Biome / Biome IDこのエフェクトを選択する地表バイオームです。新しいエフェクトでは選択が必須です。同じバイオームを対象とするルールが複数ある場合、最初に設定したエフェクトが使われます。
Particle Preset見た目を選択します。手続き的に生成される Water Splash、Rock Dust などの組み込みタイプ、または独自プレハブ用の Custom を選びます。
Emissions Per Metre地表を 1 メートル移動するごとの放出イベント数です。8。速く移動すると 1 秒あたりの放出が増え、静止中は放出しません。
Minimum Movement Speedメートル毎秒で表した移動速度のしきい値です。0.1。小さな動きを無視したい場合は増やします。
Surface Offset / Scaleヒット面の法線方向の生成位置と、エフェクト全体の均一スケールです。0.03 メートル / 1。
Particle Distance / Particle Limit新規放出を許可するカメラからの距離と、このプレイヤーの全エフェクトで共有するパーティクル総数の上限です。40 メートル / 500 個。

ベイクはこうした反応に役立ちます。 地表の検索にはコンパクトなベイク済み三角形データを使用し、メッシュの Read/Write が無効でも動作できます。現在の動的バイオームと十分に強いダスティングを解決できるため、水のバイオームが氷に覆われている場合は氷や雪のエフェクトを選択できます。エフェクトルールは動的バイオームのスロットを消費しません。

エフェクトは、アニメーションの足音イベントや計測された衝突力ではなく、移動距離に基づいて発生します。水深や浮力は計算しません。プリセットが外観を決め、どのバイオームに使うかはユーザーが指定します。

静止中、Surface Reach の範囲外、Particle Distance を超えた位置、未設定の地表に移動した場合は、新しい放出が止まります。すでに生成されたパーティクルは自然に終了します。手前に通常のコライダーがあると、その下の地形への判定が遮られ、別のオブジェクトの上では地形の粉じんが発生しません。このコンポーネントは Play モードで動作します。スキャッターパーティクルには編集中のプレビュー用に別の Preview Particles ボタンがあります。

マテリアルとカスタムメッシュ

マテリアルは DPT scatter interaction に対応している必要があります。GPU Instancing だけでは不十分です。まず付属の SH_DPT_VCTerrain シェーダーを使用して反応を確認し、その後にカスタムマテリアルへ置き換えてください。

曲がりの計算には、メッシュの境界内でのローカル Y 高さを使用します。最も低い部分を固定し、先端ほど変位を大きくします。カスタムの草は根元から先端への方向をローカル +Y に合わせ、ピボットとバウンズを確認してください。横向きのメッシュや同じバウンズに含まれる無関係なジオメトリは、不自然な曲がりマスクの原因になります。

カスタムシェーダーには、通常のスキャッターインスタンシング設定に加え、DPT スキャッターの頂点インタラクション処理とその対応プロパティが必要です。風の関数だけを追加してもプレイヤーによる曲がりは追加されません。可視パスとシャドウパスで頂点処理を一致させてください。

風の調整は 地形マテリアルの設定、バリエーション、元メッシュ、マテリアルは カスタムメッシュの設定 を参照してください。

プレイヤー、NPC、制限事項

スキャッターに影響を与えたい近くのキャラクターそれぞれに Interactor を追加します。プレイヤーと NPC は同じ共有シェーダーデータを使い、見た目の曲がりには Trigger コライダーや衝突コールバックは必要ありません。

システムは同時に 有効で Strength が正の Interactor を最大 8 個 まで扱います。近い 8 キャラクターを自動選択するのではなく、登録順で処理します。大勢のキャラクターがいるシーンでは、必要なものだけ有効にしてください。

複数のキャラクターが重なると、押しの効果が合成されますが、スキャッターグループの Bend Distance の上限は守られます。Height Tolerance は橋の上下、洞窟の床、積層された空間で反応を分離するのに役立ちます。

草が戻る動きはキャラクターの現在位置に従います。このバージョンでは、足跡の軌跡を保存したり、キャラクターが離れた後のスプリング状の復元遅延をシミュレートしたりしません。

物理的な衝突とゲームプレイ

地形の衝突メッシュとプレイヤーの移動・衝突設定は、Scatter Interactor とは別に管理してください。Interactor は描画上の影響を与えるものであり、プレイヤーコントローラーではなく、キャラクターが地形の上に立てるようにする機能でもありません。

インスタンシングされたスキャッターは、岩、木、プロップごとの個別コライダーを生成しません。プレイヤーを遮ったり、物理的に反応したりする障害物には、適切なコライダーとゲームプレイ処理を備えた別のシーンオブジェクトを使用してください。その周囲の草はインスタンシングしたままにできます。

Flow、Lake の波紋、ダスティング、スキャッターの曲がりは見た目を変更する機能です。水の浮力、氷の摩擦、滑りやすい衝突挙動、移動する水量などは追加しません。ゲームプレイ上の挙動は独自のコントローラーか デモとランタイムガイド を参考に実装してください。ベイク済み地表データの検索では、曲がった草の頂点やパーティクルを測定しません。

パフォーマンスとカリング

インタラクションは、配置を再構築したり草のインスタンスごとに GameObject を生成したりせず、対応するスキャッター頂点シェーダーに処理を追加します。負荷はメッシュの頂点数、可視インスタンス数、アクティブな Interactor の数によって変わります。密度の高い草は、ゲームカメラと対象デバイスで確認してください。

レンダラーは、設定されたインタラクションの Bend Distance を CPU/GPU カリングのバウンズに反映します。距離、LOD、個体数の制限 を利用して遠方のディテールを管理してください。風の動きに対するバウンズは別設定です。

インタラクションのトラブルシューティング

症状確認する順序
草が動かない草が表示されていること、Scatter Output が Meshes または Both であること、Player Interaction が有効であること、Bend Distance が 0 より大きいこと、マテリアルが DPT scatter interaction に対応していることを確認します。次に Interactor が有効で Strength が 0 より大きいか確認します。
キャラクターの一部に近い草だけが反応するCentre Offset、Radius、Height Tolerance を確認します。中心を上半身ではなく草の根元付近に配置します。
別の階の草まで動いてしまうHeight Tolerance を小さくし、中心の高さとスキャッターの向きを確認します。
根元が動く、または横向きに曲がるカスタムメッシュのローカル Y、ピボット、バウンズを確認します。シンプルな直立した草メッシュで試し、メッシュ制作上の問題と Interactor 設定上の問題を切り分けます。
風は動くが、プレイヤーには反応しない風とインタラクションは別々のシェーダー機能です。グループの Player Interaction の切り替えを確認し、付属の地形シェーダーと比較します。
一部の NPC が影響を与えないInteractor の上限 8 個を確認します。無効なコンポーネントや Strength 0 は影響しません。また、追加された正の Strength を持つキャラクターが距離順に自動的に並べ替えられることはありません。
パーティクルが曲がった先端を追従しないパーティクルの発生基準は配置 Transform であり、シェーダーで変形した頂点位置ではありません。放出オフセットを調整するか、先端追従が必要な場合は別のエフェクトを使用します。
草は曲がるが、草片や花粉が出ないScatter Output を Both にして Particle Preset を選び、Emission Trigger を Player Movement にします。Emitter Fraction と Rate / Emitter が 0 より大きく、移動速度が Minimum Movement Speed を超え、Interactor の Strength が正であることを確認します。Player Interaction、Bend Distance、カメラ距離も確認してください。
足元に水しぶきや砂ぼこりが出ないDPT_PlayerSurfaceEffects が有効で、Foot Offset が足元付近にあり、Surface Layers に地形が含まれ、Surface Reach が地面まで届くことを確認します。Bake Surface Data を実行し、対応する MeshCollider と Surface Target を確認して、バイオームにプリセットを割り当てます。Play モードで移動しながら試してください。
プリセットが見えている地表と一致しないエフェクトで選択した Biome ID を確認し、編集を変更した後は再ベイクします。動的ダスティングが十分に強いと、そのバイオームが選択されることがあります。別の反応が必要な場合は、そのダスティングのバイオームにもルールを追加します。
プレイヤーがスキャッターの岩を通り抜けてしまう見た目のインタラクションでは岩のコライダーは追加されません。ゲームプレイで障害物にする場合は別の衝突用オブジェクトを使用します。

サポート
