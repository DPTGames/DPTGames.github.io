プレイヤーに Player Surface Effects (DPT_PlayerSurfaceEffects) を追加します。このコンポーネントの Enable Scatter Interaction スイッチは、付近の散布メッシュの曲がりと、移動によって発生する散布パーティクル／オーディオを制御します。 Enable Surface Effects はプレイヤーの足元にある地形に応じたパーティクル、足音、足跡を制御します。どちらの機能も単独で利用できます。

植生や環境エフェクトの作成方法については 3D Scatter ガイドを参照してください。このページでは、プレイヤーの設定、接地判定、バイオーム別ルール、足音のタイミングを説明します。

目的に合ったエフェクトを選ぶ

実現したいこと必要な設定サーフェスのベイクは必要？
周囲の草を曲げるPlayer Surface Effects → Enable Scatter Interaction を有効にし、散布メッシュグループの Player Interaction も有効にします。散布メッシュが既に表示されていれば、ゲームプレイ用の追加のサーフェスベイクは不要です。
植物の配置地点で葉片、花粉、こすれる音を発生させるScatter Particle Effect または Scatter Audio → Player Movement。プレイヤーの Enable Scatter Interaction を有効にします。メッシュの曲がりは任意です。ゲームプレイ用の追加サーフェスベイクは不要です。
足元の土ぼこり、水しぶき、雪Player Surface Effects → Enable Surface Effects → パーティクルプリセットを設定したバイオームエントリ。必要です。ベイク済み Surface Data と、対応する地形 MeshCollider が必要です。
複数のバイオームに対応する足音と足跡1つのサーフェスエフェクトエントリで複数のバイオームを選択し、Footstep Audio、Footprints、任意のパーティクルを組み合わせられます。必要です。ベイク済み Surface Data と、対応する地形 MeshCollider が必要です。
地形上の配置地点で環境音を鳴らすScatter Audio → Continuous を選び、Audio Clips を割り当てます。散布配置データを使用します。詳しくは散布ガイドを参照してください。

組み込みパーティクルと足跡の輪郭はプロシージャルに生成されます。足跡にデカール、テクスチャ、専用メッシュアセットは不要です。オーディオには実際の Audio Clipsが必要で、 Custom パーティクルには独自の ParticleSystem プレハブが必要です。

見た目のインタラクションは衝突判定を追加しません。 草の曲がりや足跡はコライダーを生成せず、地形を変形せず、プレイヤーコントローラーも提供しません。

プレイヤーの動きに草を反応させる

  1. Vertex 3D Terrain ウィンドウの 3D Scatter を開きます。草の Scatter Object を展開し、Target Biomes の下にある Scatter Output で Meshes または Meshes + Particles を選択します。
  2. Placement で Player Interaction を有効にし、 Bend Distance を 0 より大きく設定します。通常の草は約 0.35 メートルから始めてください。
  3. 互換性のあるマテリアルを使用します。まず付属の SH_DPT_VCTerrain シェーダーで確認してください。
  4. プレイヤーに Player Surface Effects を追加し、 Enable Scatter Interaction.
  5. 足元のマーカーを Interaction Originに割り当てるか、 Interaction Offset を使用して影響の中心を草の根元付近へ移動します。
  6. まず Interaction Radius を 1、Interaction Height を 0.75、Interaction Strength を 1 に設定し、Play mode で草の中を移動してください。
  7. 移動によるパーティクルや葉ずれ音には、散布エフェクト／オーディオ設定の Player Movement を使用します。これらのトリガーには Player Interaction や 0 より大きい Bend Distance は不要です。これらのメッシュ設定は見た目の曲がりを有効にするものです。

3D Scatter 見出しの隣の Preview ボタンを有効にすれば、編集中にも散布メッシュの曲がりを確認できます。プレイヤーのサーフェスパーティクル、足音、足跡、散布オーディオは Play mode.

散布インタラクションだけが必要な場合は、 Enable Surface Effects をオフにできます。ただしコンポーネント自体は有効なままにしてください。

歩くキャラクターの例： 足元のマーカーを Interaction Origin に指定し、Interaction Radius を 0.8、Interaction Height を 0.5、Interaction Strength を 1 にします。草の Bend Distance は 0.35 に設定します。風は独立した環境モーション設定です。

プレイヤーと散布オブジェクトのインタラクション設定

設定項目内容初期値の目安
Enable Scatter Interaction曲がりと移動時の散布パーティクル／オーディオに影響する移動インタラクターを提供します。オン。Enable Surface Effects とは独立しています。
Interaction Origin / Interaction Offset中心となる任意の Transform と、そのローカル軸に沿ったオフセットです。Origin が未指定の場合はプレイヤーの Transform を使用します。草の根元付近に配置します。回転とスケールはオフセットに影響します。
Interaction Radius各配置地点のサーフェス平面内で測定されるワールド空間半径です。1 メートル。
Interaction Height配置地点のローカル上方向に沿った、根元からの許容される高さの差です。0.75 メートル。階層状の床や橋では小さくします。
Interaction Strength影響の強さ。0～1 の範囲です。1。0 では影響しません。
Scatter Teleport Distance一定距離を超える移動サンプルはテレポートとして扱われ、移動経路上の反応を残しません。5 メートル。移動先では引き続き曲がりが反応します。

散布グループの Bend Distance で先端の最大変位を設定します。Radius は影響範囲を決めます。選択したコンポーネントのギズモには中心と影響範囲が表示されます。斜面では各配置地点のサーフェス平面に沿って計算されます。

曲がる散布オブジェクトを選ぶ

散布設定効果
Player Interaction / Bend Distance表示メッシュの曲がりを有効にし、変位を制限します。柔らかい草や植物に使い、硬い小道具ではオフにしてください。
Enable Wind独立した環境モーションです。風がオフでもプレイヤーとのインタラクションは機能します。
Static Scatterバイオームの密度、色、サーフェスのランタイム変更を無視しますが、曲がりやプレイヤー起因のパーティクル／オーディオは動作します。
Scatter OutputMeshes と Meshes + Particles は曲げられる頂点を持ちます。Particles と Audio Only は表示メッシュを出力しません。
Particle Effect / Scatter Audioオブジェクトの配置地点を共有できますが、それぞれ固有のトリガー、発生レートまたはクールダウン、制限があります。

パーティクルとサウンドは、シェーダーで変形した先端ではなく配置 Transform から発生します。静止位置を調整するには Emission Offset または Audio Offset を設定します。詳しくは 散布トリガー と 散布オーディオ.

植物の接触によるパーティクルとサウンド

草の Scatter Object を開き、 Meshes + Particlesを選択してから Particle Effect 1を展開します。Grass Flecks または Pollen を選び、 Emission Trigger → Player Movementを設定します。プレイヤーには Enable Scatter Interaction が有効な Player Surface Effects が必要です。草の表示上の曲がりは任意です。

同じ配置地点にエフェクトを重ねるには + Add Particle Effect を使用します。花粉と葉片などを重ねられます。各エフェクトには固有のプリセット、トリガー、色、ノイズ品質、エミッター比率、レート、オフセット、制限があります。親の Shared Particle Limit は生存中のパーティクルの合計数を制限します。 Remove Effect ボタンは赤色です。

葉ずれ音には Scatter Audioを展開し、オーディオを有効にしてクリップを割り当て、 Player Movementを選びます。Minimum Movement Speed と Sound Cooldown を調整します。環境ループ音には Continuous も使用できます。足音は代わりにプレイヤーのバイオームエントリで設定します。

色を調整するには Particle Colors を使用します。Preset Colors のままにするか、Single Color または Random Between Two Colors を選択します。色のアルファは元の不透明度に乗算され、寿命に伴うフェードも適用されます。変更は新しいパーティクルに反映されます。

Player Movement は根元との近さと移動中に通過したインタラクション領域を使用します。風はトリガーになりません。編集時のパーティクルプレビューは Continuous 発生のみ対応しています。3D Scatter のメイン Preview、エフェクトの Preview Particles、Scene ビューの Effects/Particle Systems を有効にしてください。

バイオーム別サーフェスエフェクトの設定

1つのサーフェスエフェクトエントリで複数のバイオームを対象とし、パーティクル、足跡、オーディオを組み合わせられます。これらは散布配置とは独立して、プレイヤーの足元から取得した地形情報に従います。

  1. 編集後は Bake Surface Data を使用します。ベイクしたデータは DPT_TerrainSurfaceTargetに割り当てたままにし、ベイク時の三角形構成と一致する地形の MeshCollider を使用してください。ジオメトリ、トポロジー、ペイントしたバイオームを変更したら再ベイクします。
  2. Player Surface Effects で Enable Surface Effectsを有効にします。 Foot Point を足裏付近のマーカーに設定するか、 Foot Offsetを使用します。Foot Point が指定されている場合、オフセットはその位置を基準にします。
  3. 次に Surface Detectionを展開します。Surface Layers に地形を含め、プレイヤーを除外します。まず Probe Lift を 0.2、Surface Reach を 0.4 メートルに設定します。足音と足跡には、既定で 0.06 メートルの Foot Contact Distance 内での接地も必要です。
  4. Load Scene Terrain Data をクリックして、ロード済みシーンの Surface Target から重複のないベイク済みデータを追加します。Surface Data Sources は名前付きバイオームの選択肢とメッシュ一致時のフォールバックを提供しますが、ヒットした地形タイル自身の Surface Target が優先されます。
  5. Add Surface Effectをクリックし、エントリ名を付けて対象バイオームを選びます。対象を追加するには Add Biome を、現在 Surface Data Sources から使用できるすべての名前付きバイオームを選ぶには Add All を使用します。Add All は未割り当てや重複した選択肢を除去します。選択結果は保存され、新しいバイオームまで自動的に含むワイルドカードではありません。
  6. パーティクルプリセットを選びます。足跡やオーディオのみの場合は None を選択します。必要に応じて Footprints と Footstep Audio を有効にします。
  7. Minimum Movement Speed と該当エフェクトの設定を調整し、Play mode で歩いてテストします。Effect Limits and Quality を展開し、各種上限と Visual Layer を調整してください。
設定項目内容／既定値
Foot Point / Foot Offset足裏付近のサンプリング位置。オフセットは指定したポイントのローカル軸を使用し、未指定ならプレイヤーの Transform を使用します。
Surface Layers地形の判定対象とする Physics Layer。プレイヤーの子オブジェクトと Trigger Collider は無視されます。手前の通常コライダーが奥の地形を遮ることがあります。
Probe Lift / Surface Reachプレイヤーのローカル上方向に沿って、足元から 0.2 メートル上の位置からレイを開始し、0.4 メートル下まで届きます。
Foot Contact Distance足音と足跡に許容される足と地面の最大距離は 0.06 メートルです。パーティクルの Surface Offset を上げても、この範囲より高い Foot Point は修正できません。
Movement Teleport Distance足元の移動が 5 メートルを超える場合は移動軌跡を省略します。Scatter Teleport Distance とは別の設定です。
Biomes / Add All1つのエントリで複数のバイオーム ID を共有できます。Unassigned は「すべてのバイオーム」ではありません。Add All を使う前にデータを読み込んでください。
Particle Preset組み込みプリセット、ParticleSystem プレハブを使う Custom、または None を選択します。最初に追加したエントリの既定値は Grass Flecks です。
Minimum Movement Speedエントリごとの移動速度のしきい値。既定値は 0.1 メートル／秒で、移動パーティクルと自動の足跡／足音に適用されます。
Emissions Per Metre移動距離 1 メートル当たりのパーティクル発生イベント数。既定値は 8 です。足音の Animation Events モードでもパーティクル発生は移動距離に基づきます。
Surface Offset / Scaleヒット面の法線に沿ったパーティクル発生位置のオフセットとスケール。既定値は 0.03 メートル／1 です。足跡には独自のオフセットとサイズがあります。
Particle ColorsPreset Colors、Single Color、Random Between Two Colors を選べます。エントリにパーティクル出力がある場合に使用できます。

最初に一致した有効なエントリは、 パーティクル、足跡、オーディオでそれぞれ独立して選択されます。足跡のみのエントリが後続の一致エントリのパーティクルやオーディオを妨げることはありません。対象バイオームを共有する関連エフェクトは1つのエントリにまとめ、重複エントリの順序に注意してください。

2つ目以降の新規エントリは直前のエントリから足跡の形状、サイズ、色、寿命／フェード、移動速度、オーディオなどの設定をコピーします。バイオームリストは未割り当てに戻ります。設定は独立してコピーされるため、新しいエントリの変更は前のエントリに影響しません。削除するには赤い Remove Surface Effect ボタンを使用します。

ランタイムのバイオーム照会では、ヒットしたタイルの現在の動的バイオームと、十分に強い Dusting が反映されます。雪や氷で反応を変える場合は、その Dusting のバイオームも対象に追加してください。発生停止後も既存のパーティクルは寿命を終えるまで残り、足跡は独自の寿命を使用します。このコンポーネントは水深、浮力、衝突力を計算しません。

数式で生成する足跡

  1. サーフェスエフェクトエントリで対象バイオームを選択し、パーティクルが不要なら Particle Preset → None を選びます。
  2. 別個の Footprints スイッチを有効にし、 Footprint Shape → Shoe または Bare Foot.
  3. Footprint Size、Colour、Lifetime、Fade、Offset を設定します。Foot Point を地面付近に配置して Play mode で歩いてください。
足跡の設定内容／既定値
Footprint ShapeShoe は、丸みのあるつま先とかかと、浅い内側の土踏まずを持つ滑らかで一体型の靴底を描き、左右を反転して配置します。Bare Foot は足裏と指をプロシージャルに生成します。
Footprint Size幅と長さをメートル単位で設定します。新しい既定値は 0.12 × 0.32 です。以前に保存したサイズは維持されます。
Footprint Colourエントリごとの色と不透明度。既定値はアルファ 0.6 のダークブラウンです。
Footprint Lifetime / Footprint Fade合計寿命は 20 秒で、最後の 5 秒でフェードします。フェードは寿命の一部であり、終了後に追加される時間ではありません。
Footprint Offsetちらつきを減らすため、ヒットした面の法線に沿って少し浮かせます。既定値は 0.003 メートルです。大きすぎるオフセットは浮いて見える原因になります。
Footprint Limit / Footprint DistanceEffect Limits and Quality 内にあり、既定値は 128 個／60 メートルです。上限に達すると古い足跡から削除されます。画面外や範囲外の足跡は非表示になりますが、寿命のカウントは継続します。
Visual Layer足跡とパーティクルの描画レイヤー。プレイヤーの衝突レイヤーとは独立し、既定値はレイヤー 0 です。ゲームカメラの Culling Mask に含めてください。

足跡は生成された四角形と、既存のプロシージャルパーティクルシェーダーで計算される輪郭を使用します。デカール、インポートしたテクスチャ、靴のモデルは不要です。取得した地形面に配置され、URP の環境光とメインライトのリアルタイムシャドウの影響を受けます。地面を削ったりへこませたりはしません。

寿命、フェード、サイズ、オフセット、色はサーフェスエフェクトエントリごとに設定できます。たとえば雪の足跡は道路より早く消せます。同じ足跡を使うバイオームは1つのエントリにまとめられます。エントリを追加すると前の設定がコピーされるため、違う箇所だけ変更すれば済みます。

雪と道路の例： 雪／氷のバイオームを対象とする Snow Steps エントリを作り、None または Snow Puffs と短い足跡寿命を設定します。Road Steps エントリを追加し、道路バイオームを選んで足跡の色と寿命を変更します。コンポーネント共通のタイミングと制限は両方に適用されます。

足音のタイミングとオーディオ

パーティクルは移動距離に応じて発生します。 Footstep Timing は、左右交互の足跡と足音の接地タイミングをまとめて制御します。コンポーネントの Footsteps and Footprints セクションで一度設定してください。

設定項目内容／既定値
Distance Travelled接地しながら移動すると左右交互に自動で足音を発生させます。Step Distance の既定値は 0.6 メートルです。キャラクターの歩幅に合わせて調整してください。
Animation Events距離に応じた自動の足音は無効になります。アニメーション上の足が着地するたびに EmitFootstep() を呼び出します。足跡は左右交互に配置されます。コンポーネントを Animator のあるオブジェクトに配置するか、アニメーションスクリプトでイベントを転送してください。
Foot Spacing中心のサンプル位置から、ヒットしたサーフェスに沿って左右の足へ移動する距離。既定値は 0.09 メートルです。
Footstep Audioサーフェスエフェクトエントリ内で有効にし、Audio Clips を割り当てます。音を再生するたびに null でないクリップをランダムに1つ選びます。音だけにする場合は None パーティクルを選び、Footprints を無効にします。
Volume / Pitch Range空間オーディオの音量とランダムなピッチ範囲です。既定値は 0.5、0.95～1.05 です。
Near Distance / Audio Distance最大音量となる距離と可聴最大距離です。既定値は 1／25 メートルで、距離に応じて音量が線形に減衰します。
Footstep Sound Limitこのプレイヤーで同時に使用できる音声数。既定値は 8、設定範囲は 1～32 です。すべて使用中なら新しい音は再生されません。

ゲームカメラの有効な Audio Listener を使用し、Play mode でテストしてください。実際のクリップが必要で、パッケージは足音を合成しません。足音には対象バイオームと、Foot Contact Distance 内の Foot Point が必要です。

Animation Event は足音を明示的に要求しますが、地形への接地とバイオーム設定は引き続き確認されます。自動移動の速度しきい値は明示的なイベントを妨げません。このワークフローには、着地音専用コンポーネントや衝撃速度の設定はありません。

マテリアルとカスタムメッシュ

マテリアルは DPT の散布インタラクションをサポートする必要があります。GPU Instancing だけでは不十分です。まず付属の SH_DPT_VCTerrain シェーダーで反応を確認してからカスタムマテリアルへ変更してください。

曲がりはメッシュのバウンド内のローカル Y 座標を使用します。最下部は固定され、先端に向かうほど変位が増加します。カスタムの草は根元から先端がローカル +Y 方向になるように作成し、ピボットとバウンドを確認してください。横向きのメッシュや無関係なジオメトリが同じバウンド内にあると、予期しない曲がりマスクになることがあります。

カスタムシェーダーには、通常の散布インスタンシング設定に加えて、DPT の散布頂点インタラクション処理と対応するプロパティが必要です。風の関数を追加するだけではプレイヤーによる曲がりは追加されません。表示パスとシャドウパスで同じ頂点処理を使用してください。

風の調整については 地形マテリアル設定 を、バリアント、ソースメッシュ、マテリアルについては カスタムメッシュの設定 を参照してください。

プレイヤー、NPC、制限事項

散布オブジェクトに影響を与える必要がある各プレイヤー／NPC に、Enable Scatter Interaction を有効にした Player Surface Effects を追加してください。プレイヤーと NPC のコンポーネントは共通のシェーダーデータを使用し、見た目の曲がりに Trigger Collider や衝突コールバックは必要ありません。

システムが同時に使用できるのは最大 8 つの有効な、影響強度が 0 より大きいインタラクター です。最も近い 8 体を自動選択するのではなく、登録順を使用します。群衆の多いシーンでは、影響させたいアクターだけを有効にしてください。

複数のアクターが重なると、散布グループの Bend Distance を守りながら影響が合成されます。Height Tolerance は橋、洞窟の床、積層した空間で反応を分離するのに役立ちます。

元に戻る動きはアクターの現在位置に追従します。草の曲がりは移動後の曲がった軌跡を保持せず、アクターが離れた後のバネ状の復元もシミュレートしません。別機能の Footprints では寿命付きの痕跡を地形に残せます。

物理衝突とゲームプレイ

地形の衝突メッシュやプレイヤーの移動／衝突設定は、Player Surface Effects とは別に管理してください。このインタラクターは描画への影響を提供するだけで、プレイヤーコントローラーではなく、キャラクターを地形の上に立たせるものではありません。

インスタンシングされた散布オブジェクトは、岩、木、プロップごとに個別のコライダーを生成しません。プレイヤーの移動を妨げたり物理的に反応したりする必要がある障害物には、適切なコライダーとゲームプレイ処理を持つ別のシーンオブジェクトを使用してください。その周囲の草はインスタンシングのままにできます。

Flow、Lake ripples、Dusting、散布メッシュの曲がりは見た目を変える機能です。水の浮力、氷上の摩擦、滑りやすい衝突判定、移動する水域は追加しません。ゲームプレイ動作は独自のコントローラーまたは デモとランタイムガイドから接続してください。ベイク済みサーフェスの照会では、曲がった草の頂点やパーティクルを測定しません。

パフォーマンスと制限

散布インタラクションは配置を再構築せず、草1本ごとの GameObject を生成せずに、互換性のある頂点シェーダーへ処理を追加します。表示頂点数と有効なアクター数が負荷に影響します。散布カリングのバウンドには設定した Bend Distance が含まれ、風のバウンドは別管理です。

プレイヤーのパーティクル、足音、足跡はサーフェス検出とバイオームルールの選択を共有します。パーティクルシステムとオーディオソースはプーリングされます。足跡の描画にはインスタンシングバッチ、事前計算バウンド、カメラの視錐台／距離カリング、ビューと痕跡に変更がない場合の描画データキャッシュ、GPU による寿命フェードを使用します。

上限項目既定値／調整方法
有効な散布インタラクター登録順で最大 8 体の有効かつ正の強度を持つアクター。必要な近くのアクターだけを有効にしてください。
Particle Distance / Particle Limitプレイヤーのサーフェスエフェクト全体で 40 メートル／500 パーティクル。大きな半透明パーティクルが重なると高負荷になる場合があります。
Particle NoiseHigh、Medium、Low、Off から選びます。品質を下げるとプロシージャル乱流の処理が減ります。Custom プレハブは作成時のノイズ設定を保持します。
Footprint Limit / Distance128 個／60 メートル。足跡が密集する場合は、上限、寿命、距離、サイズを下げてください。
Footstep Sound Limitプレイヤーごとに 8 音声。散布レンダラーの Shared Audio Source Limit とは別です。

制限値は処理の上限を決めるだけで、発生量を増やすものではありません。実際のゲームカメラ、目標解像度、対象デバイスでプロファイリングしてください。カリングとプーリングは不要な処理を減らしますが、特定のフレームレートを保証しません。

プレイヤーエフェクトのトラブルシューティング

症状確認する順序
草が曲がらない表示メッシュ出力、Player Interaction、0 より大きい Bend Distance、互換シェーダーを確認します。プレイヤーでは Enable Scatter Interaction を有効にし、Interaction Origin/Offset、Radius、Height、Strength を確認してください。
移動パーティクルや葉ずれ音が出ないプレイヤーで Enable Scatter Interaction を有効にし、該当散布エフェクトの Player Movement を選びます。移動速度のしきい値、配置対象、割合、レート／クールダウン、カメラ／オーディオ範囲、各種上限を確認します。メッシュの曲がりは任意です。
足元のパーティクルが出ないEnable Surface Effects を有効にします。Foot Point/Offset、Surface Layers、Surface Reach、一致する MeshCollider、ベイク済み Surface Target／データ、対象バイオーム ID を確認します。None 以外のプリセットを選び、Play mode で移動し、発生レート、Particle Distance、Particle Limit を確認してください。
足跡または足音が出ないサーフェスエフェクトエントリを展開し、Footprints／Footstep Audio を有効にします。必要ならパーティクルは None にします。Foot Point を足裏付近に置き、実際の Surface Gap が Foot Contact Distance 内か確認します。Distance Travelled を使うか、Animation Events モードで EmitFootstep イベントを送信します。自動ステップではバイオーム ID と Minimum Movement Speed も確認してください。
音は出るが足跡が表示されないFootprints が有効か、Colour のアルファ、Size、Footprint Limit/Distance、Offset を確認します。カメラでプレイヤーレイヤーを非表示にしていても、Visual Layer はカメラの Culling Mask に含めてください。
足跡が浮く／ちらつくFootprint Offset を 0.003 メートル程度の小さい値にし、地形のコライダーが表示面と一致していることを確認します。足跡はコライダー法線に従い、シェーダーだけの任意の変位には追従しません。
影の中の足跡が明るいURP の最新の共有プロシージャルパーティクルシェーダーを使用し、メインライトと影を落とすオブジェクトでリアルタイムシャドウを有効にします。足跡はメインライトの影を受けますが、色は独立して設定されます。
プロシージャルエフェクトがピンクで表示されるUnity の Console でシェーダーのコンパイルエラーを確認し、最新の DPT_ProceduralParticle シェーダーを使用してください。シャドウ API の互換性はインストールした URP ヘッダーに依存します。URP と Core パッケージのバージョンを合わせてください。
バイオームを選択できない／Add All が使えないBake Surface Data を実行して Load Scene Terrain Data をクリックするか、Surface Data Sources を直接割り当てます。Add All はデータソースに含まれる名前付きバイオーム ID を使用します。
地形に対して違うエフェクトが出るエントリの順序と対象バイオームを確認します。パーティクル、足跡、オーディオはそれぞれ最初に一致する有効なエントリを独立して選択します。動的バイオーム変更や十分に強い Dusting によって別の ID が選ばれることがあります。編集内容を変更した場合は再ベイクしてください。
音が鳴らないnull でない Audio Clips を割り当て、Footstep Audio または Scatter Audio を有効にし、Volume、距離、音源数の上限、有効な Audio Listener を確認してください。音は Play mode で再生されます。
別の階の草が動く／一部のアクターが影響しない階層状の床では Interaction Height を下げます。インタラクター 8 体の上限と、0 より大きい Interaction Strength を確認してください。
散布した岩をプレイヤーがすり抜ける散布描画は障害物コライダーを追加しません。ゲームプレイ用の障害物には別の衝突オブジェクトを使ってください。
