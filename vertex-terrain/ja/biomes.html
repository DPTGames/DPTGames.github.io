小さい画面では、幅の広い表を横にスクロールするとすべての列を読めます。

バイオームは、草、砂、雪、岩、金属など、一つの再利用できる地表です。ペイントでは「どこに表示するか」、バイオームインスペクターでは「どう見えるか」を決めます。

バイオームは一つの地表を定義します。地形ジェネレーターで選ぶと新しい形状の初期外観になり、スキャッターオブジェクトの対象にすると植生を配置できます。プリセットを「Forest」と名付けるだけでは木は配置されず、「River」と名付けても流れる水の形状は作られません。Terrain Atlas の地表上に、バイオームに応じた草、花、キノコ、小石、カスタムメッシュを配置する場合は、3D スキャッターガイドを参照してください。

最初のバイオームを作る

  1. 地形エディターで Biome Library と Terrain Atlas パイプラインを選びます。
  2. バイオームを追加し、「乾いた砂」「暗い岩」など、分かりやすい名前を付けます。
  3. ベースカラーの画像を Source RGB に指定します。対応するテクスチャセットがあれば Auto Folder で入力を探せますが、割り当ては必ず確認します。
  4. 最初は法線、金属、発光を控えめにします。Auto Generate の前に、生成に使う強さを指定します。強さが 0 のマップは生成対象から除外されます。
  5. 生成テクスチャとカラーランプを確認します。実際に使うカメラ距離から見られる程度のテスト範囲を塗ります。
  6. Scale で模様の大きさ、ランプで色を調整します。必要なら法線と PBR の入力も追加します。
  7. 明るい場所と影、近距離と遠距離で確認します。大きく見た目を変える前に、バイオームを複製します。

最初は一つの目標に絞る：つやの少ない砂なら、まず色と粒の大きさを整えます。次に弱い法線効果を足し、Metallic は 0、Smoothness は低く保ちます。一度に一項目ずつ変えると、効果を判断しやすくなります。

ライブラリとバイオームインスペクター

ライブラリは、地形オブジェクトが共有するパレットです。インスペクターは選択したプリセットを編集します。カードを選ぶとその設定が表示され、複数のカードを選ぶと共通の編集項目が表示されます。値が混在している表示は、選択したプリセットの値が異なることを示します。

テクスチャの割り当てには、コンパクトなインラインフィールドを使います。スペースに余裕がある場合、サーフェス設定はペアの行にまとめられ、Rotation と Pulse も同じ行に表示されます。オン／オフ設定は強調表示されたボタンです。パレットの Set Active ボタンは、現在アクティブなパレットページでは Active と表示されます。

操作動作用途
Add現在のパイプラインの一覧にプリセットを追加します。適切な土台となるプリセットがない新しい地表に使います。
Biome Nameプリセットの名前です。見た目が分かる名前を付けます。エディターの言語を変えても、ユーザーが付けた名前はそのままです。
Auto Folder元画像のフォルダーから関連する入力テクスチャを探します。整理されたセットに便利です。特に Roughness と Smoothness、パック画像のチャンネル配置を確認します。
Duplicate設定をコピーし、元のテクスチャへの参照を保ちます。同じ画像を再インポートせず、明るい、暗い、濡れたような、回転したバリエーションを作れます。
Deleteプリセットを削除し、ライブラリの番号を更新します。ゲームプレイ側に保存した ID を確認し、必要ならサーフェスデータを再ベイクします。
並べ替え・交換パレットの順序と、その数値 ID を変えます。整理した後は、エディター外で指定している ID も確認します。
複数選択選択した複数のプリセットに共通の設定を適用します。岩のグループなどをまとめて調整できます。混在している項目を変えると、入力値が選択したすべてに適用されます。

名前と ID は別です。名前は地表を見分けるためのもの、ID は現在のパイプライン一覧内の番号です。デモで ID 6 が雪でも、別のライブラリでは岩かもしれません。ライブスロット、スキャッターの Target Biomes、ゲームプレイスクリプトを設定する前に、自分のライブラリで ID を確認してください。

共有ライブラリを編集すると、複数の地形が変わることがあります。一つの結果だけ専用のマテリアルとテクスチャを保ちたい場合は、地形ツールの独立コピー機能を使います。

どの欄にどのテクスチャを入れるか

画像ごとに、表面の異なる性質を表します。すべてのバイオームに、すべてのマップが必要なわけではありません。単純な表現なら色の元画像とランプだけで十分な場合があります。細かい表現には法線や PBR マップが役立ちます。

入力画像が持つ情報変わる見た目
Source RGB元の色付き画像。Base Color、Albedo、Diffuse と呼ばれることもあります。細部とランプを生成するための色情報です。元画像をそのままメッシュに貼るだけの処理ではありません。
Generated地形システムで使う、処理済みの細部テクスチャです。ランプと組み合わせて地表を描きます。処理済みの入力を自分で用意したい場合だけ、適した既存テクスチャを直接指定します。
Source Height素材の高低を示すグレースケール画像です。高さ・細部の生成に使います。奥行きやブレンドの表現には使えますが、地形の頂点は上がりません。
Invert Height高い部分と低い部分の扱いを逆にします。くぼみが盛り上がって見える場合などに使います。小さな範囲で変更前後を比較します。
Normal通常は青紫色の、接線空間の法線マップです。細かい凹凸への光の当たり方を変えます。Unity で Normal Map としてインポートします。衝突や輪郭は変わりません。
AO遮られた場所を暗くするアンビエントオクルージョンのマップです。素材の細かな溝に陰影を加えます。Direct Vertex Color 地形の形状 AO ベイクとは別です。
Metallic金属として扱う場所を示すマスクです。素材の反射応答を変えます。草、土、雪、普通の石では、通常ほとんど金属反応を使いません。
Smoothness / Roughness磨かれた部分や粗い部分を示すマップです。ハイライトの広がり方を変えます。滑らかさと粗さは逆の意味なので、Roughness の画像なら粗さとして扱う設定を有効にします。
Emissive発光する場所のマスクです。発光設定と生成済みデータで使います。亀裂や鉱脈には明確なマスクが有効です。発光だけで周囲を照らすライトが作られるわけではありません。
Packed PBR一つの画像の各色チャンネルに、複数の素材マスクを格納したものです。一つのファイルから複数の入力を取ります。作成時のチャンネル配置に合うマッピングが必要です。

個別テクスチャとパック PBR の選び方

AO、Metallic、Smoothness/Roughness の個別画像がある場合は Separate Textures を使います。複数のマスクを一枚にまとめた画像なら Packed Texture を使います。ファイル名だけでチャンネル配置を判断せず、配布元の仕様を確認してください。

マッピング赤緑青アルファ
Standard Unity MRAOMetallicAO無視されますSmoothness
MRAO + Height (B)MetallicAO作成済みの HeightSmoothness
Standard Unity MRARMetallicAOこれらのマスクには未使用Roughness。反転して Smoothness に変換
Unreal ORMAORoughness。反転して Smoothness に変換Metallicこれらのマスクには未使用
CustomMetallicSmoothnessAOこれらのマスクには未使用

ここでの Custom は、上記の固定配置です。任意のチャンネルを選ぶ画面ではありません。別の配置の画像は、チャンネルを組み直すか、個別のマップを使います。

パック画像の青チャンネルに保存された高さを使う

  1. PBR Mode → Packed Texture を選び、Packed PBR マップを割り当てます。
  2. チャンネルが R = Metallic、G = AO、B = Height、A = Smoothness の場合は、Mapping → MRAO + Height (B) を選びます。
  3. Parallax を含むサーフェス強度を目的の値に設定してから、Auto Generate を実行します。パック画像の B が高さの入力になり、Parallax が生成時の影響量を決めます。0 にすると除外されます。
  4. 生成された Detail テクスチャとカラーランプを一緒に確認し、必要に応じて地形テクスチャをコンパイルします。

このマッピングは任意です。通常の Standard Unity MRAO では青チャンネルを無視するため、マッピングを意図的に変更して再生成するまでは既存バイオームの結果は変わりません。B に別の細部マスクではなく Height が入っている場合だけ選択してください。既存の Source Height の割り当ては保持されますが、このマッピングを選択している間は Auto Generate がパック画像の B を使います。

Atlas のコンパイルでは、割り当て済みまたは生成済みの Detail テクスチャが優先されます。Detail テクスチャが割り当てられていない場合は、MRAO + Height がパック画像の B を直接使用できます。そのため Mapping を切り替えるだけでは既存の生成結果は置き換わりません。パックされた高さを反映したい場合は再生成してください。このオプションは既存の Detail テクスチャスライスを使用します。

Auto Generate が変更するもの

Auto Generate は、元の入力から処理済みのサーフェスデータとカラーランプを作ります。現在の Normal、AO、Smoothness、Metallic、Emissive、Parallax の強さが生成内容に影響し、0 のマップは除外されます。新しい Source RGB を指定した際にも、細部とランプが初期化されることがあります。

必要な強さを先に設定し、生成してから確認します。除外していたマップが後で必要になったら、適した元画像から再生成してください。生成に含まれていない細部を、シェーダーの倍率だけで取り戻すことはできません。

仕上げたバイオームを再生成する前に：自分で作ったランプを残したい場合は複製します。Auto Generate は手作業の色を置き換えることがあります。ランプ変換の Reset は、すべての生成やテクスチャ割り当てを取り消すボタンではありません。

カラーランプとランプ変換

カラーランプは、素材の細部の値に色を割り当てます。左側は暗い・値の低い細部、右側は明るい・値の高い細部に対応します。同じ岩の元画像でも、茶色い砂岩、冷たい灰色の石、青いスタイライズ表現に変えられます。

これはワールド高度のグラデーションではありません。右端を白にしても、自動で山頂に雪が付きません。地形の高さ・傾斜のルールには、地形側のGradient ツールを使います。

  1. ランプエディターを開き、色のキーを調整します。
  2. まず、くぼんだ細部に暗い色、明るい細部に明るい色を使います。
  3. 複数の色帯が必要なら、中間のキーを追加します。
  4. 通常のシーン照明で塗った地表を確認します。非常に狭い明るい帯は、点状のハイライトになることがあります。
  5. 段階的な色変化には Fixed を有効にし、なめらかな変化には無効にします。
変換動作基準となる値
色相（Hue）色相環に沿って色を回します。−1～+1 は、およそ −180°～+180° です。0 は保持した基準ランプの色相です。小さく変えると関連するバリエーションを作れます。
彩度（Saturation）基準ランプに対して色の鮮やかさを変えます。0 は維持、−1 は無彩色、+1 は彩度を 2 倍にしてから色の範囲に制限します。
明るさ（Brightness）色の範囲内で、ランプの色を暗く・明るくします。0 は基準の明るさです。極端な値にせず、小さな変更から試します。
Reset変換の基準として保持したランプに戻します。変換の調整を取り消すために使います。インポート直後に最初に生成したランプへ戻るとは限りません。

ランプ変換ではキーの位置とアルファは保たれます。どの細部の値に色を付けるかを変えるなら、Hue や Brightness だけでなく、キーを移動・追加します。

岩のバリエーション：灰色の岩を複製し、片方のランプを少し暖かく暗くします。テクスチャの Scale は近い値にし、片方を 90° 回転させます。両方を塗ると、同じ種類の岩に見せながら変化を加えられます。

各サーフェス設定の意味

ここでは、選択したバイオームの設定を変更します。マテリアルには、複数のバイオームへまとめて影響する全体設定もあります。個々の地表を整えてから、全体の倍率で地形を調整すると分かりやすくなります。スキャッター配置は3D スキャッターガイドで別途設定し、一つの再利用可能なスキャッターオブジェクトから複数のバイオーム ID を対象にできます。

項目低い値高い値使い方の目安
Scale：0.02～10模様が大きく、繰り返しが少なく見えます。模様が小さく、繰り返しが多く見えます。テクスチャのタイリングです。GameObject のサイズではありません。キャラクターなど既知の大きさと比較します。
Normal：0～2照明による細部の凹凸が弱くなります。照明の凹凸が強くなります。法線の元画像がある場合に使います。強すぎる法線は、形状を改善せずに表面を騒がしく見せることがあります。
AO Strength：0～1素材のくぼみの陰影が弱くなります。くぼみの陰影が強くなります。シーン全体の照明問題を AO だけで直そうとしないでください。
Parallax：0～2見かけの起伏が弱くなり、0 でその寄与を除きます。素材の細部が深く見えます。浅い角度から確認します。階段、穴、衝突の深さは作りません。
Smoothnessハイライトが広く、粗い素材に見えます。ハイライトが狭く、磨かれた素材に見えます。マップなしは 0～1、マップありは最大 2 です。1 付近ではマップの反応を保ち、1 より大きい値では全体がより均一に滑らかな方向へ変わります。
Metallic金属らしい反応が弱くなります。金属らしい反応が強くなります。マップなしは 0～1、マップありは最大 2 です。1 より大きい値は金属反応を広げるため、単純な中立倍率とは異なります。
Emissive：0～1発光が弱くなります。発光設定からの光が強くなります。変わらない場合は、元のマスクとマテリアルの発光強度を確認します。Bloom は別のシーン・ポストプロセス設定です。
Pulse無効では発光が一定になります。有効ではパルス動作を使います。パルス発光とダスティングは、同じ頂点では併用できません。その場所でダスティングを使う場合は Pulse を無効にします。ランタイムデモの Slot 4 のパルスは、別のマテリアル制御例です。
Rotation：0°、90°、180°、270°バイオームのテクスチャ細部の向きを変えます。方向を合わせたり、同じ素材の複製に変化を付けたりします。地形のメッシュは回転しません。
Anti-Tiling：0～1繰り返しを崩す変化が減ります。0 はそのバイオームの寄与を除きます。模様の繰り返しが目立たないよう、変化を増やします。マテリアルのパッチ・色設定と併用します。強すぎると、方向を意図した模様が分かりにくくなります。
Seam Blend：0～1テクスチャ投影間のブレンドが弱くなります。投影の接続がやわらかくなります。ワールド基準のブレンドは、移動または回転するオブジェクトには固定されません。ずれを隠すには、マテリアルの Seam Blend Fade Distance を小さくします。頂点を溶接したり、隙間を閉じたりはできません。
Priority：0～100ゲームプレイ用の代表バイオームをベイクするとき、優先度が低くなります。十分な割合を占める候補の中で、優先されます。描画の前後関係ではありません。静的ベイクは正規化した被覆率が約 10% 以上の候補を考慮します。ライブの重みによる問い合わせは別のルールです。

見た目とゲームプレイの設定を分けて考える：Priority を変えると、目に見える混ざり方は同じでも、ベイクした代表バイオームが変わる場合があります。足音などに使う場合は、レイキャストテスターで確認します。

良いプリセットを保ちながら変化を作る

関連する地表は Duplicate から始めると安全です。コピーごとに設定を持ち、元画像への参照は共有します。互換性のあるコピーは生成済みの元データを再利用できます。ランプや回転だけを変えるために、新しい画像をインポートする必要はありません。

  • 乾いた岩と濡れたような岩：細部を同じに保ち、濡れた表現のコピーはランプを少し暗く、Smoothness を高くします。見た目の変更で、物理的な濡れのシミュレーションではありません。
  • きれいな石と摩耗した石：同じ細部を使い、色と控えめな法線・視差の変更で差を付けます。
  • 繰り返す素材に変化を付ける：同じ見た目を大量に複製するより、関連するランプと回転をいくつか作り、重み付きで混ぜて塗ります。

複数のバリエーションをまとめて変えるには複数選択を使います。編集前に、どの項目が混在しているかを確認し、残したい違いを消さないようにします。

二つの地表を一つの新しいバイオームにする

Merge は、ちょうど二つの選択したバイオームから新しい生成地表を作ります。石に土が混ざった素材などを、毎回二種類ずつ塗る代わりに再利用したいときに便利です。元のプリセットは残ります。

項目意味判断の目安
Mix Ratio：0.1～0.9二つの入力の比率です。中央に近いほど均等、端に近づくほど片方を強くします。どちらが増えるかはプレビューで確認します。
Softness：0～1元の素材の領域同士が、どれだけ徐々につながるかです。低い値は明確な領域、高い値はやわらかい境界になります。
パッチの大きさ混ざる領域のサイズです。大きいと広い素材の領域、小さいと散らばった細部に見えます。
不規則さ領域の輪郭の不均一さです。控えめなら丸い領域、高くすると崩れた、ぎざぎざの輪郭になります。

実際の Scale で合成後の地表を確認します。プレビューで良く見えても、細かく繰り返すと騒がしく見えることがあります。地形上で二つの地表の接する場所を正確に決めたい場合は、通常のバイオームペイントを使います。

Direct Vertex Color のバイオーム

Direct Vertex Color は、専用のプリセット一覧を持つ色ベースの方式です。バイオームのベースカラーと、この方式で利用できる項目で見た目を作ります。色はメッシュに保存されるので、頂点密度によって塗った境界の細かさが変わります。

Terrain Atlas の法線テクスチャ、パック PBR、視差が、そのまま同じテクスチャ表現として引き継がれるとは限りません。色ベースの結果を求めるときに選び、シーンの照明で確認してください。

接触部の陰影を追加するなら、主要な形状を仕上げてから Direct Vertex Color の AO ベイカーを使います。手順は保存と最適化を参照してください。

テクスチャ品質、メモリ、共有アセット

ライブラリは、元の入力を地形マテリアル用のテクスチャにまとめます。生成の設定で、鮮明さ、メモリ使用量、プラットフォーム対応のバランスを取ります。

項目効果選び方
解像度生成テクスチャのサイズです。Auto、または 256～8192 の指定値を選べます。中程度から始め、ゲームカメラで確認します。高解像度はメモリを多く使い、元画像にない細部は作れません。
圧縮高品質の圧縮形式や RGBA32 など、選択した形式で生成します。対象機器で細部と色を比較します。非圧縮は一般に多くのメモリを使います。
ミップマップ画面上で小さくなる細部用に、低解像度の画像を用意します。さまざまな距離から見る地形に有効です。変更時は遠くのちらつきと鮮明さを比較します。
異なる元画像別の入力セットでは追加の生成データが必要になることがあります。関連するバリエーションでは適切に元画像を共有します。カード数だけで負荷を判断せず、生成アセットを確認します。

通常のライブラリ編集では、ツールの処理を通じて生成データが更新されます。マテリアルが合っていない場合は Compile Terrain Textures を使い、正しいライブラリとマテリアルを参照しているか確認します。ゲームプレイ用サーフェスデータの再ベイクは別の操作です。テクスチャ生成だけでは、古い三角形とバイオームの対応は更新されません。

バイオームでよくある問題

Stylized Lighting と AO、Pulse とダスティングの互換性、移動する地形での Seam Blend については、マテリアル FAQも参照してください。

問題確認すること
Stylized Lighting でマテリアルが暗すぎるこのモードでは AO が影として扱われます。バイオームの AO Strength またはマテリアルの Surface AO Strength を下げます。高さの解釈が逆なら Invert Height を試し、必要に応じて再生成します。
ダスティングを塗った場所で Pulse が止まるパルス発光とダスティングは同じ頂点では併用できません。その領域ではどちらか一方を使用し、ダスティングを使う場合は Pulse を無効にします。
元画像と完成した色が違うGenerated とランプを確認します。Source RGB は生成の入力で、最終的な色はランプが決めます。照明と全体の倍率も確認します。
盛り上がりがくぼんで見えるInvert Height と高さの元画像を確認し、テスト中は強すぎる Parallax を下げます。
パック画像の青チャンネルの Height が見た目に反映されないMRAO + Height (B) を選び、B に Height が入っていて Parallax が 0 より大きいことを確認してから Auto Generate を実行します。コンパイル時は、既存の生成済み Detail テクスチャが優先されます。
全面が光沢・金属になるPBR の配置、Roughness の扱い、スライダー値を確認します。マップありの 1 より大きい値は、反応を均一に近づけます。
法線の細部が出ない画像の割り当てとインポート設定、バイオームの強さ、生成設定、全体の法線強度とフェードを確認します。
Auto Generate で色が消えたランプが再生成される場合があります。可能なら元に戻すか、保存・複製したプリセットを使います。再生成前にランプを複製してください。
カラーランプで雪の高度が変わらない地形の Gradient ツールを使います。バイオームのランプは素材の細部の色で、ワールド高度の選択ではありません。
模様の繰り返しが目立つScale、バイオームの Anti-Tiling、マテリアルの変化設定を確認します。回転やランプの関連バリエーションも試します。
Auto Folder の後でマップがおかしい検出した入力とチャンネル配置を確認します。Roughness を Smoothness として使うと結果が逆になります。
Priority を変えても見た目が変わらないゲームプレイ用の代表バイオームを選ぶ設定です。見た目の描画順ではありません。
実行時の効果が別の地表を変える追加、削除、並べ替え後の ID を確認します。デモの番号は名前や共通の定数ではありません。
