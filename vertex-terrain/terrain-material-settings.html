Vertex 3D Terrain - Terrain Material Settings

Material Reference Guide
A practical reference for the terrain-specific controls exposed by the Vertex 3D Terrain material. This page covers global biome rendering, distance fades, anti-tiling and live biome modifiers without documenting the internal shader implementation.
Scope: This guide covers the Terrain Surfaces & Biomes controls that are specific to Vertex 3D Terrain. Shared material features such as general lighting, wind and other core material controls are documented separately.
Quick Navigation Reference: 1. Terrain Surface Setup 2. Global Surface Controls 3. Distance Fades 4. Anti-Tiling 5. Live Biome Modifiers 6. Flow & Waterfalls 7. Dusting 8. Example Workflows 9. Troubleshooting Support

1. Terrain Surface Setup

Open the material and expand Terrain Surfaces & Biomes. The terrain-specific controls appear when Enable Surfaces (Biomes) is enabled.

Property Description
Enable Surfaces (Biomes) Turns the terrain biome surface system on or off for this material.
Ground Color Ramp Atlas Generated biome color data used by the terrain material. This is normally assigned by Vertex 3D Terrain and should not need to be edited by hand.
Ground Detail Array Generated terrain detail data shared by the compiled biomes. This is also normally managed automatically.
Total Grounds Count The number of compiled biome entries available to the material. Treat this as generated library data rather than an artistic control.
Generated fields: If the Color Ramp Atlas, Detail Array or biome count are missing or incorrect, rebuild or reassign the Ground Library through the terrain tools rather than trying to repair those values manually in the material.

2. Global Surface Controls

These settings affect the appearance of all terrain biomes using this material. Per-biome values still define the character of each surface; these controls act as overall material-level multipliers or adjustments.

Property Typical Use Description
Detail Tiling Scale Overall texture scale Changes the global tiling frequency of biome surface detail. Use this only when the entire terrain material needs to appear larger or smaller in scale.
Surface Normal Strength Bump intensity Global multiplier for terrain normal detail. Lower it for a softer surface or increase it when the terrain needs stronger small-scale relief.
Surface Metallic Strength Metal response Global multiplier for metallic response across terrain biomes.
Surface Smoothness Strength Gloss / wet look Global multiplier for terrain smoothness. Higher values make reflective surfaces read more strongly.
Surface AO Strength Crevice shading Controls the overall strength of terrain ambient occlusion shading.
Surface Emissive Strength Lava, glow, magical surfaces Global multiplier for emissive regions used by terrain biomes.
Surface Height Contrast Biome blend definition Controls how strongly height information influences transitions between blended terrain biomes. Increase it for more defined material boundaries; reduce it for softer blending.
Parallax Extrusion Scale Perceived depth Controls the apparent physical depth of terrain detail. The Inspector range is 0 to 1. Set it to 0 when parallax depth is not required.
Recommended order: Set the biome itself up correctly first, then use these global controls for final material-wide balancing. Avoid compensating for one badly configured biome by changing a global multiplier that affects every other biome.

3. Distance Fade Controls

Distance fades reduce expensive or high-frequency detail as it becomes less useful on screen. Each slider ranges from 0 to 50 world units.

Property Description
Parallax Fade Distance Controls how far from the camera parallax depth remains active before fading away. Keep this only as high as needed for the expected close-up camera distance.
Anti-Tiling Fade Distance Controls the distance over which anti-tiling variation remains active. Distant terrain usually needs less variation processing.
Seam Blend Fade Distance Controls the distance used for terrain seam blending and distant projection support.
Normal Fade Distance Controls how far detailed terrain normals remain fully active before fading at distance.
Performance: Lower fade distances reduce the amount of expensive detail evaluated on distant terrain. Increase a fade only when the visual improvement is noticeable at that distance.
0 values: The Inspector treats 0 as the disabled setting for the corresponding distance effect.

4. Anti-Tiling Controls

Anti-tiling breaks up obvious texture repetition across large surfaces. These controls are intentionally broad artistic adjustments rather than per-biome replacement settings.

Property Description
Rotation Patch Scale Controls the size of regions used to vary the orientation of repeating surface detail. Use larger regions for broad variation and smaller regions when repetition is obvious over short distances.
Color Patch Scale Controls the size of the terrain's broad color-variation regions.
Color Ramp Shift Controls how strongly the terrain's biome colors vary between those regions.
Brightness Contrast Controls the difference between lighter and darker variation regions.
Tip: Anti-tiling works best when it is subtle. If the variation itself becomes easy to see, reduce the strength or increase the patch size until it stops drawing attention.

5. Live Biome Modifiers

Enable Live Biome Modifiers exposes four material-level modifier slots. These are designed for temporary or runtime-style appearance changes without editing the underlying biome preset.

Important: Live modifiers only affect biomes targeted by their biome ID. They do not replace the source biome settings stored in the Ground Library.

Modifier Slots

Control Range Description
Modifier Slot 1-4 On / Off Enables or disables that live modifier group.
Target Biomes 1-3 Sets how many biome IDs the slot affects. One slot can target up to three biomes at the same time.
Target Biome 1-3 ID 0-255 Biome IDs affected by the slot. Use the IDs shown by the Vertex 3D Terrain biome tools.
Weight Multiplier 0-5 Changes how strongly the targeted biome contributes when blended with other biomes. 1 leaves the blend unchanged, values below 1 reduce its influence, and values above 1 increase it.

Surface Overrides

Surface Overrides temporarily multiply selected appearance properties for all biome IDs targeted by the slot.

Property Range Description
Smoothness Mult 0-3 Multiplies the targeted biome's smoothness. Useful for making a surface look temporarily wetter, glossier or duller.
Normal Strength Mult 0-3 Multiplies the normal strength of the targeted biome.
Parallax Depth Mult 0-3 Multiplies the targeted biome's parallax depth.
Emissive Mult 0-10 Multiplies emissive output for the targeted biome. Useful for effects such as lava, magical surfaces or pulsing glow.
Example: To make several rocky biomes look wet during rain, place their biome IDs in one modifier slot, increase Smoothness Mult, and leave the source biome presets unchanged.

6. UV Flow Animation & Waterfall Projection

Each live modifier slot can animate the surface detail of its targeted biomes. This is useful for water, lava, magical energy, flowing slime and other moving terrain surfaces.

Control Range Description
Enable Flow On / Off Enables animated surface movement for the biome IDs targeted by this modifier slot.
Back and Forth On / Off Switches from continuous movement to an oscillating motion. This is useful for shores, lakes and other surfaces that should surge rather than continually scroll in one direction.
Waterfall Projection On / Off Enables the special waterfall treatment for steep world-up surfaces. Leave this disabled for ordinary flow, curved terrain and planetoids.
Compass Heading 0-359° Sets the flow direction. 0° = East, 90° = North, 180° = West and 270° = South.
Flow Speed -1 to +1 Controls animation speed. Negative values reverse the direction.
Planetoids: Waterfall Projection is based on normal world-up terrain. Keep it disabled on planetoids. Normal flow can still be used without the waterfall option.
Water workflow: For a lake feeding a waterfall, use the same water biome for normal flow and enable Waterfall Projection only where that material setup is intended to run over steep terrain. If you need different speeds or behaviour, a duplicated biome can be used as a dedicated waterfall variant.

7. Dusting Layer

Dusting allows another biome to coat the targeted biome where dusting data has been painted. Typical uses include snow over grass or rock, ice over water, ash over soil, or sand collecting over another surface.

Control Range Description
Enable Dusting On / Off Turns dusting on for the biome IDs targeted by this live modifier slot.
Dusting Biome ID Biome ID The biome that will appear as the coating material, for example Snow over Grass.
Dusting Strength 0-2 Controls the intensity of the coating.
Slope Threshold 0-1 Controls which upward-facing slopes can hold the dusting. Lower values allow coating on more angles; higher values restrict it toward flatter upward-facing surfaces.
Snow example: Target the Grass and Rock biome IDs, set the Dusting Biome ID to Snow, then raise Slope Threshold if the snow is collecting too strongly on steep cliff faces.

8. Example Workflows

Wet Terrain During Rain

  1. Enable Live Biome Modifiers.
  2. Enable one modifier slot.
  3. Add the biome IDs that should appear wet.
  4. Leave Weight Multiplier at 1 unless the biome blend itself also needs to change.
  5. Increase Smoothness Mult.
  6. Optionally reduce or increase Normal Strength Mult to match the desired wet-surface look.

Animated Water

  1. Target the water biome ID.
  2. Enable Flow.
  3. Set Compass Heading to the intended direction.
  4. Adjust Flow Speed.
  5. Enable Back and Forth for shoreline or lake-style movement.
  6. Leave Waterfall Projection disabled unless the water is intended to run over steep world-up terrain.

Snow or Ash Accumulation

  1. Target the base biomes that can receive the coating.
  2. Enable Dusting.
  3. Select the Snow, Ash or other coating biome ID.
  4. Adjust Dusting Strength.
  5. Use Slope Threshold to control how readily the coating remains on steep slopes.

9. Troubleshooting Notes

"My biome textures are missing or the terrain looks completely wrong."
Check that Ground Color Ramp Atlas, Ground Detail Array and Total Grounds Count contain the expected generated data. If they are missing, rebuild or reassign the biome library using Vertex 3D Terrain rather than manually constructing these fields.
"Parallax is too expensive or shimmers in the distance."
Reduce Parallax Extrusion Scale and/or lower Parallax Fade Distance. Distant surfaces generally do not benefit from full parallax depth.
"My terrain pattern is obviously repeating."
First make sure the biome's own scale is sensible. Then adjust Rotation Patch Scale and Color Patch Scale, followed by small amounts of Color Ramp Shift and Brightness Contrast.
"Live Biome Modifiers do nothing."
Confirm Enable Live Biome Modifiers is enabled, the modifier slot is active, and the correct biome ID is listed under Target Biomes. Also make sure the Weight Multiplier and the desired override are not set to neutral values.
"Flow is enabled but nothing moves."
Check that the slot targets the correct biome ID, Enable Flow is on, and Flow Speed is not 0. If testing a blended area, confirm that the targeted biome is actually contributing to that surface.
"The flow direction is backwards."
Change Compass Heading by 180°, or use the opposite sign on Flow Speed when a complete direction reversal is required.
"A planetoid is stretching like a waterfall."
Disable Waterfall Projection for that slot. Standard flow is suitable for curved terrain; Waterfall Projection is intended for world-up terrain and floating-island style waterfalls.
"Dusting appears on slopes where I do not want it."
Increase Slope Threshold so the dusting favours flatter upward-facing terrain. Reduce Dusting Strength if the coating is also too dominant.
"Changing a live modifier permanently changed my biome."
Live modifier controls are material-level overrides. To permanently change the biome preset itself, edit the biome through the Vertex 3D Terrain biome tools instead.
