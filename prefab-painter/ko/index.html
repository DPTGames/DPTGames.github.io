DPT Games Prefab Painter

위치·회전·크기와 오브젝트별 색상 변화를 무작위로 적용하여 씬에 프리팹을 직접 페인팅할 수 있습니다. 시작하는 데 필요한 기능이 기본 제공됩니다.

주요 기능

  • URP 지원 및 창 너비에 맞게 조정되는 인스펙터 UI
  • 배치 전에 확인할 수 있는 실물 크기(1:1) 홀로그램 프리팹 미리보기
  • 에디터 창 너비에 맞게 조절되는 간결한 UI
  • 회전하는 호버 미리보기와 썸네일 그리드를 제공하는 프리팹 팔레트
  • 드래그 앤 드롭으로 프리팹 추가, 영역 다중 선택 및 드래그로 제거
  • 저장할 수 있는 팔레트 프리셋으로 바이옴 또는 소품 구성을 즉시 전환
  • 단축키로 항목 선택(Shift + 1–0 / 숫자 키패드) 및 전체 선택 해제(Shift + D). 번호 배지로 페인팅 중에도 프리팹을 전환할 수 있음
  • 지형 텍스처(스플랫맵) 필터링, 실시간 미리보기 제외 및 그룹별 재정의 지원
  • 그룹마다 배치 레이어, 부모 오브젝트 및 지형 스플랫맵 설정 가능
  • 페인팅할 때 C# 컴포넌트 자동 추가
  • 페인트, 스캐터, 라인, 그리드, 경로 및 측정 모드
  • 경로 모드에서 여러 그룹을 연속 배치하고 이전 구간도 다시 계산하여 이음새 조정
  • 배치 후 회전 조정으로 정확한 위치 맞춤
  • Smart Clearance 및 전환 가능한 Check Clearance로 겹침 제어
  • 에디터 내 물리 시뮬레이션으로 자연스럽게 떨어뜨려 배치
  • 다음 기능과 연동: DPT_ShaderVariation . 드로우 콜을 추가하지 않고 오브젝트별 색상 변경 가능
  • Unity 실행 취소 기록 완벽 지원
빠른 이동: 시작하기 프리팹 팔레트 페인팅 및 조작 시각 효과 및 변형 변형 및 배치 계층, 태그, 레이어 및 스크립트 텍스처 채널 패커 단축키 목록 문제 해결 지원

시작하기

몇 단계만 거치면 페인터를 열어 에셋 배치를 시작할 수 있습니다.

빠른 시작

  1. Unity 메뉴 표시줄에서 Tools → DPT Games → Prefab Painter 을 엽니다. 창을 도킹하거나 크기를 바꿀 수 있습니다. 좁은 창에서는 컨트롤이 세로로 쌓이고 넓은 창에서는 여러 열로 표시됩니다.
  2. 개별 프리팹을 그룹에 끌어 놓아 추가할 수 있습니다. 폴더 계층을 자동으로 정리하려면 최상위 폴더를 팔레트 상단의 Create Groups from Subfolders 영역에 놓습니다. 바로 아래의 하위 폴더마다 이름을 딴 그룹이 생성되며 더 깊은 폴더의 항목은 가장 가까운 상위 그룹에 포함됩니다.
  3. 지형이나 바닥 표면의 레이어에 맞도록 Paintable Layer 를 설정합니다.
  4. 필요한 경우에만 Parent Object 를 지정하거나 New 를 클릭하여 새로 만듭니다. 부모 오브젝트를 수동으로 지정할 필요는 없습니다.
  5. 초록색 START PAINTING ['] 버튼을 클릭합니다. 도구가 활성화되지만 기본 설정에서는 일반 브러시 페인팅에 Ctrl 키를 누르고 있어야 합니다.
  6. 씬에서 Ctrl + Left Click 을 누른 채 드래그하면 프리팹을 페인팅합니다. 또는 페인팅 버튼 아래의 Require Ctrl to Paint 를 해제하면 Left Click + Drag 만으로 페인팅할 수 있습니다.
실행 취소: 페인트, 지우기, 라인, 그리드 및 경로 작업은 모두 Unity 실행 취소 기록에 등록됩니다. Ctrl + Z 및 Ctrl + Y 를 사용할 수 있습니다.

프리팹 팔레트

팔레트에서 배치할 프리팹을 관리합니다. 여러 그룹, 저장 가능한 프리셋 및 다양한 추가·제거 방식을 지원합니다.

폴더 자동 그룹화: 상위 폴더를 팔레트 그룹 위의 Create Groups from Subfolders 영역에 놓으면 바로 아래의 하위 폴더를 기준으로 그룹을 자동 생성합니다. 예를 들어 Nature/Trees, Nature/Rocks 및 Nature/Plants 는 세 그룹이 됩니다. 더 깊은 폴더는 가까운 상위 그룹에 포함됩니다. 상위 폴더에 직접 들어 있는 프리팹은 상위 폴더 이름의 그룹으로 들어갑니다. 이름이 같은 그룹은 재사용하고 중복 프리팹은 건너뜁니다. 폴더를 기존 그룹에 놓으면 모든 프리팹이 그 그룹에 추가됩니다. 많은 에셋도 단계적으로 불러옵니다. 숫자 키 단축키는 처음 10개 그룹에만 적용되며 나머지 그룹은 창에서 선택할 수 있습니다.
컨트롤 설명
활성 팔레트 파일 및 새 이름으로 저장 현재 팔레트를 프로젝트 에셋으로 저장하여 재사용합니다. 오브젝트 필드에서 다른 팔레트를 불러와 소품 세트나 바이옴 테마를 전환할 수 있습니다.
썸네일 그리드 불러온 프리팹의 아이콘을 보여 줍니다. 썸네일에 마우스를 올리면 오브젝트가 자동 회전하는 확대 고해상도 미리보기가 나타납니다. 오른쪽 클릭으로 프리팹 열기, 배리언트 생성 및 활성 상태 변경 등을 할 수 있습니다.
항목 단축키 선택 [Shift + 1–0] 및 전체 선택 해제 [Shift + D] 하나의 프리팹 그룹이 활성화되어 있으면 처음 10개 프리팹에 번호 배지(1–0)가 표시됩니다. 항목을 전환하려면 Shift + [1–0] 키를 누릅니다(또는 Line/Path 모드에서는 1–0 키를 Ctrl + Alt 누른 채 바로 입력할 수도 있습니다). 라인이나 경로를 그리는 동안에도 선택 항목을 바꿀 수 있으며 숫자 키패드도 지원합니다. 전체 선택을 해제하려면 Shift + D 를 누르면 작업을 중단하지 않고 선택을 모두 해제합니다. 그룹을 바꿔도 선택 내용은 유지되며 번호 배지는 새 그룹의 항목에 표시됩니다.
생성 가중치 팔레트에서 하나 이상의 프리팹을 선택하면 선택 항목 설정 패널이 나타납니다. Spawn Weight 슬라이더나 입력 필드에서 다른 프리팹에 비해 얼마나 자주 생성될지 정합니다. 가중치 2는 가중치 1보다 두 배 자주 생성됩니다. 썸네일의 작은 w 배지는 기본값이 아닌 가중치가 설정되었다는 뜻입니다. 가중치는 팔레트 파일에 저장됩니다.
그룹 및 재정의 설정 그룹은 + Group 로 추가할 수 있습니다. 또는 상위 폴더를 Create Groups from Subfolders에 놓아 자동 생성할 수 있습니다. 처음 10개 그룹은 1–9 / 0 로 전환하며 추가 그룹은 에디터 창에서 선택할 수 있습니다. 활성화된 그룹이 없으면 모든 그룹을 페인팅할 수 있습니다. 그룹마다 Spawn Layer, Paintable Layer, Parent Object 및 Terrain Splatmap을 재정의할 수 있습니다.
영역 선택 썸네일 그리드에서 드래그하여 여러 프리팹을 선택합니다. 여러 항목을 한꺼번에 이동하거나 제거할 때 편리합니다.
씬으로 드래그 팔레트의 프리팹을 Scene 뷰로 드래그하여 한 번씩 수동으로 배치할 수 있습니다.
제거 영역으로 드롭 선택한 프리팹을 이 영역으로 드래그하면 팔레트에서 제거합니다.

페인팅 조작

패널 위쪽에서 Paint, Erase, Recolor및 Measure 탭을 선택합니다. Erase, Recolor 또는 Measure 모드에서 해당 단축키를 다시 누르면 Paint 모드로 돌아옵니다. 큰 초록색 버튼으로 페인팅을 시작하고 빨간색 버튼으로 중지합니다. Start Painting은 도구를 활성화할 뿐입니다. Require Ctrl to Paint를 해제하지 않으면 Ctrl 키가 필요합니다. 해제하면 마우스 왼쪽 버튼과 드래그만으로 페인팅할 수 있습니다. Alt 카메라 조작, Ctrl+Alt 라인, Ctrl+Shift 그리드 및 경로 편집 단축키는 그대로 유지됩니다.

배치 모드

모드 사용 방법
페인트 모드 기본 모드입니다. Ctrl + Left Click 을 누른 채 드래그하면 브러시 반경 내 표면에 프리팹을 계속 배치합니다. 또는 Require Ctrl to Paint 를 해제하고 왼쪽 버튼과 드래그만 사용할 수도 있습니다. Scatter 모드가 켜져 있으면 예상 생성 수(~N)가 표시됩니다.
스캐터 모드 [O] 한 번의 스트로크로 브러시 전체 영역에 여러 프리팹을 무작위로 배치합니다. 넓은 영역에 풀이나 바위 같은 지표 오브젝트를 밀집 배치할 때 유용합니다. O키로 켜거나 끕니다.
라인 모드 키를 누른 채 Ctrl + Alt + Drag 를 사용하면 시작 지점부터 직선을 따라 프리팹을 배치합니다. 라인 모드는 연속 클릭에서 경계 위치를 기억하므로 모서리나 여러 구간도 불필요한 틈이나 겹침 없이 연결됩니다. 작업 중 그룹을 바꾸어 벽과 문 같은 다른 오브젝트도 이어 붙일 수 있습니다.
그리드 모드 키를 누른 채 Ctrl + Shift + Drag 를 사용하면 일정한 그리드 간격으로 프리팹을 배치합니다. 바닥 타일, 상자나 농작물처럼 규칙적인 배치에 적합합니다. 그리드 간격은 브러시 크기와 독립적이며 드래그로 범위를 조절할 수 있습니다.
경로 페인트 [G] 부드러운 곡선 경로를 따라 프리팹을 배치합니다. G 키로 경로 모드에 들어간 후 Ctrl + Left Click 로 노드를 추가합니다. 다시 G 키를 누르거나 Enter 키로 마칩니다. 현 길이 기반 반복 계산으로 실제 크기를 계산하므로 급격한 곡선에서도 벽 같은 오브젝트를 정확히 이어 붙입니다. 작업 중 그룹을 바꿀 수 있고 각 구간은 할당된 프리팹을 개별적으로 관리합니다. 기존 경로 노드 핸들을 클릭해 선택한 다음 팔레트 항목이나 그룹을 변경하면 해당 구간을 나중에 갱신할 수도 있습니다.
측정 모드 [Q / Shift+Q] 씬 내 거리를 확인하는 대화형 측정 도구입니다. Q 키로 선 측정, Shift + Q 키로 그리드 측정을 실행합니다. 다른 모드로 전환해도 측정 결과는 ESC 키를 누를 때까지 화면에 남습니다.

브러시 설정

Require Ctrl to Paint: 기존 사용 방식과의 호환성을 위해 기본적으로 켜져 있습니다. 해제하면 페인팅이 활성화된 동안 일반 왼쪽 클릭 및 드래그로 페인트, 지우기 또는 색 변경을 할 수 있습니다. 씬 뷰에서 실수로 페인팅하지 않으려면 켜 두세요. Ctrl+Alt 라인과 Ctrl+Shift 그리드 단축키는 항상 사용할 수 있으며 오른쪽 클릭 카메라 조작은 바뀌지 않습니다.

설정 설명
실시간 프리팹 미리보기 [F] 실제 배치 위치, 회전 및 크기를 확인할 수 있는 1:1 홀로그램 미리보기를 씬에 표시합니다. F키로 켜거나 끕니다.
페인팅 대상 레이어 이 레이어에 있는 표면에만 프리팹을 배치합니다. 지형이나 바닥 메시의 레이어와 일치시켜야 합니다. 일치하지 않으면 레이캐스트가 지나가서 배치되지 않습니다.
지형 스플랫맵 사용 Unity Terrain에서 페인팅할 때 풀, 흙, 바위 같은 특정 Terrain Layer와 최소 혼합 가중치로 생성 위치를 제한합니다. 흙길 위에 풀이 생성되는 등의 배치를 방지합니다. 모든 배치 모드, 실시간 미리보기 제외 및 그룹별 설정을 지원합니다.
브러시 모양 [C] 브러시 범위를 원형과 사각형 사이에서 전환합니다. C 키를 눌러 바꿉니다.
브러시 반경 [ [ / ] ] 브러시의 크기를 조절합니다. [ 키로 줄이고 ] 키로 늘립니다.
배치 무작위화 [U] 켜면 커서 위치가 아니라 브러시 반경 안의 무작위 지점에 프리팹을 배치합니다. Scatter뿐 아니라 Paint, Line, Grid 등 모든 배치 모드에 적용됩니다. U키로 전환합니다. 꺼도 브러시 반경 설정은 유지됩니다.
최소 간격 [M / Shift+M] 오브젝트 사이의 최소 거리를 설정합니다. M 키로 늘리고 Shift+M 키로 줄입니다. Smart Clearance가 켜져 있으면 오브젝트 크기도 고려합니다. ‘변형 및 배치’를 참고하세요.
생성 간격 [X / Shift+X] 드래그하는 동안 프리팹을 얼마나 자주 배치할지 정합니다. 값이 낮을수록 빠르게 생성됩니다. X 키로 간격을 늘리고 Shift+X 키로 줄입니다.
경로 길이에 맞춰 간격 조정 [S] Path Paint가 활성화될 때만 표시됩니다. 켜면 경로를 정확히 닫도록 간격을 약간 늘리거나 줄입니다. 도로처럼 길이가 고정된 모듈식 오브젝트에서는 이음새 문제를 막기 위해 끄세요.
브러시 핸들 색상 씬 뷰에 표시되는 브러시 원의 색상을 바꿉니다. 지형 색상 때문에 잘 보이지 않을 때 조절하세요.

시각 효과 및 변형

DPT 셰이더 파이프라인을 사용하는 인스턴스별 외형 변화입니다. 추가 머티리얼 없이 GPU 배칭을 유지하면서 배치된 오브젝트의 다양성을 높입니다.

설정 설명
밝기 무작위화 [B] 배치한 각 프리팹에 DPT_ShaderVariation 컴포넌트로 밝기를 무작위 조절합니다. 같은 에셋을 반복 배치했을 때 단조로운 조명을 줄여 줍니다.
색조 적용 [V] 프리팹에 기본 색조와 선택적 HSV 변화를 적용합니다. DPT 셰이더를 사용하는 식물, 바위나 기타 에셋에 자연스러운 색상 변화를 더합니다.
셰이더 연동: DPT 셰이더는 GPU Renderer Shader User Value(RSUV) 스트림에서 인스턴스별 변형 값을 읽습니다. Unity 6 GPU Resident Drawer와 호환되며 변형으로 드로우 콜 수가 늘어나지 않습니다. 표준 URP Lit 대체 셰이더가 감지될 때만 Color Property Name 필드를 편집할 수 있으며 이 경우 Material Property Block을 사용합니다.

변형 및 배치

배치한 프리팹의 방향, 크기, 이름 및 씬 계층 정리 방식을 설정합니다.

설정 설명
표면 방향에 맞추기 [N] 배치한 오브젝트의 위쪽 축을 표면 법선에 맞춥니다. 경사면이나 울퉁불퉁한 지형에 유용합니다.
Y 회전 무작위화 [Y] 각 프리팹을 수직축 주위로 무작위 회전합니다. 같은 에셋을 많이 배치할 때 반복되는 외형을 줄여 줍니다.
크기 무작위화 [L] 지정한 최소값과 최대값 사이에서 각 프리팹의 크기를 무작위로 설정합니다. 끄면 고정 크기 슬라이더가 나타납니다.
고정 크기 Randomize Scale이 꺼져 있을 때 표시됩니다. 모든 프리팹에 같은 크기 배율을 적용합니다.
쌓기 허용 [K] 켜면 이미 페인팅한 오브젝트 위에도 프리팹을 배치할 수 있습니다. 바위에 이끼나 잔돌을 얹을 때 유용합니다. 끄면 같은 부모 아래에 있는 기존 페인팅 오브젝트 위에 배치하지 않습니다.
콜라이더 기준 배치 [P] 피벗이 아니라 콜라이더 경계의 아래쪽을 기준으로 배치합니다. 피벗이 중앙에서 벗어난 오브젝트가 땅에 묻히는 것을 방지합니다. 콜라이더가 없는 프리팹에는 임시 콜라이더가 자동으로 생성됩니다.
Smart Clearance [I] 오브젝트의 실제 크기를 고려해 배치 간격을 판단합니다. Min Spacing이 낮아도 겹침을 방지하며 Min Spacing을 올리면 오브젝트 크기에 추가 간격이 더해집니다.
Check Clearance 전환 [D] 오브젝트 사이의 겹침 검사를 켜거나 끕니다. 끄면 검사를 생략하므로 일부 겹침이 허용되는 대량 스캐터 배치에서 성능이 크게 향상될 수 있습니다. D키로 전환합니다.
물리 낙하 [H] 배치 후 에디터에서 짧은 물리 시뮬레이션을 실행하여 중력에 따라 자연스럽게 자리 잡게 합니다. 바위 더미나 울퉁불퉁한 지형에 유용합니다. 생성 높이 오프셋의 상한이 높아져 더 높은 곳에서 떨어뜨릴 수 있습니다.
배치 후 회전 [J] Scatter, Line, Grid 또는 Path로 배치한 뒤 마우스를 움직여 결과를 회전할 수 있습니다. 배치한 오브젝트 그룹의 중심을 기준으로 회전하고 표면 접지도 실시간으로 갱신합니다. 클릭하여 확정합니다.

계층, 태그 및 스크립트

배치한 오브젝트의 정리, 설정 재정의 및 페인팅 중 컴포넌트 추가 옵션입니다.

설정 설명
부모 오브젝트 및 이름 부모 오브젝트 지정은 선택 사항입니다. 지정하면 모든 프리팹을 해당 부모의 자식으로 배치합니다. 이름을 입력하고 New 를 누르면 새 부모 오브젝트를 만듭니다. 배치된 자식 오브젝트는 선택한 이름 규칙에 따라 번호가 붙습니다. 그룹마다 다른 부모 오브젝트를 설정할 수도 있습니다.
이름 지정 규칙 배치된 오브젝트 이름의 접두사나 패턴을 설정합니다. 예를 들어 Rock_001, Rock_002처럼 일련번호를 매길 수 있습니다.
태그 및 레이어 재정의 원본 프리팹 설정 대신 지정한 태그와 레이어를 배치된 오브젝트에 적용합니다. 자식 오브젝트까지 적용할지 선택할 수 있으며 그룹별 재정의도 지원합니다.
스크립트 컴포넌트 자동 추가 프리팹 배리언트를 만들지 않고 페인팅한 프리팹에 원하는 C# 컴포넌트를 자동으로 추가할 수 있습니다.
  • Root : 생성된 루트 오브젝트에 추가합니다.
  • Named Child : 이름이 일치하는 자식 오브젝트에 추가합니다(대소문자 구분).
  • Skip If Already Exists : 같은 컴포넌트가 이미 있으면 중복 추가하지 않습니다.

텍스처 채널 패커

DPT 셰이더는 메탈릭, 오클루전, 디테일 및 스무스니스 정보를 하나의 텍스처로 결합하는 패킹 형식을 사용합니다. 내장 패커는 Tools → DPT Games → Texture Channel Packer에서 실행할 수 있습니다.

  1. 원본 맵을 다음 채널에 할당합니다.
    • 빨강: 메탈릭 맵
    • 초록: 오클루전 맵
    • 파랑: 디테일 / 마스크 맵
    • 알파: 스무스니스 맵
  2. 채널별 옵션을 설정합니다.
    • Invert: 값을 반전합니다(1.0 - value). 러프니스 맵을 스무스니스 맵으로 바꿀 때 사용합니다.
    • Convert Brightness: RGB 평균 명도((R + G + B) / 3)에서 회색조 값을 추출합니다. 알파 채널이 없는 24비트 RGB 파일을 사용할 때 켭니다.
  3. 슬롯을 비워 두었다면 Empty Value 슬라이더로 해당 채널의 기본 고정값을 지정할 수 있습니다.
  4. 마지막으로 Pack and Save Texture 을 클릭하여 패킹된 텍스처를 생성합니다.

필수 Unity 가져오기 설정

패킹하기 전에 모든 원본 텍스처의 Unity 인스펙터에서 다음 설정을 확인하세요.

  • Read/Write: 사용 : 패커가 픽셀 데이터를 읽는 데 필요하며 꺼져 있으면 오류가 발생합니다.
  • sRGB(Color Texture): 사용 안 함 : 이 맵은 색상 텍스처가 아니라 데이터 텍스처입니다. 켜져 있으면 메탈릭, 러프니스 및 AO 값이 달라집니다.
  • Alpha Is Transparency: 사용 : 스무스니스 채널을 0~1 범위에서 올바르게 읽도록 합니다.
밝기 변환: 내장된 Convert Brightness 옵션은 24비트 RGB 맵을 스칼라 데이터로 에디터에서 직접 변환하므로 외부 도구가 필요하지 않습니다.

문제 해결

페인팅해도 프리팹이 배치되지 않음
가장 흔한 원인은 레이어가 일치하지 않는 것입니다. 페인터는 Paintable Layer에 지정된 레이어의 표면에만 배치합니다. 지형이나 바닥 메시의 레이어와 페인터의 Paintable Layer가 같은지 확인하세요. 페인팅도 활성화되어 있어야 하며 버튼이 빨간색 Stop Painting으로 표시되는지 확인하세요.
Use Terrain Splatmaps를 켜면 지형에 배치되지 않음
선택한 Terrain Layer가 페인팅하려는 텍스처(예: Layer 0의 풀)와 일치하고 브러시 위치의 가중치가 Min Weight 이상인지 확인하세요. 텍스처 경계의 혼합이 약하면 Min Weight를 0.2~0.3으로 낮추어 전환 영역에도 배치할 수 있습니다.
오브젝트가 겹치거나 서로 파고듦
먼저 Smart Clearance [I] 을 켜고 Check Clearance [D] 도 켜져 있는지 확인하세요. 각 프리팹의 실제 크기를 고려해 안전한 간격을 확보합니다. 간격을 더 늘리려면 Min Spacing을 늘리세요. 간격 검사는 같은 부모 오브젝트의 자식끼리만 수행하며 서로 다른 부모 사이에서는 검사하지 않습니다.
오브젝트가 탑처럼 쌓임
일부러 겹쳐 배치하려는 경우가 아니라면 Allow Stacking [K] 을 끄세요. 그러면 같은 부모 아래에 있는 기존 페인팅 오브젝트 위에는 새 프리팹을 배치하지 않습니다.
모든 오브젝트가 똑같이 보이고 색상 변화가 없음
먼저 Randomize Brightness [B] 또는 Apply Color Tint [V] 가 켜져 있는지 확인하세요. 프리팹이 DPT 셰이더를 사용하는지도 확인하세요. 표준 URP Lit 셰이더는 인스턴스별 RSUV 변형을 지원하지 않습니다.
실수로 다른 곳에 페인팅했습니다. 되돌릴 수 있나요?
예. 페인트, 지우기, 라인, 그리드 및 경로 작업은 모두 Unity 실행 취소를 지원합니다. Ctrl + Z 키로 되돌릴 수 있습니다. 또는 Erase 모드로 전환하고 Ctrl + Right Click 키로 오브젝트를 개별적으로 제거할 수 있습니다.
Physics Fall을 켜도 효과가 없음
프리팹에 콜라이더가 있는지 확인하세요. 없으면 Place By Collider [P] 를 켜서 물리 시스템과 상호 작용하도록 하세요. 시뮬레이션은 에디터에서 짧게 실행됩니다. 오브젝트가 원래 위치로 돌아오면 다른 스크립트가 Transform을 덮어쓰는지 확인하세요.
크기나 회전을 무작위화하면 GPU 배칭이 깨지나요?
아니요. Unity 6의 GPU Resident Drawer와 SRP Batcher는 인스턴스마다 서로 다른 변환 행렬을 처리합니다. 위치, 회전 또는 크기를 무작위화해도 드로우 콜 수에 부정적인 영향을 주지 않습니다.

지원, 문의 및 맞춤형 연동

기술 지원, 버그 신고, 에셋 설정 또는 기타 도움이 필요하면 문의 양식을 통해 이메일로 연락해 주세요. 패키지 관련 문제를 문의하는 가장 확실한 방법입니다.

이 양식으로 맞춤형 테크니컬 아트 작업도 문의할 수 있습니다. 외부 3D 모델을 DPT 시스템에 통합하거나 맞춤형 버텍스 데이터 패킹, 절차적 나뭇결 매핑, GPU 바람 시스템 또는 게임용 LOD 예산 최적화가 필요하다면 요구 사항과 일정에 대해 문의해 주세요.
