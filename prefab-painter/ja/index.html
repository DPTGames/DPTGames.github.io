DPT Games Prefab Painter

ランダムな位置・回転・スケールやオブジェクトごとの色の変化を使い、シーン内にプレハブを直接ペイントできます。必要な機能が揃っているので、導入後すぐに作業を始められます。

主な機能

  • URP対応。インスペクターのウィンドウ幅に合わせてレイアウトが変化
  • クリック前に確認できる実寸のホログラム型プレハブプレビュー
  • エディターのウィンドウ幅に応じて調整されるコンパクトなUI
  • 回転するホバープレビューとサムネイルグリッドを備えたプレハブパレット
  • ドラッグ＆ドロップでプレハブを追加。範囲選択とドラッグでの削除に対応
  • 保存可能なパレットプリセットでバイオーム用・小物用セットを即座に切り替え
  • ショートカットによるアイテム選択（Shift + 1–0 ／テンキー）と選択解除（Shift + D）。番号バッジを使ってペイント中でもプレハブを切り替え可能
  • 地形テクスチャ（スプラットマップ）によるフィルタリング。プレビューのリアルタイム除外とグループ別設定に対応
  • 配置レイヤー、親オブジェクト、スプラットマップをグループごとに設定可能
  • ペイント時にC#コンポーネントを自動追加
  • ペイント、スキャッター、ライン、グリッド、パス、計測モード
  • パスモードで複数グループを連続配置。既存セグメントも再計算して継ぎ目を調整
  • 配置後の回転調整による正確な位置合わせ
  • Smart Clearanceと切り替え可能なCheck Clearanceで重なりを制御
  • エディター内の物理シミュレーションで自然に落下・整列
  • 次の機能と連携： DPT_ShaderVariation 。追加のドローコールなしでオブジェクトごとの色変更が可能
  • UnityのUndo履歴に完全対応

はじめに

数ステップでペインターを開き、アセットの配置を始められます。

クイックスタート

  1. Unityのメニューバーから Tools → DPT Games → Prefab Painter を開きます。ウィンドウはドッキングとサイズ変更に対応しています。狭い場合はコントロールが縦に並び、広い場合は複数列で表示されます。
  2. 個々のプレハブを既存グループへドラッグして追加できます。フォルダー階層を自動整理するには、最上位フォルダーをパレット上部の Create Groups from Subfolders へドロップします。直下の子フォルダーごとに名前付きグループが作成され、さらに深いフォルダーの内容は最も近い上位グループへまとめられます。
  3. 地形や地面のレイヤーに合わせて Paintable Layer を設定します。
  4. 必要な場合のみ Parent Object を割り当てるか、 New をクリックして新規作成します。親オブジェクトの手動指定は必須ではありません。
  5. 緑色の START PAINTING ['] ボタンをクリックします。これでツールが有効になりますが、初期設定では通常のブラシペイントに Ctrl キーを押し続ける必要があります。
  6. シーン上で Ctrl + Left Click を押しながらドラッグするとプレハブをペイントできます。代わりに、ペイントボタンの下にある Require Ctrl to Paint をオフにすると、 Left Click + Drag だけでペイントできます。
元に戻す： ペイント、消去、ライン、グリッド、パスはすべてUnityのUndoに登録されます。 Ctrl + Z と Ctrl + Y を利用できます。

プレハブパレット

パレットでは配置対象のプレハブを管理します。複数グループ、保存できるプリセット、追加・削除の各種操作に対応しています。

フォルダーを自動グループ化： 親フォルダーを、パレットグループの上にある Create Groups from Subfolders 領域へドロップすると、直下の子フォルダーから自動的にグループが作成されます。たとえば Nature/Trees、 Nature/Rocks 、 Nature/Plants は3つのグループになります。さらに深い階層は対応する上位グループに含まれます。親フォルダー直下のプレハブは親フォルダー名のグループに入ります。同名のグループは再利用され、重複プレハブはスキップされます。フォルダーを 既存グループへドロップした場合は、すべてそのグループに追加されます。大量のフォルダーも段階的に読み込まれます。数字キーによる切り替えは最初の10グループのみで、追加グループはウィンドウから選択できます。
操作 説明
使用中のパレットファイルと「名前を付けて保存」 現在のパレットをプロジェクト内の再利用可能なアセットとして保存します。オブジェクトフィールドから別のパレットを読み込み、小物セットやバイオームテーマを切り替えられます。
サムネイルグリッド 読み込んだプレハブのアイコンを表示します。サムネイルにカーソルを合わせると、オブジェクトが自動回転する拡大高解像度プレビューが表示されます。右クリックするとプレハブを開く、バリアントを作成する、有効状態を切り替えるなどの操作ができます。
アイテムのショートカット選択 [Shift + 1–0] と全選択解除 [Shift + D] 単一グループがアクティブなとき、最初の10プレハブには番号バッジ（1–0）が表示されます。選択を切り替えるには Shift + [1–0] を押します（またはLine／Pathモードでは 1–0 を Ctrl + Alt 押しながら直接入力することもできます）。ラインやパスの編集中も切り替え可能で、テンキーにも対応しています。全選択を解除するには Shift + D を押すと作業を中断せず選択を解除できます。グループを変更しても選択内容は保持され、番号バッジは新しいグループに切り替わります。
出現ウェイト パレット内のプレハブを1つ以上選択すると 選択アイテム設定 パネルが表示されます。 Spawn Weight スライダーまたは入力欄で、他のプレハブに対する出現頻度を設定します。値2は値1のプレハブの2倍の頻度になります。サムネイルに表示される小さな w バッジは標準以外のウェイトが設定されている印です。ウェイトはパレットファイルに保存されます。
グループと個別設定 グループは + Group で追加できます。または親フォルダーを Create Groups from Subfoldersにドロップして自動作成できます。最初の10グループは 1–9 / 0 で切り替えます。それ以降のグループはエディター内で選択できます。どのグループも有効にしていない場合、全グループからペイントできます。グループごとにSpawn Layer、Paintable Layer、Parent Object、Terrain Splatmapを個別設定できます。
範囲選択 サムネイルグリッド上でドラッグすると複数のプレハブを選択できます。まとめて移動・削除するときに便利です。
シーンへドラッグ パレット内のプレハブをSceneビューへドラッグすると、1個ずつ手動配置できます。
削除エリアへドロップ 選択したプレハブをこの領域へドラッグすると、パレットから削除できます。

ペイント操作

パネル上部の Paint、 Erase、 Recolor、 Measure タブを選びます。Erase、Recolor、Measureのショートカットを同じモードで押すとPaintへ戻ります。緑色の大きなボタンでペイントを開始し、赤いボタンで停止します。 Start Paintingはツールを有効にするだけです。Require Ctrl to Paintをオフにしない限り、Ctrlキーは必要です。 オフにすると左クリックとドラッグだけでペイントできます。Altによる視点操作、Ctrl+Altのライン、Ctrl+Shiftのグリッド、パス編集はそれぞれ専用の操作を維持します。

配置モード

モード 使い方
ペイントモード 標準モードです。 Ctrl + Left Click を押しながらドラッグするとブラシ範囲内のサーフェスへ連続配置します。 Require Ctrl to Paint をオフにして左クリックとドラッグだけでもペイントできます。Scatterモードが有効な場合、概算生成数（~N）が表示されます。
スキャッターモード [O] 1回のストロークでブラシ全体に多数のプレハブをランダム配置します。広い範囲の草や岩など、密集した地表物の配置に適しています。 Oでオン／オフを切り替えます。
ラインモード キーを押しながら Ctrl + Alt + Drag 開始地点から直線状にプレハブを配置します。ラインは連続クリック間の接続位置を記憶し、角や複数セグメントでも余分な隙間や重なりなく端を揃えます。作業中にグループを切り替えて壁や門など異なる部品も接続できます。
グリッドモード キーを押しながら Ctrl + Shift + Drag 一定間隔のグリッドに沿ってプレハブを配置します。床タイル、箱、作物など規則的な配置に便利です。グリッドの間隔はブラシ半径と独立しており、ドラッグ中にグリッド範囲を調整できます。
パスペイント [G] 滑らかな曲線パスに沿ってプレハブを配置します。 G でパスモードに入り、 Ctrl + Left Click でノードを追加します。もう一度 G を押すか Enter で終了します。弦長による反復計算で実際の寸法を求め、急なカーブでも壁などの端を正確に繋ぎます。途中でグループを切り替えられ、各セグメントは割り当てられたプレハブを個別に管理します。既存ノードのハンドルをクリックして選択し、パレットのアイテムやグループを変更すると、そのセグメントを後から更新することもできます。
計測モード [Q / Shift+Q] シーン内の距離を確認するための計測ツールです。 Q でライン計測、 Shift + Q でグリッド計測を行います。別のモードへ切り替えても計測結果は ESC を押すまで画面に残ります。

ブラシ設定

Require Ctrl to Paint： 互換性のため初期状態ではオンです。オフにすると、ペイントが有効な間は左クリックとドラッグだけでペイント、消去、リカラーができます。シーンの通常操作時に誤配置を防ぎたい場合はオンのままにしてください。Ctrl+AltのラインとCtrl+Shiftのグリッドは常に使用可能です。右クリックによるカメラ操作は変わりません。

設定 説明
ライブプレハブプレビュー [F] 実際の配置位置、回転、スケールを確認できる1:1のホログラムプレビューをシーン内に表示します。 Fでオン／オフを切り替えます。
ペイント対象レイヤー このレイヤー上のサーフェスにのみプレハブを配置します。地形や地面メッシュと同じレイヤーを選んでください。異なる場合、レイキャストが通過して配置できません。
地形スプラットマップを使用 Unity Terrain上にペイントするとき、草、土、岩など特定のTerrain Layerと最小ブレンドウェイトで生成位置を制限します。土の道に草が出るなどの誤配置を防ぎます。全配置モードに適用され、リアルタイムプレビューの除外やグループ別設定にも対応します。
ブラシ形状 [C] ブラシ範囲を円形と四角形で切り替えます。 C で切り替えます。
ブラシ半径 [ [ / ] ] ブラシの範囲を調整します。 [ で縮小し、 ] で拡大します。
配置をランダム化 [U] オンにするとカーソルの中心ではなくブラシ半径内のランダムな位置に配置されます。ScatterだけでなくPaint、Line、Gridなどすべての配置モードに影響します。 Uで切り替えます。オフにしてもブラシ半径の設定は保持されます。
最小間隔 [M / Shift+M] オブジェクト間の最短距離を指定します。 M で増やし、 Shift+M で減らします。Smart Clearanceが有効な場合はオブジェクトの大きさも考慮されます（「変形と配置」を参照）。
生成間隔 [X / Shift+X] ドラッグ中の配置間隔（時間）を制御します。値が小さいほど高速に配置されます。 X で間隔を長くし、 Shift+X で短くします。
間隔をパス長に合わせる [S] Path Paintのときだけ表示されます。オンにするとパスを閉じるため間隔をわずかに伸縮します。道路など寸法が固定されたモジュール部品では、継ぎ目を防ぐためオフにしてください。
ブラシハンドルの色 シーンビューのブラシ円の色を変更します。地形と色が似ていて見づらいときに調整してください。

表示とバリエーション

DPTシェーダーパイプラインによるオブジェクトごとの見た目の変化です。追加のマテリアルを作らず、GPUバッチングを維持したまま多様性を加えられます。

設定 説明
明るさをランダム化 [B] 配置した各プレハブに対し DPT_ShaderVariation コンポーネントを使って明るさをランダムに変更します。同一アセットの反復による単調なライティングを和らげます。
色合いを適用 [V] プレハブに基本色と任意のHSV変化を適用します。DPTシェーダーを使う草木、岩、その他のアセットの色調に変化を付けられます。
シェーダー連携： DPTシェーダーはGPUのRenderer Shader User Value（RSUV）ストリームからインスタンスごとの変化を読み取ります。Unity 6のGPU Resident Drawerと互換性があり、変化によってドローコール数は増えません。標準URP Litの代替シェーダーが検出されたときのみColor Property Name欄を編集でき、その場合はMaterial Property Blockを使用します。

変形と配置

配置したプレハブの向き、スケール、名前、シーン階層での整理方法を設定します。

設定 説明
地面に揃える [N] 配置したオブジェクトの上方向を、接触面の法線に合わせます。斜面や起伏のある地形に便利です。
Y回転をランダム化 [Y] 各プレハブを垂直軸の周りにランダム回転させます。同じアセットを多数配置しても単調に見えにくくなります。
スケールをランダム化 [L] 指定した最小値と最大値の間でスケールをランダムに設定します。オフにすると固定スケールのスライダーが表示されます。
固定スケール Randomize Scaleがオフのときに表示されます。すべてのプレハブに同じスケール倍率を適用します。
積み重ねを許可 [K] オンにすると、既にペイントしたオブジェクトの上にも配置できます。岩に苔や小石を重ねる場合などに便利です。オフの場合は同じ親の下にあるペイント済みオブジェクト上への配置を防ぎます。
コライダー基準で配置 [P] ピボットではなくコライダーの境界下面を基準に配置します。中心からずれたピボットを持つオブジェクトが地面に埋まるのを防ぎます。コライダーがない場合は一時的なコライダーが生成されます。
Smart Clearance [I] オブジェクトの物理的な大きさを考慮して配置間隔を判定します。Min Spacingが小さくても重なりを防ぎ、Min Spacingを増やすとオブジェクト本来の大きさに追加の隙間を設けられます。
Check Clearance切り替え [D] オブジェクト同士の重なり確認をオン／オフにします。オフにすると検査を省略するため、多少重なってもよい大量のScatter配置では大幅に高速化できます。 Dで切り替えます。
物理落下 [H] 配置後に短いエディター内物理シミュレーションを実行し、重力で自然に着地させます。岩の山や凹凸のある地形などに便利です。落下開始位置のオフセット上限が引き上げられており、より高い位置から落とせます。
配置後に回転 [J] Scatter、Line、Grid、Pathで配置した後、マウス移動でグループを回転できる状態になります。配置済みオブジェクトの中心を軸に回転し、サーフェスへの接地もリアルタイムで調整されます。クリックで確定します。

階層、タグ、スクリプト

配置したオブジェクトの整理、タグ・レイヤーの上書き、ペイント時のコンポーネント追加を設定します。

設定 説明
親オブジェクトと名前 親オブジェクトの指定は任意です。指定するとすべてのプレハブがその子として配置されます。名前を入力して New を押すと新しい親を作れます。配置した子オブジェクトは選択した命名規則に従って連番になります。グループ別に異なる親を設定することもできます。
命名規則 配置されたオブジェクト名の接頭辞やパターンを設定します。たとえば Rock_001, Rock_002のように連番を付けられます。
タグとレイヤーの上書き プレハブ元の設定を無視して、配置オブジェクトに指定のタグとレイヤーを適用します。子オブジェクトにも適用するか選択でき、グループごとの上書きにも対応します。
スクリプトコンポーネントの自動追加 プレハブバリアントを作成せず、ペイントしたプレハブに任意のC#コンポーネントを自動追加できます。
  • Root ：生成されたルートオブジェクトに追加します。
  • Named Child ：名前が一致する子オブジェクトに追加します（大文字・小文字を区別）。
  • Skip If Already Exists ：既にあるコンポーネントの重複追加を防ぎます。

テクスチャチャンネルパッカー

DPTシェーダーは、メタリック、オクルージョン、ディテール、スムースネスを1枚にまとめたパックテクスチャを使用します。内蔵パッカーは Tools → DPT Games → Texture Channel Packerから起動できます。

  1. 元のテクスチャを次のチャンネルに割り当てます。
    • 赤： メタリック
    • 緑： オクルージョン
    • 青： ディテール／マスク
    • アルファ： スムースネス
  2. チャンネルごとのオプションを設定します。
    • Invert： 値を反転します（1.0 - value）。ラフネスマップからスムースネスマップへ変換する場合に使います。
    • Convert Brightness： RGBの平均輝度（(R + G + B) / 3）からグレースケール値を算出します。アルファのない24ビットRGBテクスチャを使う場合に有効にしてください。
  3. スロットを空欄にした場合、 Empty Value スライダーでそのチャンネルの固定値を指定できます。
  4. 最後に Pack and Save Texture をクリックしてパックテクスチャを生成します。

必要なUnityインポート設定

パック前に、すべてのソーステクスチャについてUnityインスペクターで次を確認してください。

  • Read/Write：有効 ：パッカーがピクセルを読み取るために必要です。無効だとエラーになります。
  • sRGB（Color Texture）：無効 ：これらは色ではなくデータテクスチャです。オンだとメタリック、ラフネス、AO値が変わってしまいます。
  • Alpha Is Transparency：有効 ：スムースネスチャンネルが0〜1の範囲で正しく読み取られるようにします。
明るさへの変換： 内蔵の Convert Brightness オプションは、24ビットRGBマップからスカラー値をエディター内で生成します。外部ツールは不要です。

トラブルシューティング

ペイントしてもプレハブが配置されない
最も多い原因はレイヤーの不一致です。ペインターはPaintable Layerに指定されたレイヤーのサーフェスにのみ配置します。地形／地面メッシュとペインターのPaintable Layerが一致するか確認してください。また、ペイントが有効でボタンが赤い Stop Paintingになっているか確認します。
Use Terrain Splatmapsをオンにすると地形上に配置されない
選択したTerrain Layerが配置したいテクスチャ（例：Layer 0の草）と一致していて、ブラシ位置のウェイトが Min Weight 以上か確認してください。境界のブレンドが薄い場合はMin Weightを0.2〜0.3などに下げると移行部分にも配置できる場合があります。
オブジェクトが重なったり、互いにめり込む
まず Smart Clearance [I] を有効にし、 Check Clearance [D] もオンになっているか確認します。オブジェクトの大きさを考慮して安全な間隔を確保します。追加の隙間が必要な場合は Min Spacingを上げます。間隔のチェックは同じ親にある子オブジェクト同士で行われ、別の親に属するオブジェクト間ではチェックされません。
オブジェクトが塔のように積み重なる
意図的に重ねたい場合を除き、 Allow Stacking [K] をオフにしてください。オフにすると、同じ親にある以前ペイントしたオブジェクトの上には配置しません。
すべて同じ見た目で色の変化がない
まず Randomize Brightness [B] または Apply Color Tint [V] が有効か確認してください。プレハブがDPTシェーダーを使用しているかも確認します。標準URP LitシェーダーはインスタンスごとのRSUV変化に対応していません。
誤った場所にペイントした。元に戻せる？
はい。ペイント、消去、ライン、グリッド、パスはUnityのUndoに対応しています。 Ctrl + Z で取り消せます。またEraseモードに切り替えて Ctrl + Right Click でオブジェクトを個別に削除することもできます。
Physics Fallを有効にしても効果がない
プレハブにコライダーがあるか確認してください。ない場合は Place By Collider [P] を有効にすると物理システムと連携できるようになります。シミュレーションはエディター内で短時間行われます。元の位置に戻る場合は、スクリプトがTransformを上書きしていないか確認してください。
スケールや回転のランダム化でGPUバッチングは壊れる？
いいえ。Unity 6のGPU Resident DrawerとSRP Batcherは、インスタンスごとに異なるTransform行列を扱えます。位置、回転、スケールのランダム化によってドローコール数が増えることはありません。
