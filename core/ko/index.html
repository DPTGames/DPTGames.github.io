DPT Games VCCORE 머티리얼 시스템

DPT 에셋 패키지가 공유하는 마스터 셰이더와 머티리얼을 사용해 GPU Resident Drawer 및 SRP Batcher 같은 최신 Unity 렌더링 기능과 호환되며 높은 성능을 유지합니다.

하나의 머티리얼을 공유하는 설계 철학

수십 개의 개별 머티리얼로 배칭을 깨고 드로우 콜을 늘리는 대신 DPT 에셋은 하나의 머티리얼을 공유하도록 설계되었습니다. Inspector는 현재 사용 중인 워크플로에 필요한 속성만 표시합니다.

중요: 런타임 비용은 머티리얼에서 실제로 활성화되어 사용되는 기능에 따라 결정됩니다. 에셋이 특정 기능에 유효한 데이터를 제공하지 않는 등 해당 기능을 사용하지 않으면 셰이더가 그 처리 경로를 건너뛰므로 그 시스템으로 인한 런타임 GPU 비용이 발생하지 않습니다.

여러 패키지 혼합과 권장 사항

Harvestable Nature와 Interactive Props처럼 여러 DPT 패키지를 같은 씬에서 사용하는 경우 모든 에셋에 정확히 동일한 Material 에셋을 할당하면 배칭 성능을 극대화할 수 있습니다.

패키지를 함께 사용할 때 중요한 설정:

성능과 배칭 효율을 위해 모든 에셋이 단일 M_DPT_VCCORE 마스터 머티리얼을 공유하는 것을 강력하게 권장합니다.

셰이더는 동적 분기와 키워드 컴파일을 사용하므로 Normal Map 배열이나 Procedural Details를 사용하지 않는 일반 에셋도 이러한 기능을 사용하는 복잡한 에셋과 같은 머티리얼을 공유할 수 있습니다. 사용하지 않는 경로는 최소의 런타임 비용으로 건너뜁니다.

상황에 따라 바뀌는 Inspector UI

VCCORE Inspector는 현재 설정에 맞춰 불필요한 필드를 숨깁니다.

  • Workflow Setup: Use Vertex Colors를 켜면 셰이더가 메시 데이터를 읽는 방식으로 전환되므로 일반적인 Base Color와 Metallic/AO 텍스처 슬롯을 자동으로 숨깁니다.
  • 종속 속성: Use Normal Texture 또는 절차적 디테일 등의 고급 옵션은 관련 토글을 켰을 때만 강도 슬라이더와 텍스처 슬롯을 표시합니다.
Use Vertex Colors는 텍스처만 제어하는 옵션이 아닙니다:

Use Vertex Colors를 끄면 텍스처 슬롯뿐 아니라 Emission System, Wind System, Procedural Details 섹션도 숨겨집니다. 이러한 기능은 버텍스 컬러 파이프라인에 의존하므로 패키지가 설치되어 있어도 일반 텍스처 워크플로에서는 표시되지 않습니다. 다시 켜면 사용할 수 있습니다. Stylized Lighting과 Metallic/Non-Metallic Tint 컨트롤은 이 설정의 영향을 받지 않습니다.

생태계 감지와 적응형 UI

마스터 머티리얼 Inspector의 Ecosystem Detection System은 현재 프로젝트에 설치된 DPT 패키지를 자동으로 확인합니다. 설치하지 않은 패키지의 기능을 표시하지 않고 프로젝트에 맞게 구성을 변경합니다.

동작 방식

각 DPT 패키지에는 고유한 시그니처 파일이 포함됩니다. 패키지를 로드하거나 가져올 때 에디터가 가벼운 프로젝트 스캔을 한 번 실행해 사용할 수 있는 기능을 갱신합니다.

  • 맞춤 작업 공간: Vegetation Systems, Procedural Details, Emission, DPT Package Normals 등의 고급 속성은 해당 기능의 시그니처가 있는 패키지를 설치한 경우에만 표시됩니다.
  • 기능 확장: 새 DPT 패키지를 가져오면 시그니처가 감지되고 기존 설정을 비활성화하거나 초기화하지 않은 채 관련 필드가 자동으로 나타납니다.
  • 독립적인 Core 업데이트: 기능 판단이 시그니처를 기반으로 하기 때문에 기존 테마별 에셋 확장팩을 수정하거나 다시 다운로드하지 않고 Core 폴더를 업데이트할 수 있습니다.
수동 설정 불필요:

검색은 Unity 컴파일 과정에서 자동으로 수행됩니다. 별도의 시리얼 키, 활성화 패널, 프리프로세서 지시문 또는 복잡한 스크립트 설정 배열이 필요하지 않습니다.

절차적 디테일(Procedural Details)

Use Procedural Details를 켜면 메시의 버텍스 데이터를 기반으로 미세한 표면 디테일을 생성하는 컨트롤이 나타납니다. 에셋마다 메모리를 많이 사용하는 텍스처를 할당하는 대신 GPU에서 수학적으로 디테일을 계산합니다.

Rock, Leather, Bark 등 사용할 수 있는 기능은 설치된 DPT 패키지에 따라 다르지만 슬라이더의 기본 동작은 같습니다.

  • Strength: 생성된 노멀의 강도입니다. 값을 높이면 조명 아래에서 표면의 돌출부와 홈이 더 깊고 강하게 보입니다.
  • Width: 절차적 패턴의 스케일을 조절합니다. 주의: Width 값을 높이면 타일링 빈도가 증가해 무늬가 더 작고 촘촘하게 보입니다.
  • Value(지원 기능에 한함): 생성된 디테일의 기본 색상 대비를 조절합니다. 원본 색상에 비해 표면을 밝게 하거나 어둡게 만들 수 있습니다.

Procedural Detail Array

SRP Batcher 및 GPU Resident Drawer와의 호환성을 극대화하기 위해 Bark, Leather, Rock, 금속 결함 등의 절차적 표면 디테일은 최적화된 단일 Texture2D Array에 담깁니다.

이 배열은 모든 DPT 패키지에서 공유합니다. 마스터 셰이더는 버텍스 컬러의 Alpha 채널을 사용해 메시마다 올바른 텍스처 슬라이스를 선택하므로 머티리얼 변경이나 추가 드로우 콜이 필요하지 않습니다.

  • 설정 불필요: 배열이 미리 구성되어 있습니다. 머티리얼의 Use Procedural Details를 켜면 알맞은 노멀과 디테일이 즉시 적용됩니다.
  • 메모리 효율: 배열에 들어 있는 모든 디테일 텍스처는 최적화된 512×512 해상도입니다. 반복되는 미세 패턴의 선명함을 유지하며 VRAM 사용량을 줄입니다.
  • 동적 분기: 메시가 절차적 디테일을 사용하지 않거나 관련 강도 값이 0이면 셰이더는 배열 샘플링을 건너뛰어 GPU 부담을 줄입니다.
모바일 및 저메모리 프로젝트:

엄격한 모바일 또는 VR 메모리 예산을 위해 Core 폴더에 256×256 배열 변형도 포함되어 있습니다. Material Inspector의 Procedural Details 텍스처 슬롯에서 교체할 수 있습니다.

Wood Grain Value Map:

노멀 배열 외에도 Procedural Wood Grain의 기본 색상 값을 조절하는 전용 패킹 텍스처 하나가 있습니다. Wood 기능이 활성화되면 디테일 배열과 함께 자동으로 사용됩니다.

Fur Detail Value:

Fur 디테일은 다른 디테일 텍스처와 달리 Fur Detail Value 슬라이더를 통해 기본 색상만 변경합니다.

스타일라이즈드 조명과 그림자 형태

VCCORE에는 선택적으로 활성화할 수 있는 Stylized Lighting 모드가 있습니다. 기본 PBR의 부드러운 조명 감소를 원하는 형태로 연출할 수 있는 명암 경계로 바꾸고 그림자 색상과 어두운 정도를 독립적으로 설정합니다. 끄면 일반 PBR과 동일하게 작동하며 이 시스템으로 인한 런타임 비용이 없습니다.

Shadow Terminator 및 Light Terminator(범위: 0.0~1.0)

표면에서 빛을 받는 영역과 그림자 영역이 전환되는 위치를 정의합니다.

  • 0.0: 완전히 밝은 쪽으로 경계가 이동합니다.
  • 1.0: 완전히 어두운 그림자 쪽으로 경계가 이동합니다.

두 Terminator 사이의 간격을 넓히면 일반적인 Lambert 셰이딩과 비슷하게 전환이 넓고 부드러워집니다. 간격을 좁히면 경계가 더 선명해지고 두 값이 만나면 명확한 셀 셰이딩 경계선이 생깁니다.

기본값:

Shadow Terminator는 0.3, Light Terminator는 0.5로 대비가 강한 비교적 날카로운 경계를 만듭니다. Shadow Tint는 검정색이고 Shadow Strength는 1.0이므로 Stylized Lighting을 켜면 바로 효과를 볼 수 있습니다.

Terminator 값은 서로 교차하지 않습니다:

Shadow Terminator와 Light Terminator는 클램프 처리되어 한 값이 다른 값을 넘어가지 않습니다. 다른 쪽을 지나가도록 드래그하면 두 번째 값도 함께 이동하여 순서가 유지됩니다.

내부적으로는 표면 노멀과 광원 방향의 내적을 원래의 -1…1 범위에서 0…1로 다시 매핑한 half-Lambert 값으로 전환을 계산합니다. 0은 광원 반대쪽을 향하는 면, 1은 광원을 정면으로 향하는 면입니다. 두 Terminator는 이 값의 하한과 상한을 정하므로 0과 1에 가깝게 벌리면 부드러운 전환이, 좁히면 선명한 전환이 만들어집니다.

Light Normal Smoothness(범위: 0.0~1.0)

세밀한 노멀 맵이 있는 로우폴리 메시에서는 날카로운 명암 경계가 폴리곤 경계에서 계단 모양으로 보일 수 있습니다. Light Normal Smoothness는 조명 내적 계산에 사용하는 노멀을 디테일 노멀 맵과 깨끗한 버텍스 노멀 사이에서 부드럽게 섞습니다.

정반사와 직접광 하이라이트에는 노멀 맵의 미세한 범프 디테일을 그대로 유지하면서 거친 그림자 경계를 개선합니다.

Shadow Strength(범위: 0.0~1.0)

그림자 영역을 얼마나 어둡게 하고 색상을 입힐지 결정합니다.

  • 0.0: Shadow Tint 또는 Terminator 값과 관계없이 그림자 영역이 바뀌지 않고 흰색으로 유지됩니다.
  • 1.0: 그림자 영역이 완전히 어두워지며 설정한 Shadow Tint 색상이 최대 강도로 적용됩니다.
Shadow Strength가 Terminator의 가시성을 제어합니다:

Shadow Strength가 0.0이면 그림자 형태가 계산되더라도 효과가 흰색으로 처리됩니다. Terminator 설정을 변경해도 눈에 띄지 않으므로 효과를 확인하려면 0보다 높게 설정하세요.

Shadow Tint

표면의 그림자 쪽에 적용되는 색상을 설정합니다. Shadow Strength에 따라 혼합된 뒤 최종 출력 전에 Base Color에 곱해집니다. 추가 조명이나 후처리 없이 따뜻한 조명에 차가운 푸른 그림자를 조합하는 등의 연출이 가능합니다.

Shadow Rim Lighting(반사광 및 가장자리 광선)

VCCORE에는 Emission에서 직접 계산하는 그림자측 환경 반사광과 림 라이팅이 통합되어 있습니다. 직접광 감쇠에 의해 어두워지지 않고, 그림자쪽 실루엣에 시원한 색의 테두리나 역광 같은 효과를 줄 수 있습니다.

  • Shadow Rim Color (HDR): 그림자측 환경광의 독립적인 HDR 색상입니다.
  • Shadow Rim Sharpness: 테두리 하이라이트의 날카로움입니다. 높을수록 매우 얇은 선이, 낮을수록 넓고 부드러운 빛이 나타납니다.
  • Shadow Rim Strength: 반사광 밝기를 제어하는 전체 강도 값입니다.
표면 특성 반영과 캐비티 마스킹:

광택이 있는 금속 표면은 선명한 림을, 무광 표면은 부드러운 반사광을 만듭니다. 이중 임계값 AO 마스킹(Cavity Killer)은 바깥 실루엣을 유지하면서 소켓이나 파이프 내부 같은 깊은 빈 공간을 검게 유지합니다.

실시간 투사 그림자 제어(Cast Shadow Min / Max)

자체 명암 경계와 별도로 나뭇잎이나 캐릭터가 오브젝트 위에 드리우는 URP 실시간 그림자의 임계값과 부드러움을 제어합니다.

  • Cast Shadow Min: 들어오는 실시간 그림자가 나타나기 시작하는 임계값입니다.
  • Cast Shadow Max: 실시간 그림자가 최대 불투명도에 이르는 임계값입니다.

Min과 Max 간격을 넓히면 부드러운 그림자, 좁히면 자체 셰이딩과 맞는 선명한 셀 스타일 그림자가 됩니다. 높은 값에서 발생할 수 있는 그림자 맵 바이어스 깜빡임을 줄이도록 안전한 클램프가 포함되어 있습니다.

씬 그림자 관련 설정(URP 전용)

Shadow Terminator, Light Terminator, Shadow Tint 및 Shadow Strength는 머티리얼 내부의 자체 셰이딩 효과로 Unity의 실시간 투사 그림자 및 씬 색상 보정과는 별개입니다. 필요에 따라 URP 에셋과 Volume Profile의 그림자 설정을 맞춰 조정하세요.

Emission System

VCCORE에는 최적화된 발광 시스템이 포함됩니다. Inspector에서 Enable Emission을 켜면 메시에서 발광하도록 지정한 영역의 색상과 강도를 조절할 수 있습니다.

Emission 패키지 시그니처 필요:

Emission System은 Ecosystem Detection System에 속합니다. Emission 시그니처 파일을 포함한 DPT 패키지가 설치되어 있지 않으면 Inspector에 섹션이 나타나지 않습니다. 또한 버텍스 컬러 기반 기능이므로 Use Vertex Colors도 켜야 합니다.

전역 발광과 인스턴스별 발광

하나의 머티리얼을 공유하면서 전역 설정과 오브젝트별 설정을 모두 지원합니다.

  • Global Material Emission: Material Inspector의 Emissive Color와 기본 Emission Strength는 같은 머티리얼을 사용하는 씬의 모든 오브젝트에 공통으로 적용됩니다.
  • Per-Instance Emission: DPT_ShaderVariation의 Instance Color 및 Alpha 채널은 전역 발광값에 곱해져 머티리얼을 복제하지 않고 개별 오브젝트의 발광 색상과 강도를 조절합니다.

Metallic Emissive Color

기본 Base Emissive Color와 별도로 Metallic Emissive Color 속성이 있습니다. 같은 메시의 금속 부분(철 룬, 구리 파이프, 강철 통풍구 등)의 발광 색조를 비금속 표면과 독립적으로 설정할 수 있습니다.

금속 오브젝트의 예외:

정반사 처리 방식 때문에 금속 영역의 발광 색상은 스크립트를 이용해 인스턴스별로 변경할 수 없습니다. 금속 색상은 Material Inspector의 Metallic Emissive Color에서 전역으로 지정해야 합니다. 다만 DPT_ShaderVariation의 Alpha 채널을 사용해 금속 영역의 발광 강도는 인스턴스별로 조절할 수 있습니다.

정확한 색상 변경을 위한 흰색 기본값:

같은 머티리얼을 사용하면서 빨간 포션과 파란 포션의 발광 색을 다르게 만들려면 Emissive Color를 순수 흰색으로 설정하세요. 색상을 곱하는 방식이므로 스크립트의 색상이 최종 발광 색조를 결정합니다. 단, 이 방법은 비금속 영역에만 적용됩니다. 금속 발광 색상은 흰색 기본값을 사용해도 인스턴스별로 변경할 수 없습니다.

고급 설정: 본체와 발광에 다른 색 사용:

DPT_ShaderVariation은 MeshRenderer마다 한 색상을 전달하므로 본체 틴트와 발광이 동일한 색조를 공유합니다. 진한 파란색 검에 주황색 룬을 빛나게 하려면 룬을 별도의 자식 메시로 분리하고 본체와 룬에 각각 Variation 컴포넌트를 사용하세요. 같은 마스터 머티리얼로 배칭을 유지할 수 있습니다.

Wind System과 바람 움직임

VCCORE의 경량 절차적 바람 시스템은 GPU 버텍스 변위를 사용합니다. Wind Waving을 켜면 자연스러운 파도 모양의 움직임과 방향성 흔들림을 버텍스 셰이더에서 계산하며 CPU 본 스키닝이나 버텍스 물리 연산이 필요하지 않습니다.

Wind 패키지 시그니처 필요:

Wind System은 Ecosystem Detection System에 의해 표시 여부가 결정됩니다. Harvestable Nature나 Foliage 팩처럼 Wind 시그니처 파일이 포함된 DPT 패키지를 설치해야 합니다. Use Vertex Colors도 활성화되어야 합니다.

Wind Strength

버텍스 변위의 전체 속도와 진폭을 조절합니다. 0.0으로 설정하면 바람 처리 경로는 활성화된 상태로 움직임만 완전히 멈춥니다.

360° 방향 컨트롤(Compass 및 Pitch)

복잡한 3D 벡터 좌표 대신 두 개의 직관적인 슬라이더로 바람 방향을 지정합니다.

  • Compass Heading(0°~359°): 수평 흔들림과 월드에 전파되는 바람 파동의 방향을 제어합니다.
    • 0°: 동쪽(+X)
    • 90°: 북쪽(+Z)
    • 180°: 서쪽(−X)
    • 270°: 남쪽(−Z)
  • Vertical Pitch(−45°~+45°): 바람의 수직 기울기를 조절합니다. 0°는 지면과 평행한 바람, 양수는 상승기류, 음수는 경사면을 따라 내려가는 기류를 뜻합니다.
하드웨어 친화적인 정규화 단위 벡터:

Editor GUI가 Compass Heading과 Pitch 값을 정규화된 3D 단위 벡터로 변환합니다. 모든 방향에서 일정한 변위 속도와 파동 빈도를 유지하고 불필요한 GPU ALU 연산 및 0으로 나누는 문제를 줄입니다.

Color Variation

인스턴스별 색상과 밝기는 DPT_ShaderVariation 컴포넌트가 처리합니다. 공유 머티리얼을 복제하거나 수정하지 않고 Unity의 GPU 인스턴싱 버퍼로 데이터를 직접 전달합니다.

  • DPT Prefab Painter 사용: Randomize Brightness를 켜면 컴포넌트가 자동으로 추가되고 설정되어 수동 작업이 필요하지 않습니다.
  • 수동 배치: 씬의 오브젝트 또는 루트 부모에 DPT_ShaderVariation을 추가하고 Inspector의 Instance Color를 조절합니다.
하나의 공유 머티리얼 유지:

변형 데이터가 GPU 인스턴스 버퍼로 직접 전달되므로 서로 다른 색상의 오브젝트가 많아도 공유 머티리얼은 복제되거나 변경되지 않습니다. 배칭과 GPU Resident Drawer 호환성이 유지됩니다.

금속 및 비금속 틴트 제어

마스터 머티리얼에는 금속 및 비금속 영역용 개별 토글과 강도 슬라이더가 있어 DPT_ShaderVariation의 인스턴스 색상을 재질마다 제어할 수 있습니다.

  • 스크립트 의존성: 토글은 셰이더 처리를 켜고 끄는 역할만 합니다. RSUV를 통해 색상을 전달하는 DPT_ShaderVariation 컴포넌트가 없다면 시각적 변화가 없습니다.
  • Non-Metallic Tint: 확산 반사가 있는 비금속 영역에 틴트를 적용할지 결정합니다. 끄면 해당 영역은 인스턴스 틴트의 영향을 받지 않습니다.
  • Metallic Tint: 금속 영역에 틴트를 적용할지 결정합니다. 끄면 금속 영역의 원래 물리 기반 정반사 특성이 유지됩니다.
최적화된 키워드 구조:

금속 및 비금속 틴트를 위한 중복 셰이더 컴파일 키워드를 제거하고 빠른 동적 분기로 처리합니다. 틴트 기능을 유지하면서 셰이더 배리언트 수와 프로젝트 빌드 시간을 줄입니다.

Tint Strength 슬라이더(범위: −2.0~1.0)

두 강도 슬라이더 모두 비대칭 범위를 사용하며 단순한 혼합을 넘어 양방향으로 제어합니다.

  • 0.0: 해당 표면 종류에 틴트를 적용하지 않습니다.
  • 1.0: 인스턴스 색상과 정확히 일치하는 최대 틴트 강도입니다.
  • 음수(−2.0~0.0): 해당 재질의 틴트 방향을 반전시켜 같은 메시의 영역 사이에 대비를 만들 수 있습니다. 예를 들어 상자의 나무 부분을 어둡게 하면서 금속 장식을 더 밝게 보이게 할 수 있습니다.

밝기 범위와 HDR 틴트 시스템을 포함한 DPT_ShaderVariation의 자세한 기술 설명은 Shader Variation 가이드를 참고하세요.
