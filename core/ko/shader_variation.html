DPT_ShaderVariation 컴포넌트

DPT_ShaderVariation 컴포넌트는 씬 에셋의 인스턴스별 색상을 관리합니다. DPT Prefab Painter로 배치하면 자동으로 작동하며, 커스텀 GameObject, 빈 루트 부모 또는 모듈식 프리팹에 수동으로 연결해 적은 비용으로 색상을 조절할 수도 있습니다.

핵심 아키텍처

선택한 색상을 읽고 RGB 채널을 정규화해 24비트 색상 정밀도를 유지하면서 나머지 8비트를 독립적인 밝기 배율로 인코딩합니다. 이 벡터 패킹 방식은 색상 왜곡 없이 최대 2.0배의 HDR 밝기를 지원합니다. 결과는 부호 없는 단일 32비트 정수(uint)로 압축되고 Renderer Shader User Value(RSUV) 스트림을 통해 GPU 인스턴싱 버퍼로 전달됩니다.

색상 변형은 SetShaderUserValue를 통해 GPU 인스턴스에서 처리되므로 원본 공유 머티리얼을 복제하거나 수정하지 않습니다. 색상이 서로 다른 수천 개의 오브젝트도 통합된 하드웨어 드로우 콜로 처리할 수 있어 불필요한 VRAM 사용을 방지합니다.

컴포넌트 Inspector 필드

Hierarchy에서 DPT_ShaderVariation 컴포넌트가 있는 오브젝트를 선택하고 다음 항목을 설정하세요.

필드설명
Instance Color오브젝트의 GPU 스트림으로 보내는 색상 틴트 및 밝기 배율입니다. 흰색(1,1,1,1)은 기본 중립값입니다. 낮은 값은 오브젝트를 어둡게 하고 색상 크기가 큰 값은 HDR 밝기로 높입니다. 발광 오브젝트에서는 Alpha 채널이 발광 강도를 직접 제어합니다. 속성을 통해 직접 설정하거나 필드 변경 추적으로 갱신할 수 있습니다.
Color Property Name표준 머티리얼로 대체 처리할 때 사용하는 셰이더 변수 이름입니다. 표준 URP 셰이더는 예를 들어 _BaseColor를 사용합니다. 커스텀 DPT 머티리얼이 감지되면 이 필드는 잠겨서 편집할 수 없습니다. DPT 외부 머티리얼용 설정입니다.
Update Every Frame성능 주의: 매 프레임 Update()를 실행해 동적 색상 변경을 추적합니다. 피해 효과 깜빡임이나 맥동하는 발광처럼 게임 중 색상이 변할 때만 켜세요. 일반 소품은 CPU 오버헤드를 없애기 위해 끄는 것을 권장합니다. 이전 이름은 Is Animated입니다.
빈 루트 부모에도 컴포넌트를 연결할 수 있습니다. 필터링된 계층 탐색을 통해 LOD0, LOD1, 중첩된 파괴 잔해 메시 등에 색상을 함께 적용하므로 파괴 가능한 오브젝트 시스템과도 호환됩니다.

고급 아키텍처 기능

1. 동적 색상 업데이트(Update Every Frame)

Unity Animator가 스크립트 필드를 애니메이션하거나 외부 스크립트가 값을 바꾸면 직렬화된 내부 필드(instanceColor)가 직접 수정됩니다. 일반적인 C# 공개 속성 세터(InstanceColor)를 거치지 않으므로 스크립트가 GPU에 갱신을 보내야 한다는 사실을 감지하기 어렵습니다.

이 문제를 효율적으로 해결하기 위해 Update Every Frame을 켜면 내부 추적 루프가 활성화됩니다.

void Update()
{
    if (instanceColor != lastInstanceColor)
    {
        lastInstanceColor = instanceColor;
        ApplyVariation();
    }
}
  • 동적 소품(대포 도화선, 피해 시 깜빡임 등): Update Every Frame을 켜면 Animator나 외부 스크립트가 변경한 값을 해당 프레임에 감지해 GPU에 전달합니다. Alpha 채널 애니메이션으로 발광을 맥동시키거나 천천히 사라지게 하는 효과도 가능합니다.
  • 일반 배경 오브젝트(통, 바위 등): 옵션을 끄면 초기화할 때 한 번만 데이터를 전송하고 스크립트 자체를 비활성화(enabled = false)합니다. 수천 개 소품에서 발생할 수 있는 Unity와 관리 코드 사이의 라이프사이클 호출 비용을 없애 CPU 프레임 부담을 방지합니다.

2. 할당 없는 초기화

대량의 색상 변형 소품을 런타임에서 생성할 때 가비지 컬렉션(GC) 급증을 막기 위해 초기화 중 배열 할당을 피합니다. 미리 확보한 비직렬화 제네릭 리스트(tempRendererList 및 filteredRenderers)를 재사용하여 계층을 검색하고 Renderer 캐시를 만듭니다.

3. 중첩 계층 보호

불이 붙은 도화선이 여러 단계 아래의 자식인 공성 무기처럼 복잡한 프리팹에서는 GetComponentsInChildren<Renderer>()를 통한 일반 재귀 검색이 자식 Renderer까지 부모에게 할당해 고유한 색상을 덮어쓸 수 있습니다.

DPT_ShaderVariation은 캐시를 만들 때 계층의 가장 가까운 관리자 컴포넌트를 검사하는 필터를 사용합니다.

for (int i = 0; i < tempRendererList.Count; i++)
{
    Renderer rend = tempRendererList[i];
    if (rend != null && rend.GetComponentInParent<DPT_ShaderVariation>() == this)
    {
        filteredRenderers.Add(rend);
    }
}

부모가 자식 메시를 수집할 때 자신이 그 Renderer에서 가장 가까운 Variation 관리자인지 확인합니다. 도화선 같은 자식에 별도의 DPT_ShaderVariation이 있으면 부모는 해당 Renderer를 건드리지 않습니다. 메인 구조물의 색을 관리하면서 하위 부품의 색상을 독립적으로 제어할 수 있습니다.

성능 및 최적화 호환성

현대적인 렌더링 구성과의 호환성은 다음과 같습니다.

렌더링 경로호환성참고 사항
GPU Resident Drawer(Unity 6+)VCCore 필요DPT VCCore 머티리얼 또는 RSUV를 지원하는 커스텀 셰이더에서만 완전히 지원됩니다. URP Default Lit 같은 표준 머티리얼은 Material Property Block이 필요하며 해당 오브젝트는 GPU Resident Drawer에서 제외됩니다.
SRP Batcher(URP / HDRP)지원공유 셰이더 키워드에 기반한 CPU 드로우 콜 최적화가 유지됩니다.
GPU Instancing지원모든 인스턴스가 동일한 머티리얼 파일을 사용하므로 기존 GPU 인스턴싱이 유지됩니다.
Static Batching미지원GPU 기반 워크플로와 호환되지 않습니다. 배치한 오브젝트에 Batching Static을 지정하지 마세요. 메시 병합 때문에 GPU Resident Drawer가 개별 소품을 인스턴싱할 수 없습니다.

MaterialPropertyBlock 동적 폴백 경로

최적화된 VCCore 머티리얼 대신 URP Default Lit 같은 Unity 기본 머티리얼을 사용하면 자동으로 폴백이 실행됩니다. Color Property Name 필드를 편집할 수 있게 하고 _BaseColor 또는 _Color 같은 색상 속성을 감지해 MaterialPropertyBlock(MPB)을 통해 인스턴스별 색상을 전달합니다.

중요한 파이프라인 경고: MPB 폴백은 머티리얼 복제를 피하므로 메모리 측면에서는 유리하지만, Material Property Block은 GPU Resident Drawer와 SRP Batcher를 모두 비활성화합니다. Unity 6 이상에서 대규모 인스턴싱 게임을 만든다면 제공되는 VCCore 머티리얼을 사용해 빠른 렌더링 경로를 유지하세요.

문제 해결

Inspector에서 색상이 바뀌는데 메시에 반영되지 않습니다

메시에 Batching Static이 지정되지 않았는지 확인하세요. 또한 셰이더가 unity_RendererUserValue 채널을 지원하는지, 표준 머티리얼 폴백을 사용한다면 Color Property Name에 입력한 이름과 일치하는지 확인하세요.

스크립트나 Animator가 색을 바꿔도 화면에 변화가 없습니다

Inspector에서 Update Every Frame이 활성화되어 있는지 확인하세요. 끄면 초기화 이후 컴포넌트 자체가 비활성화되어 애니메이션이나 외부 스크립트의 내부 필드 변경을 추적하지 않습니다.

부모 스크립트가 하위 오브젝트의 색상 애니메이션을 덮어씁니다

하위 오브젝트에 자체 DPT_ShaderVariation 컴포넌트를 추가하세요. 중첩 계층 보호는 하위 오브젝트가 자신의 관리 컴포넌트를 찾을 수 있어야 작동합니다.
