VCCORE シェーダーでカスタムモデルとテクスチャを使用する

DPT の Core シェーダーフレームワークを使って、独自または外部の 2D テクスチャを対象メッシュに適用するための技術ガイドです。

概要

DPT フレームワークは、テクスチャを使わない高度に最適化された頂点データ方式を中心に設計されていますが、マスターシェーダーは通常の 2D テクスチャマップにも対応しています。このガイドでは、テクスチャ方式を正しく使用するためのマテリアル割り当て、スロット間の依存関係、ワークフロー設定を説明します。

マテリアル設定の手順

1. アセットの割り当て

プロジェクト内の M_DPT_VCCORE という名前の Core マスターマテリアルを見つけ、対象 GameObject の Mesh Renderer に直接割り当てます。

2. テクスチャマップの割り当て

Material Inspector の指定スロットに、以下の規則でテクスチャを割り当てます。

シェーダーのテクスチャスロット必要な入力アセットと設定
Base Color主となる拡散反射／アルベドマップを割り当てます。Prefab Painter の数学的な色乗算を綺麗に反映させるため、彩度を抑えた、またはグレースケールのベースマップを推奨します。
Metallic/AO/Smoothness PackedEditor の Texture Channel Packer ツールで生成したパック済みテクスチャを割り当てます。フラグメントシェーダーは R、G、A チャンネルを個別に取り出してサンプリングします。
Use Normal Texture（トグル）このチェックボックスを有効にして法線マップ用スロットを表示し、表面の接線ベクトルに関する計算を有効にします。
Normal MapUse Normal Texture が有効な場合にのみ表示されます。制作した法線マップを割り当て、Unity のインポート設定でテクスチャタイプを Normal map にしてください。

3. パラメーターの強度調整

テクスチャを割り当てたら、Inspector 下部のスライダーでメッシュ表面の見え方を調整します。

  • Metallic Strength：パック済みテクスチャの Red チャンネルから読み取る金属性の反射強度を調整します。金属性が高い部分では、物理的な材質特性を保つため色相バリエーションが自動的に抑制されます。
  • Smoothness Strength：パック済みテクスチャの Alpha チャンネルから得た表面の微細な粗さに基づいて滑らかさを調整します。
  • AO Strength：Green チャンネルから抽出したオクルージョンの深さと影の明瞭さを調整します。
  • Normal Strength：割り当てた法線マップの方向成分の強さと、見かけ上の凹凸の深さを調整します。

カスタムモデルの頂点カラーを使う

標準の 2D テクスチャではなく、独自の頂点カラーメッシュを使用する場合は、Workflow Setup の Use Vertex Colors を有効にできます。ただし、外部メッシュには DPT 純正アセットの UV や頂点ストリームに格納された特殊なデータが存在しないため、プロシージャルディテールシステムを無効にする必要があります。

必須：Procedural Details を無効にする

カスタムモデルでは Use Procedural Details を必ず無効にしてください。Bark、Rock、Leather などを扱う生成モジュールは、DPT 純正アセット向けに調整された特定の頂点ウェイトマッピングを必要とします。通常のカスタムモデルで有効のままにすると、シェーディングの破損、法線の歪み、視覚的なアーティファクトが発生します。

独自モデルでも完全なプロシージャルディテール機能を使用したい場合は、DPT 専用パイプラインに従ってメッシュの頂点データをパックする必要があります。この統合を依頼する場合は、以下のサポート・カスタム統合の案内をご覧ください。
