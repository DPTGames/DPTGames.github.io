DPT Games VCCORE マテリアルシステム

DPT アセット共通のマスターシェーダーとマテリアルを使用し、GPU Resident Drawer や SRP Batcher など、最新の Unity レンダリング機能との互換性と高い性能を実現します。

1 つのマテリアルを共有する設計思想

大量の個別マテリアルでバッチ処理を分断しドローコールを増やす代わりに、DPT アセットは同じマテリアルを共有するよう設計されています。Inspector は使用中のワークフローに応じて必要な設定のみを表示します。

重要：実行時の負荷は、マテリアル上で実際に有効な機能によって決まります。アセットがある機能を使用せず、有効な入力データもない場合は、シェーダーがその処理経路をスキップするため、そのシステムによる GPU 負荷は発生しません。

複数パッケージの併用と推奨設定

Harvestable Nature と Interactive Props など、複数の DPT パッケージを同じシーンで使う場合は、すべてに同一の Material アセットを割り当てることで性能を最大限に引き出せます。

複数パッケージを使用する場合の重要な設定：

バッチ処理効率を高めるため、すべてのアセットで単一の M_DPT_VCCORE マスターマテリアルを共有することを強く推奨します。

シェーダーは動的分岐とキーワードコンパイルを使用します。Normal Map 配列や Procedural Details のような高度な機能を使わない通常のアセットも、それらを使用する複雑なアセットとマテリアルを共有できます。不要な処理は最小限の実行時負荷でスキップされます。

動的な Inspector インターフェース

VCCORE の Inspector は状況に応じて表示項目を切り替え、不要な設定を隠します。

  • Workflow Setup：Use Vertex Colors を有効にすると、メッシュデータを読む方式に切り替わるため、通常の Base Color と Metallic/AO のテクスチャスロットが自動的に非表示になります。
  • 入れ子になった設定：Use Normal Texture やプロシージャルディテールのような高度な設定は、対応するトグルを有効にした場合にのみ強度スライダーとテクスチャスロットを表示します。
Use Vertex Colors はテクスチャ以外の機能も制御します：

Use Vertex Colors を無効にすると、通常のテクスチャスロットだけでなく、Emission System、Wind System、Procedural Details も非表示になります。これらは頂点カラーを使用する処理経路に依存するため、導入済みパッケージに関係なく通常のテクスチャ方式では表示されません。再び有効にすると設定できます。一方、Stylized Lighting と Metallic/Non-Metallic Tint の設定は影響を受けません。

エコシステム検出と適応型 UI

マスターマテリアルの Inspector は、導入済みパッケージを自動判定する Ecosystem Detection System を備えています。所有していないパッケージの設定を表示せず、現在のプロジェクトに合わせて構成を変えます。

動作の仕組み

各 DPT パッケージには固有のシグネチャーファイルがあります。読み込みまたはインポート時に、エディターは軽量なプロジェクトスキャンを実施して利用できる機能を更新します。

  • 必要な項目だけを表示：Vegetation Systems、Procedural Details、Emission、DPT Package Normals などは、その機能を使うパッケージのシグネチャーが存在する場合だけ表示されます。
  • 追加パッケージに対応：別の DPT パッケージを追加するとシグネチャーが検出され、既存の設定を無効化・リセットせずに新しい項目が自動的に表示されます。
  • Core を個別更新可能：機能判定はシグネチャーに基づくため、テーマ別アセットパックを変更したり再ダウンロードしたりせずに Core フォルダーを更新できます。
手動設定は不要：

検出は Unity のコンパイル処理中に自動実行されます。シリアルキー、認証画面、独自プリプロセッサーディレクティブ、複雑なスクリプト設定配列は不要です。

プロシージャルディテール

Use Procedural Details を有効にすると、メッシュの頂点データに基づいて微細な表面ディテールを生成する設定が表示されます。個別の大容量テクスチャを使う代わりに、GPU 上で数学的に計算されます。

Rock、Leather、Bark など、利用できる機能は導入済みの DPT パッケージによって異なりますが、スライダーの基本的な意味は共通です。

  • Strength：生成される法線の強さを制御します。大きくすると、凹凸や溝が光の当たり方によってより深く見えます。
  • Width：模様のスケールを調整します。注意：このスライダーを上げるとタイリング頻度が増し、模様は視覚的に小さく密になります。
  • Value（対応する機能のみ）：生成されたディテールのベースカラーのコントラストを調整し、元のオブジェクトより明るく、または暗くできます。

Procedural Detail Array

SRP Batcher と GPU Resident Drawer への互換性を高めるため、Bark、Leather、Rock や金属表面の微細なディテールなどは、最適化された単一の Texture2D Array に格納されています。

この配列はすべての DPT パッケージで共有されます。マスターシェーダーが頂点カラーの Alpha チャンネルを使用してメッシュごとに適切なテクスチャスライスを選択するため、マテリアルを変更したりドローコールを増やしたりする必要はありません。

  • 設定不要：配列は構成済みです。マテリアルの Use Procedural Details を有効にすると、必要な法線とディテールが適用されます。
  • メモリ効率：各ディテールテクスチャは最適化された 512×512 解像度です。繰り返し使用する微細な模様の鮮明さを保ちながら VRAM 消費を抑えます。
  • 動的分岐：メッシュがディテールを使わない場合や関連スライダーが 0 の場合は、配列サンプリングの処理がスキップされます。
モバイル・低メモリ環境：

厳しいモバイルや VR のメモリ制限向けに、Core フォルダーには 256×256 の配列も同梱されています。Material Inspector の Procedural Details テクスチャスロットから差し替えられます。

Wood Grain Value Map：

法線配列とは別に、Procedural Wood Grain のベースカラー値を調整する専用のパック済みテクスチャが 1 つあります。Wood 機能を有効にするとディテール配列と連携して自動的に使用されます。

Fur Detail Value：

Fur ディテールは、他のディテールテクスチャとは異なり、Fur Detail Value スライダーを通してベースカラーのみを変更します。

Stylized Lighting と影の形状

VCCORE には任意で有効化できる Stylized Lighting モードがあります。標準的な PBR の滑らかな減衰を、アートディレクション可能な明暗の境界に置き換え、影の色と暗さを独立して調整します。無効時は通常の PBR と同様に動作し、この処理による実行時負荷は発生しません。

Shadow Terminator と Light Terminator（範囲：0.0～1.0）

表面上で明るい領域から暗い領域へ移る境界を指定します。

  • 0.0：境界が完全に照らされた側に寄ります。
  • 1.0：境界が完全に影になった暗い側に寄ります。

2 つの値の間隔を広げると、通常の Lambert シェーディングのように柔らかく広いグラデーションになります。近づけると境界が硬くなり、同じ位置では明確なセルシェーディングの境界線になります。

初期値：

Shadow Terminator は 0.3、Light Terminator は 0.5 で、コントラストのある比較的シャープな境界を作ります。Shadow Tint は黒、Shadow Strength は 1.0 なので、Stylized Lighting を有効にするだけで効果を確認できます。

2 つの Terminator は交差できません：

Shadow Terminator と Light Terminator にはクランプ処理があり、一方を他方の値を越えてドラッグすると、もう一方も連動して移動します。

内部では、表面法線とライト方向の内積を元の -1…1 から 0…1 に変換した half-Lambert 値に基づいて境界を計算します。0 は光と逆向きの面、1 は光に正対する面です。2 つの Terminator がこの値の下限・上限を定めるため、0 と 1 に向けて広げるほど滑らかになり、近づけるほど鋭くなります。

Light Normal Smoothness（範囲：0.0～1.0）

細かな法線マップを持つローポリメッシュでは、シャープな明暗境界がポリゴン沿いにギザギザになる場合があります。Light Normal Smoothness は、照明の内積計算に使う法線をディテール法線マップと滑らかな頂点法線の間でブレンドします。

これにより、鏡面反射と直接光のハイライトに法線マップの細かな凹凸を残しながら、ギザギザした影の境界を抑えられます。

Shadow Strength（範囲：0.0～1.0）

影の領域の暗さと色付けの強さを制御します。

  • 0.0：Shadow Tint や Terminator の設定に関係なく、影側の色は変更されません（白）。
  • 1.0：影の領域は設定した Shadow Tint の色と強さを完全に反映します。
Shadow Strength が Terminator の見え方を決めます：

Shadow Strength が 0.0 の場合も境界は計算されますが、影の効果が白に解決されるため、Terminator を動かしても見た目が変わりません。効果を確認するには 0 より大きくしてください。

Shadow Tint

影側に適用する色です。Shadow Strength に応じてブレンドされた後、最終出力前に Base Color に乗算されます。追加ライトやポストプロセスなしで、暖色系の光に青い影を組み合わせるなどの演出ができます。

Shadow Rim Lighting（反射光とエッジグロー）

VCCORE は影側の環境反射光とリムライトを Emission で直接計算します。直接光の減衰に影響されず、暗い側の輪郭を鮮やかに、または背面から照らされたように表現できます。

  • Shadow Rim Color (HDR)：影側の環境グローに使う独立した HDR カラー。
  • Shadow Rim Sharpness：輪郭ハイライトの鋭さ。大きいほど細い線になり、小さいほど幅広く柔らかい光になります。
  • Shadow Rim Strength：環境反射光の輝度を制御する全体倍率。
表面特性と空洞によるマスキング：

磨かれた金属では輪郭が鋭く、マットな表面では柔らかくなるよう、リムライトは表面の材質に反応します。2 段階の AO マスク（Cavity Killer）によって、外周シルエットの光を損なわずにソケットやパイプの内部を暗く保ちます。

リアルタイム投影影の制御（Cast Shadow Min / Max）

自己シェーディングの Terminator に加え、URP で木の葉やキャラクターなどがオブジェクトに落とすリアルタイム影のしきい値と柔らかさを独立して調整できます。

  • Cast Shadow Min：受け取ったリアルタイム影が現れ始めるしきい値。
  • Cast Shadow Max：その影が最大の不透明度になるしきい値。

Min と Max の間隔を広げると柔らかい影に、狭めるとセルシェーディングに合う鮮明な影になります。大きな値でもシャドウマップのバイアスによるちらつきを避ける安全なクランプ処理があります。

シーンの影に関する補助設定（URP のみ）

Shadow Terminator、Light Terminator、Shadow Tint、Shadow Strength はマテリアル内部の自己シェーディングであり、Unity のリアルタイム影やシーンのカラーグレーディングとは別です。必要に応じて URP アセットや Volume Profile の影設定を調整し、表現を一致させてください。

Emission System

VCCORE には最適化された Emission System があります。Inspector で Enable Emission を有効にすると、メッシュで発光対象として指定された領域の色と強さを設定できます。

Emission のパッケージシグネチャーが必要：

Emission System は Ecosystem Detection System によって管理されます。Emission シグネチャーファイルを含む DPT パッケージが存在しない場合、Inspector に項目は表示されません。頂点カラー方式のため Use Vertex Colors も有効にする必要があります。

マテリアル共通の発光とインスタンス別の発光

1 つのマテリアルを共有しながら、全体設定と個別設定の両方に対応します。

  • Global Material Emission：Material Inspector の Emissive Color と Emission Strength が全体の設定です。同じマテリアルを使用するシーン内のすべてのオブジェクトに適用されます。
  • Per-Instance Emission：DPT_ShaderVariation コンポーネントの Instance Color と Alpha チャンネルがマテリアルの発光設定に乗算され、マテリアルを複製せずにオブジェクトごとの色と強さを変更できます。

Metallic Emissive Color

通常の Base Emissive Color とは別に Metallic Emissive Color があり、同じメッシュの金属部品（鉄製ルーン、銅製パイプ、換気口など）の発光色を非金属部分とは独立して制御できます。

金属オブジェクトの例外：

鏡面反射の処理上、金属領域の発光色はスクリプトを使ってインスタンスごとに変更できません。色は Material Inspector の Metallic Emissive Color で共通に指定します。ただし、DPT_ShaderVariation の Alpha チャンネルを使って、発光強度だけはオブジェクトごとに制御できます。

正確な色付けには白いベースカラー：

同一マテリアルで赤いポーションと青いポーションの発光色を変える場合は、Material Inspector の Emissive Color を純白にします。乗算なのでスクリプト側の色がそのまま最終的な色を決定します。これは非金属領域のみで有効です。金属領域の発光色はベースを白にしてもインスタンス別に変更できません。

高度な設定：本体と発光を異なる色にする：

DPT_ShaderVariation は MeshRenderer ごとに 1 つの色を渡すため、本体の色付けと発光は同じ色相を共有します。濃い青の剣にオレンジのルーンを光らせるには、ルーンを別の子メッシュに分け、本体とルーンに個別の Variation コンポーネントを使用してください。同じマスターマテリアルのままバッチ処理できます。

Wind System と風による動き

VCCORE は軽量な GPU 頂点変位の風システムを備えています。Wind Waving を有効にすると、自然な波や方向性のある揺れを頂点シェーダーで計算します。CPU 側のボーンスキニングや頂点物理演算は不要です。

Wind のパッケージシグネチャーが必要：

Wind System は Ecosystem Detection System に管理されます。Harvestable Nature や Foliage パックなど、Wind シグネチャーファイルを含むパッケージが存在すると表示されます。また、Use Vertex Colors を有効にする必要があります。

Wind Strength

頂点変位の揺れの速度と振幅を全体的に調整します。0.0 に設定すると、風システム自体は有効なまま動きが完全に停止します。

360° の風向設定（Compass と Pitch）

3D ベクトルを直接入力する代わりに、2 つのスライダーで方向を決められます。

  • Compass Heading（0°～359°）：横方向の揺れと、ワールド内を進む風の波の向きを設定します。
    • 0°：東（+X）
    • 90°：北（+Z）
    • 180°：西（−X）
    • 270°：南（−Z）
  • Vertical Pitch（−45°～+45°）：風の上下方向の傾き。0° は水平の風、正の値は上昇気流、負の値は斜面に沿う下降気流を表します。
正規化済みの単位ベクトル：

Editor GUI は Compass Heading と Pitch を正規化済みの 3D 単位ベクトルに変換します。全方向で風の速度と周波数が一定になり、不要な GPU 演算やゼロ除算を避けられます。

Color Variation

インスタンスごとの色と明るさは DPT_ShaderVariation コンポーネントによって制御されます。共通マテリアルを複製・変更せず、Unity の GPU インスタンスバッファーに直接データを書き込みます。

  • DPT Prefab Painter を使用：Randomize Brightness を有効にすると、コンポーネントが自動追加・設定されます。手動設定は不要です。
  • オブジェクトを手動配置：シーン内のオブジェクトや親オブジェクトに DPT_ShaderVariation を追加し、Inspector の Instance Color で調整します。
共有マテリアルを維持：

バリエーションは GPU インスタンスバッファー経由で渡されるため、異なる色を持つオブジェクトが大量に存在してもマテリアルは複製・変更されず、GPU Resident Drawer との互換性とバッチ処理が保たれます。

金属・非金属の色付け制御

マスターマテリアルには、金属部と非金属部それぞれにトグルと強度スライダーがあり、DPT_ShaderVariation の色付けを材質ごとに制御できます。

  • スクリプトが必要：トグル自体は処理の有効・無効を決めるだけです。RSUV 経由で色を送る DPT_ShaderVariation がなければ見た目は変わりません。
  • Non-Metallic Tint：非金属部を色付けするか指定します。無効にすると非金属部はインスタンス色の影響を受けません。
  • Metallic Tint：金属部への色付けを指定します。無効にすると金属部は色変更の対象外となり、元の物理的な鏡面反射特性を保ちます。
最適化されたキーワード構造：

金属・非金属の色付けに関する不要なシェーダーキーワードは削除され、速い動的分岐で切り替えます。バリエーションの機能を残しながら、シェーダーバリアント数とビルド時間を削減します。

Tint Strength スライダー（範囲：−2.0～1.0）

金属・非金属の両方で、同じ非対称の値範囲を使用します。

  • 0.0：該当する表面の色付けを無効にします。
  • 1.0：インスタンスカラーをそのまま反映する最大の色付け強度です。
  • 負の値（−2.0～0.0）：色付け方向を反転して、同じメッシュ内の材質間でコントラストを生み出します。たとえば宝箱の木材を暗くし、同時に金属の留め具を明るく見せることができます。

明るさの範囲、HDR の色付けを含む DPT_ShaderVariation の技術仕様は Shader Variation ガイドを参照してください。
