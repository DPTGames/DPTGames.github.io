Bayonet Attachment & Melee

Optional firearm feature · Mesh visibility, attachment events, melee damage and demo input

Optional melee functionality on any firearm

The bayonet is a separate attack mode in DPT_Firearm. It can show or hide a visual child and perform a short forward sphere sweep. It uses the same damage interface as hitscan and projectile hits, so targets do not require bayonet-specific health scripts.

Attaching a Bayonet

  1. Parent the bayonet model under the rifle root and assign its GameObject to Bayonet Visual. Do not assign the root itself.
  2. Create a Bayonet_Tip empty at the blade tip with +Z pointing in the thrust direction. Assign it to Bayonet Tip.
  3. Enable Bayonet Equipped for the initial state, or disable it for a detached initial state.
  4. Set hit reach, sweep radius, damage, cooldown and hit layers. Invoke AttackBayonet() from your own controller or use the optional demo input.
  5. For targets with physics reactions, set Bayonet Impact Impulse to zero if the receiver already applies an impulse.

Public API & Events

using DPT.Firearms.Runtime;
using UnityEngine;

public class ExampleBayonetControl : MonoBehaviour
{
    [SerializeField] private DPT_Firearm firearm;

    public void Attach() => firearm.SetBayonetEquipped(true);
    public void Remove() => firearm.SetBayonetEquipped(false);
    public void Toggle() => firearm.ToggleBayonet();
    public void Stab() => firearm.AttackBayonet();
}
EventWhen invoked
onBayonetEquipped / onBayonetRemovedWhen the equipped state changes through the API.
onBayonetAttackWhen an attack is accepted, whether it hits or misses.
onBayonetHitWhen the sweep strikes an eligible Collider, including a collider without a damage receiver.
BayonetHitOccurred(Vector3)C# event providing the world-space hit point.

How Bayonet Hits Apply Damage

  • The script checks overlap at the tip and then performs a forward sphere cast if necessary. It ignores the firearm’s own descendants and trigger Colliders.
  • It finds the closest eligible collider and sends damage to IDPT_FirearmDamageable.ReceiveFirearmHit() if the target has a receiver.
  • A successful collision can fire the bayonet hit event even when the struck object does not implement the damage interface.
  • Attacking is discrete, not continuous contact damage. A mesh touching an object does not automatically trigger another hit.

Optional Demo Input

Add DPT_FirearmBayonetDemoInput in the DPT.Firearms.Demo.Runtime namespace to the demo weapon. Default keys are V to equip/remove the bayonet and F to perform a stab. This controller belongs in the DPT.Firearms.Demo.Runtime assembly.
