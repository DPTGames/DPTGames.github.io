Bayonet Attachment & Melee

Optional melee · Animated stabs and swipes using the blade collider

Animated blade movement with swept collision sampling

DPT_Firearm can equip a bayonet and execute an animated stab or side-to-side swipe. Hits are detected by sampling the configured Bayonet Collider throughout the damaging motion using overlap and penetration tests. The system shares IDPT_FirearmDamageable with bullets.

Attaching a Bayonet

  1. Parent the bayonet model under the weapon, then assign its GameObject as Bayonet Visual. Do not assign the firearm root.
  2. Add a Bayonet Collider covering the blade. It must be an enabled BoxCollider, SphereCollider, CapsuleCollider or convex MeshCollider. Trigger targets are ignored.
  3. Assign an optional Bayonet Tip with +Z in the thrust direction and a Bayonet Motion Transform that contains the blade collider. The motion Transform can be the firearm root or a child of it.
  4. Set Bayonet Damage, Stab Distance, Stab Duration, Swipe Angle, Swipe Duration, Swipe Distance, Return Duration and Attack Cooldown.
  5. Use AttackBayonet() for a thrust or AttackBayonetSwipe() for a swipe. Enable Bayonet Equipped to start with the blade attached.

Public API & Events

using DPT.Firearms.Runtime;
using UnityEngine;

public class ExampleBayonetControl : MonoBehaviour
{
    [SerializeField] private DPT_Firearm firearm;

    public void Attach() => firearm.SetBayonetEquipped(true);
    public void Remove() => firearm.SetBayonetEquipped(false);
    public void Toggle() => firearm.ToggleBayonet();
    public void Stab() => firearm.AttackBayonet();
    public void Swipe() => firearm.AttackBayonetSwipe();
}
EventWhen it fires
onBayonetEquipped / onBayonetRemovedBayonet equipped-state changes.
onBayonetAttackAny accepted stab or swipe begins, even if it misses.
onBayonetSwipeAn accepted swipe begins.
onBayonetHit / BayonetHitOccurred(Vector3)Each eligible target struck during the current attack, including targets without a damage receiver.

How Bayonet Hits Apply Damage

  • During the damaging portion of a stab or swipe, the controller calculates a swept region covering the blade's previous and current bounds.
  • It queries nearby colliders using Physics.OverlapBoxNonAlloc and checks sampled blade poses with Physics.ComputePenetration. This is not the older tip-based sphere cast.
  • Each detected damageable target receives ReceiveFirearmHit() once per attack. The firearm tracks already-struck targets to avoid repeated hits during one swing.
  • Optional Bayonet Impact Impulse affects dynamic Rigidbodies. Set it to zero if the target damage handler already supplies a physical impulse.
  • Blade contact outside an active damaging stage does not create continuous damage.
