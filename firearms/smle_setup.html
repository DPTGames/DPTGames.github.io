SMLE Mk III Example Setup

Worked example · Ten-round magazine, two five-round chargers and correct contents-only loading

The SMLE is an example of a reusable firearms system

DPT_Firearm manages firing, ammunition, reload types and shared visual references for other firearms too. The optional DPT_FirearmProceduralBolt supplies the moving bolt and charger-loading animation for this particular rifle.

Procedural Bolt Settings

Assign Bolt Transform, enable Animate Reload, set Loading Visual Mode = Contents Only and assign Loading Contents to the cartridge group from the source loading prefab. Use Auto Cycle After Shot only if you want the action to cycle on its own following each shot.

Preparing the Five-Round Charger Prefab

SMLE_Loaded_Charger  [assigned as DPT_Firearm / Loading Prefab]
├── Charger_Body
└── Cartridges        [assign this Transform to Procedural Bolt / Loading Contents]
    ├── Cartridge_01
    ├── Cartridge_02
    ├── Cartridge_03
    ├── Cartridge_04
    └── Cartridge_05
  1. Make the charger body and its cartridges separate hierarchy children. Do not put the metal body under the Cartridges group.
  2. Assign the SMLE_Loaded_Charger prefab asset to DPT_Firearm → Loading Prefab.
  3. Assign the Cartridges Transform from that prefab asset to DPT_FirearmProceduralBolt → Loading Contents. This is an object field, not a child-name string; the script locates the equivalent Transform inside spawned copies.
  4. With Hide Unused Contents enabled, keep one direct child per cartridge. This allows a partly empty magazine to be replenished without displaying all five rounds in the visual.
  5. Adjust Loading Spawn Offset, Loading Guide Travel and Loading Insert Travel on the bolt component. The first stage seats the charger into the guide; the second moves only the cartridges down into the magazine.
Correct mechanical behaviour: The loaded charger is fitted into the bridge, its cartridges are pressed down into the magazine and the empty metal charger is removed or ejected. The charger itself does not enter the magazine. Reloading from empty can require two five-round chargers.

No DPT_FirearmLoadingVisual script is required. Loading prefab ownership remains in DPT_Firearm; the procedural bolt contains only visual-animation settings and the reference to the contents group.

Placing Muzzle, Ejection and Loading Markers

  1. Muzzle Point: put its blue +Z axis downrange, precisely at the barrel exit.
  2. Ejection Point: position it beside the receiver opening, away from moving parts.
  3. Loading Spawn Point: place it near the charger bridge, then assign it to the firearm's Loading Spawn Point field. Do not assign a second spawn point to the bolt.
  4. ADS Camera Pose: place an empty behind the rear sight, aligned down the barrel.
  5. Bayonet Tip: position at the blade tip with +Z in the intended stabbing direction.

FBX and Local Axis Notes

  • For predictable behaviour, use +Z forward, +Y up and +X right on the firearm root.
  • Use the actual Unity Transform axes after FBX import. A mesh may not inherit the expected orientation.
  • The procedural bolt provides separate Invert Bolt Travel Z and Invert Bolt Rotation Z settings.
  • Use Loading Travel Direction in the loading spawn point's local orientation. In Contents Only mode, the script converts that direction for the contents group's parent.

Acceptance Test

  1. Fire a live round. Check that the projectile appears, ammunition decreases and the bolt cycles according to your control settings.
  2. Reload with an empty magazine. The bolt should open, the first loaded charger should enter the guide, the cartridges should descend while the charger body stays put and the empty charger should be removed.
  3. Verify that a second five-round load appears when ten rounds are missing, and that the bolt closes only after loading completes.
  4. Test a partial reload with fewer than five rounds missing; ensure the contents visual shows only the number being inserted.
  5. Check muzzle alignment, casing ejection, sound and ADS with spread temporarily set to zero.
Using another weapon: The same core firearm can animate a whole magazine or one round at a time by changing its reload type, supplying another loading prefab and using a suitable action controller. The procedural bolt component is specific to bolt-action motion.
