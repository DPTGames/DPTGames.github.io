SMLE Mk III Example Setup

SMLE worked example · Magazine display, five-round chargers, single-round top-offs and bolt timing

The SMLE demonstrates reusable firearm and optional bolt components

DPT_Firearm owns ammunition, chamber and visual references. The bullet prefab owns firing simulation and impact properties. DPT_FirearmProceduralBolt handles the SMLE's mechanical bolt motion, casing ejection timing and scene-based charger animations. Optional visual feeding, material-specific projectile reactions and standalone recoil can be enabled without changing the SMLE ammunition model.

Procedural Bolt Settings

Assign Bolt Transform, enable Animate Reload and select Loading Visual Mode = Contents Only. Set Spent Case Ejection Point to approximately 0.85 for ejection near the end of rearward extraction. Auto Cycle After Shot is optional: disable it if you want the player to operate the bolt manually.

Chamber state: A full magazine and empty chamber can be chambered by cycling the bolt. With no reserve ammo, Reload requests can trigger that cycle rather than starting an impossible ammunition refill.

Preparing the Five-Round Charger Prefab

Loading_Visual_Root      [existing inactive scene object]
├── Charger_Body         [Firearm: Loading Device]
└── Cartridges           [Firearm: Loading Contents]
    ├── Cartridge_01
    ├── Cartridge_02
    ├── Cartridge_03
    ├── Cartridge_04
    └── Cartridge_05
  1. Place the entire charger hierarchy in the rifle scene or prefab hierarchy where it should begin its animation. Keep it inactive by default.
  2. Assign the root to DPT_Firearm → Loading Visual Root.
  3. Assign the metal body and cartridge-group Transforms to Loading Device and Loading Contents. Both references come from the same scene hierarchy.
  4. On the procedural bolt use Contents Only. The root enters the guide and the cartridges move down independently of the charger body.
  5. Set Loading Travel Direction, Loading Guide Travel and Loading Insert Travel to match the model's orientation and distance.
  6. Enable Allow Single Round Top Off With Clips for partial reloads. Assign a separate Single Round Loading Visual or rely on Live Round Prefab as fallback. A prefab asset is spawned once at the Loading Visual Root pose, reused and then hidden.
Realistic charger behaviour: The empty metal charger stays at the guide as its rounds are pressed into the magazine, then the charger is removed or ejected. The metal body does not descend into the magazine.

For a visible magazine, assign Magazine Round Visuals from bottom to top. Assign Magazine Follower and an Empty Offset if the follower should rise as ammunition is consumed. These visual objects are separate from the loading charger and from the chambered-round visual.

Placing Muzzle, Ejection and Loading Markers

  1. Muzzle Point: place at the barrel exit with +Z pointing downrange. Assign on the firearm.
  2. Ejection Point: place by the right-hand receiver opening. The script spawns spent casings or unfired chambered rounds here.
  3. Loading Visual Root: position the inactive scene charger at the start of the visual loading movement. The single-round prefab fallback also uses this pose.
  4. Loading Ejection Point: optional separate marker for empty chargers or live rounds ejected to make room for a full charger.
  5. ADS Camera Pose: empty Transform behind the iron sights. Keep Main Camera outside the rifle hierarchy.
  6. Bayonet Tip: empty at blade tip with +Z in the intended thrust direction, if a bayonet is equipped.

FBX and Local Axis Notes

  • Use the actual Unity Transform axes rather than assuming exported FBX axes match the model. Test +Z forward at the muzzle.
  • Use Invert Bolt Travel Z or adjust extraction/closing slides if the bolt moves forwards when it should retract. Use Invert Bolt Rotation Z or the sign of Open Angle for unlocking direction.
  • Loading Travel Direction is applied relative to the loading visual's parent for the scene hierarchy. The Contents Only path converts that direction into the cartridge group's parent space.
  • Keep the intact and deformed bullet meshes under the projectile prefab, not under the live-round ejection or chambered-round visual references.

Optional Advanced Features for the SMLE

Animated Cartridge Feeding

For a visible feed sequence, assign Magazine Round Visuals from bottom to top and position Chambered Round Visual where the loaded cartridge rests. Enable Animate Cartridge Feeding under the procedural bolt's Cartridge Feeding subsection. The top visible magazine cartridge travels towards the chamber while the bolt closes. The visual returns to its original pose when the firearm refreshes the magazine and chamber state.

Bullet Surface Rules

Add DPT_FirearmSurfaceImpact to the Bullet projectile prefab. Configure optional Layer Rules for wood, metal and other target layers. Set the rule's Reaction, speed thresholds and any impact mark, spalling and audio overrides. The .303 round continues to use the projectile's default first-contact stop when no matching rule exists. See Material-Specific Surface Reactions.

Standalone Recoil

Open Procedural Recoil in the firearm Inspector, choose Add Procedural Recoil and assign a camera or dedicated child recoil pivot. Set Position Kick, Rotation Kick, limits and Recovery Speed. The included demo controller automatically suppresses its own recoil when this optional module is enabled with a target. See Standalone Procedural Recoil.

Setup Diagnostics

Open Setup Diagnostics on the firearm before testing. It checks projectile prefab components and visuals, muzzle assignment, bolt Transform, magazine visual references, cartridge-feeding prerequisites, trigger offsets and single-round top-off fallbacks.

Acceptance Test

  1. Start with 9 magazine rounds and Start Chambered enabled. Confirm nine magazine rounds and one chambered round. Then test ten magazine rounds, Start Chambered disabled and Auto Chamber From Magazine On Start enabled.
  2. Fire and cycle the bolt. Confirm the spent casing ejects during rearward extraction at the configured fraction, tumbles after ejection and the new round is chambered before bolt closure.
  3. With five or more rounds missing, reload using the five-round charger. Its body should stop at the guide while its contents descend.
  4. With one to four rounds missing, ensure Allow Single Round Top Off With Clips is enabled and that an individual cartridge visual appears for each top-off.
  5. With no reserve ammunition and an empty chamber, press Reload while magazine rounds remain. Confirm the bolt cycles and feeds a round without increasing total ammunition.
  6. Inspect Magazine Round Visuals, the follower, chambered-round and spent-casing visuals through firing and reloading. Check all references and movement against your model.
  7. Test both projectile modes on the projectile prefab. Confirm the crushed-bullet child replaces the intact visual and follows a moving struck collider. A separate impact effect should not create another crushed bullet.
  8. Enable Animate Cartridge Feeding and cycle the bolt with at least one magazine cartridge visible. Confirm it moves towards the chamber only during the forward stroke and that the magazine visual count remains correct.
  9. If using surface rules, test a thin wood object and a grazing metal surface in both Hitscan and Swept Projectile modes. Confirm the crushed bullet appears only after a final stop.
  10. Add optional procedural recoil to a dedicated pivot and fire several shots. Confirm recoil accumulates and recovers, with no additional recoil applied by the demo controller.
Other weapons: Use DPT_Firearm with another model and a different projectile prefab. The procedural bolt is optional and its scene-based loading visual is specific to manual-action animation.
