DPT Games Functional Firearms

System guide · Generic components demonstrated with an SMLE Mk III bolt-action rifle

A reusable firearm controller with configurable projectile prefabs

Configure firing modes, ammunition, chambering, magazine display, casing ejection, reload procedures, optional bolt action, bayonet attacks and events. The SMLE Mk III demonstrates these systems but is not required. The firearm owns the weapon and ammunition; the projectile prefab owns its ballistic and impact behaviour. Optional surface rules can now add material-dependent penetration, ricochets and contact effects without changing the firearm controller.

Quick Start

  1. Add DPT_Firearm and an AudioSource to your weapon root. Set its fire mode, magazine capacity and initial chamber state.
  2. Create a child Muzzle Point at the barrel exit pointing +Z downrange. Assign it on the firearm and tune Spread Degrees.
  3. Create a DPT_FirearmProjectile prefab with a root Rigidbody. On that prefab set Shot Type to Hitscan or Swept Projectile and configure damage, range, velocity, layers and impact effects.
  4. Assign the prefab to Projectile Prefab on the firearm. Hitscan uses it to create a remnant only on a hit; swept mode launches it from the muzzle.
  5. Add an Ejection Point beside the receiver and optional spent casing, live-round, muzzle-flash and audio references.
  6. For bolt-action weapons add DPT_FirearmProceduralBolt and assign its Bolt Transform. For charger reloads, provide an existing inactive Loading Visual Root scene hierarchy.
  7. Connect trigger and reload APIs from your player controller, or use the optional demo input. Keep the demo's Main Camera outside the weapon hierarchy.
  8. Optionally add DPT_FirearmSurfaceImpact to the bullet prefab to configure layer-specific stop, penetration and ricochet responses. Without it the projectile stops at its first hit.
  9. Use Setup Diagnostics to review references and add DPT_FirearmRecoil from the Procedural Recoil section if you want recoil independently of the demo controller.

Optional Advanced Projectile and Animation Features

Surface reactions

Attach the optional DPT_FirearmSurfaceImpact component to the projectile prefab for ordered layer rules, penetration, ricochets, material effects and contact limits.

Magazine-to-chamber feeding

Use Animate Cartridge Feeding on the procedural bolt to move an existing magazine visual during the forward bolt stroke without changing ammunition counts.

Standalone recoil

Add DPT_FirearmRecoil to drive a chosen Transform from shot events. The demonstration disables its own visual recoil when this module is configured.

Setup Diagnostics

Open Setup Diagnostics on a single selected firearm to see warnings and informational checks. The section verifies the assigned projectile component and Rigidbody, muzzle, projectile visual references, magazine visual entries, procedural bolt Transform, trigger motion offsets and stripper-clip top-off visual or fallback. It also reports when visual cartridge feeding has insufficient references. These messages do not change runtime behaviour.

Configuration workflow: Fix missing component and Transform assignments first, then test shooting, reloading and optional visual modules in Play Mode. The diagnostics panel is not a runtime test.

Reload Types and Loading Visuals

DPT_Firearm owns ammunition and reload operations. Optional action controllers supply animation without duplicating ammunition state.

Reload type / visualBehaviour
Full MagazineReloads the magazine in one operation.
Individual RoundsAdds cartridges one at a time. The procedural bolt can reuse a single loading scene object.
Stripper ClipsTransfers up to Rounds Per Load from a charger. Contents Only keeps its metal body at the guide while pushing cartridges down.
Mixed clip + single roundWith Allow Single Round Top Off With Clips enabled, full chargers are followed by individual loading for any one-to-four-round remainder.
Visual ownership: Set up an existing inactive scene Loading Visual Root on the firearm. For Contents Only, assign its Loading Device and Loading Contents children. The optional Single Round Loading Visual can instead be a prefab asset, which is instantiated once and reused for top-offs.

See SMLE setup for a scene hierarchy and Procedural Bolt & Loading Animations for timing, ejection and troubleshooting.

Audio and Visual Effects

  • Firearm Shot Sounds, Reload Sounds, Bolt Sounds and Empty Sounds cover the weapon's mechanical audio.
  • Muzzle Flash Prefab instantiates a temporary effect. Muzzle Flash Light pulses an existing Light, which can start inactive.
  • Projectile Impact Effect Prefab is a separate surface decal, crater or particle effect, not the crushed bullet. Impact audio, physics impulse and projectile screen shake use the projectile's hit event in either shot mode.
  • Reload Bolt Close Sounds play from the procedural bolt during post-reload closure.
  • Spent Casing Tumble Speed gives spent casings initial angular velocity when the ejected prefab has a Rigidbody.
  • Optional DPT_FirearmSurfaceImpact overrides contact effects and sounds per matching physics layer. DPT_FirearmRecoil provides shot-driven visual recoil on a separate pivot, while screen-shake senders provide distance-attenuated camera displacement.

Common Troubleshooting

SymptomCheck
Shot mode or damage cannot be found on firearmThese are now configured on the assigned DPT_FirearmProjectile prefab.
Two crushed-bullet visuals after impactAssign the deformed mesh as a child on the projectile. Keep Impact Effect Prefab for a separate surface effect, not another bullet.
Crushed bullets float after targets moveThe projectile parents to the struck collider at impact. If a destruction system replaces the collider with fragments, extra integration is needed.
Charger or cartridges do not animateAssign an existing scene Loading Visual Root and its Loading Device and Loading Contents children. Do not use the old Loading Prefab field.
Top-off round does not appearEnable Allow Single Round Top Off With Clips. Set Single Round Loading Visual or a Live Round Prefab and position Loading Visual Root correctly.
Magazine has rounds but chamber is emptyCycle the action. Optionally enable Auto Chamber From Magazine On Start if the weapon should spawn ready to fire.
Spent casing ejects during closureAdjust Spent Case Ejection Point on the procedural bolt. It is triggered during the rearward extraction stage.
Bayonet strikes do not registerAssign Bayonet Collider and its motion Transform. The current melee system performs animated stabs/swipes with collider sweeps rather than a tip-radius sphere cast.
Scripts cannot find firearm classesCheck asmdef references and import DPT.Firearms.Runtime.
Projectile always stops instead of penetratingAdd DPT_FirearmSurfaceImpact to the projectile prefab, match the hit layer and verify the penetration speed and thickness. Penetration needs a detectable exit surface.
Ricochet never occursCheck the surface rule, minimum ricochet speed, angle from the surface normal and Max Ricochets.
Recoil appears twiceAssign and enable a single recoil owner. The demo controller suppresses its camera recoil when an active DPT_FirearmRecoil has a target.
Cartridge feed does not animateEnable Animate Cartridge Feeding on the procedural bolt. Assign the firearm Magazine Round Visuals and Chambered Round Visual, then cycle a round from the magazine.
