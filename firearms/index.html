DPT Games Functional Firearms

Component User Guide
The DPT_Firearm component provides a configurable firearm controller for bolt-action, self-loading, automatic and burst-fire weapons. It includes magazine/chamber accounting, optional swept projectiles, casing ejection, audio, UnityEvents and an animation-friendly manual action.

Quick Setup Checklist

  1. Add DPT_Firearm to the root of the rifle or firearm prefab. No siege weapon components are required.
  2. Create a child Empty named Muzzle_Point at the muzzle and orient its local +Z axis along the bullet's firing direction. Assign it to Muzzle Point.
  3. Create a child Empty named Ejection_Point beside the receiver. Assign it to Ejection Point and adjust Ejection Local Direction.
  4. Choose Shot Type: Hitscan for immediate raycast hits or Swept Projectile for a moving bullet prefab.
  5. For swept shots, create a prefab with DPT_FirearmProjectile on its root and assign it to Projectile Prefab. See the Projectile Guide.
  6. Create separate spent casing and optional unfired-round prefabs with a root Rigidbody and suitable Collider. Assign them to Spent Casing Prefab and Live Round Prefab.
  7. Configure magazine capacity, starting rounds, chamber state and reserve ammunition. Magazine Rounds never includes the round in the chamber.
  8. Assign optional Chambered Round Visual and Chambered Casing Visual child objects to show the current chamber state.
  9. Assign a root or explicit AudioSource, fire sounds, bolt sounds, reload sounds and optional muzzle flash prefab.
  10. If using an Animator, assign it and enable Use Animator Triggers only after creating the expected triggers Fire, DryFire, Cycle and Reload.
  11. Optionally add DPT_FirearmDemoInput for testing. The included sample only handles fire, bolt cycle and reload keys.
  12. Add a DPT_FirearmDamageRelay to a target, or implement IDPT_FirearmDamageable for code-driven damage handling.
No destruction dependencies: This firearm package uses the DPT.Firearms namespace. It does not require DPT_SiegeWeapon, DPT_Projectile, DPT_BreakableProp or a debris hierarchy.

Operation & Fire Modes

The current component tracks its chamber, magazine, spare rounds, trigger state and action cycle separately. Unlike the siege weapon controller, it does not expose a formal WeaponState enum. Use its state properties to inspect readiness.

Chambered → Fire → Spent Case → Eject → Feed Next Round → Chambered
Mode / BehaviourWhat Happens
Semi AutomaticOne shot per trigger press. Fire() can also be called directly for one shot.
AutomaticTriggerDown() starts repeated fire while held, governed by Rounds Per Minute; TriggerUp() stops it.
BurstTriggerDown() fires up to Burst Size shots, subject to ammunition and the RPM interval.
Manual ActionAfter firing, the spent casing stays in the chamber until the user cycles the action. Intended for bolt-action rifles.
Self-loading ActionWith Manual Action disabled, a successful shot ejects the spent case and feeds the next magazine round immediately. This is simplified and is not frame-synchronised to a slide or bolt animation.
Manual action does not cycle automatically. If the SMLE fires once and will not fire again, check SpentCaseInChamber, then call CycleAction() or perform an animated cycle. This is intentional.

The visual objects do not need Rigidbody components while they remain attached to the rifle. Give dropped or ejected ammunition its own separate prefab with one Rigidbody at the root.

Manual Bolt Cycling & Reload Animation

Instant Cycle

Call CycleAction() to execute one complete cycle immediately. It starts the cycle, sends the optional Cycle Animator trigger, ejects a spent case or unfired cartridge, feeds the next round and finishes the cycle.

Animation-Driven Cycle

  1. Assign an Animator and enable Use Animator Triggers.
  2. Create a trigger parameter named exactly Cycle.
  3. Call RequestCycleAnimation() when the player cycles the bolt. This begins the cycle and raises the Animator trigger.
  4. At the extractor/ejection animation frame, add an Animation Event calling EjectChamber().
  5. When the bolt pushes the next round forward, add an Animation Event calling ChamberNextRound().
  6. At the end of the bolt-closing animation, add an Animation Event calling EndCycle().
Important: The code does not automatically call EndCycle() when using RequestCycleAnimation() with a valid Animator. If the animation omits that event, IsCycling remains true and the rifle cannot fire or reload. Do not call both CycleAction() and RequestCycleAnimation() for the same action.

Timed Magazine Reload

Reload() runs a timer and replenishes the magazine at its completion. It does not animate inserting individual cartridges, removing the magazine or operating the bolt. The Animator and external gameplay code own those visuals. It respects magazine capacity and reserve ammunition.

SMLE loading: The actual Lee-Enfield is usually loaded using five-round chargers with the magazine fitted. You can animate charger loading while the firearm component's timed reload replenishes its magazine count, but the script does not currently model charger objects or five-round batches.

Scripting API

Public MethodBehaviour
bool Fire()Attempts one shot immediately. Returns true when a shot is fired; respects safety, chamber state, cycling/reloading and RPM.
void TriggerDown() / TriggerUp()Start and stop trigger-driven firing. Required for automatic and burst behaviour in the sample input pattern.
void SetSafety(bool engaged)Sets the safety state. Enabling the safety releases the held trigger.
void InitializeAmmunition()Resets magazine, reserve and chamber to their configured starting values.
bool BeginCycle()Locks the action into cycling mode unless already reloading or cycling.
void EjectChamberedCase()Ejects a fired casing only when one exists.
void EjectChamber()Ejects whichever item is in the chamber: spent case or unfired cartridge.
bool ChamberNextRound()Moves one magazine round into an empty chamber; returns true if successful.
void EndCycle()Completes the action cycle, plays bolt audio and sends onCycle.
void CycleAction()Performs the full ejection and chambering cycle immediately.
bool RequestCycleAnimation()Requests an Animator-driven cycle; requires Animation Events when Animator triggers are enabled.
bool Reload()Starts a timed magazine reload if there is room and reserve ammunition.
void CompleteReload()Refills the magazine only while reloading; designed for completion of the timed sequence.
void AddReserveAmmo(int amount)Adjusts the reserve count, clamped to zero or above.

Example: Manual Bolt Controller

using UnityEngine;
using DPT.Firearms;

public class RifleControls : MonoBehaviour
{
    [SerializeField] private DPT_Firearm rifle;

    public void Shoot() => rifle.Fire();
    public void CycleBolt() => rifle.RequestCycleAnimation();
    public void ReloadMagazine() => rifle.Reload();
}

For an animation-driven bolt, the Animator's animation events must call EjectChamber(), ChamberNextRound() and EndCycle() on the object containing DPT_Firearm.

Audio, VFX & Casing Ejection

Fire, reload, bolt and dry-fire clips are randomised from their respective arrays. The component uses the assigned AudioSource or a source on the same object; it does not create an AudioSource automatically. Sound playback uses PlayOneShot and a random pitch offset.

The muzzle flash is instantiated at the muzzle transform. A hit effect can be assigned for Hitscan mode; moving projectiles have their own effect and sound settings in the Projectile Guide.

Ejection physics: An ejected prefab needs a root Rigidbody if it should receive velocity. The Ejection Local Direction vector is converted from the ejection transform's local space to world space. With Ignore Own Colliders enabled, collisions between spawned casing colliders and cached firearm colliders are ignored.

Troubleshooting

SymptomCheck
First shot works but the rifle stopsFor a bolt-action SMLE this is expected: call CycleAction() or complete the animation-driven cycle.
Fire returns falseCheck SafetyOn, IsReloading, IsCycling, the RPM cooldown and whether the chamber is loaded. Swept shots also require a valid projectile prefab.
Bolt animation blocks further firingEnsure your final Animation Event invokes EndCycle().
Projectile flies in the wrong directionCheck the muzzle point’s local +Z axis and its hierarchy scale/rotation.
No firing soundAssign an AudioSource and populate Shot Sounds. The component does not auto-create a source.
Reload seems to do nothingThe reload only refills the magazine. A spent case must still be extracted when manual action is enabled.
Projectile misses thin geometrySwept projectiles raycast along traveled segments, but layer masks, triggers and first-hit rules still apply.
Hits do not deal damageAttach a component implementing IDPT_FirearmDamageable to the struck object or a parent; check collision layers.

Compatibility & Scope

  • Built for Unity 6.x and standalone from the Siege Weapons runtime.
  • Uses UnityEngine Physics and UnityEvents; the optional demo input supports Input System and legacy Input Manager defines.
  • Ballistic swept projectiles are simulated with raycasts, not Rigidbody flight collisions.
  • There is no included first-person controller, aiming/recoil implementation, magazine mesh animation, full Animator Controller, penetration, ricochet or projectile pooling.
  • Direct integration with DPT_Cuttable requires an adapter using the destruction package's actual API. See Damage Integration.
