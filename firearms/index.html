Weapon setup, ammunition, procedural actions and player integration

Set up a firearm

DPT_Firearm handles input requests, firing, ammunition and reload state. Add a procedural action to animate a bolt, hinge or cylinder. The projectile prefab handles the shot after it leaves the weapon.

The included SMLE Mk III, double-barrel shotgun and Colt New Service revolver prefabs show three working setups. The rifle demonstrates magazine and charger loading, the shotgun demonstrates independent barrels and shell insertion and the revolver demonstrates a swing-out cylinder with six independently tracked chambers.

Quick Start

  1. For a working starting point, open the range demo or drag an included complete weapon prefab into your scene. For a new weapon, add DPT_Firearm to its root.
  2. Assign Muzzle Point under Projectiles & Impacts. Place it at the model’s muzzle and point its local +Z along the direction of fire. For a multi-chamber weapon, assign the chamber-specific muzzle references under Multi Chamber Ammunition. The firearm-level Fallback Muzzle Point is used when a chamber has no muzzle assigned. Assign a Projectile Prefab or an ammo profile with a projectile override.
  3. Choose Reload Type, set the starting ammunition and assign the ejection point for casing effects. For a multi-chamber weapon, add Multi Chamber Ammunition and configure its slots.
  4. To animate moving parts, add Procedural Action in the firearm Inspector. Select the action that matches the reload type and assign its pivots.
  5. Check Setup Diagnostics. Try Fire and Reload in the Inspector during Play Mode or connect your controller through Player Binding.
Which setup should I copy? Start with SMLE.MKIII_01_Complete for a magazine-fed bolt action, Double_Barrell_Shotgun_Complete for two independently loaded barrels or Revolver_01_Complete for a six-chamber swing-out cylinder.

Prefab Setup & Firing

Open a prefab in Prefab Mode or select its scene instance. Under Prefab Setup, Auto Setup Parts fills empty part fields from names such as Muzzle_Point, EjectionPoint, BoltPivot and Trigger_AudioSource. Add the action and chamber components first if you want the tool to find their parts. Check the result, especially the two barrels’ references. Ambiguous names are skipped. Use Unity’s Undo to revert an assignment.

SettingWhat it changes
Fire ModeSemi Automatic fires once per press. Automatic keeps firing while held. Burst stops after Burst Size or when the trigger is released.
Manual ActionFires one shot per press and leaves the chamber spent until the action cycles. A procedural bolt can cycle on its own if Auto Cycle After Shot is enabled.
Rounds Per MinuteControls the interval between shots in modes that use the rate limit. Double-barrel firing uses independent chamber states.
Automatic ReloadRequests a reload when the weapon runs out and is ready. Automatic Reload Delay lets the last action finish before the reload request.
Magazine DisplayList live round visuals from bottom to top. The lowest rounds disappear first. The magazine follower starts in its full pose and moves towards Magazine Follower Empty Offset as the magazine empties.

Ammunition & Chambers

Magazine and reserve

Starting Magazine Rounds fills the magazine up to Magazine Capacity. Start Chambered starts with a separate live round. Leave it off and enable Auto Chamber From Magazine On Start to move a round out of the starting magazine and into the chamber. With ammo profiles off, Starting Reserve Rounds supplies the spare ammo.

Ammo profiles

Enable Use Ammo Types to track each cartridge or shell’s profile in the magazine, chamber and reserve. Set Default Ammo Type and add Ammo Reserves entries with their starting round counts. If the default is empty, the first assigned reserve is used. Unlimited Reserve allows reloads without spending the reserve.

  • Create Ammo Profile under Prefab Setup saves a separate asset using the weapon’s settings or its starting profile. Create and Assign makes the asset the default and adds it to the reserves. When converting to profiles it copies the old starting reserve count. For a weapon already using profiles, set Starting Rounds for Copy.
  • Use Next Reload Ammo Type in Play Mode or call SelectAmmoType or CycleAmmoType through your controller. The selection applies as rounds are loaded. Already loaded rounds keep their own profile.
  • Replace Loaded Ammo On Reload allows a reload to eject mismatched live rounds and load the requested type, even when full. Keep enough of the requested ammo in reserve. On a double barrel, a chamber’s preferred profile takes precedence over the current selection.

See Ammo Profile Settings for projectile overrides, spread and pellet counts.

Multi Chamber Ammunition

Use Reload Type = Multi Chamber for independently tracked barrels or cylinder chambers. In Multi Chamber Ammunition, select Action Kind and add one Chambers entry per slot. Starting Live Rounds fills slots from the beginning of the list. Starting Index chooses the initial slot, starting at zero.

Per-chamber setupPurpose
Muzzle Point / Ejection PointShot origin and casing direction for the slot. An empty reference uses the firearm’s assigned point.
Live Round Visual / Spent Case VisualObjects under the weapon hierarchy for live and spent rounds. If there is no separate spent visual, the live visual can stay visible until ejection.
Loading Start Point / Loading End PointOptional poses for procedural insertion. Put the end pose where the round should sit in the open action. A fixed marker under the moving assembly is easy to inspect.
Starting Ammo Type / Preferred Reload Ammo TypeOptional overrides for the initially loaded round and for subsequent reloads. Leave them empty to use the firearm’s starting and selected ammo.

Automatically Index After Shot, Index After Dry Fire and Skip Empty Chambers control how selection advances. Fire Both Barrels can discharge both live slots on one press. Projectiles Per Barrel is the fallback pellet count when no profile supplies one.

Reload Modes

Reload TypeWhat it doesTypical presentation
Full MagazineFills the available magazine space in one operation, up to the available reserve ammunition.Timed reload, Animator events or a compatible procedural bolt.
Individual RoundsLoads one cartridge at a time.Timed or animated insertion, optionally with a procedural bolt.
Stripper ClipsLoads a group up to Rounds Per Load. The SMLE example uses a charger.Procedural bolt and an inactive loading hierarchy, or timed and Animator-driven loading.
Single ChamberLoads the breech directly from reserve.Procedural break action or a basic reload.
Multi ChamberLoads eligible individual chambers from reserve.Double-barrel break action, revolver action or a basic chamber reload.
  • Open Action On Reload opens the action and ejects a spent case when appropriate. Chamber On Reload can fill an empty magazine-fed chamber when reloading finishes.
  • For clips, Allow Single Round Top Off With Clips uses full clips followed by individual cartridges for a small remainder. Eject Magazine Rounds For Full Loads can instead make room for a full clip. Mixed loading takes priority over full-load ejection.
  • Operate Action When Fully Loaded lets Reload play an inspection cycle when the weapon has nothing to load. Use Fully Loaded Inspection Hold Duration to adjust the procedural hold.

Animator-driven reloads

Use Animator and Use Animator Triggers under Animation & Audio to send Fire, DryFire, Reload and Cycle. For an animation-event reload, enable Reload Uses Animation Events in a compatible reload mode. Put DPT_FirearmReloadAnimationRelay beside the Animator if the clips play on a child.

Animation eventWhen to call it
OpenReloadActionAt the action-open point when your reload needs this stage.
InsertReloadRoundAnimationEventAt each individual cartridge insertion.
BeginReloadChargerAnimationEvent, InsertReloadChargerAnimationEvent, EjectReloadChargerAt the relevant clip animation stages.
CompleteReload / CancelReloadFinish the reload or exit an interrupted animation.
Choose one reload driver. Turn off Reload Uses Animation Events when the procedural action drives the reload. For Multi Chamber, set up the chamber bank and procedural action directly.

Procedural Actions

Add DPT_FirearmProceduralAction through Firearm > Procedural Action. Configure the mechanism in that section of the firearm Inspector. The component chooses the active mechanism from the Action Type and reload configuration.

Action TypeCompatible setup
Bolt ActionFull Magazine, Individual Rounds or Stripper Clips.
Break ActionSingle Chamber, or Multi Chamber with Action Kind set to Double Barrel.
RevolverMulti Chamber with Action Kind set to Revolver.

Bolt Action

  1. Assign the moving Bolt Transform in its closed pose. Enable Manual Action for the SMLE-style firing cycle. Set Auto Cycle After Shot if the animation should start without another input.
  2. In Bolt Movement, tune Initial Slide, Open Angle, Extraction Slide and Closing Slide. These are offsets from the rest pose. Invert Bolt Travel Z and Invert Bolt Rotation Z correct imported axes independently.
  3. Set the stage durations and Spent Case Ejection Point. This value is the fraction of the rearward extraction stage when the case is ejected.
  4. Use Animate Cartridge Extraction or Animate Cartridge Feeding with assigned cartridge visuals. Put the chambered round and its casing in the weapon and list any magazine round visuals.

Charger and individual loading

Assign an existing inactive Loading Visual Root under Loading Visuals. Let the procedural bolt animate it using Animate Reload. Configure the guide and insertion travel, stage durations and delay between loads in Reload Animation.

Loading Visual ModeHierarchy
Whole ObjectMoves the full loading hierarchy together.
Contents OnlyAssign Loading Device and Loading Contents below the root. Put one visible round per child under Loading Contents.
Individual RoundsUses a single cartridge visual. For a clip top-off, use Single Round Loading Visual or the live round prefab. An ammo profile can supply its own loading visual.

Use Disable Loading Physics if the animated objects contain physics components. Reload Closing Speed Multiplier changes closing after reloading. Reload Closing Sound Override can give that stage its own clips and source.

Break Action

Assign Hinge Pivot and set its local Hinge Axis, opening angle and durations. Parent the moving barrels and chamber markers to the hinged assembly. For Single Chamber, assign Loading Cartridge Visual and its start and end poses if you want visible insertion.

For a double barrel, configure the individual chamber references under Multi Chamber Ammunition. Opening Lever adds the lever movement before the barrels open. Extractor Pivot can move during extraction. Ejection Fraction, Post Ejection Load Delay, Per Cartridge Duration and Between Cartridges Delay control the shell sequence. Eject Existing Case Objects releases the visible case or round and recreates the hidden chamber visual for later loads.

Check the end marker for each shell with the action open. Align it with the seated shell’s pose and keep it under the same moving assembly.

Revolver

Choose Swing Out, Top Break or Loading Gate under Revolver Action. Assign Action Pivot for opening and Cylinder Pivot for indexing. Tune the local opening and indexing axes independently. Reverse Indexing flips the animation direction.

Use Extractor Rod for visible extraction. Set per-slot loading markers where the chambers need different paths. Use Speedloader applies to swing-out or top-break reloads when no live rounds remain in the cylinder. Loading Gate reloads index the cylinder and insert rounds one at a time. Set Post Ejection Load Delay to add a pause after cases eject during reload.

For a Swing Out action, turn on Enable Cylinder Spin to allow a manual spin while the cylinder is open. Set Cylinder Spin Duration and Cylinder Spin Turns under Cylinder Rotation. The range demo binds cylinder spin to C.

The mechanism captures its closed pose at startup. Capture Current Closed Pose is available in Play Mode for testing. Close and align the action before capturing.

Safety & Trigger Animation

Place the Safety Switch Transform at its Safety Off pose, then set the local position and rotation offsets for Safety On. Engage Safety and Disengage Safety preview the movement in Play Mode. Safety still blocks firing with the transform unassigned. Use Safety Engage Sounds, Safety Disengage Sounds and Safety Blocked Trigger Sounds for the three actions.

Assign Trigger Transform and set its local pull position, rotation and release time. Enable Animate Trigger On Dry Fire if the trigger should move on an empty chamber. For two triggers, assign Trigger 1 Transform and Trigger 2 Transform to the corresponding barrels. If Trigger 2 is empty, both barrels use Trigger 1.

Bayonet

Enable Enable Bayonet and set Bayonet Equipped for its initial state. Assign the Bayonet Visual and a Bayonet Collider around the blade. Use Bayonet Tip to help define thrust direction and, if needed, a Bayonet Motion Transform that moves with the blade.

Tune stab and swipe motion, return time, cooldown, damage and Bayonet Hit Layers. The blade sweep looks for an IDPT_FirearmDamageable receiver on the hit object or its parents. ToggleBayonet() changes the equipped state. AttackBayonet() requests a stab and AttackBayonetSwipe() requests a swipe. The TryBayonetAttack() and TryBayonetSwipe() variants report whether the attack started.

Aim, ADS Calibration & Scene Gizmos

Camera ModeUse it when
External CameraYour FPS controller moves the camera. Aim can still supply crosshair convergence, sensitivity and optional field-of-view blending.
Follow WeaponThe Aim component should position the camera between the weapon’s hip and ADS poses. Keep the aim root outside the camera hierarchy.
  1. Open Aim Calibration on the firearm and add the Aim component if needed.
  2. In Edit Mode, choose Scene View or Assigned View Camera from Capture From. Frame the weapon and click Capture Hip Pose or Capture ADS Pose. The captured transform stays editable under the weapon.
  3. Set Calibration Distance (m) and click Align ADS to Muzzle Line to rotate the ADS pose towards the muzzle line at that distance.
  4. Enable Converge Shots To Crosshair if you want shots to start at the muzzle and aim towards the camera’s target. Use Aiming Range, Aim Layers and Ignored Hierarchy to control what the camera can pick.

Turn on Gizmos in the Scene view and select the firearm or Aim object. Scene Gizmos controls part markers, hip and ADS poses, the calibration target, spread, range, trajectory and damage falloff. Spread and range are on by default. Frame the muzzle to see the guides. Use Preview Distance to shorten them and Label Size to scale the text. The previews ignore scene obstructions.

Recoil & Firing Shake

In Recoil & Firing Shake, add DPT_FirearmRecoil if you want procedural kick, camera shake or both. For kick, assign Recoil Target, then set the local position and rotation kick, maximum offsets and recovery speed. Use a pivot that your camera or weapon controller will leave free for the recoil offset.

Enable Firing Screen Shake on the recoil module and set its magnitude, duration and radius. Add DPT_FirearmCameraShakeReceiver to the camera that should receive nearby shake. For a separate shake on projectile contact, see Impact Shake.

Audio, Casing Ejection & Effects

Inspector sectionSetup
Animation & AudioAssign the shared Audio Source or use dedicated Shot, Reload, Action, Trigger and Empty sources. Trigger clips fall back to the action source, then the shared source. Other dedicated sources fall back to the shared source.
Shot Sounds / Trigger Pull Sounds / Empty SoundsShot sounds play for a live shot. Trigger pull clips play once for an accepted press that fires or dry fires. Empty clips add the dry-fire sound. Safety-blocked feedback has its own clip and event.
Action AudioSet distinct Action Opening Sounds and Action Closing Sounds. Either can fall back to Action Sounds. A procedural action can provide clips for its own stages.
Casing EjectionSet the ejection point, spent case and live round prefabs. Give the ejected prefabs a Rigidbody and collider for physics. Use speed, local direction, tumble and lifetime to tune the effect.

For casing sounds on contact, add DPT_FirearmCasingImpactAudio to the ejected casing prefab. Give it impact clips and tune the collision layers, minimum speed, volume and sound limit. For dust, sparks and decals, see Projectile Effects.

Connect a Player Controller

  1. Add UI/Firearm_Player_Binding.prefab to your player or scene and assign the player camera to View Camera. Its aim setup uses External Camera. Let your FPS controller handle camera position and rotation. Turn off Control Field Of View if it also handles zoom.
  2. Add UI/Firearm_HUD.prefab and assign its Firearm HUD component to the binding’s Hud field. Assign Initial Firearm for a fixed weapon or call EquipFirearm with your active scene weapon when the player equips it.
  3. Call TriggerDown on press and TriggerUp on release. Pass the ADS button state to SetAiming. Call Unequip when the player holsters the weapon.
using DPT.Firearms.Runtime;
using DPT.Firearms.UI;
using UnityEngine;

public sealed class ExampleWeaponInput : MonoBehaviour
{
    [SerializeField] private DPT_FirearmPlayerBinding binding;

    public void Equip(DPT_Firearm sceneWeapon) => binding.EquipFirearm(sceneWeapon);
    public void PressFire() => binding.TriggerDown();
    public void ReleaseFire() => binding.TriggerUp();
    public void Aim(bool held) => binding.SetAiming(held);
    public void Reload() => binding.Reload();
    public void Cycle() => binding.CycleAction();
    public void Safety() => binding.ToggleSafety();
    public void NextAmmoType() => binding.CycleAmmoType();
    public void Holster() => binding.Unequip();
}

HUD feedback

The HUD shows weapon name, safety, ready ammunition, reserve, chamber and action state. The Selected line shows the next reload’s ammo type. For magazine-fed weapons, 10 / 10 +1 means ten in the magazine and one in the chamber. A multi-chamber weapon shows the live total and the individual chamber states.

Safety Flash Duration and Safety Flash Color tune the blocked-trigger warning. Enable Hit Feedback controls the hit marker and optional confirmation clip. Assign a Hit Marker graphic or a Hit Feedback Sound if you want to customise it. A projectile confirmation requires a positive hit delivered to a damage receiver.

If the HUD has missing fonts in a fresh project, import TMP Essential Resources from Window > TextMeshPro where available. You can assign your own TMP font assets to the HUD labels.

Events & Scripting API

Use the binding for input and presentation or call the firearm directly from your controller. RequestCycleAnimation() routes the request to the active action and falls back to the available gameplay or Animator path.

API or eventUse it for
TriggerDown() / TriggerUp() / Fire()Trigger press and release or a single shot attempt. Fire() returns whether a shot fired.
Reload() / RequestCycleAnimation() / ToggleSafety()Request the next action from your player controller.
SelectAmmoType / CycleAmmoType() / AddReserveAmmoSelect the next reload type or add ammo through a pickup or inventory.
ShotFired / HitOccurred / DamageableHitOccurredReceive the shot origin, the initial hitscan contact or the point of a positive damageable hit, respectively. For every projectile contact, use DPT_FirearmProjectile.Impacted.
TriggerBlockedBySafety / AmmoSelectionChanged / ChamberAmmoChangedUpdate player feedback for the blocked trigger, reload selection or chamber ammo. DPT_FirearmMultiChamber also exposes its own chamber and index events.
ReloadRoundsInserted / ReloadChargerInserted / BayonetHitOccurredRespond to load progress, a completed charger insertion or a bayonet contact.

The Events section also exposes UnityEvents for firing, dry fire, reload stages, casing or live-round ejection, chambering and bayonet actions. See Damage Integration for the damage interface and event relay.

Setup Diagnostics

Select one firearm and open Setup Diagnostics. The Inspector checks required references and warns about mismatched reload and action settings, missing chamber data, reserve profiles and presentation references. Click an issue to open the relevant section and field.

Troubleshooting

SymptomCheck
The weapon clicks or refuses to fire.Check the safety, live chamber state, projectile prefab and whether the action is open, cycling or still reloading.
Changing ammo has no immediate effect.Chamber a round of the selected profile or reload with replacement enabled. Check any per-chamber preferred reload profile and the available reserve.
A shell loads in the wrong place.Check the loading end pose and the chamber visual under the moving barrel or cylinder assembly. Verify the slot assignments on the loaded prefab or scene instance.
The bolt opens or rotates the wrong way.Confirm the closed rest pose and check the model’s local axes. Use the separate travel and rotation inversion settings on the bolt action.
ADS moves the camera unexpectedly.Check Camera Mode, the aim root and pose markers. If another script drives the camera, use External Camera and disable any overlapping field-of-view control.
Range and spread guides are hard to see.Enable Scene view Gizmos, select the firearm and frame the muzzle. Check the individual toggles and shorten Preview Distance.
