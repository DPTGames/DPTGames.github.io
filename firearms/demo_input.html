Range Demo

Try the included weapons, ammo profiles and moving targets

Run the range

Open Firearms_DemoScene/Firearms_DemoScene.unity and enter Play Mode. The scene starts with the SMLE Mk III. Switch to the double-barrel shotgun to try shell insertion and ammo replacement, or to the Colt New Service revolver to try the swing-out cylinder.

The sample is a camera-only range. For a project with its own movement and input, see Connect a Player Controller.

Try the Weapons

SMLE Mk III

Fire the rifle and watch the bolt and magazine display. B requests a cycle if the action is ready. Reload after firing several shots to see the charger or single-round top-off animation.

Double-barrel shotgun

Press 2. With both barrels loaded, press T to select the other ammo type and R to swap shells. The supplied setup uses Replace Loaded Ammo On Reload. The reload needs shells of the selected type in reserve.

Colt New Service revolver

Press 3 to equip the revolver. Press B to swing the cylinder open, then C to spin it. Press B again to close it. Fire and press R to see the reload sequence and watch the individual chamber states in the HUD.

Press T before reloading to see the distinction between Selected and the chamber readout. Selection controls the next load. Chamber state shows what is already in the weapon.

Set Up Another Demo Weapon

  1. Place the weapon in the scene. Add or reuse one DPT_FirearmDemoInput on a controller object that stays active while weapons switch.
  2. Assign View Camera. Keep the camera outside the weapon hierarchies. It can be a separate scene object. The demo looks for the Main Camera when the reference is empty.
  3. For one weapon, assign Firearm. For switching, add scene weapon instances to Weapon Slots and give them display names. Keep their hierarchies separate so the controller can activate them independently.
  4. Set the zero-based Starting Weapon Index. Enable Mouse Wheel Weapon Switch if you want scrolling. Align Weapon Positions On Switch carries the previous aim-root position across a switch.
  5. Link the Hud and optional Player Binding if you are rebuilding the scene. Keep the HUD outside the weapon hierarchies so it remains visible when switching.

The same controller exposes EquipWeapon(int index), CycleWeapon(int direction), CycleDemoAmmoType() and ResetTargets() for demo UI or buttons.

Camera, Crosshair & HUD

The demo binds DPT_FirearmAim to the active weapon. For each weapon, assign hip and ADS pose markers or set camera offsets. Captured hip or ADS markers saved in the weapon’s Aim component take precedence over the demo markers for those poses.

Moving Targets

DPT_FirearmMovingTarget moves a target from its starting position and lets it react physically on the first hit. To add another target, give it a collider and Rigidbody, then set Move Speed, Move Distance and Impact Force. Release Constraints On Hit allows it to tumble.

Assign VFX_Impact_Sparks to the target’s Hit Effect Prefab for a first-hit burst. Backspace restores the active targets in the same scene so they can react again.

Input Compatibility

The demo assembly requires the Unity Input System package to compile. The demo uses the Input System when that backend is enabled. With only the legacy Input Manager enabled, it reads legacy keyboard and mouse input, including the Mouse X and Mouse Y axes for look input.

For gameplay integration, route your own input to DPT_FirearmPlayerBinding or DPT_Firearm. Keep the demo input components on sample scenes.

Troubleshooting

SymptomCheck
Mouse look or firing does nothing.Click the Game view to capture the cursor. Verify the camera, weapon slot and input backend.
The shotgun reloads the same shells.Check the selected profile, reserve count and each chamber’s preferred reload type. To swap a full load, enable replacement.
The weapon or camera faces backwards.Check View Forward Mode and its reference. Inspect the muzzle and captured hip or ADS poses in the Scene view.
Only one weapon can be selected.Check that each slot references an independent scene weapon and that the controller is outside the switched hierarchies.
