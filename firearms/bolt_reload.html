Procedural Bolt & Loading Animations

Optional manual-action animation · Shared loading prefab, three visual modes and SMLE charger example

One ammunition system, optional weapon-specific animation

DPT_Firearm owns the reload type, ammo counts, loading prefab and spawn point. DPT_FirearmProceduralBolt is an optional bolt-action controller that animates the bolt and the contents of the configured loading prefab. Other firearms can use the same core without adding a procedural bolt.

Quick Setup

  1. Add DPT_FirearmProceduralBolt alongside DPT_Firearm on a bolt-action weapon and assign Bolt Transform to the moving bolt mesh or pivot.
  2. On DPT_Firearm, choose Reload Type, assign the Loading Prefab and set the Loading Spawn Point. These references belong on the firearm, not on the procedural bolt.
  3. For the SMLE, select Stripper Clips, set Rounds Per Load = 5, enable Manual Action and disable Chamber On Reload. The procedural bolt advances the next cartridge as it closes.
  4. Disable Reload Uses Animation Events if the procedural controller will manage reloading. Disable Use Animator Triggers if no Animator is used.
  5. On DPT_FirearmProceduralBolt, enable Animate Reload and choose a Loading Visual Mode. For a historical charger feeding loose cartridges, select Contents Only and assign Loading Contents.
  6. Adjust the local spawn, guide and insertion travel values to match the weapon's model. Use Auto Cycle After Shot only if you want the procedural action to cycle automatically after each shot.

Sequence and Ammunition State

Shot → Unlock → Retract / eject → Feed / advance → Lock

For a procedural reload, the controller opens the bolt, calls the firearm's reload APIs and waits for loading before closing. Ammunition counts and reload events are still controlled by DPT_Firearm; moving the visual alone does not change ammunition.

  • Stripper Clips: opening the action is required. The bolt animator displays a group of up to Rounds Per Load cartridges, inserts that group using TryInsertReloadCharger(int) and ejects the used charger before continuing if more rounds are needed.
  • Individual Rounds: the procedural controller shows one loading operation per round and calls TryInsertReloadRound() after each insertion.
  • Full Magazine: the visual can represent a magazine insertion. The core firearm refills the magazine when CompleteReload() runs.
  • Reloading is not available while an action cycle is already in progress. The procedural controller can queue a reload request until cycling finishes.

Loading Visual Modes

ModeWhat movesSuggested use
Whole ObjectMoves the entire instantiated loading prefab through the guide and insertion phases.Detachable magazines or a simplified whole-object animation.
Contents OnlyMoves the loaded device into the guide, leaves its body in place and moves only the selected Loading Contents group down during insertion.SMLE five-round charger / stripper clip, where only cartridges enter the magazine.
Individual RoundsSpawns and animates a separate copy of the loading prefab for each round, rather than moving a multi-round group.Weapons loaded one cartridge at a time.

Contents Only: prefab hierarchy

Loading_Prefab
├── Charger_Body
└── Cartridges             [assign this Transform to Loading Contents]
    ├── Cartridge_01
    ├── Cartridge_02
    ├── Cartridge_03
    ├── Cartridge_04
    └── Cartridge_05

On the procedural bolt, Loading Contents is a Transform object reference, not a child-name string. It must point to a child of the same prefab asset assigned to the firearm's Loading Prefab. The controller maps the source child to its corresponding child in each instantiated copy using the hierarchy. Do not assign an unrelated scene copy of the charger.

Keep the metal charger and the cartridge group as siblings. For partial reloads, Hide Unused Contents can hide extra rounds when the assigned group contains exactly Rounds Per Load direct child objects. The earliest child objects are kept active first.

Historical behaviour: On an SMLE, the charger stays at the guide as its rounds are pressed into the internal magazine. The metal charger does not descend with the ammunition. It is removed or ejected after loading.

Troubleshooting Motion and Reloading

IssueResolution
Contents Only shows the device but the cartridges do not descendAssign Loading Contents to the cartridge group Transform inside the prefab asset. Verify the field references a descendant of the assigned Loading Prefab, not a scene instance.
Loading prefab does not appearAssign Loading Prefab on the firearm, choose the correct Reload Type and check Loading Spawn Point and offsets. For an SMLE use Stripper Clips, not Full Magazine, to display one or two five-round loads.
Extra cartridges appear on a partial loadEnable Hide Unused Contents and ensure the contents group has exactly one direct child per cartridge, matching Rounds Per Load.
Bolt retracts towards the muzzleToggle Invert Bolt Travel Z, or reverse the extraction and closing slides, but not both.
Bolt rotates the wrong wayToggle Invert Bolt Rotation Z or change the Open Angle sign.
Reload never finishesEnsure Reload Uses Animation Events is disabled when using procedural reload, and avoid running two independent reload controllers.
Closing feels slowRaise Reload Closing Speed Multiplier, or lower Post Load Close Delay.
Loading object enters the magazine incorrectlySelect Contents Only for a charger rather than Whole Object. Adjust Loading Guide Travel and Loading Insert Travel separately.
