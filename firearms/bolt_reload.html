Procedural Bolt & Loading Animations

Manual bolt motion · Scene-based charger visuals, individual top-offs and ejection timing

Ammunition is managed by the firearm, animation by the optional bolt

DPT_Firearm owns the magazine, chamber, reload type and visual references. DPT_FirearmProceduralBolt animates a chosen bolt Transform and reuses an existing, usually inactive, loading hierarchy. Full five-round chargers and single-round top-offs have distinct visual paths. An optional cartridge feed animation now moves the highest visible magazine round towards the chamber during the bolt forward stroke.

Quick Setup

  1. Add DPT_FirearmProceduralBolt beside DPT_Firearm and assign Bolt Transform. Enable Manual Action on the firearm.
  2. For the SMLE choose Reload Type = Stripper Clips, Rounds Per Load = 5 and disable Chamber On Reload when the procedural bolt handles chambering.
  3. Create an existing scene object under the rifle for the loaded charger. Assign its root to Loading Visual Root on the firearm. It should be initially inactive, positioned at the start of the loading animation and must not be the firearm root or one of its parents.
  4. For Contents Only, assign Loading Device to the charger's metal body and Loading Contents to its cartridge group. Both must be children of Loading Visual Root.
  5. On the bolt, enable Animate Reload and select Loading Visual Mode = Contents Only. Adjust Loading Travel Direction, Guide Travel, Insert Travel and stage durations.
  6. Disable Reload Uses Animation Events if the procedural controller owns the sequence. Only enable Auto Cycle After Shot if you want automatic bolt cycling.
The earlier Loading Prefab, Loading Spawn Point, Loading Spawn Offset and Loading Rotation Offset instructions no longer apply. The current version reuses an assigned scene object.

Sequence and Ammunition State

Fire → Lift / unlock → Pull back → Eject at configured extraction fraction → Feed next round → Push forward → Lock

Spent Case Ejection Point is a progress fraction of the rearward extraction stage, defaulting to 0.85 (85%). It affects normal cycling and procedural reload extraction. On a normal cycle, ChamberNextRound() runs after extraction, before the forward stroke.

  • Stripper Clips: Opening the action is required. A charger transfers up to Rounds Per Load cartridges. An optional empty charger can be ejected after each successful load.
  • Mixed charger + individual loading: Enable Allow Single Round Top Off With Clips. Complete chargers are used when at least one full charger's worth of space and ammunition remain. Remaining one-to-four-round top-offs use a single cartridge visual and TryInsertReloadRound().
  • Full charger preference: When mixed loading is disabled, Eject Magazine Rounds For Full Loads can eject surplus live rounds to make space for a full charger. This option is ignored when mixed loading is enabled.
  • Individual Rounds: Reuses the loading visual for each inserted cartridge. Full Magazine: Refills the magazine when CompleteReload() runs.
  • Chamber-only operation: With no reserve ammunition, an empty chamber and rounds remaining in the magazine, a Reload request can instead initiate a bolt cycle. It does not manufacture reserve ammunition.

Assign both child Transforms from the scene hierarchy on the firearm. In Contents Only mode, Hide Unused Contents hides surplus direct cartridge children for partial charger loads. When Eject Magazine Rounds For Full Loads is active, the visual intentionally shows a full charger.

Separate visual: Single Round Loading Visual accepts an existing scene object or a prefab asset. If an asset is assigned, the procedural bolt instantiates it once at the Loading Visual Root position and reuses it for subsequent top-offs. If unassigned, it falls back to Live Round Prefab. Position the Loading Visual Root carefully because it supplies the prefab starting pose.

Visual Magazine-to-Chamber Feeding

The optional Animate Cartridge Feeding setting is found under Action & Procedural Bolt → Cartridge Feeding. It uses an existing top visible cartridge from the firearm's Magazine Round Visuals array and the Chambered Round Visual as its destination. No additional cartridge prefab is spawned.

  1. On DPT_Firearm, assign Magazine Round Visuals bottom-to-top and assign Chambered Round Visual at the cartridge's final seated position.
  2. On DPT_FirearmProceduralBolt, enable Animate Cartridge Feeding under Cartridge Feeding (enabled by default in the new script).
  3. Cycle the bolt with an available magazine round. During the forward stroke, the selected magazine cartridge moves and rotates towards the chambered visual's Transform.
  4. At the end of feeding, the source visual returns to its original local pose, magazine visibility refreshes and the chambered-round visual represents the newly chambered cartridge.
Ammunition state: This is a presentation-only animation. ChamberNextRound() still handles the ammunition transfer. The feed animation coordinates visual visibility so the chambered round does not appear fully seated before the forward stroke finishes.
Fallback: Without visible magazine cartridges or a chambered-round visual, existing chambering behaviour continues without this additional animation. If the procedural bolt component is interrupted or disabled, the feeding visual is restored to its original pose.

Troubleshooting Motion and Reloading

IssueCheck
Charger does not appearAssign an existing inactive Loading Visual Root scene object and confirm Animate Reload is enabled. Do not drag only a Project-window prefab into this field.
Contents Only moves the charger but not cartridgesAssign Loading Device and Loading Contents from the same scene hierarchy. Both must be under Loading Visual Root.
Single round never appears with Stripper ClipsEnable Allow Single Round Top Off With Clips and assign Single Round Loading Visual or Live Round Prefab. This path only runs when fewer than Rounds Per Load rounds can be inserted.
Single-round prefab spawns out of positionPlace the inactive Loading Visual Root at the desired starting pose. A prefab asset used for top-off is instantiated at that root's position and rotation.
Wrong bolt direction or rotationCheck Invert Bolt Travel Z, Invert Bolt Rotation Z, Extraction Slide and Open Angle. Do not invert twice.
Casing ejects too lateAdjust Spent Case Ejection Point within the rearward extraction stage; try 0.85 as a starting value.
Reload never completesDisable Reload Uses Animation Events when the procedural controller owns reloading. Avoid independent controllers acting on the same firearm.
Closing is slowRaise Reload Closing Speed Multiplier or reduce Post Load Close Delay.
Feed animation does not playEnable Animate Cartridge Feeding under the bolt component. Assign the firearm Magazine Round Visuals in bottom-to-top order and the Chambered Round Visual, then cycle with ammunition in the magazine.
Cartridge animates from the wrong locationAdjust the source magazine cartridge Transform and the chambered-round visual pose. The animation interpolates their current world positions and rotations.
