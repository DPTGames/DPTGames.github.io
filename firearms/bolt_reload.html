Procedural Bolt & Charger Reload

SMLE worked example · Five-stage action, magazine reload visuals, state locking and closing sounds

Manual-action animation without an Animator

DPT_FirearmProceduralBolt drives one assigned bolt Transform. The SMLE example demonstrates automatic post-shot cycling, manually requested cycling, single- and double-charger reload visuals and separate bolt-closing sound.

On this pageQuick Setup Mechanical Sequence Charger Visuals Timing and Audio Axis and Reload Troubleshooting

Quick Setup

  1. Add DPT_FirearmProceduralBolt to the same GameObject as DPT_Firearm.
  2. Assign Bolt Transform to the moving bolt mesh/pivot, not the whole rifle.
  3. On the firearm, enable Manual Action, disable Chamber On Reload and turn off Use Animator Triggers.
  4. Enable Auto Cycle After Shot with Auto Cycle Delay = 0 for immediate post-shot cycling.
  5. Set the opening angle and local extraction/closing offsets to suit the model. Assign a charger prefab and its spawn marker if using charger visuals.

Sequence and Ammunition State

Shot → Unlock → Retract / eject → Feed / advance → Lock
  • A successful shot leaves a spent casing in the chamber. The procedural bolt calls BeginCycle(), extracts and ejects it, calls ChamberNextRound() and finishes with EndCycle().
  • On reload, the bolt opens and retracts, any spent casing is ejected, charger visuals play, the magazine is replenished, a round is chambered when appropriate and the bolt closes.
  • Firing input should be blocked until the bolt has closed. Pressing fire during reload is ignored, not buffered for playback afterward.
  • For a live round already in the chamber, topping up the magazine should not automatically eject it.

Charger / Clipper Strip Settings

FieldPurpose
Clipper PrefabTemporary five-round visual. Does not need an Animator or its own rigidbody-driven motion.
Clipper Spawn PointPosition and rotation reference; defaults to Ejection Point if empty.
Rounds Per ClipperNormally 5 for the SMLE, so a ten-round replenishment shows two strips.
Clipper Spawn Offset / Rotation OffsetLocal pose of the instantiated strip relative to the spawn marker.
Clipper Travel DirectionLocal travel axis for insertion; default negative local Y.
Clipper Guide TravelInitial distance into the charger bridge.
Clipper Push TravelExtra distance downward until the visual is fully hidden.
Clipper Guide Duration / Push DurationTiming of the two insertion phases.
Between Clippers DelayShort pause when two strips are needed.
Disable Clipper PhysicsKeeps temporary visual colliders from interfering with the rifle.
Complete Reload After Last ClipperFinishes ammunition loading when the final visual completes, rather than waiting for the full Reload Duration.
Post Clipper Close DelayOptional short pause after loading before closing the bolt.
Visual simplification: In the historical loading process, the cartridges are pushed into the magazine and the empty metal charger is removed. The demo may instead move the whole five-round model below the receiver then destroy it. This is a presentation shortcut, not a physics-based loading simulation.

Troubleshooting Motion and Locks

IssueResolution
Bolt retracts towards muzzleEnable Invert Bolt Travel Z, or reverse the extraction and closing slides, but not both.
Bolt rotates opposite the intended directionEnable Invert Bolt Rotation Z or change Open Angle sign.
Bolt cannot cycle after first shotAssign Bolt Transform, enable Auto Cycle After Shot and ensure Firearm Manual Action is enabled.
One-strip reload pauses too longEnable Complete Reload After Last Clipper and lower Post Clipper Close Delay.
Closing feels slowRaise Reload Closing Speed Multiplier, for example from 1.3 to 1.5.
Charger remains sticking outIncrease Clipper Push Travel or adjust spawn offset / travel direction.
Fire input causes state lock during reloadVerify the firearm and procedural bolt versions match; do not also wire a second manual cycle through UnityEvents.
Scene object fails to restoreCheck the assigned moving Transform is a bolt child, not the rifle root or the ADS camera marker.
