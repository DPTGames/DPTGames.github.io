Damage Integration

Reusable hit interface · Health, UnityEvents, physics responses and optional destruction integrations

Connect firearms to any health or hit-response system

Damage delivery is separated from the SMLE model and from the optional demo controllers. Both bullet hit modes and the bayonet can call the common IDPT_FirearmDamageable interface.

Shared Damage Contract

using UnityEngine;

namespace DPT.Firearms.Runtime
{
    public interface IDPT_FirearmDamageable
    {
        void ReceiveFirearmHit(float damage, Vector3 point,
            Vector3 direction, GameObject source);
    }
}
The firearm and projectile resolve this interface from the struck Collider’s parent hierarchy. point is a world-space impact position and direction is the incoming attack direction.

DPT_FirearmDamageRelay

  1. Add DPT_FirearmDamageRelay to the target or a parent of its Collider.
  2. Connect On Damage to a UnityEvent listener that accepts a float, or use On Hit for parameterless reactions.
  3. For more information, read LastDamage, LastHitPoint, LastHitDirection and LastSource, or subscribe to the Hit C# event.

Implementing a Custom Health Receiver

using DPT.Firearms.Runtime;
using UnityEngine;

public class ExampleFirearmHealth : MonoBehaviour, IDPT_FirearmDamageable
{
    [SerializeField] private float health = 100f;

    public void ReceiveFirearmHit(float damage, Vector3 point,
        Vector3 direction, GameObject source)
    {
        health = Mathf.Max(0f, health - damage);
        if (health == 0f)
        {
            gameObject.SetActive(false);
        }
    }
}

Example: Shoot a Moving Primitive Out of the Air

  • Add a Collider, Rigidbody and a demo target component that implements IDPT_FirearmDamageable.
  • Before impact, use a kinematic Rigidbody with gravity disabled and drive its position using MovePosition() from FixedUpdate().
  • When hit, stop scripted movement, set the Rigidbody non-kinematic, enable gravity and apply an impulse at the hit point.
  • If that receiver applies its own impulse, set the firearm’s Hitscan Impact Impulse, the projectile’s Physics Impact Impulse and the bayonet’s Impact Impulse to zero to avoid stacking forces.
